# 5. การตั้งค่าสถาบันและลำดับการตั้งค่าเริ่มต้น

## การตั้งค่าสถาบัน

ตั้งค่าที่ **การตั้งค่า > สถาบัน** (สิทธิ์ `จัดการการตั้งค่าสถาบัน`)

| การตั้งค่า | คำอธิบาย |
|---|---|
| ชื่อสถาบัน | กรอกตามแต่ละภาษา แสดงที่มุมซ้ายบนของแผงผู้ดูแลระบบ |
| เขตเวลา | ใช้อ้างอิงในการพิจารณาวันที่ของภาคการศึกษาและช่วงเวลาดำเนินการ เช่น `Asia/Seoul` เวลาที่จัดเก็บทั้งหมดจะแสดงตามเขตเวลานี้ |
| ภาษาที่เปิดให้ใช้ | ภาษาที่ผู้ใช้เลือกได้ รายการจะแสดงเฉพาะภาษาที่ติดตั้งไฟล์คำแปลไว้แล้ว |
| ภาษาเริ่มต้น | ใช้กับผู้ใช้ที่ยังไม่ได้เลือกภาษา และเมื่อไม่ทราบภาษาของเบราว์เซอร์ |

## ลำดับการตั้งค่าเริ่มต้นสำหรับมหาวิทยาลัยใหม่

หลังจากผู้ดูแลด้าน IT ดำเนินการ `setup_install` เสร็จแล้ว (คู่มือการปฏิบัติการ [การติดตั้ง](../operations/installation.md)) ผู้ดูแลงานบริหารจะป้อนข้อมูลตามลำดับด้านล่าง ขั้นตอนหลังอ้างอิงรหัสจากขั้นตอนก่อนหน้า จึงต้องทำตามลำดับ

1. **การตั้งค่าสถาบัน**: ชื่อ เขตเวลา ภาษา (บทนี้)
2. **ข้อมูลรหัส**: ค่าของเชื้อชาติ ประเภทการรับเข้า และประเภทห้อง ([บทที่ 6](06-code-data.md)) หากใช้โปรไฟล์มหาวิทยาลัยเกาหลีระหว่างการติดตั้ง จะมีประเภทห้องอยู่แล้ว
3. ตรวจสอบ **ประเภทหน่วยงาน** แล้วจึงป้อน **หน่วยงาน**: มหาวิทยาลัย → คณะ → ภาควิชา ([บทที่ 7](07-org-units-and-programs.md)) หากมีหน่วยงานจำนวนมาก ให้ใช้ CSV ([บทที่ 9](09-csv-import.md))
4. **หลักสูตร**: หลักสูตรปริญญาของแต่ละภาควิชา ([บทที่ 7](07-org-units-and-programs.md))
5. **อาคาร**, **ห้อง** ([บทที่ 8](08-facilities.md) ใช้ CSV ได้)
6. ตรวจสอบ **ประเภทภาคการศึกษา** และ **คาบ** ([บทที่ 10](10-terms.md))
7. ตรวจสอบ **หมวดวิชา** และ **เกณฑ์ระดับคะแนน** ต้องกำหนดเกณฑ์เริ่มต้นหนึ่งเกณฑ์ ([บทที่ 11](11-course-categories-and-grade-scales.md))
8. **ปีการศึกษา** → **ภาคการศึกษา** → **ช่วงเวลาดำเนินการ** ของแต่ละภาคการศึกษา ([บทที่ 10](10-terms.md))
9. **ผู้ใช้และสิทธิ์การเข้าถึง**: บทบาทที่ต้องใช้ขอบเขตหน่วยงาน เช่น เจ้าหน้าที่ภาควิชา จะเลือกภาควิชาเป็นเป้าหมายของขอบเขตได้แล้ว ([บทที่ 2](02-users-and-roles.md))

เมื่อป้อนข้อมูลเสร็จแล้ว ให้ขอผู้ดูแลด้าน IT ตรวจสอบช่วงเวลาดำเนินการด้วย `uv run manage.py term_inspect`
