# คู่มือผู้ดูแลระบบ

- ผู้อ่าน: เจ้าหน้าที่งานบริหารวิชาการ (ทะเบียนนักศึกษา ฝ่ายวิชาการ หนังสือรับรอง การรับสมัคร) และผู้ดูแลระบบ
- ชื่อหน้าจอในคู่มือนี้ใช้ตามข้อความที่แสดงในส่วนติดต่อผู้ใช้ภาษาไทย

| บท | เนื้อหา |
|---|---|
| [1. เริ่มต้นใช้งาน](01-getting-started.md) | การเข้าสู่ระบบ พอร์ทัลและแผงผู้ดูแลระบบ ภาษา |
| [2. ผู้ใช้และบทบาท](02-users-and-roles.md) | บัญชีผู้ใช้ บทบาทและสิทธิ์ การกำหนดบทบาท (ขอบเขต ระยะเวลา) |
| [3. การยืนยันตัวตนแบบสองขั้นตอน](03-two-factor-authentication.md) | วิธีที่ผู้ใช้ลงทะเบียน การตั้งค่านโยบาย การรีเซ็ต |
| [4. การตรวจสอบ](04-audit.md) | บันทึกการดำเนินงาน การเปลี่ยนแปลงข้อมูล เหตุการณ์ด้านความปลอดภัย |
| [5. การตั้งค่าสถาบันและลำดับการตั้งค่าเริ่มต้น](05-institution-setup.md) | ชื่อสถาบัน ภาษา เขตเวลา ลำดับการป้อนข้อมูลอ้างอิงสำหรับมหาวิทยาลัยใหม่ |
| [6. ข้อมูลรหัส ประเทศ ภาษา](06-code-data.md) | รายการรหัส เช่น เชื้อชาติ ประเภทการรับเข้า ประเภทห้อง |
| [7. หน่วยงานและหลักสูตร](07-org-units-and-programs.md) | โครงสร้างคณะ/ภาควิชา ช่วงเวลาที่มีผล การปรับโครงสร้าง หลักสูตรปริญญา |
| [8. อาคารและห้อง](08-facilities.md) | อาคาร ห้อง ความจุ |
| [9. การนำเข้า CSV](09-csv-import.md) | รูปแบบไฟล์ ผลการนำเข้าและการจัดการแถวที่นำเข้าไม่สำเร็จ |
| [10. ปีการศึกษา ภาคการศึกษา ช่วงเวลาดำเนินการ](10-terms.md) | สถานะภาคการศึกษา ช่วงการเรียน ช่วงเวลาดำเนินการ เช่น การลงทะเบียนเรียนและผู้มีสิทธิ์ คาบ |
| [11. หมวดวิชาและเกณฑ์ระดับคะแนน](11-course-categories-and-grade-scales.md) | หมวดวิชา เกรดและค่าระดับคะแนน |
| [12. บุคคลและระเบียนนักศึกษา](12-people-and-student-records.md) | บุคคล การขึ้นทะเบียนนักศึกษาและรหัสนักศึกษา ขอบเขตการดู อาจารย์ |
| [13. การเปลี่ยนสถานภาพและอาจารย์ที่ปรึกษา](13-status-changes-and-advisors.md) | สถานภาพนักศึกษา คำร้องเปลี่ยนสถานภาพและการอนุมัติ การบันทึกโดยตรง อาจารย์ที่ปรึกษา |
| [14. การรวมข้อมูลบุคคลและการเชิญให้สร้างบัญชี](14-merge-and-invitations.md) | การรวมข้อมูลบุคคลที่ซ้ำกัน การเชิญบุคคลที่ยังไม่มีบัญชี |
| [15. วิธีการเข้าสู่ระบบ](15-sign-in-methods.md) | การเข้าสู่ระบบด้วยรหัสนักศึกษา การล็อกบัญชี การเข้าสู่ระบบด้วยบัญชีสถาบัน (SSO) |
| [16. การรับสมัคร](16-admissions.md) | บัญชีผู้สมัคร รอบรับสมัคร การพิจารณาใบสมัครและผลการคัดเลือก การสร้างระเบียนนักศึกษา |
| [17. รายวิชาและเกณฑ์การสำเร็จการศึกษา](17-courses-and-curriculum.md) | ฉบับรายวิชาและการปรับปรุง วิชาบังคับก่อนและรายวิชาเทียบเท่า เกณฑ์การสำเร็จการศึกษาตามหมวดวิชา |
| [18. กลุ่มเรียนและตารางเรียน](18-sections-and-timetables.md) | ช่วงการเรียน เวลาเรียนและห้อง อาจารย์ผู้สอน การจัดสรรที่นั่ง ประมวลรายวิชา การคัดลอกภาคการศึกษา |
| [19. วิชาเอกที่สองและวิชาโท](19-second-majors-and-minors.md) | การตั้งค่าหลักสูตร การยื่นคำขอของนักศึกษา การอนุมัติ การสิ้นสุด |
| [20. การลงทะเบียนเรียน](20-registration.md) | ชุดกฎ หน่วยกิตสูงสุด ที่นั่งและรายชื่อสำรอง การระงับการลงทะเบียนและการอนุญาตพิเศษ การปรับรายการลงทะเบียนโดยเจ้าหน้าที่ ประวัติการลงทะเบียน |
| [21. ผลการเรียน](21-grades.md) | การกรอกเกรด การส่งและยืนยันเกรด การอนุมัติการแก้ไขเกรด เกรดเฉลี่ยและการเรียนซ้ำ การปิดภาคการศึกษา (รอพินิจ เกียรตินิยม) ใบแสดงผลการเรียน นโยบายการวัดผล |
| [22. การประเมินรายวิชา](22-course-evaluation.md) | คำตอบแบบไม่ระบุตัวตน แบบประเมินและคำถาม การตั้งค่าและช่วงเวลาของภาคการศึกษา การประกาศผลและจำนวนผู้ตอบขั้นต่ำ การจำกัดการดูเกรด |
| [23. หนังสือรับรอง](23-certificates.md) | ประเภทและแม่แบบตามภาษา เลขที่หนังสือรับรอง การออกและข้อจำกัด ทะเบียนการออก (สร้างใหม่ เพิกถอน) หน้าตรวจสอบ พอร์ทัลนักศึกษา |
| [24. การสอบ](24-assessments.md) | ประเภทการสอบและด้าน การตัดสินผลผ่าน รอบสอบและการสมัครสอบ การกรอกผลสอบและ CSV การประกาศผล ผลสอบภายนอกและหลักฐาน การเชื่อมโยงกับเกณฑ์การสำเร็จการศึกษา |
| [25. ห้องเรียนของอาจารย์และการเข้าเรียน](25-classroom-and-attendance.md) | รายชื่อนักศึกษาและ CSV การสร้างและยกเลิกครั้งเรียน การบันทึกและสรุปการเข้าเรียน PDF ใบเช็กชื่อ การดูการเข้าเรียนของนักศึกษา |
| [26. การตรวจสอบการสำเร็จการศึกษาและการสำเร็จการศึกษา](26-graduation.md) | กฎเกณฑ์ การบันทึกผลการตรวจสอบและการตรวจสอบเป็นชุด การยกเว้นเกณฑ์ การดำเนินการสำเร็จการศึกษาและเลขที่ปริญญาบัตร |
| [27. รายงานและวิวสำหรับรายงาน](27-reports.md) | รายงานมาตรฐานและ CSV วิวในสคีมาสำหรับรายงาน การเข้าถึงจาก BI |
| [28. การเชื่อมต่อ LMS](28-lms-integration.md) | แพลตฟอร์มและไดรเวอร์ การเชื่อมโยงรายวิชาและประวัติการซิงก์ การอัปเดตทันทีและการกระทบยอดทุกคืน ร่างคะแนนจาก LMS |

หน้าจอข้อมูลอ้างอิง (เมนู **ข้อมูลอ้างอิง**) จะมองเห็นได้เมื่อมีสิทธิ์ `ดูข้อมูลอ้างอิง` และแต่ละหน้าจอต้องมีสิทธิ์จัดการของหน้าจอนั้นด้วย (เช่น `จัดการหน่วยงานและการปรับโครงสร้าง`) จึงจะสร้างหรือแก้ไขรายการได้
