# 7. หน่วยงานและหลักสูตร

เมนู: **ข้อมูลอ้างอิง > ประเภทหน่วยงาน**, **หน่วยงาน**, **หลักสูตร**

## หน่วยงาน

มหาวิทยาลัย คณะ ภาควิชา สาขาวิชา และหน่วยงานสนับสนุน จัดการได้ในหน้าจอเดียว ใช้แทนคณะ (`SFCOLLEGE`) และภาควิชา (`SFDEPARTMENT`) ของระบบเดิม (YUSTIC)

| ฟิลด์ | คำอธิบาย |
|---|---|
| รหัส | รหัสประจำหน่วยงานที่ใช้ถาวร เช่น `CSE` |
| ประเภท | มหาวิทยาลัย คณะ ภาควิชา ฯลฯ (เพิ่มได้ที่หน้าจอประเภทหน่วยงาน) |
| ชื่อ, ชื่อย่อ | ตามแต่ละภาษา |
| หน่วยงานต้นสังกัด | หน่วยงานที่หน่วยงานนี้สังกัดอยู่ ไม่สามารถย้ายหน่วยงานไปไว้ใต้ตนเองหรือใต้หน่วยงานย่อยของตนเองได้ |
| มีผลตั้งแต่, มีผลถึง | ช่วงเวลาที่หน่วยงานดำรงอยู่ หากวันสิ้นสุดว่างหมายถึงยังดำเนินงานอยู่ |

- โดยค่าเริ่มต้น รายการจะแสดง **เฉพาะที่มีผลอยู่** ปิดตัวกรองเพื่อดูหน่วยงานในอดีตด้วย
- เมื่อเลือกหน่วยงานเป็นขอบเขตของการกำหนดบทบาท หน่วยงานทั้งหมดที่อยู่ภายใต้จะรวมอยู่ด้วย ตัวอย่าง: ขอบเขตคณะวิศวกรรมศาสตร์ = ทุกภาควิชาในคณะวิศวกรรมศาสตร์

## การปรับโครงสร้าง

ระเบียนนักศึกษาและเกรดในอดีตต้องชี้ไปยังหน่วยงานตามที่เป็นอยู่ในเวลานั้น จึงไม่แก้ไขหน่วยงานโดยตรง แต่บันทึกการเปลี่ยนแปลงเป็น **การปรับโครงสร้าง** แทน

1. เปิดหน้า **แก้ไข** ของหน่วยงานที่จะยุบ (หรือเปลี่ยนแปลง)
2. กด **ปรับโครงสร้าง**
3. เลือกประเภทการเปลี่ยนแปลง
   - **เปลี่ยนชื่อ**: สร้างหน่วยงานที่ใช้ชื่อใหม่ก่อน แล้วกำหนดเป็นหน่วยงานสืบทอด
   - **ควบรวม**: เมื่อหลายหน่วยงานรวมเป็นหนึ่งเดียว ให้กำหนดหน่วยงานสืบทอดเดียวกันจากแต่ละหน่วยงาน
   - **แยก**: เมื่อหน่วยงานหนึ่งแบ่งออกเป็นหลายหน่วยงาน ให้กำหนดหน่วยงานสืบทอดหลายหน่วยงาน
   - **ย้ายสังกัด**: เมื่อหน่วยงานย้ายไปอยู่ใต้หน่วยงานต้นสังกัดอื่นในฐานะหน่วยงานใหม่
4. กรอก **วันที่มีผล** และเหตุผล หน่วยงานจะสิ้นสุดในวันก่อนวันที่มีผล และรายการจะปรากฏใน **หน่วยงานสืบทอด** ด้านล่าง

การพิมพ์ผิดเล็กน้อยให้แก้ไขโดยการ **แก้ไข** ชื่อ ไม่ใช่การปรับโครงสร้าง (การเปลี่ยนแปลงข้อมูลจะถูกบันทึกไว้)

## หลักสูตร

หลักสูตรปริญญาหรือหลักสูตรสาขาวิชา ระเบียนนักศึกษาสังกัดหลักสูตร ([บทที่ 12](12-people-and-student-records.md))

| ฟิลด์ | คำอธิบาย |
|---|---|
| รหัส, ชื่อ, ชื่อปริญญา | ตัวอย่างชื่อปริญญา: วิศวกรรมศาสตรบัณฑิต |
| ระดับปริญญา | อนุปริญญา ปริญญาตรี ปริญญาโท ปริญญาเอก ประกาศนียบัตร ไม่มีปริญญา |
| หน่วยงาน | ภาควิชาที่รับผิดชอบหลักสูตร |
| ระยะเวลาศึกษาตามหลักสูตร | ระยะเวลามาตรฐานในการสำเร็จการศึกษา (ปี) |
| มีผลตั้งแต่, มีผลถึง | ช่วงเวลาที่หลักสูตรดำรงอยู่ ไม่ใช่ช่วงเวลาที่รับนักศึกษาใหม่ |
| รับวิชาเอกที่สอง, รับวิชาโท | นักศึกษาจากหลักสูตรอื่นสามารถยื่นคำขอเรียนหลักสูตรนี้เป็นวิชาเอกที่สองหรือวิชาโทได้หรือไม่ ([บทที่ 19](19-second-majors-and-minors.md)) |
