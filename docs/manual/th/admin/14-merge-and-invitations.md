# 14. การรวมข้อมูลบุคคลและการเชิญให้สร้างบัญชี

เมนู: **นักศึกษาและบุคลากร > บุคคล** จากนั้นใช้ **รวมข้อมูลซ้ำ** และ **เชิญให้สร้างบัญชี** ที่ด้านบนของหน้ารายละเอียดของบุคคล

## การรวมข้อมูลบุคคลที่ซ้ำกัน

ใช้เมื่อมนุษย์คนเดียวกันถูกลงทะเบียนเป็นบุคคลสองรายการ (เช่น การคืนสภาพนักศึกษาที่หาบุคคลเดิมไม่พบจึงสร้างบุคคลใหม่) ต้องมีสิทธิ์ `รวมข้อมูลบุคคลที่ซ้ำกัน`

1. ค้นหารายการที่อาจซ้ำ: ค้นหาในรายการบุคคลด้วยชื่อและวันเกิดเดียวกัน หรือเลขประจำตัวประชาชนเดียวกัน ผู้ดูแลด้าน IT สามารถสร้างรายการที่อาจซ้ำทั้งหมดได้ด้วย `uv run manage.py people_find_duplicates`
2. ในหน้ารายละเอียดของ **บุคคลที่จะนำออก (รายการซ้ำ)** กด **รวมข้อมูลซ้ำ** เลือกบุคคลจากรายการที่ **เก็บบุคคลนี้ไว้** แล้วกรอกเหตุผล เมื่อการรวมเสร็จสิ้น ระบบจะพาไปยังหน้าของบุคคลที่เก็บไว้
3. ระเบียนนักศึกษา ใบสมัคร ข้อมูลอาจารย์ ผู้ปกครอง และบัญชีของบุคคลที่นำออกจะย้ายไปยังบุคคลที่เก็บไว้ หากทั้งสองมีบัญชี บัญชีของบุคคลที่นำออกจะถูกปิดใช้งาน และการเข้าสู่ระบบด้วยบัญชีสถาบันที่เชื่อมโยงไว้จะถูกย้ายเท่าที่ทำได้
4. บุคคลที่นำออกจะยังคงอยู่ในสถานะ **รวมแล้ว** (ตัวกรองรายการ **รวมแล้ว**) เพื่อให้ยังค้นหาระเบียนเก่าได้ แต่ใช้สร้างระเบียนนักศึกษาใหม่ไม่ได้

- หากทั้งสองบุคคลมีข้อมูลอาจารย์ ระบบจะไม่ยอมรวม ให้จัดการข้อมูลอาจารย์ก่อน
- หากทั้งสองบุคคลมีใบสมัครที่ยังเปิดอยู่ในรอบรับสมัครเดียวกัน ระบบจะไม่ยอมรวม ให้ขอผู้สมัครถอนใบสมัครหนึ่งใบ
- **การดำเนินการนี้ย้อนกลับไม่ได้** ตรวจสอบระเบียนนักศึกษาและวันเกิดทุกครั้งก่อนรวม การรวมจะถูกบันทึกในบันทึกการดำเนินงานพร้อมเหตุผล

## การเชิญให้สร้างบัญชี

ส่งอีเมลคำเชิญให้บุคคลที่ยังไม่มีบัญชี เช่น นักศึกษาและอาจารย์ที่โหลดด้วย CSV ต้องมีสิทธิ์ `เชิญบุคคลให้สร้างบัญชี`

1. ในหน้ารายละเอียดของบุคคล กด **เชิญให้สร้างบัญชี** แล้วกรอกอีเมลสำหรับเข้าสู่ระบบ (โดยปกติเป็นอีเมลส่วนตัว)
2. เมื่อผู้รับตั้งรหัสผ่านผ่านลิงก์ในอีเมล บัญชีจะถูกสร้างและเข้าสู่ระบบทันที

- ลิงก์มีอายุตาม **การตั้งค่า > ระเบียนนักศึกษา > ลิงก์คำเชิญมีอายุ (วัน)** (ค่าเริ่มต้น 14 วัน)
- การส่งซ้ำจะทำให้ลิงก์เดิมใช้ไม่ได้
- ไม่สามารถเชิญบุคคลที่มีบัญชีอยู่แล้ว หรือใช้อีเมลที่บัญชีอื่นใช้อยู่ได้
- บัญชีเดิมยังคงใช้ต่อได้หลังสำเร็จการศึกษา ขอให้ผู้ที่ใช้เพียงอีเมลของสถาบันเปลี่ยนอีเมลสำหรับเข้าสู่ระบบเป็นอีเมลส่วนตัว ([บทที่ 15](15-sign-in-methods.md))
