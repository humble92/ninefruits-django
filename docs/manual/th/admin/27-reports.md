# 27. รายงานและวิว reporting

เมนู: **รายงาน > รายงาน** (สิทธิ์ `ดูและดาวน์โหลดรายงานมาตรฐาน`) ค่าเริ่มต้นของบทบาท: เจ้าหน้าที่ทะเบียน เจ้าหน้าที่ฝ่ายวิชาการ เจ้าหน้าที่ภาควิชา (ภายในขอบเขต)

## รายงานมาตรฐาน

เลือกรายงานและตัวกรอง: หน้าจอแสดงได้สูงสุด 500 แถว และ **ดาวน์โหลด CSV** จะได้ข้อมูลครบทุกแถว (UTF-8 พร้อม BOM เปิดใน Excel ได้โดยตรง) การดาวน์โหลดจะถูกบันทึกในเหตุการณ์ตรวจสอบ `reports.exported` และเหตุการณ์ในบันทึกความปลอดภัย `data.exported` (รายงาน ตัวกรอง จำนวนแถว) ค่าที่ขึ้นต้นด้วย `=`, `+`, `-`, `@` (หรือแท็บหรือการขึ้นบรรทัดใหม่) จะถูกส่งออกโดยเติมเครื่องหมายอัญประกาศเดี่ยว (`'`) นำหน้า เพื่อไม่ให้ Excel เรียกใช้เป็นสูตร

| รายงาน | ตัวกรอง | เนื้อหา |
|---|---|---|
| รายชื่อนักศึกษา | หน่วยงาน (รวมหน่วยงานย่อย) สถานภาพ ชั้นปี | รหัสนักศึกษา ชื่อ หลักสูตร หน่วยงาน ชั้นปี สถานภาพ วันที่เข้าศึกษา วันที่สำเร็จการศึกษา เลขที่ปริญญาบัตร |
| จำนวนนักศึกษาตามหน่วยงาน หลักสูตร ชั้นปี และสถานภาพ | หน่วยงาน สถานภาพ | จำนวนนักศึกษา |
| สรุปผลการเรียนรายภาคการศึกษา | ภาคการศึกษา สถานภาพทางวิชาการ | หน่วยกิตและเกรดเฉลี่ยรายภาคการศึกษาและสะสม จำนวนครั้งที่รอพินิจ อันดับเกียรตินิยม ([บทที่ 21](21-grades.md)) |
| ผู้มีสิทธิ์สำเร็จการศึกษา | ครบตามเกณฑ์หรือไม่ | ผลการตรวจสอบการสำเร็จการศึกษาล่าสุดต่อนักศึกษาและหลักสูตร ([บทที่ 26](26-graduation.md)) |
| การเปลี่ยนสถานภาพ | ภาคการศึกษา ช่วงเวลา | ประเภทการเปลี่ยนแปลง สถานภาพก่อนและหลัง วันที่มีผล สถานะคำร้อง |
| จำนวนผู้ลงทะเบียนต่อกลุ่มเรียน | ภาคการศึกษา หน่วยงาน | กลุ่มเรียน อาจารย์ผู้สอน จำนวนรับ ลงทะเบียนแล้ว รายชื่อสำรอง |
| นักศึกษาที่ไม่ได้ลงทะเบียนในภาคการศึกษา | ภาคการศึกษา หน่วยงาน | นักศึกษาที่กำลังศึกษาแต่ไม่มีรายการลงทะเบียนในภาคการศึกษานั้น |

ข้อมูลที่มองเห็นได้เป็นไปตามขอบเขตสิทธิ์ของผู้ดู (ขอบเขตการดูระเบียนนักศึกษา เป็นต้น) รายงานค่าธรรมเนียมและค่าเล่าเรียนของระบบเดิม (YUSTIC) (การค้างชำระค่าเล่าเรียน เป็นต้น) อยู่นอกขอบเขตและไม่มีในระบบนี้

## วิว reporting

รายงานอ่านข้อมูลจากวิวของ schema `reporting` ในฐานข้อมูล เครื่องมือ BI และผู้ใช้ SQL สามารถสืบค้นวิวเดียวกันด้วยบทบาทแบบอ่านอย่างเดียว `app_reporting`

| วิว | เนื้อหา |
|---|---|
| `reporting.students` | ระเบียนนักศึกษา + ชื่อบุคคล + ชื่อหลักสูตรและหน่วยงาน |
| `reporting.headcount` | จำนวนนักศึกษาตามหน่วยงาน หลักสูตร ชั้นปี และสถานภาพ |
| `reporting.term_records` | สรุปผลการเรียนรายภาคการศึกษา |
| `reporting.course_grades` | ผลการเรียนรายรายวิชา (ยืนยันแล้วหรือไม่ เกรด ผ่าน เรียนซ้ำ) |
| `reporting.section_enrollments` | จำนวนผู้ลงทะเบียนและรายชื่อสำรองต่อกลุ่มเรียน อาจารย์ผู้สอน |
| `reporting.section_meetings` | เวลาเรียนและห้อง |
| `reporting.status_changes` | การเปลี่ยนสถานภาพ |
| `reporting.degree_audits` | ผลการตรวจสอบการสำเร็จการศึกษาล่าสุดต่อนักศึกษาและบทบาทของหลักสูตร |

- คอลัมน์ที่แปลแล้ว (`program_name` เป็นต้น) เป็นไปตาม locale ของเซสชัน: `SET app.locale = 'ko';` คอลัมน์ jsonb ดิบ (`program_name_i18n` เป็นต้น) ก็ใช้ได้เช่นกัน
- วิวเป็นแบบ `security_invoker` ดังนั้น row level security ของผู้ดูจึงมีผลตามเดิม หากอ่านด้วยบัญชีนักศึกษา จะได้เฉพาะแถวของนักศึกษารายนั้น
- นิยามของวิวอยู่ใน `db/sql/views/reporting.sql` (`database/sql/views/reporting.sql` ของต้นฉบับโดยไม่เปลี่ยนแปลง) หลังแก้ไขจะนำไปใช้อีกครั้งจาก migration ของ `core` แอปพลิเคชันอ่านวิวเหล่านี้ผ่านโมเดลแบบ unmanaged (`ninefruits.reporting.models` เช่น `ReportStudent`)

วิว `AV_*` ของระบบเดิม (ประมาณ 90 วิว) ไม่ได้ใช้งานจึงไม่ได้ย้ายมา

## หน้าจอในการติดตั้งนี้

- **รายงาน > รายงาน** (`/admin/reports/`): เลือกรายงานแล้วกด **แสดง** เพื่อแสดงตัวกรองของรายงานนั้น (ต้นฉบับเปลี่ยนตัวกรองทันทีที่เลือกรายงาน) กรอกตัวกรองแล้วกด **แสดง** อีกครั้ง รายงานที่มีตัวกรองภาคการศึกษาจะไม่มีแถวจนกว่าจะเลือกภาคการศึกษา
- ที่อยู่ของ CSV คือ `/reports/{report}.csv?filter=value` (เช่น `/reports/students.csv?status=enrolled`) ระบบยอมรับเฉพาะชื่อรายงานและชื่อตัวกรองที่อยู่ในรายการ และคอลัมน์และการเรียงลำดับถูกกำหนดตายตัวตามนิยามของรายงาน
- เวลาใน CSV (เวลาตรวจสอบ เวลาพิจารณา) เขียนแบบเดียวกับต้นฉบับ คือเป็นข้อความ PostgreSQL ในเขตเวลา UTC (`2026-10-24 07:26:59+00`) วันที่เป็น `YYYY-MM-DD` จริง/เท็จเป็น `Y`/`N`
- ตัวกรองหน่วยงานของรายงานจำนวนผู้ลงทะเบียนต่อกลุ่มเรียนกรองตามรหัสหน่วยงาน (วิวไม่มีรหัส id ของหน่วยงาน) ในต้นฉบับ การเลือกตัวกรองนี้จะล้มเหลว
- กลุ่มเรียนและเวลาเรียนไม่มีความปลอดภัยระดับแถว จึงแสดงแถวกลุ่มเรียนทั้งหมด จำนวนผู้ลงทะเบียนและผู้รอในรายชื่อสำรองจะนับเฉพาะรายการลงทะเบียนและรายชื่อสำรองที่ผู้อ่านมองเห็นได้
