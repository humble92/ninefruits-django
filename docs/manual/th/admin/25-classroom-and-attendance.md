# 25. ห้องเรียนของอาจารย์ผู้สอนและการเข้าเรียน

เมนู: อาจารย์ผู้สอนใช้ **รายวิชาที่สอน > รายชื่อนักศึกษาและการเข้าเรียน** ในพอร์ทัล (`/portal/sections/{section ID}/attendance/`) นักศึกษาใช้ **การเข้าเรียน** ในพอร์ทัล (`/portal/attendance/`) เจ้าหน้าที่ใช้แท็บ **ครั้งเรียน** ของหน้าจอ **หลักสูตรและกลุ่มเรียน > กลุ่มเรียน > เปลี่ยน** ในแผงผู้ดูแลระบบ

| ผู้ใช้ | สิ่งที่ทำได้ |
|---|---|
| อาจารย์ผู้สอนที่ได้รับมอบหมาย | รายชื่อนักศึกษา (พร้อมรูปถ่าย) และ CSV ใบลงชื่อเข้าเรียน PDF การสร้าง เพิ่ม และงดครั้งเรียน การกรอกการเข้าเรียน |
| เจ้าหน้าที่ที่มีสิทธิ์ `วางแผนกลุ่มเรียน` (ภายในขอบเขต) | เหมือนอาจารย์ผู้สอน + ครั้งเรียนในแผงผู้ดูแลระบบ |
| เจ้าหน้าที่ที่มีสิทธิ์ `ดูกลุ่มเรียน` (ภายในขอบเขต) | รายชื่อนักศึกษา ใบลงชื่อเข้าเรียน การดูการเข้าเรียน |
| นักศึกษา | การเข้าเรียนของตนเอง |

ฟังก์ชันห้องเรียน เช่น ประกาศ งานที่มอบหมาย และเอกสารประกอบการสอน ให้เป็นหน้าที่ของ LMS (แผนการย้ายระบบ หัวข้อ 12)

## ความแตกต่างจากระบบเดิม

- **ระบบเดิม (YUSTIC) ไม่ได้บันทึกการเข้าเรียน** "ใบลงชื่อเข้าเรียน" ของระบบเดิมเป็น PDF ที่พิมพ์ช่องว่าง (27 ถึง 34 ช่อง แตกต่างกันไปตามสำเนา) ไว้ข้างรายชื่อนักศึกษา โดยไม่มีวันที่และผลรวม ระบบใหม่สร้าง **ครั้งเรียน** จากเวลาเรียน บันทึกมาเรียน มาสาย ขาดเรียน หรือลา ในแต่ละครั้งเรียน และพิมพ์บันทึกและผลรวมลงในใบลงชื่อเข้าเรียน PDF
- **รายชื่อนักศึกษา** หน้าจอของอาจารย์ผู้สอนในระบบเดิมแสดงเพียงรหัสนักศึกษาและชื่อ (และเปิดเผยเลขประจำตัวประชาชนและที่อยู่ในหน้าต่างป๊อปอัป) และไม่มีการดาวน์โหลด Excel ระบบใหม่แสดงเฉพาะรหัสนักศึกษา ชื่อ รูปถ่าย หลักสูตร ชั้นปี และอีเมลติดต่อ และดาวน์โหลดเป็น CSV ได้ การดาวน์โหลดจะถูกบันทึกในบันทึกการตรวจสอบ
- **การเข้าถึงข้อมูลนักศึกษาของอาจารย์ผู้สอน** นโยบายความปลอดภัยระดับแถว (`student_records_instructor_select` ฟังก์ชัน `util.taught_student_record_ids()`) ให้อาจารย์ผู้สอนเห็นระเบียนนักศึกษาและข้อมูลบุคคลของนักศึกษาในกลุ่มเรียนของตน และกฎการมองเห็นของแอปพลิเคชันก็ตรงกัน (ก่อนหน้านี้ ต้นฉบับแสดงเฉพาะนักศึกษาในความดูแล ทำให้ชื่อว่างเปล่าแม้ในหน้าจอกรอกเกรด)

## ครั้งเรียน

- **สร้าง**: หนึ่งครั้งเรียนต่อการเรียนแต่ละครั้งตามเวลาเรียนรายสัปดาห์ (วัน เวลา คาบ) อาจารย์ผู้สอนใช้ปุ่ม **สร้างจากเวลาเรียน** เจ้าหน้าที่ใช้ปุ่ม **สร้างครั้งเรียน** เหนือแท็บ **ครั้งเรียน** (มีหน้ายืนยัน) หรือคำสั่ง `uv run manage.py attendance_generate_sessions {term}` (ทั้งภาคการศึกษา) ครั้งเรียนและการเข้าเรียนที่มีอยู่จะไม่ถูกแตะต้อง จึงรันซ้ำได้หลังเวลาเรียนเปลี่ยน กลุ่มเรียนที่ถูกยกเลิกจะถูกข้าม
- **เพิ่มครั้งเรียน**: การเรียนนอกเวลาเรียน เช่น การสอนชดเชย (วันที่ เวลาเริ่ม เวลาสิ้นสุด) ได้เฉพาะวันที่ภายในช่วงการเรียน และได้เพียงหนึ่งครั้งเรียนต่อวันที่และเวลาเริ่ม
- **งดเรียน**: งดครั้งเรียนพร้อมเหตุผล ครั้งเรียนยังคงอยู่แต่ไม่นับในผลรวม **คืนค่า** จะนำกลับมา
- ไม่มีปฏิทินวันหยุด ให้งดครั้งเรียนในวันหยุดนักขัตฤกษ์ (เมื่อมีการเพิ่มปฏิทินภาคการศึกษา ตัวสร้างจะข้ามวันเหล่านั้นได้)

## การกรอกการเข้าเรียน

ที่ **การเข้าเรียน** ของครั้งเรียน ให้เลือกมาเรียน มาสาย ขาดเรียน หรือลา สำหรับนักศึกษาแต่ละคน เพิ่มหมายเหตุ (200 ตัวอักษร) แล้วกด **บันทึกการเข้าเรียน** วิธีที่เร็วที่สุดคือ **มาเรียนทั้งหมด** (ทำเครื่องหมายมาเรียนให้ทุกคนโดยยังไม่บันทึก) แล้วจึงเปลี่ยนเฉพาะกรณียกเว้น

- กรอกการเข้าเรียนได้ตั้งแต่วันที่มีครั้งเรียน (ครั้งเรียนในอนาคตหรือที่งดแล้วกรอกไม่ได้)
- การบันทึกอีกครั้งจะบันทึกเฉพาะนักศึกษาที่เปลี่ยนแปลง และเหตุการณ์ตรวจสอบ (`attendance.recorded`) จะเก็บค่าเดิมและค่าใหม่ของนักศึกษาแต่ละคนไว้
- การล้างสถานะจะทำให้นักศึกษากลับเป็น "ยังไม่บันทึก"
- บันทึกได้เฉพาะนักศึกษาที่ลงทะเบียนอยู่และเรียนครบแล้ว (นักศึกษาที่ลดหรือถอนรายวิชาจะไม่อยู่ในรายชื่อ)

## ผลรวม

| รายการ | นิยาม |
|---|---|
| ครั้งเรียนที่จัดแล้ว | ครั้งเรียนที่ไม่ได้งดและอยู่ในวันนี้หรือก่อนหน้า |
| อัตราการเข้าเรียน | (มาเรียน + มาสาย + ลา) ÷ ครั้งเรียนที่จัดแล้ว × 100 ทศนิยมหนึ่งตำแหน่ง (ปัดครึ่งขึ้น) |
| ยังไม่บันทึก | ครั้งเรียนที่จัดแล้วแต่ไม่มีบันทึก |

ไม่มีกฎที่แปลงจำนวนครั้งที่มาสายเป็นการขาดเรียน หรือให้ F เมื่อขาดเรียนเกินหนึ่งในสาม เนื่องจากแตกต่างกันไปในแต่ละมหาวิทยาลัย อาจารย์ผู้สอนจึงนำการเข้าเรียนไปพิจารณาในเกรดเอง กฎการนับอยู่ในบริการเดียว (`AttendanceSummary`) รายชื่อนักศึกษา ใบลงชื่อเข้าเรียน และหน้าของนักศึกษาจึงแสดงตัวเลขเดียวกัน

## ใบลงชื่อเข้าเรียน PDF และรายชื่อนักศึกษา CSV

การดาวน์โหลดทั้งสองแบบจะถูกบันทึกในบันทึกการตรวจสอบ (`attendance.sheet_exported`, `attendance.roster_exported`) ค่าใน CSV ที่ขึ้นต้นด้วย `=`, `+`, `-` หรือ `@` (หรือแท็บหรือการขึ้นบรรทัดใหม่) จะถูกส่งออกโดยเติมเครื่องหมายอัญประกาศเดี่ยวนำหน้า เพื่อไม่ให้ถูกเรียกใช้เป็นสูตร

- **ใบลงชื่อเข้าเรียน (PDF)** (`/sections/{section ID}/attendance-sheet`): A4 แนวนอน นักศึกษาเรียงลงด้านล่าง ครั้งเรียนเรียงตามแนวนอน (ไม่รวมครั้งที่งด) เครื่องหมาย O/△/X/E และผลรวมต่อนักศึกษา ครั้งเรียนที่ยังไม่ถึงจะเว้นว่างไว้ จึงใช้บันทึกด้วยมือได้ด้วย เมื่อเซิร์ฟเวอร์ PDF (Gotenberg) ไม่ตอบสนอง จะแสดงข้อความ "ไม่สามารถสร้าง PDF ได้"
- **รายชื่อนักศึกษา (CSV)** (`/sections/{section ID}/roster.csv`): รหัสนักศึกษา ชื่อ หลักสูตร ชั้นปี อีเมลติดต่อ สถานะการลงทะเบียน UTF-8 พร้อม BOM จึงเปิดใน Excel ได้โดยตรง

## พอร์ทัลนักศึกษา

**การเข้าเรียน**: แยกตามภาคการศึกษา (ค่าเริ่มต้นคือภาคการศึกษาล่าสุดที่เริ่มแล้ว) และรายวิชา จำนวนครั้งที่มาเรียน มาสาย ขาดเรียน และลา และอัตราการเข้าเรียน เมื่อขยายจะเห็นบันทึกต่อครั้งเรียนที่จัดแล้ว (เฉพาะที่อาจารย์ผู้สอนกรอกไว้ มิฉะนั้นแสดง "ยังไม่บันทึก")

## ขั้นตอนการดำเนินงาน

1. ก่อนเริ่มภาคการศึกษา ให้กำหนดเวลาเรียนของกลุ่มเรียนให้เรียบร้อย ([บทที่ 18](18-sections-and-timetables.md))
2. สร้างครั้งเรียนด้วย `uv run manage.py attendance_generate_sessions {term} --actor=...` (อาจารย์ผู้สอนสร้างบนหน้าจอได้เช่นกัน) เฉพาะกลุ่มเรียนเดียว: `--section=CSE2010-01` ดูเพียงจำนวนกลุ่มเรียน: `--dry-run` ([คำสั่งสำหรับการดำเนินงาน](../operations/commands.md))
3. รันอีกครั้งเมื่อเวลาเรียนเปลี่ยน ครั้งเรียนของเวลาที่ถูกนำออกจะไม่ถูกลบโดยอัตโนมัติ ให้งดครั้งเรียนเหล่านั้น

## หน้าจอในการติดตั้งนี้

หน้าจอและฟังก์ชันเป็นแบบเดียวกับต้นฉบับ (Filament, Livewire) แต่การควบคุมบางอย่างทำงานต่างกันเล็กน้อย

- แท็บ **ครั้งเรียน** ของหน้าจอเปลี่ยนกลุ่มเรียนในแผงผู้ดูแลระบบ: วันที่ เวลา ห้อง สถานะ จำนวนบันทึกที่กรอก เหตุผล **งดเรียน** ของแถวจะเปิดหน้ากรอกเหตุผล **คืนค่า** จะเปิดหน้ายืนยัน **สร้างครั้งเรียน** เป็นปุ่มการดำเนินการที่ด้านบนของหน้าจอ เจ้าหน้าที่ที่มีเพียงสิทธิ์ `ดูกลุ่มเรียน` จะเห็นแท็บโดยไม่มีปุ่ม
- ในพอร์ทัลของอาจารย์ผู้สอน **งดเรียน** จะเปิดช่องเหตุผลในแถวของครั้งเรียน ให้กรอกเหตุผลแล้วกด **งดเรียน** อีกครั้ง (แทนกล่องถามของเบราว์เซอร์ในต้นฉบับ)
- หน้ากรอก **การเข้าเรียน** ลงท้ายด้วย `?meeting={meeting ID}` จึงบุ๊กมาร์กได้ **กลับ** จะกลับไปยังรายชื่อนักศึกษาและรายการครั้งเรียน
- ภายใต้ความปลอดภัยระดับแถว รายชื่อนักศึกษาจะมีข้อมูลเฉพาะสำหรับผู้ที่เห็นรายการลงทะเบียนและระเบียนนักศึกษาได้ บทบาทเริ่มต้น (เจ้าหน้าที่ฝ่ายวิชาการ เจ้าหน้าที่ภาควิชา) มีสิทธิ์ `ดูรายการลงทะเบียนและรายชื่อนักศึกษา` และ `ดูระเบียนนักศึกษา` ด้วย บทบาทที่ได้รับเพียง `วางแผนกลุ่มเรียน` จะเห็นรายชื่อนักศึกษาและใบลงชื่อเข้าเรียนว่างเปล่า (เหมือนในต้นฉบับ)
