# 17. รายวิชาและเกณฑ์การสำเร็จการศึกษา

เมนู: **หลักสูตรและกลุ่มเรียน > รายวิชา**, **เกณฑ์การสำเร็จการศึกษา** (สิทธิ์ `จัดการรายวิชา ฉบับรายวิชา และเงื่อนไขรายวิชา`, `จัดการเกณฑ์การสำเร็จการศึกษา`)

## รายวิชาและฉบับรายวิชา

รายวิชาประกอบด้วย **รหัส** ที่ไม่เปลี่ยนแปลง และ **ฉบับ** ที่มีช่วงเวลามีผล ชื่อวิชา หน่วยกิต ชั่วโมง หมวดวิชา การวัดผล และเงื่อนไขรายวิชาเป็นของฉบับรายวิชา ระบบเดิม (YUSTIC) แยกรายวิชาด้วยรหัสวิชาและวันที่เริ่ม แต่ผลการเรียนอ้างถึงเพียงรหัสวิชา จึงไม่ชัดเจนว่านักศึกษาเรียนฉบับใด ในระบบใหม่ กลุ่มเรียนและผลการเรียนจะอ้างถึงฉบับรายวิชา

- ช่วงเวลาของฉบับต่าง ๆ ของรายวิชาเดียวกันทับซ้อนกันไม่ได้ (ข้อจำกัดของฐานข้อมูล) ในวันใดวันหนึ่งจะมีฉบับที่มีผลเพียงฉบับเดียว
- กลุ่มเรียนจะเปิดสอนด้วยฉบับที่มีผลในวันเริ่มต้นของช่วงการเรียน

| ช่อง | คำอธิบาย |
|---|---|
| รหัสวิชา | เช่น `CSE2010` รหัสไม่มีความหมายทางธุรกิจ (กฎอย่างการตรวจรหัส `009*` สำหรับธนาคารหน่วยกิตในระบบเดิมถูกแทนที่ด้วยช่องด้านล่าง) |
| หน่วยงานที่รับผิดชอบ | หน่วยงานที่ดูแลรายวิชา เป็นหน่วยงานผู้เปิดสอนเริ่มต้นของกลุ่มเรียน |
| ชื่อวิชา, คำอธิบายรายวิชา | แยกตามภาษา |
| หน่วยกิต, ชั่วโมงบรรยายและชั่วโมงปฏิบัติ | ทีละ 0.5 |
| หมวดวิชา | ข้อมูลอ้างอิง > หมวดวิชา |
| การวัดผล | เกรดตัวอักษร หรือ ผ่าน/ไม่ผ่าน |
| นับรวมในหน่วยกิตสูงสุด | เมื่อปิด รายวิชาจะไม่ถูกนับในหน่วยกิตสูงสุดของการลงทะเบียน (รายวิชาในธนาคารหน่วยกิต เป็นต้น) |
| การประเมินรายวิชา | เมื่อปิด รายวิชาจะไม่ถูกประเมิน (การฝึกปฏิบัติ การฝึกงาน เป็นต้น [บทที่ 22](22-course-evaluation.md)) |
| เรียนซ้ำเพื่อรับหน่วยกิตเพิ่มได้ | การเรียนอีกครั้งจะได้รับหน่วยกิตอีกครั้งแทนที่จะเป็นการเรียนซ้ำ (สัมมนาที่หัวข้อเปลี่ยนไป เป็นต้น) |

## การปรับปรุงรายวิชา

เมื่อหน่วยกิตหรือชื่อวิชาเปลี่ยน อย่าแก้ไขฉบับเดิม แต่ให้ **ปรับปรุง** แทน ในหน้าจอ **แก้ไข** รายวิชา ที่แท็บ **ฉบับ** ให้คลิก **ปรับปรุงตั้งแต่วันที่** ที่ฉบับปัจจุบัน แล้วกรอกวันที่เริ่มของฉบับใหม่ ค่าที่เปลี่ยน และเหตุผล

- ฉบับปัจจุบันจะสิ้นสุดในวันก่อนวันเริ่ม ฉบับใหม่เริ่มต้นจากสำเนาของฉบับปัจจุบันพร้อมเงื่อนไขรายวิชา
- กลุ่มเรียนที่เปิดสอนแล้วและผลการเรียนในอดีตจะยังคงอ้างถึงฉบับเดิม
- แก้ไขฉบับโดยตรงเฉพาะการแก้ไขที่ไม่เปลี่ยนความหมาย เช่น คำสะกดผิด (จะปรากฏในบันทึกการเปลี่ยนแปลงข้อมูล)

## วิชาบังคับก่อนและวิชาเรียนควบคู่

เปิดฉบับรายวิชาจากแท็บ **ฉบับ** (ลิงก์ของแถว) แล้วกรอกที่ **เงื่อนไขรายวิชา** ด้านล่างของหน้าจอฉบับรายวิชา ฉบับใหม่เพิ่มได้ด้วย **เพิ่มฉบับรายวิชา** ในหน้าจอรายวิชา

| ช่อง | คำอธิบาย |
|---|---|
| ประเภท | วิชาบังคับก่อน (ต้องผ่านก่อน) หรือ วิชาเรียนควบคู่ (เรียนพร้อมกันในภาคการศึกษาเดียวกัน หากผ่านแล้วก็ถือว่าครบเงื่อนไข) |
| กลุ่ม | ผ่านรายวิชาใดรายวิชาหนึ่งในกลุ่มเดียวกันก็เพียงพอ (หรือ) ต้องผ่านเงื่อนไขทุกกลุ่ม (และ) |
| เกรดขั้นต่ำ | รหัสเกรดในเกณฑ์ระดับคะแนนเริ่มต้น (เช่น `C0`) เว้นว่าง: เกรดที่ผ่าน |
| เรียนในภาคการศึกษาเดียวกันได้ | เมื่อวิชาบังคับก่อนสามารถเรียนในภาคการศึกษาเดียวกันได้ |

ตัวอย่าง: กลุ่ม 1 มี `CSE1001` กลุ่ม 2 มี `MAT1001` และ `MAT1002` → `CSE1001` และ (`MAT1001` หรือ `MAT1002`) กฎวิชาบังคับก่อนจะตรวจสอบเงื่อนไขนี้ระหว่างการลงทะเบียนเรียน ([บทที่ 20](20-registration.md))

## รายวิชาเทียบเท่า

เมื่อการปฏิรูปหลักสูตรมีรายวิชาใหม่มาแทนรายวิชาเดิม ให้กรอกรายวิชาที่มาแทนพร้อมช่วงเวลาในแท็บ **รายวิชาเทียบเท่า** ของหน้าจอ **แก้ไข** รายวิชา เมื่อเปิด **เทียบเท่าซึ่งกันและกัน** แต่ละรายวิชาจะใช้แทนกันได้ทั้งสองทาง เมื่อปิด เฉพาะรายวิชาเทียบเท่าจะใช้แทนรายวิชานี้ได้ ใช้ในการตรวจสอบการเรียนซ้ำ ([บทที่ 20](20-registration.md)) และการตรวจสอบการสำเร็จการศึกษา ([บทที่ 26](26-graduation.md))

## เกณฑ์การสำเร็จการศึกษา

ชุดเกณฑ์หนึ่งชุดสร้างขึ้นต่อหลักสูตร **บทบาทของหลักสูตร** (หลักสูตรหลัก วิชาเอกที่สอง วิชาโท) และช่วง **ปีหลักสูตร** นักศึกษาจะอยู่ภายใต้ชุดเกณฑ์ที่ตรงกับปีหลักสูตรในระเบียนนักศึกษาของตน

- ปีหลักสูตรของหลักสูตรและบทบาทของหลักสูตรเดียวกันทับซ้อนกันไม่ได้ เว้นปีสิ้นสุดว่างไว้เพื่อให้ชุดเกณฑ์มีผลจนกว่าชุดถัดไปจะเริ่ม
- ประเภทของเกณฑ์

| ประเภท | ข้อมูลที่กรอก | ตัวอย่าง |
|---|---|---|
| หน่วยกิตตามหมวดวิชา | หมวดวิชา หน่วยกิตขั้นต่ำ | วิชาศึกษาทั่วไปบังคับ 9 หน่วยกิต |
| รายวิชาบังคับ | รายการรายวิชา | วิชาเอกบังคับทั้ง 4 รายวิชา |
| เลือกจากกลุ่มรายวิชา | รายการรายวิชา หน่วยกิตขั้นต่ำหรือจำนวนรายวิชาขั้นต่ำ | 12 หน่วยกิตจากวิชาเอกเลือก |
| สอบผ่าน | ประเภทการสอบ | สอบผ่านการสอบประมวลความรู้ภาษาอังกฤษ ([บทที่ 24](24-assessments.md)) |

วิชาเอกที่สองและวิชาโทมีชุดเกณฑ์ของตนเองที่เล็กกว่าหลักสูตรหลัก (เช่น 36 หน่วยกิตสำหรับวิชาเอกที่สอง 21 หน่วยกิตสำหรับวิชาโท) เกณฑ์เหล่านี้ตรวจสอบโดยการตรวจสอบการสำเร็จการศึกษา ([บทที่ 26](26-graduation.md))

## การนำเข้า CSV

**นำเข้า CSV** ในรายการรายวิชา (สิทธิ์ `จัดการรายวิชา ฉบับรายวิชา และเงื่อนไขรายวิชา`) ใช้โหลดฉบับรายวิชาครั้งละจำนวนมาก หนึ่งแถวคือหนึ่งฉบับ รายวิชาค้นหาด้วยรหัส (และสร้างใหม่หากยังไม่มี) ฉบับรายวิชาค้นหาด้วยรหัสและวันที่เริ่ม การนำเข้าไฟล์เดิมซ้ำจึงเป็นการปรับปรุง และแถวที่มีวันที่เริ่มต่างออกไปจะกลายเป็นฉบับปรับปรุงใหม่ แถวที่มีช่วงเวลาทับซ้อนจะล้มเหลวเฉพาะแถวนั้น

| คอลัมน์ | คำอธิบาย |
|---|---|
| `code` | รหัสวิชา (ต้องมี) |
| `org_unit` | รหัสหน่วยงานที่รับผิดชอบ ต้องมีสำหรับรายวิชาใหม่ |
| `effective_start_date`, `effective_end_date` | ช่วงเวลาของฉบับ (`YYYY-MM-DD`) |
| `title_en`, `title_ko`, `title_zh-hans`, `title_lo` | ชื่อวิชาตามภาษา ต้องมีชื่อภาษาอังกฤษสำหรับรายวิชาใหม่ |
| `credits`, `lecture_hours`, `lab_hours` | หน่วยกิต (ต้องมีสำหรับฉบับใหม่ 0–30) ชั่วโมง (0–40) |
| `category` | รหัสหมวดวิชา |
| `grading_basis` | `graded` หรือ `pass_fail` |
| `counts_toward_credit_limit` | `1`/`0` |

ทำสิ่งเดียวกันได้ด้วย `uv run manage.py reference_import courses <file> --actor=<email>` ([บทที่ 9](09-csv-import.md))
