# 8. อาคารและห้อง

เมนู: **ข้อมูลอ้างอิง > อาคาร**, **ห้อง** (สิทธิ์ `จัดการอาคารและห้อง`)

## อาคาร

กรอกรหัส (เช่น `SCI`) ชื่อ (ตามแต่ละภาษา) และที่อยู่ อาคารที่มีห้องอยู่จะลบไม่ได้ เมื่อเลิกใช้แล้วให้ปิด **ใช้งาน**

## ห้อง

| ฟิลด์ | คำอธิบาย |
|---|---|
| อาคาร, หมายเลขห้อง | หมายเลขห้องต้องไม่ซ้ำกันภายในอาคารเดียวกัน เช่น `101` |
| ชื่อ | ไม่บังคับ เช่น หอประชุมใหญ่ |
| ประเภทห้อง | ค่าจากรายการรหัส `room_type` (ห้องเรียน ห้องปฏิบัติการ ฯลฯ) |
| หน่วยงาน | ภาควิชาที่ดูแลห้อง (ไม่บังคับ) |
| ความจุ | ใช้เปรียบเทียบกับจำนวนรับของกลุ่มเรียนเมื่อจัดตารางเรียน ([บทที่ 18](18-sections-and-timetables.md)) |
| ใช้จัดตารางเรียน | เมื่อปิด ห้องจะไม่ถูกนำมาใช้เมื่อจัดตารางเรียน (สำนักงาน ห้องเก็บของ ฯลฯ) |

หากมีห้องจำนวนมาก ให้ใช้ [การนำเข้า CSV](09-csv-import.md) ต้องลงทะเบียนอาคารก่อน
