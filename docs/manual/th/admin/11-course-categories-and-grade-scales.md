# 11. หมวดวิชาและเกณฑ์ระดับคะแนน

## หมวดวิชา

เมนู: **ข้อมูลอ้างอิง > หมวดวิชา** (สิทธิ์ `จัดการหมวดวิชา`) ใช้แทน `SFOBJDIST` ของระบบเดิม (YUSTIC)

การจัดประเภทรายวิชา เช่น วิชาศึกษาทั่วไปบังคับ หรือวิชาเอกเลือก หมวดวิชาจัดกลุ่มได้โดยกำหนดหมวดหลักในฟิลด์ **ระดับบน** (เช่น ศึกษาทั่วไป → ศึกษาทั่วไปบังคับ ศึกษาทั่วไปเลือก) เกณฑ์การสำเร็จการศึกษา ([บทที่ 17](17-courses-and-curriculum.md), [บทที่ 26](26-graduation.md)) อ้างอิงหมวดวิชาเหล่านี้ เช่น "วิชาเอกบังคับ 30 หน่วยกิต"

## เกณฑ์ระดับคะแนน

เมนู: **ข้อมูลอ้างอิง > เกณฑ์ระดับคะแนน** (สิทธิ์ `จัดการเกณฑ์ระดับคะแนน`) ใช้แทน `SSCOREDEF` ของระบบเดิม

| ฟิลด์ของเกณฑ์ | คำอธิบาย |
|---|---|
| ค่าระดับคะแนนสูงสุด | เช่น 4.5 |
| ค่าเริ่มต้น | กำหนดเป็นค่าเริ่มต้นได้เพียงเกณฑ์เดียว เปิดได้เฉพาะเมื่อยังไม่มีเกณฑ์ใดเป็นค่าเริ่มต้น (ดูด้านล่าง) |

เปิดเกณฑ์แล้วเพิ่มเกรดที่ **เกรด** ด้านล่าง

| ฟิลด์ของเกรด | คำอธิบาย |
|---|---|
| เกรด | เช่น `A+`, `P` |
| ค่าระดับคะแนน | ต้องกรอกสำหรับเกรดที่นำมาคิดเกรดเฉลี่ย |
| ตั้งแต่/ถึง (%) | ช่วงการแปลงคะแนนดิบ (ไม่บังคับ) เช่น A+ 95–100 |
| นำมาคิดเกรดเฉลี่ย | ปิดสำหรับเกรดที่ไม่นำมาคิดเกรดเฉลี่ย เช่น P/NP |
| ผ่าน | ปิดสำหรับเกรดที่ไม่ได้รับหน่วยกิต เช่น F หรือ NP |
| ใช้กับ | รายวิชาที่วัดผลเป็นเกรด (เกรดตัวอักษร) รายวิชาผ่าน/ไม่ผ่าน (P, NP) หรือทั้งสองแบบ (เช่น I ไม่สมบูรณ์) หน้าจอกรอกเกรดจะแสดงเฉพาะเกรดที่ตรงกับรูปแบบการวัดผลของรายวิชา |

**เกณฑ์เริ่มต้นถูกกำหนดตายตัวตั้งแต่การติดตั้งและเปลี่ยนไม่ได้** (มติวันที่ 2026-10-23) เนื่องจากเกรดและเกรดเฉลี่ยทั้งหมดแสดงตามเกณฑ์นั้น กำหนดด้วย `setup_install --grade-scale=4.5|4.3` หากไม่ระบุตัวเลือก เกณฑ์ของโปรไฟล์แรกจะเป็นค่าเริ่มต้น แฟล็กค่าเริ่มต้นเปลี่ยนบนหน้าจอไม่ได้และเกณฑ์เริ่มต้นลบไม่ได้ ช่วงคะแนนและค่าระดับคะแนนของแต่ละเกรดแก้ไขได้ในหน้าจอนี้ ([บทที่ 21](21-grades.md))

เกณฑ์ที่โหลดจากโปรไฟล์

- มหาวิทยาลัยเกาหลี: เกณฑ์ 4.5 (`KR45`): A+ 4.5 (95–100), A0 4.0 (90–), B+ 3.5 (85–), B0 3.0 (80–), C+ 2.5 (75–), C0 2.0 (70–), D+ 1.5 (65–), D0 1.0 (60–), F 0, P, NP
- `--grade-scale=4.3` หรือโปรไฟล์ YUST เดิม: เกณฑ์ 4.3 (`KR43` หรือ `YUST43`): A+ 4.3 (97–100), A0 4.0 (93–), A- 3.7 (90–), B+ 3.3 (87–), B0 3.0 (83–), B- 2.7 (80–), C+ 2.3 (77–), C0 2.0 (73–), C- 1.7 (70–), D+ 1.3 (67–), D0 1.0 (63–), D- 0.7 (60–), F 0, P, NP (โปรไฟล์เดิมมี N และ I ด้วย) ช่วงคะแนนเริ่มต้นห่างกันช่วงละ 3 คะแนน จึงควรปรับให้ตรงกับเกณฑ์ของสถาบัน

เกณฑ์ที่มีการใช้ในเกรดแล้วจะลบไม่ได้
