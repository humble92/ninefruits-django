# 21. ผลการเรียน

เมนู: **ผลการเรียน > ความคืบหน้าการส่งเกรด**, **คำขอเปลี่ยนวิธีวัดผล**, **การแก้ไขเกรด**, **บันทึกผลรายภาคการศึกษา**, **การตั้งค่า > นโยบายการวัดผล** อาจารย์ผู้สอนใช้ **รายวิชาที่สอน > กรอกเกรด** ในพอร์ทัล

| สิทธิ์ | สิ่งที่ทำได้ |
|---|---|
| `ดูเกรด ความคืบหน้าการส่งเกรด และบันทึกผลรายภาคการศึกษา` | ดูความคืบหน้าการส่งเกรด บันทึกผลรายภาคการศึกษา และรายงานผลการเรียนของนักศึกษา |
| `ยืนยันและส่งคืนเกรด กรอกเกรดแทนอาจารย์ผู้สอน ปิดภาคการศึกษา` | ยืนยันหรือส่งคืนเกรดของกลุ่มเรียน กรอกเกรดแทนอาจารย์ผู้สอน (ไม่ขึ้นกับช่วงเวลาดำเนินการ) ส่งเกรดที่เกินสัดส่วนสูงสุดของเกรดเป็นกรณียกเว้น ปิดภาคการศึกษา คำนวณใหม่ หากกำหนดพร้อมขอบเขตหน่วยงาน จะครอบคลุมเฉพาะกลุ่มเรียนที่หน่วยงานนั้นเปิดสอน |
| `รับแจ้งเมื่อเจ้าหน้าที่ส่งเกรดเกินสัดส่วนสูงสุด` | รับการแจ้งเตือนการส่งเกรดเป็นกรณียกเว้น กำหนดพร้อมขอบเขตหน่วยงานให้หัวหน้าภาควิชาและหัวหน้าฝ่ายวิชาการ |
| `ขอแก้ไขเกรดที่ยืนยันแล้ว` | ขอแก้ไขเกรดของกลุ่มเรียนที่ตนเองไม่ได้สอน (เช่น การยกเลิกเกรดเนื่องจากการทุจริตทางวิชาการ) |
| `อนุมัติหรือไม่อนุมัติการแก้ไขเกรด (ยกเว้นคำขอของตนเอง)` | พิจารณาคำขอแก้ไขเกรด |
| `จัดการนโยบายเกรดเฉลี่ย การเรียนซ้ำ สถานภาพทางวิชาการ และเกียรตินิยม` | การตั้งค่านโยบายการวัดผล |

อาจารย์ผู้สอนกรอกเกรดและขอแก้ไขเกรดของกลุ่มเรียนของตนเองได้โดยไม่ต้องมีสิทธิ์ใด ค่าเริ่มต้นของบทบาท: เจ้าหน้าที่ทะเบียนมีสิทธิ์ดู ยืนยัน อนุมัติ และรับแจ้งกรณียกเว้น เจ้าหน้าที่ฝ่ายวิชาการมีสิทธิ์ดู ขอแก้ไข และนโยบาย เจ้าหน้าที่ออกหนังสือรับรองและเจ้าหน้าที่ภาควิชามีสิทธิ์ดู คำขอเปลี่ยนวิธีวัดผลพิจารณาด้วยสิทธิ์ `วางแผนกลุ่มเรียน`

## ความแตกต่างจากระบบเดิม

- ในระบบเดิม (YUSTIC) เกรดที่อาจารย์ผู้สอนบันทึกจะเป็นผลสุดท้ายทันที และฝ่ายวิชาการแก้ไขโดยตรงบนหน้าจอ ไม่มีเหตุผลและขั้นตอนการอนุมัติ และการแก้ไขโดยบางบัญชีไม่ปรากฏแม้แต่ในบันทึกสำรอง ระบบใหม่มีขั้นตอน **กรอก → ส่ง → ยืนยัน** และเกรดที่ยืนยันแล้วจะเปลี่ยนได้ก็ต่อเมื่อ **ผู้อื่นอนุมัติคำขอแก้ไข** เท่านั้น ทั้งแอปพลิเคชันและฐานข้อมูล (ทริกเกอร์) บังคับใช้ข้อนี้
- ในระบบเดิม อาจารย์ผู้สอนสามารถบันทึกเกรดของกลุ่มเรียนที่ตนไม่ได้สอนได้โดยการดัดแปลงคำขอ ระบบใหม่ตรวจสอบอาจารย์ผู้สอนที่ได้รับมอบหมายและขอบเขตสิทธิ์ทั้งบนเซิร์ฟเวอร์และในฐานข้อมูล
- เกรดเฉลี่ย การรอพินิจ และเกียรตินิยมไม่ได้คำนวณใหม่ทุกครั้งในทุกหน้าจอ แต่จัดเก็บเป็น **บันทึกผลรายภาคการศึกษา** เมื่อปิดภาคการศึกษา จะกลายเป็นบันทึกอย่างเป็นทางการของภาคการศึกษานั้น
- การเรียนซ้ำจะนำเกรดเดิมออกจากเกรดเฉลี่ยสะสม **หลังจากยืนยันเกรดใหม่แล้ว** เท่านั้น (ระบบเดิมนำออกตั้งแต่ลงทะเบียน และไม่คืนค่าเมื่อกลุ่มเรียนถูกยกเลิก)
- ระบบเดิมเพียงปิดเมนูผลการเรียน แต่ยังเห็นผลการเรียนได้ผ่านที่อยู่ ระบบใหม่บังคับใช้การระงับการดูผลการเรียนบนเซิร์ฟเวอร์

## ลำดับขั้นตอนของภาคการศึกษา

1. **ช่วงเวลาดำเนินการ** ([บทที่ 10](10-terms.md)): ช่วง **กรอกเกรด** สำหรับแต่ละช่วงการเรียน อาจารย์ผู้สอนกรอกและส่งเกรดได้เฉพาะในช่วงนี้
2. อาจารย์ผู้สอนกรอกและส่งเกรด `uv run manage.py grades_remind_missing {term}` จะส่งอีเมลเตือนไปยังอาจารย์ผู้สอนที่ยังไม่ได้ส่ง
3. ที่ **ความคืบหน้าการส่งเกรด** ให้ยืนยันเกรดของแต่ละกลุ่มเรียนหรือส่งคืนอาจารย์ผู้สอน
4. เมื่อยืนยันเกรดครบทุกกลุ่มเรียนแล้ว ให้ **บันทึกผลรายภาคการศึกษา > ปิดภาคการศึกษา** บันทึกผลรายภาคการศึกษา สถานภาพทางวิชาการ และเกียรตินิยมจะถูกกำหนด และภาคการศึกษาจะเปลี่ยนเป็น **ปิดผลการเรียน**
5. เกรดที่เปลี่ยนหลังจากนั้นต้องผ่าน **การแก้ไขเกรด**

## เกณฑ์ระดับคะแนนและวิธีวัดผล

**เกณฑ์ระดับคะแนนกำหนดตอนติดตั้งและเปลี่ยนแปลงไม่ได้** (การตัดสินใจเมื่อ 2026-10-23) เนื่องจากเกรดและเกรดเฉลี่ยทั้งหมดอยู่บนเกณฑ์นั้น กำหนดด้วย `uv run manage.py setup_install --grade-scale=4.5|4.3` มิฉะนั้นจะใช้เกณฑ์ของโปรไฟล์แรก (มหาวิทยาลัยเกาหลี 4.5, YUST เดิม 4.3) เครื่องหมาย **ค่าเริ่มต้น** ที่ ข้อมูลอ้างอิง > เกณฑ์ระดับคะแนน ย้ายไม่ได้ และเกณฑ์เริ่มต้นลบไม่ได้ **ช่วงคะแนน** (ร้อยละต่ำสุดและสูงสุด) และค่าระดับคะแนนของแต่ละเกรดแก้ไขได้ที่หน้าจอนั้น ([บทที่ 11](11-course-categories-and-grade-scales.md))

ทุกกลุ่มเรียนมี **วิธีวัดผล** ค่าเริ่มต้นคือ **การวัดผลแบบอิงเกณฑ์**

| วิธีวัดผล | สิ่งที่อาจารย์ผู้สอนกรอก | สิ่งที่จัดเก็บ | เงื่อนไขการส่ง |
|---|---|---|---|
| การวัดผลแบบอิงเกณฑ์ (ค่าเริ่มต้น) | **คะแนน (0–100)** ของนักศึกษาแต่ละคน เกรดเป็นไปตามช่วงคะแนนและเลือกเองไม่ได้ (เลือกโดยตรงได้เฉพาะเกรดที่ไม่มีคะแนน เช่น I) | คะแนน (ต้นฉบับ) เกรด ค่าระดับคะแนน | นักศึกษาทุกคนมีเกรด |
| การวัดผลแบบอิงกลุ่ม | **เกรด** ของนักศึกษาแต่ละคน ไม่มีการกรอกคะแนน (หากกรอกจะถูกปฏิเสธ) | เกรด ค่าระดับคะแนน | นักศึกษาทุกคนมีเกรด + เป็นไปตาม **สัดส่วนสูงสุดของเกรด** |
| รายวิชาผ่าน/ไม่ผ่าน | P/NP ไม่ว่าจะใช้วิธีวัดผลใด | เกรด | นักศึกษาทุกคนมีเกรด |

- อาจารย์ผู้สอนที่ต้องการใช้การวัดผลแบบอิงกลุ่มให้คลิก **ขอใช้ การวัดผลแบบอิงกลุ่ม** (พร้อมเหตุผล) ในหน้าจอกรอกเกรด ผู้มีสิทธิ์ `วางแผนกลุ่มเรียน` ของหน่วยงานที่เปิดสอน (เจ้าหน้าที่ภาควิชา เจ้าหน้าที่ฝ่ายวิชาการ) จะอนุมัติหรือไม่อนุมัติ (ต้องระบุหมายเหตุ) ที่ **ผลการเรียน > คำขอเปลี่ยนวิธีวัดผล** และอาจารย์ผู้สอนจะได้รับแจ้งทางอีเมล เมื่ออนุมัติ เกรดฉบับร่างที่กรอกด้วยวิธีเดิมจะถูกล้าง เมื่อ **ส่งแล้ว** จะขอหรือเปลี่ยนวิธีวัดผลไม่ได้อีก เจ้าหน้าที่สามารถเปลี่ยนวิธีวัดผลได้ที่หน้าจอกลุ่มเรียนเช่นกัน แต่ได้เฉพาะก่อนมีการกรอกเกรด
- เกรดสูงสุดสำหรับการเรียนซ้ำ: ภายใต้การวัดผลแบบอิงเกณฑ์ คะแนนที่จะให้เกรดสูงกว่าเพดาน **จะถูกลดลงเป็นเกรดเพดาน** (คะแนนยังคงเดิม) ภายใต้การวัดผลแบบอิงกลุ่ม จะเลือกเกรดที่สูงกว่าเพดานไม่ได้

## สัดส่วนสูงสุดของเกรด (การวัดผลแบบอิงกลุ่ม)

**การตั้งค่า > นโยบายการวัดผล > การวัดผลแบบอิงกลุ่ม**: สัดส่วนสูงสุดต่อกลุ่มเกรด (ค่าเริ่มต้น กลุ่ม A 30% กลุ่ม B 40%) ส่วนเผื่อเกินสัดส่วนสูงสุด (ค่าเริ่มต้น 1 จุดร้อยละ) จำนวนนักศึกษาที่ได้รับเกรดขั้นต่ำสำหรับการตรวจสอบ (ค่าเริ่มต้น 10)

- กลุ่มเกรดแบ่งตามตัวอักษร: A+, A0 และ A- เป็นกลุ่ม A ส่วน B+, B0 และ B- เป็นกลุ่ม B กลุ่มที่ไม่กำหนดสัดส่วน (C, D, F) ไม่มีข้อจำกัด
- ตัวหารคือจำนวนนักศึกษาในกลุ่มเรียนที่มีเกรดซึ่งนับในเกรดเฉลี่ย ไม่รวมนักศึกษาที่ถอนรายวิชาและ P/NP/I
- กลุ่มเรียนที่มีนักศึกษาน้อยกว่าจำนวนขั้นต่ำจะไม่ถูกตรวจสอบ (A 30% จากนักศึกษา 7 คนเป็นไปไม่ได้)
- อาจารย์ผู้สอนดูการกระจายเกรดปัจจุบันเทียบกับสัดส่วนสูงสุดได้ด้วย **ตรวจสอบสัดส่วนเกรด** ในหน้าจอกรอกเกรด และ **ส่งไม่ได้** หากเกินสัดส่วนสูงสุด
- เจ้าหน้าที่ที่มีสิทธิ์จัดการเกรดสามารถส่งเกรดที่เกินสัดส่วนสูงสุดได้ แต่เป็น **การส่งเป็นกรณียกเว้น**: ต้องระบุเหตุผล การกระจายเกรดและเหตุผลจะถูกบันทึกในบันทึกการดำเนินงาน ผู้มีสิทธิ์ `รับแจ้งเมื่อเจ้าหน้าที่ส่งเกรดเกินสัดส่วนสูงสุด` (หัวหน้าภาควิชา หัวหน้าฝ่ายวิชาการ กำหนดพร้อมขอบเขตหน่วยงาน) จะได้รับอีเมล และกลุ่มเรียนจะถูกทำเครื่องหมาย **ส่งเป็นกรณียกเว้น** ที่ **ความคืบหน้าการส่งเกรด** สามารถกรองเฉพาะการส่งเป็นกรณียกเว้นได้

## การกรอกเกรด (อาจารย์ผู้สอน)

ในพอร์ทัลที่ **รายวิชาที่สอน** ให้เปิด **กรอกเกรด** ของกลุ่มเรียน ด้านบนของหน้าจอแสดงวิธีวัดผลของกลุ่มเรียน คำแนะนำการกรอก และคำขอเปลี่ยนวิธีวัดผล

- การวัดผลแบบอิงเกณฑ์: เกรดจะปรากฏทันทีที่กรอกคะแนน
- การวัดผลแบบอิงกลุ่ม: เลือกเฉพาะเกรด ไม่มีคอลัมน์คะแนน ตรวจสอบสัดส่วนสูงสุดด้วย **ตรวจสอบสัดส่วนเกรด** แล้วส่ง
- รายการเกรดเป็นไปตามการวัดผลของรายวิชา รายวิชาเกรดตัวอักษรแสดงเกรดตัวอักษร รายวิชาผ่าน/ไม่ผ่านแสดง P/NP ([บทที่ 11](11-course-categories-and-grade-scales.md))
- **บันทึกฉบับร่าง** ได้ทุกเมื่อ นักศึกษาไม่เห็นเกรดฉบับร่าง
- **ส่งเกรด** ต้องมีเกรดของนักศึกษาทุกคน หลังส่งแล้ว อาจารย์ผู้สอนจะเปลี่ยนเกรดไม่ได้อีก หากเกรดผิด ให้ขอให้ฝ่ายวิชาการส่งคืนเกรดก่อนการยืนยัน หรือขอแก้ไขหลังการยืนยัน
- นักศึกษาที่ถอนรายวิชาแสดงเป็น W และไม่ได้รับเกรด

## การยืนยันและการส่งคืน (ฝ่ายวิชาการ)

**ความคืบหน้าการส่งเกรด**: กลุ่มเรียนของภาคการศึกษาพร้อมจำนวนที่ยังไม่ส่ง ส่งแล้ว และยืนยันแล้ว ตัวกรอง **พร้อมยืนยัน** แสดงเฉพาะกลุ่มเรียนที่ส่งเกรดของนักศึกษาครบทุกคนแล้ว

- **ยืนยันเกรด**: ยืนยันเกรดที่ส่งแล้ว รายการลงทะเบียนจะเปลี่ยนเป็น **เรียนครบแล้ว** และนักศึกษาจะเห็นเกรด บันทึกผลรายภาคการศึกษาของนักศึกษาจะถูกคำนวณใหม่ สามารถเลือกหลายกลุ่มเรียนแล้วยืนยันด้วย **ยืนยันรายการที่เลือก** กลุ่มเรียนที่มีนักศึกษายังไม่ได้ส่งเกรดจะถูกข้าม
- **ส่งคืนอาจารย์ผู้สอน**: ยกเลิกการส่งพร้อมเหตุผล เกรดจะกลับเป็นฉบับร่างและอาจารย์ผู้สอนจะได้รับอีเมล
- **ผลการเรียน**: เปิดหน้าจอกรอกเกรด ฝ่ายวิชาการกรอกหรือเปลี่ยนเกรดได้ก่อนการยืนยันโดยไม่ขึ้นกับช่วงเวลาดำเนินการ เมื่อเจ้าหน้าที่เปลี่ยนเกรดที่อาจารย์ผู้สอน **ส่งแล้ว** ค่าเดิมและค่าใหม่จะถูกบันทึกในเหตุการณ์ตรวจสอบ `grades.submitted_changed`

## การแก้ไขเกรด

เป็นวิธีเดียวในการเปลี่ยนเกรดที่ยืนยันแล้ว

1. คำขอ: อาจารย์ผู้สอนคลิก **ขอแก้ไข** สำหรับนักศึกษาในหน้าจอกรอกเกรด (พร้อมเหตุผล คะแนนใหม่สำหรับการวัดผลแบบอิงเกณฑ์ เกรดใหม่สำหรับการวัดผลแบบอิงกลุ่ม) เพดานเกรดของการเรียนซ้ำมีผลกับการแก้ไขด้วย สำหรับกลุ่มเรียนที่ไม่ได้สอน เจ้าหน้าที่ที่มีสิทธิ์ `ขอแก้ไขเกรดที่ยืนยันแล้ว` ยื่นคำขอที่หน้าจอเดียวกัน คำขอที่ยังเปิดอยู่มีได้เพียงหนึ่งรายการต่อเกรด
2. การพิจารณา: ที่ **ผลการเรียน > การแก้ไขเกรด** (ค่าเริ่มต้น: รายการรอพิจารณา เมนูแสดงจำนวนที่รอพิจารณา) คลิก **อนุมัติ** หรือ **ไม่อนุมัติ** (ต้องระบุหมายเหตุ) ผู้ยื่นคำขอพิจารณาคำขอของตนเองไม่ได้ (บังคับด้วยข้อจำกัดของฐานข้อมูลด้วย)
3. เมื่ออนุมัติ เกรด (คะแนนและเกรดสำหรับการวัดผลแบบอิงเกณฑ์) จะเปลี่ยนทันที และบันทึกผลรายภาคการศึกษาของนักศึกษาและเกรดเฉลี่ยสะสมของภาคการศึกษาถัดมาจะถูกคำนวณใหม่ สถานภาพทางวิชาการและเกียรตินิยมคงค่าที่กำหนดไว้เมื่อปิดภาคการศึกษา

ผู้ยื่นคำขอสามารถ **ยกเลิกคำขอ** ได้ขณะที่ยังรอพิจารณา ทุกคำขอและการพิจารณาจะถูกบันทึกในบันทึกการดำเนินงานพร้อมเหตุผล

## การคำนวณเกรดเฉลี่ย

| รายการ | กฎ |
|---|---|
| หน่วยกิตที่ลงทะเบียน | ทุกรายวิชาที่ยืนยันเกรดแล้ว (รวม F, P, NP, I) |
| หน่วยกิตที่ได้ | เกรดที่ผ่าน (ไม่รวม F, NP, I) |
| หน่วยกิตที่นำมาคิดเกรดเฉลี่ย | เกรดที่นับในเกรดเฉลี่ย F นับเป็น 0 คะแนน ไม่รวม P/NP/I |
| เกรดเฉลี่ย | ผลรวม (ค่าระดับคะแนน × หน่วยกิต) ÷ หน่วยกิตที่นำมาคิดเกรดเฉลี่ย ภาคการศึกษาที่มีแต่รายวิชาผ่าน/ไม่ผ่านจะไม่มีเกรดเฉลี่ย |
| ทศนิยม | จำนวนทศนิยมและการปัดเศษ (ปัดครึ่งขึ้น ตัดทิ้ง) ตามนโยบาย คำนวณด้วยจำนวนเต็มจึงไม่มีความคลาดเคลื่อนที่ค่าขอบ (เช่น 3.4375 → 3.438) |
| เกรดเฉลี่ยภาคการศึกษา | ทุกเกรดของภาคการศึกษานั้น (เกรดเดิมที่ถูกแทนด้วยการเรียนซ้ำยังคงนับในเกรดเฉลี่ยของภาคการศึกษาของตนเอง) |
| เกรดเฉลี่ยสะสม | รายวิชาที่เรียนซ้ำนับเพียงครั้งเดียว ตามนโยบาย: **ครั้งล่าสุด** (ค่าเริ่มต้น ใช้ครั้งล่าสุดแม้จะได้เกรดต่ำกว่า) หรือ **ครั้งที่ดีที่สุด** เกรดที่ถูกแทนจะไม่นับในหน่วยกิตสะสมด้วย และหน้าจอผลการเรียนจะแสดงว่า "ถูกแทนด้วยการเรียนซ้ำในเกรดเฉลี่ยสะสม" |

ความสัมพันธ์ของการเรียนซ้ำกำหนดขึ้นเมื่อลงทะเบียน ([บทที่ 20](20-registration.md)): การเรียนรายวิชาเดิมหรือรายวิชาเทียบเท่าอีกครั้งจะเชื่อมโยงกับรายการลงทะเบียนครั้งก่อน

## สถานภาพทางวิชาการและเกียรตินิยม (การปิดภาคการศึกษา)

| นโยบาย | ค่าเริ่มต้น | โปรไฟล์ YUST เดิม |
|---|---|---|
| เกณฑ์รอพินิจ | เกรดเฉลี่ยภาคการศึกษาต่ำกว่า 1.75 | ต่ำกว่า 1.3 |
| พิจารณาเฉพาะภาคการศึกษาปกติ | ใช่ | ใช่ |
| จำนวนครั้งที่รอพินิจเพื่อพิจารณาพ้นสภาพ | 0 (ปิด) | 4 |
| นับเฉพาะการรอพินิจติดต่อกัน | ไม่ (นับรวม) | ไม่ |
| เกรดเฉลี่ยขั้นต่ำและหน่วยกิตที่นำมาคิดเกรดเฉลี่ยขั้นต่ำสำหรับเกียรตินิยม | 4.0, 15 หน่วยกิต | 0, 0 (ระบบเดิมเพียงเลือก N อันดับแรก) |
| ไม่ให้เกียรตินิยมหากมีรายวิชาที่ไม่ผ่าน | ใช่ | ไม่ |
| ทศนิยมของเกรดเฉลี่ย | 2 ตำแหน่ง ปัดครึ่งขึ้น | 3 ตำแหน่ง ปัดครึ่งขึ้น |
| เกณฑ์ระดับคะแนน (กำหนดตอนติดตั้ง) | 4.5 (KR45) | 4.3 (YUST43) |
| สัดส่วนสูงสุดของเกรด (การวัดผลแบบอิงกลุ่ม) | A 30%, B 40%, ส่วนเผื่อ 1 จุดร้อยละ ตรวจสอบเมื่อมีนักศึกษาตั้งแต่ 10 คน | เหมือนกัน |

- **รอพินิจ**: เกรดเฉลี่ยภาคการศึกษา **ต่ำกว่า** เกณฑ์ ภาคการศึกษาที่มีแต่รายวิชาผ่าน/ไม่ผ่านจะไม่มีการรอพินิจ
- **พิจารณาพ้นสภาพ**: ทำเครื่องหมายเมื่อจำนวนครั้งที่รอพินิจถึงเกณฑ์ การพ้นสภาพเองเป็นการเปลี่ยนสถานภาพ ([บทที่ 13](13-status-changes-and-advisors.md))
- เมื่อพิจารณาเฉพาะภาคการศึกษาปกติ ภาคฤดูร้อนและภาคฤดูหนาวจะไม่มีสถานภาพทางวิชาการ และไม่ทำให้การรอพินิจติดต่อกันขาดช่วง
- **เกียรตินิยม**: นักศึกษาที่ผ่านเกณฑ์จะถูกจัดอันดับตามเกรดเฉลี่ยภาคการศึกษาในแต่ละหลักสูตร (คะแนนเท่ากันได้อันดับเดียวกัน และข้ามอันดับถัดไป)
- **สถานภาพทางวิชาการ** ในระเบียนนักศึกษาจะเปลี่ยนเป็นผลล่าสุด เงื่อนไข "สถานภาพทางวิชาการ" ของช่วงเวลาดำเนินการและสิทธิ์ลงทะเบียนกลุ่มเรียนใช้ค่านี้

ในหน้าจอ **บันทึกผลรายภาคการศึกษา** ให้กรองตามภาคการศึกษา สถานภาพทางวิชาการ เกียรตินิยม และหลักสูตร เพื่อดูรายชื่อนักศึกษาที่อยู่ในสถานภาพรอพินิจและรายชื่อผู้ได้เกียรตินิยม (รายงานการรอพินิจและเกียรตินิยมของระบบเดิม) ให้รัน **ปิดภาคการศึกษา** ด้วย **แสดงตัวอย่างเท่านั้น** (ค่าเริ่มต้น) ก่อน เพื่อดูกลุ่มเรียนที่ยังไม่ยืนยัน แล้วจึงปิดตัวเลือกนี้และรันอีกครั้ง **คำนวณใหม่** จะนำนโยบายที่เปลี่ยนไปใช้กับบันทึกของภาคการศึกษาที่ผ่านมา (ต้องระบุเหตุผล)

## หน้าจอของนักศึกษาและรายงานผลการเรียน

เมื่อเจ้าหน้าที่เปิดรายงานผลการเรียนของนักศึกษา จะถูกบันทึกในเหตุการณ์ตรวจสอบ `transcript.viewed` (พร้อมรหัสนักศึกษา)

- **ผลการเรียน** ในพอร์ทัล: เกรดที่ยืนยันแล้วแยกตามภาคการศึกษา (การถอนรายวิชาแสดงเป็น W) เกรดเฉลี่ยภาคการศึกษาและหน่วยกิตที่ได้ เกรดเฉลี่ยสะสม สถานภาพทางวิชาการ เกียรตินิยม ศิษย์เก่าก็ดูได้ เกรดที่ยังไม่ยืนยันจะไม่แสดง
- **พิมพ์**, **PDF**: รายงานผลการเรียนฉบับไม่เป็นทางการสำหรับตรวจสอบ PDF สร้างโดย Gotenberg ใบแสดงผลการเรียนฉบับทางการออกเป็นหนังสือรับรอง ([บทที่ 23](23-certificates.md)) เจ้าหน้าที่เปิดรายงานผลการเรียนของนักศึกษาได้ด้วย **รายงานผลการเรียน** ในหน้าจอระเบียนนักศึกษาหรือในบันทึกผลรายภาคการศึกษา (สิทธิ์ `ดูเกรด`)
- นักศึกษาที่มี **การระงับ** ที่เปิด **ระงับการดูผลการเรียน** จะดูหน้าจอผลการเรียนหรือรายงานผลการเรียนไม่ได้ ([บทที่ 20](20-registration.md))
- ในช่วงประเมินรายวิชา นักศึกษาที่ยังประเมินรายวิชาของภาคการศึกษาไม่ครบจะถูกซ่อนเกรดของภาคการศึกษานั้น (เป็นการตั้งค่า [บทที่ 22](22-course-evaluation.md))

## นโยบายการวัดผล

**การตั้งค่า > นโยบายการวัดผล** (สิทธิ์ `จัดการนโยบายเกรดเฉลี่ย การเรียนซ้ำ สถานภาพทางวิชาการ และเกียรตินิยม`) ใช้เปลี่ยนรายการในตารางด้านบน นโยบายที่เปลี่ยนจะมีผลตั้งแต่การคำนวณครั้งถัดไป หากต้องการนำไปใช้กับบันทึกของภาคการศึกษาที่ผ่านมา ให้ **คำนวณใหม่** สถานภาพทางวิชาการและเกียรตินิยมกำหนดขึ้นเมื่อปิดภาคการศึกษา จึงไม่ถูกนำไปใช้ซ้ำกับภาคการศึกษาที่ปิดแล้ว

## หน้าจอในการติดตั้งนี้

หน้าจอและฟังก์ชันเป็นแบบเดียวกับต้นฉบับ (Filament, Livewire) แต่วิธีใช้งานต่างกันเล็กน้อย

- เมนูแถวของ **ความคืบหน้าการส่งเกรด**: **เกรด** (หน้าจอกรอกเกรดในพอร์ทัล) **ยืนยันเกรด** (หน้าจอยืนยัน) **ส่งคืนอาจารย์ผู้สอน** (หน้าจอกรอกเหตุผล) หากต้องการยืนยันหลายกลุ่มเรียน ให้เลือกในรายการแล้วเลือก **ยืนยันรายการที่เลือก** ในรายการการดำเนินการ ตัวกรอง: ภาคการศึกษา (ค่าเริ่มต้น: ภาคการศึกษาที่กำลังดำเนินอยู่ **ทั้งหมด** สำหรับทุกภาคการศึกษา) หน่วยงานที่เปิดสอน ส่งแบบกรณียกเว้น พร้อมยืนยัน
- **อนุมัติ** และ **ไม่อนุมัติ** ในเมนูแถวของ **การแก้ไขเกรด** และ **คำขอเปลี่ยนวิธีวัดผล** จะเปิดหน้าจอให้กรอกหมายเหตุ รายการค่าเริ่มต้นแสดงคำขอที่รอพิจารณา และเมนูแสดงจำนวนที่รอพิจารณา
- **ปิดภาคการศึกษา** เหนือรายการ **บันทึกผลรายภาคการศึกษา**: ภาคการศึกษา **แสดงตัวอย่างเท่านั้น** (เปิดไว้โดยค่าเริ่มต้น) เหตุผล การแสดงตัวอย่างจะแสดงเป็นข้อความว่าปิดภาคการศึกษาได้หรือไม่ และกลุ่มเรียนที่ยังไม่ยืนยัน (สูงสุด 30 กลุ่ม) การปิดที่เริ่มแล้วจะทำงานเป็นงานในคิว (Celery) ครั้งละ 100 คน การปิดที่กำลังดำเนินอยู่จะแสดงความคืบหน้าเหนือรายการบันทึกผลรายภาคการศึกษา เมื่อเสร็จ ภาคการศึกษาจะเปลี่ยนเป็น **ปิดผลการเรียน** และเจ้าหน้าที่ผู้เริ่มจะได้รับอีเมล หากงานใดล้มเหลว การปิดจะไม่เสร็จและภาคการศึกษาจะคงอยู่ตามเดิม ให้แก้ไขสาเหตุแล้วปิดอีกครั้ง (ได้ผลลัพธ์เดียวกัน) จากบรรทัดคำสั่ง: `uv run manage.py term_close {term} --dry-run`, `uv run manage.py term_close {term} --reason=...` ([คำสั่ง](../operations/commands.md))
- ใน **นโยบายการวัดผล** ให้เขียนสัดส่วนเกรดสูงสุดเป็นตัวอักษรเกรดและร้อยละ คั่นด้วยจุลภาค เช่น `A=30, B=40` เว้นว่างหมายถึงไม่จำกัด
- การกรอกเกรดในพอร์ทัล: เมื่อวัดผลแบบอิงเกณฑ์ เกรดจะแสดงข้างคะแนนไม่นานหลังพิมพ์ **บันทึกฉบับร่าง** **ตรวจสอบสัดส่วนเกรด** และ **ส่งเกรด** อยู่ที่ด้านล่างของหน้าจอ เมื่อบันทึกไม่สำเร็จ (เช่น คะแนนอยู่นอกช่วง) ค่าที่กรอกจะแสดงอีกครั้งพร้อมข้อผิดพลาด **ขอแก้ไข** ที่แถวของนักศึกษาจะเปิดช่องคำขอใต้ตาราง
- ที่อยู่รายงานผลการเรียนสำหรับเจ้าหน้าที่: `/student-records/{student record id}/transcript/` (ปุ่ม **รายงานผลการเรียน** ในหน้าจอระเบียนนักศึกษา **รายงานผลการเรียน** ที่แถวของบันทึกผลรายภาคการศึกษา) เพิ่ม `?format=pdf` เพื่อรับเป็น PDF
- สำหรับกลุ่มเรียนที่เชื่อมโยงกับ LMS หน้าจอกรอกเกรดสามารถโหลดคะแนนจาก LMS เป็นฉบับร่างได้ ([บทที่ 28](28-lms-integration.md)) เกรดของภาคการศึกษาที่การประเมินรายวิชาเปิดอยู่และยังประเมินไม่เสร็จจะถูกซ่อนพร้อมข้อความแจ้งและลิงก์ไปยัง **การประเมินรายวิชา** ([บทที่ 22](22-course-evaluation.md))
