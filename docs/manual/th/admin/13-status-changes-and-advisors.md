# 13. การเปลี่ยนสถานภาพและอาจารย์ที่ปรึกษา

เมนู: **นักศึกษาและบุคลากร > การเปลี่ยนสถานภาพ**, **ประเภทการเปลี่ยนสถานภาพ** และแท็บ **การเปลี่ยนสถานภาพ** กับ **อาจารย์ที่ปรึกษา** ในระเบียนนักศึกษา

## สถานภาพนักศึกษา

| สถานภาพ | ความหมาย |
|---|---|
| กำลังศึกษา | ลงทะเบียนเรียนได้ |
| ลาพักการศึกษา | ระเบียนยังคงอยู่ ลงทะเบียนเรียนไม่ได้ |
| ลาออก, พ้นสภาพ | ระเบียนสิ้นสุดแล้ว การคืนสภาพนักศึกษาจะสร้างระเบียนใหม่ |
| สำเร็จการศึกษา | ต้องมีวันที่สำเร็จการศึกษา บัญชียังคงอยู่โดยมีสิทธิ์เข้าถึงแบบศิษย์เก่า |

กำลังศึกษาและลาพักการศึกษานับเป็น "นักศึกษาปัจจุบัน" (การเข้าสู่ระบบด้วยรหัสนักศึกษา การกำหนดอาจารย์ที่ปรึกษา ฯลฯ)

## ประเภทการเปลี่ยนสถานภาพ

แต่ละประเภทกำหนด **สถานภาพใหม่**, **เปลี่ยนได้จากสถานภาพ** และ **นักศึกษายื่นคำร้องได้** หรือไม่ การติดตั้งจะสร้างประเภทลาพักการศึกษา กลับเข้าศึกษา ลาออก พ้นสภาพ คืนสภาพนักศึกษา และสำเร็จการศึกษา ชื่อเปลี่ยนได้ และชื่อที่เปลี่ยนแล้วจะคงอยู่แม้ติดตั้งใหม่

## คำร้องของนักศึกษาและการอนุมัติ

1. นักศึกษายื่นคำร้องที่ **ระเบียนของฉัน** ในพอร์ทัล โดยระบุประเภท วันที่มีผล และเหตุผล ระเบียนหนึ่งมีคำร้องที่รอพิจารณาได้ครั้งละหนึ่งรายการ และนักศึกษายกเลิกคำร้องได้ก่อนมีการพิจารณา
2. เจ้าหน้าที่กด **อนุมัติ** หรือ **ไม่อนุมัติ** ในรายการ **การเปลี่ยนสถานภาพ** (ค่าเริ่มต้น: รอพิจารณา) การไม่อนุมัติต้องระบุหมายเหตุ ใช้เมนูการดำเนินการของแต่ละแถว ซึ่งจะมีหน้าต่างให้กรอกหมายเหตุ
3. เมื่ออนุมัติ สถานภาพของระเบียนจะเปลี่ยนทันทีและการเปลี่ยนแปลงจะถูกเพิ่มในประวัติ

- ต้องมีสิทธิ์ `อนุมัติและบันทึกการเปลี่ยนสถานภาพ` และพิจารณาได้เฉพาะระเบียนที่อยู่ในขอบเขตของสิทธิ์ (หน่วยงาน หลักสูตร)
- ท่านไม่สามารถอนุมัติคำร้องที่ตนเองยื่นได้ (การแบ่งแยกหน้าที่)
- หากสถานภาพของระเบียนเปลี่ยนไปหลังจากยื่นคำร้อง (เช่น มีการบันทึกการลาพักด้วยวิธีอื่นไปแล้ว) จะอนุมัติคำร้องนั้นไม่ได้ ให้ไม่อนุมัติแล้วขอให้ยื่นคำร้องใหม่

## การบันทึกโดยตรงโดยเจ้าหน้าที่

การพ้นสภาพ คำร้องที่รับเป็นกระดาษ และกรณีคล้ายกัน ให้บันทึกโดยตรงด้วย **บันทึกการเปลี่ยนสถานภาพ** ในระเบียนนักศึกษา ต้องระบุเหตุผล และผู้บันทึกจะถูกจัดเก็บเป็นผู้อนุมัติ ต้องมีสิทธิ์ `อนุมัติและบันทึกการเปลี่ยนสถานภาพ`

การเปลี่ยนแปลงทุกครั้งจะถูกบันทึกในบันทึกการดำเนินงานและการเปลี่ยนแปลงข้อมูล ([บทที่ 4](04-audit.md))

## อาจารย์ที่ปรึกษา

ที่ **กำหนดอาจารย์ที่ปรึกษา** ในระเบียนนักศึกษา ให้เลือกอาจารย์ บทบาท (อาจารย์ที่ปรึกษาหลัก อาจารย์ที่ปรึกษาร่วม) และวันเริ่มต้น (สิทธิ์ `กำหนดอาจารย์ที่ปรึกษา`)

- มีอาจารย์ที่ปรึกษาหลักได้หนึ่งคน การกำหนดอาจารย์ที่ปรึกษาหลักคนใหม่จะสิ้นสุดการกำหนดเดิมในวันก่อนวันเริ่มต้น โดยยังคงเก็บประวัติไว้
- เลือกได้เฉพาะอาจารย์ที่ยังปฏิบัติงานอยู่
- อาจารย์ที่ปรึกษาจะเห็นนักศึกษาในความดูแลปัจจุบันที่ **นักศึกษาในความดูแล** ในพอร์ทัล และดูระเบียนของนักศึกษาเหล่านั้นได้
