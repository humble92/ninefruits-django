# 6. ข้อมูลรหัส ประเทศ ภาษา

เมนู: **ข้อมูลอ้างอิง > รายการรหัส**, **ประเทศ**, **ภาษา** (สิทธิ์ `จัดการข้อมูลรหัส ประเทศ และภาษา`)

## ข้อมูลรหัส

รายการสั้น ๆ ที่แตกต่างกันไปในแต่ละมหาวิทยาลัย แต่ละรายการ (ประเภท) มีค่ารหัสของตนเอง

| รหัสรายการ | วัตถุประสงค์ | ระบบเดิม (YUSTIC) |
|---|---|---|
| `ethnicity` | เชื้อชาติ | `FNATION` |
| `admission_type` | ประเภทการรับเข้า | `FADMDIST` |
| `room_type` | ประเภทห้อง | `ROOM.FORWHAT` |

- รายการของระบบ (สามรายการข้างต้น) ถูกเรียกใช้ด้วยรหัสในแอปพลิเคชัน จึงเปลี่ยนหรือลบรหัสรายการไม่ได้ แต่เพิ่มค่าได้อย่างอิสระ
- เปิดรายการแล้วเพิ่มค่าที่ **รหัส** ด้านล่าง รหัสใช้ตัวพิมพ์เล็กภาษาอังกฤษ ตัวเลข และขีดล่าง (เช่น `korean`) กรอกชื่อตามแต่ละภาษา ต้องกรอกชื่อภาษาอังกฤษ
- อย่าลบค่าที่เลิกใช้แล้ว ให้ปิด **ใช้งาน** แทน ค่าที่ยังมีข้อมูลใช้อยู่จะลบไม่ได้
- หากมีค่าจำนวนมาก ให้ใช้ [การนำเข้า CSV](09-csv-import.md)

## ประเทศและภาษา

รายการตามมาตรฐาน ISO (249 ประเทศ ประมาณ 180 ภาษา) จะถูกโหลดระหว่างการติดตั้ง ชื่อจะถูกกรอกให้อัตโนมัติสำหรับภาษาที่ติดตั้งไว้

- หากต้องการเปลี่ยนชื่อที่แสดงบนหน้าจอ ให้เปลี่ยนที่ **แก้ไข** ชื่อที่เปลี่ยนแล้วจะคงอยู่แม้มีการอัปเดตระบบในภายหลัง
- หากต้องการซ่อนรายการจากตัวเลือก ให้ปิด **ใช้งาน**
