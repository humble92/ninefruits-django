# 2. ผู้ใช้และบทบาท

## แนวคิด

| คำศัพท์ | ความหมาย |
|---|---|
| สิทธิ์ | สิทธิ์ในการใช้ฟังก์ชันหนึ่ง ตัวอย่าง: `ดูผู้ใช้`, `รีเซ็ตการยืนยันตัวตนแบบสองขั้นตอน` |
| บทบาท | ชุดของสิทธิ์ ตัวอย่าง: เจ้าหน้าที่ทะเบียน เจ้าหน้าที่ภาควิชา |
| การกำหนดบทบาท | การมอบบทบาทให้ผู้ใช้พร้อมขอบเขตและระยะเวลา |
| ขอบเขต | ส่วนที่บทบาทมีผล: **ทั้งหมด**, **หน่วยงาน** (คณะ ภาควิชา ฯลฯ) หรือ **หลักสูตร** |
| บทบาทตามสถานะ | ผู้สมัคร นักศึกษา ศิษย์เก่า อาจารย์ อาจารย์ที่ปรึกษา ระบบมอบให้อัตโนมัติจากข้อมูลทางวิชาการ ไม่สามารถกำหนดด้วยตนเองได้ |

เมื่อหน้าที่รับผิดชอบเปลี่ยนไป จะเปลี่ยนเพียงการตั้งค่าบทบาทหรือการกำหนดบทบาทเท่านั้น โดยไม่ต้องแก้ไขโปรแกรม การเปลี่ยนแปลงทุกครั้งจะถูกบันทึกไว้ในบันทึกการตรวจสอบ เมนูของแผงผู้ดูแลระบบและปุ่มในแต่ละหน้าจอจะเป็นไปตามสิทธิ์ทันที ระบบไม่ใช้ "กลุ่ม" (groups) และ "ผู้ใช้ระดับสูงสุด" (superusers) ที่มีมาในตัวของ Django

## การสร้างบัญชีผู้ใช้

1. ไปที่ **ผู้ใช้และสิทธิ์การเข้าถึง > ผู้ใช้** แล้วกด **เพิ่ม ผู้ใช้**
2. กรอกชื่อ อีเมล และภาษา แล้วกด **บันทึก**
3. ผู้ใช้จะได้รับลิงก์ทางอีเมลเพื่อตั้งรหัสผ่าน ผู้ดูแลระบบจะไม่เห็นรหัสผ่านเลย

ระบบไม่ลบบัญชี หากต้องการหยุดใช้บัญชี เช่น เมื่อมีผู้ลาออก ให้เปิดผู้ใช้ ปิด **ใช้งาน** แล้วบันทึก บัญชีที่ไม่ใช้งานจะเข้าสู่ระบบไม่ได้และสูญเสียสิทธิ์ทั้งหมด หน้าจอที่เข้าสู่ระบบค้างไว้จะถูกออกจากระบบเมื่อมีคำขอครั้งถัดไป

ข้อป้องกันเมื่อแก้ไขบัญชี

- ท่านไม่สามารถปิดการใช้งานบัญชีของตนเองได้
- ท่านไม่สามารถแก้ไขบัญชีที่มีสิทธิ์ซึ่งท่านไม่มี (ผู้ดูแลที่มีสิทธิ์สูงกว่า) ได้
- การเปลี่ยนอีเมลจะรีเซ็ตการยืนยันอีเมล สิ้นสุดเซสชันการเข้าสู่ระบบทั้งหมดของผู้ใช้นั้น และบันทึกเหตุการณ์ด้านความปลอดภัย `เปลี่ยนอีเมล`
- เมื่อผู้ใช้เปลี่ยนรหัสผ่าน เซสชันบนอุปกรณ์อื่นและอุปกรณ์ที่จดจำไว้จะสิ้นสุด และระบบจะบันทึกเหตุการณ์ด้านความปลอดภัย `เปลี่ยนรหัสผ่าน`

## การสร้างและแก้ไขบทบาท

1. ไปที่ **ผู้ใช้และสิทธิ์การเข้าถึง > บทบาท** แล้วกด **เพิ่ม บทบาท** หรือเปิดบทบาทจากรายการ
2. **ชื่อภายในระบบ** ใช้ตัวพิมพ์เล็กภาษาอังกฤษและขีดล่าง (เช่น `exam_office`) ไม่ควรเปลี่ยนหลังจากสร้างแล้ว
3. กรอก **ชื่อที่แสดง** ตามแต่ละภาษา ต้องกรอกชื่อภาษาอังกฤษ การล้างช่องของภาษาใดจะลบชื่อในภาษานั้น
4. ใน **สิทธิ์** ให้เลือกสิทธิ์ตามฟังก์ชัน เมื่อบันทึก สิทธิ์ที่เพิ่มและถูกนำออกจะถูกบันทึกไว้ในบันทึกการตรวจสอบ

| ประเภทบทบาท | การแก้ไข | การลบ |
|---|---|---|
| บทบาทของระบบ (ผู้ดูแลระบบ) | แก้ไขได้เฉพาะชื่อ มีสิทธิ์ทั้งหมดเสมอ | ไม่ได้ |
| บทบาทตามสถานะ | ชื่อที่แสดงและสิทธิ์ ยกเว้นชื่อภายในระบบ | ไม่ได้ |
| บทบาททั่วไป | ทั้งหมด | ได้เฉพาะเมื่อไม่มีการกำหนดบทบาทที่มีผลอยู่ |

## การกำหนดบทบาท

1. ไปที่ **ผู้ใช้และสิทธิ์การเข้าถึง > ผู้ใช้** แล้วเปิดผู้ใช้ รายการ **การกำหนดบทบาท** ที่ด้านล่างแสดงการกำหนดปัจจุบันและในอดีต
2. กด **กำหนดบทบาท** ที่ด้านบนของหน้า แล้วกรอกบทบาท ขอบเขต วันเริ่มต้น/สิ้นสุด (ไม่บังคับ) และ **เหตุผล**
   - หากขอบเขตเป็นหน่วยงานหรือหลักสูตร ให้เลือกที่ **เป้าหมายของขอบเขต** การเลือกหน่วยงานจะรวมหน่วยงานทั้งหมดที่อยู่ภายใต้หน่วยงานนั้นด้วย
   - เว้นวันเริ่มต้นว่างไว้เพื่อให้มีผลทันที เว้นวันสิ้นสุดว่างไว้สำหรับการกำหนดที่ไม่มีกำหนดสิ้นสุด
3. การกำหนดบทบาทไม่สามารถแก้ไขได้ หากต้องการเปลี่ยน ให้กด **สิ้นสุดการกำหนด** ที่การกำหนดเดิม (ต้องระบุเหตุผล) แล้วสร้างการกำหนดใหม่ ประวัติจะยังคงอยู่ครบถ้วน

ท่านไม่สามารถสิ้นสุดการกำหนดบทบาทของตนเองได้ (การแบ่งแยกหน้าที่) กรุณาขอให้ผู้ดูแลท่านอื่นดำเนินการ

กฎที่ป้องกันการยกระดับสิทธิ์

- ท่านไม่สามารถกำหนดบทบาทให้ตนเองได้
- ท่านไม่สามารถกำหนดบทบาทที่มีสิทธิ์ซึ่งท่านไม่มีได้
- ขอบเขตเลือกได้เฉพาะภายในขอบเขตของสิทธิ์ `กำหนดและสิ้นสุดบทบาท` ของท่านเอง ตัวอย่างเช่น ผู้ดูแลที่มีสิทธิ์นี้ในขอบเขตคณะวิศวกรรมศาสตร์ไม่สามารถกำหนดขอบเขตทั้งหมดหรือขอบเขตของคณะอื่นได้
- คำสั่ง `security_create_administrator` ที่ใช้สร้างผู้ดูแลระบบคนแรกนั้นผู้ดูแลเซิร์ฟเวอร์เป็นผู้รัน กฎเหล่านี้จึงไม่มีผลกับคำสั่งนี้ ([คู่มือคำสั่ง](../operations/commands.md)) ใช้คำสั่ง `createsuperuser` ของ Django ไม่ได้
