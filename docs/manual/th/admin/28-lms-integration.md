# 28. การเชื่อมต่อ LMS

เมนู: **การเชื่อมต่อ LMS > แพลตฟอร์ม LMS**, **การเชื่อมโยงรายวิชา**, **บันทึกการซิงค์** ในแผงผู้ดูแลระบบ (สิทธิ์ `จัดการแพลตฟอร์ม LMS การเชื่อมโยง และการซิงค์` ค่าเริ่มต้น: ผู้ดูแลระบบ เจ้าหน้าที่ฝ่ายวิชาการ) อาจารย์ผู้สอนใช้ลิงก์ LMS ที่ **รายวิชาที่สอน** ในพอร์ทัลและในรายละเอียดกลุ่มเรียน และใช้ **ดึงคะแนนจาก LMS** ในหน้าจอกรอกเกรด การดึงคะแนนเป็นไปตามเงื่อนไขเดียวกับการกรอกเกรด (อาจารย์ผู้สอนที่ได้รับมอบหมาย ภายในช่วงกรอกเกรด)

รายละเอียดสำหรับนักพัฒนา (การเขียนตัวเชื่อมต่อ API) อยู่ใน [คู่มือการเชื่อมต่อ LMS](../../../lms-integration-guide.md)

## ข้อมูลใดไปที่ใด

| SIS → LMS | เมื่อใด |
|---|---|
| กลุ่มเรียน (การสร้างรายวิชา) + อาจารย์ผู้สอน | เมื่อกลุ่มเรียน **เผยแพร่แล้ว** และด้วย `lms_sync` |
| การลงทะเบียนที่ยืนยันแล้ว → การเพิ่มสมาชิก | ทันทีเมื่อลงทะเบียน เลื่อนจากรายชื่อสำรอง หรือลงทะเบียนโดยเจ้าหน้าที่ |
| การลดรายวิชาหรือถอนรายวิชา → การนำสมาชิกออก | ทันที |
| การกระทบยอดทั้งหมด | ทุกวันเวลา 02:30 (`lms_reconcile` งานตามกำหนดเวลา `lms.reconcile`) |

| LMS → SIS | เมื่อใด |
|---|---|
| คะแนนสุดท้าย (ฉบับร่าง) | เมื่ออาจารย์ผู้สอนคลิก **ดึงคะแนนจาก LMS** ในหน้าจอกรอกเกรด อาจารย์ผู้สอนเป็นผู้บันทึกและส่งเอง |

เกรดที่ยืนยันแล้วจะไม่ถูกส่งไปยัง LMS เอกสารประกอบการสอน งานที่มอบหมาย และแบบทดสอบอยู่ใน LMS

## แพลตฟอร์ม

**แพลตฟอร์ม LMS**: รหัส ชื่อ (ตามภาษา) ไดรเวอร์ URL หลัก ข้อมูลรับรอง ใช้งาน ซิงค์รายชื่อนักศึกษา ดึงคะแนนสุดท้าย

- ไดรเวอร์ **ไม่มี (บันทึกเท่านั้น)**: ไม่เรียกใช้สิ่งใด และบันทึกสิ่งที่จะถูกส่ง ใช้เพื่อตรวจสอบขั้นตอนหรือสาธิตก่อนการเชื่อมต่อจริง แพลตฟอร์ม `DEMO` ในข้อมูลสาธิตใช้ไดรเวอร์นี้
- `Moodle`, `Open edX`: ยังไม่มีตัวเชื่อมต่อ (ทำเครื่องหมายว่า "ยังไม่รองรับ") เมื่อเลือกใช้ การซิงค์จะถูกบันทึกว่าล้มเหลว
- การเปิด **ใช้งาน** จะทำให้การเผยแพร่กลุ่มเรียนและการเปลี่ยนแปลงการลงทะเบียนถูกส่งทันทีตั้งแต่นั้นไป และรวมแพลตฟอร์มไว้ในการกระทบยอดทุกคืน
- **ข้อมูลรับรอง** เขียนเป็น `key=value` บรรทัดละหนึ่งรายการ (เช่น `token=...`) จัดเก็บแบบเข้ารหัสและจะไม่แสดงกลับมาอีก การเว้นช่องว่างไว้เมื่อแก้ไขจะคงค่าที่จัดเก็บไว้ ประวัติการเปลี่ยนแปลงข้อมูลก็ไม่เก็บค่าเหล่านี้

## การเชื่อมโยงรายวิชาและบันทึกการซิงค์

- **การเชื่อมโยงรายวิชา**: กลุ่มเรียนใดเชื่อมโยงกับรายวิชาใดบนแพลตฟอร์ม (id, URL) สถานะ (รอดำเนินการ/เชื่อมโยงแล้ว/ล้มเหลว) การซิงค์ล่าสุดและข้อผิดพลาด ตัวกรองตามแพลตฟอร์ม สถานะ และภาคการศึกษา ค้นหาด้วยรหัสวิชา การดำเนินการของแถว **ซิงค์อีกครั้ง** (มีหน้ายืนยัน) จะส่งกลุ่มเรียน อาจารย์ผู้สอน และรายชื่อนักศึกษาอีกครั้ง
- **บันทึกการซิงค์**: ผลลัพธ์และข้อความของแต่ละขั้นตอน (รายวิชา เพิ่มและลบสมาชิก ดึงคะแนน ส่งคะแนนแล้ว กระทบยอด) ดูสาเหตุของความล้มเหลวได้ที่นี่ การเปิดแถวจะแสดงเวลาเริ่มและเวลาเสร็จ และข้อมูลที่ส่ง
- คำสั่ง: `uv run manage.py lms_sync {platform} --term={term}` (ส่งทั้งหมด, `--dry-run`), `uv run manage.py lms_reconcile` (กระทบยอด) ดู [คำสั่งสำหรับการดำเนินงาน](../operations/commands.md#การเชื่อมต่อ-lms-ระยะที่-12)

## พอร์ทัล

- ลิงก์รายวิชาบนแพลตฟอร์มจะแสดงในรายละเอียดรายวิชาสำหรับนักศึกษาและอาจารย์ผู้สอน และในรายการ **รายวิชาที่สอน** ของอาจารย์ผู้สอน (คอลัมน์ **LMS** เฉพาะกลุ่มเรียนที่เชื่อมโยงแล้ว)
- การกรอกเกรด: เมื่อเปิด **ดึงคะแนนสุดท้าย** สำหรับแพลตฟอร์มและกลุ่มเรียนเชื่อมโยงแล้ว ปุ่ม **ดึงคะแนนจาก LMS** จะปรากฏ ปุ่มนี้เพียงเติมคอลัมน์คะแนนและไม่บันทึก

## API สำหรับการเชื่อมต่อ

API (`/api/v1/lms/platforms/...`) ให้บริการแพลตฟอร์มที่รายงานผลภายหลังหรือส่งคะแนนมาเอง ให้สร้างบัญชีสำหรับการเชื่อมต่อแยกต่างหากที่มีเพียงสิทธิ์ `จัดการแพลตฟอร์ม LMS การเชื่อมโยง และการซิงค์` ผู้ดูแลระบบจะออกโทเค็นด้วย `uv run manage.py api_issue_token {email} --days=365` แล้วส่งให้ผู้ดูแลแพลตฟอร์ม โทเค็นจะแสดงเพียงครั้งเดียวเมื่อออก `api_revoke_tokens` ใช้เพิกถอน การออกและการเพิกถอนจะถูกบันทึกในบันทึกการตรวจสอบ

- คะแนนที่ได้รับผ่านการส่งคะแนน (`.../scores/`) ก็จะไม่ถูกบันทึกเช่นกัน เมื่ออาจารย์ผู้สอนคลิก **ดึงคะแนนจาก LMS** คะแนนล่าสุดที่ได้รับจะถูกเติมลงในแบบฟอร์มเป็นฉบับร่าง
- ผลการซิงค์ (`.../sync-results/`) จะถูกเก็บไว้ใน **บันทึกการซิงค์** และผลของรายวิชาจะเปลี่ยนสถานะใน **การเชื่อมโยงรายวิชา**

## คำถามที่พบบ่อย

- **นักศึกษาไม่ปรากฏใน LMS** นักศึกษาต้องมีบัญชี (ผู้ใช้) จึงจะซิงค์ได้ หากไม่มี ให้ส่งคำเชิญ ([บทที่ 14](14-merge-and-invitations.md)) การกระทบยอดครั้งถัดไปจะเพิ่มนักศึกษาเข้าไป
- **การซิงค์ล้มเหลวอยู่ตลอด** อ่านข้อความในบันทึกการซิงค์ ข้อมูลรับรองหมดอายุเป็นสาเหตุที่พบบ่อย เปลี่ยนค่าในหน้าจอแก้ไขแพลตฟอร์มแล้ว **ซิงค์อีกครั้ง**
- **เราเปลี่ยนแพลตฟอร์ม** สร้างแพลตฟอร์มใหม่และปิด ใช้งาน ของแพลตฟอร์มเดิม การเชื่อมโยงจะสร้างแยกกันต่อแพลตฟอร์ม

## หน้าจอในการติดตั้งนี้

หน้าจอและฟังก์ชันเป็นแบบเดียวกับต้นฉบับ (Filament, Livewire) แต่การโต้ตอบบางอย่างต่างกัน

- ข้อมูลรับรองกรอกเป็นบรรทัด `key=value` ในช่องข้อความแทนตารางคีย์/ค่าของต้นฉบับ บรรทัดที่รูปแบบไม่ถูกต้องจะถูกปฏิเสธพร้อมหมายเลขบรรทัด
- **ตัวเลือก** ของแพลตฟอร์ม (รหัสบทบาทของแต่ละแพลตฟอร์ม เป็นต้น) ไม่มีช่องบนหน้าจอ นักพัฒนาเป็นผู้กำหนดเมื่อตัวเชื่อมต่อต้องการ ([คู่มือการเชื่อมต่อ](../../../lms-integration-guide.md) หัวข้อ 3)
- **ซิงค์อีกครั้ง** ต้องผ่านหน้ายืนยัน ข้อผิดพลาดของตัวเชื่อมต่อ (ไดรเวอร์ที่ไม่มีตัวเชื่อมต่อ แพลตฟอร์มขัดข้อง) จะแสดงเป็นข้อความ "การซิงค์ล้มเหลว: ..." และการเชื่อมโยงรายวิชาจะเป็นล้มเหลว (ต้นฉบับแสดงหน้าข้อผิดพลาด)
- บันทึกการซิงค์เป็นแบบอ่านอย่างเดียว การเปิดแถวจะแสดงข้อมูลที่ส่งเป็น JSON
- **ดึงคะแนนจาก LMS** ในหน้าจอกรอกเกรดอยู่ในแถวปุ่มใต้ตาราง จะแสดงหน้าอีกครั้งโดยเปลี่ยนเฉพาะช่องคะแนน และคงค่าที่พิมพ์ไว้แล้ว จะไม่มีการบันทึกใด ๆ จนกว่าจะกด **บันทึกฉบับร่าง**
- API สำหรับการเชื่อมต่อและคำสั่งโทเค็น (`api_issue_token`, `api_revoke_tokens`) เป็นของใหม่ในการติดตั้งนี้ (ต้นฉบับไม่มี API)
