# 3. การยืนยันตัวตนแบบสองขั้นตอน

## วิธีที่ผู้ใช้ลงทะเบียน

ผู้ใช้ลงทะเบียนได้ที่หน้า **ความปลอดภัย** ของพอร์ทัล (`/portal/security/` ในแผงผู้ดูแลระบบคือเมนูผู้ใช้ **การยืนยันตัวตนแบบสองขั้นตอน**) ระบบจะขอยืนยันรหัสผ่านอีกครั้งก่อนลงทะเบียนหรือปิดใช้งาน

### แอปยืนยันตัวตน (แนะนำ)

1. กด **เปิดใช้การยืนยันตัวตนแบบสองขั้นตอน**
2. สแกนคิวอาร์โค้ดด้วยแอปยืนยันตัวตน เช่น Google Authenticator หรือ Microsoft Authenticator
3. กรอกรหัส 6 หลักที่แสดงในแอป แล้วกด **ยืนยัน**
4. เก็บ **รหัสกู้คืน** ที่แสดงบนหน้าจอไว้ในที่ปลอดภัย หากโทรศัพท์สูญหาย รหัสแต่ละรหัสใช้ได้หนึ่งครั้ง

### รหัสทางอีเมล

แสดงเฉพาะเมื่อผู้ดูแลระบบอนุญาต มีไว้สำหรับผู้ใช้ที่ใช้แอปยืนยันตัวตนไม่ได้ และมีความปลอดภัยน้อยกว่าแอป

1. ในส่วน **รหัสทางอีเมล** กด **ส่งรหัสเพื่อตั้งค่า**
2. กรอกรหัส 6 หลักที่ส่งไปยังอีเมลของบัญชี แล้วกด **ยืนยัน**
3. หลังจากนั้น ทุกครั้งที่เข้าสู่ระบบจะได้รับรหัสทางอีเมล รหัสใช้ได้หนึ่งครั้งภายใน 10 นาที หากกรอกผิด 5 ครั้งต้องขอรหัสใหม่ ส่งรหัสได้นาทีละหนึ่งครั้งและไม่เกิน 5 ครั้งต่อชั่วโมง

ลงทะเบียนได้ทั้งสองวิธี เมื่อนโยบายเป็น "บังคับ" จะปิดใช้งานวิธีสุดท้ายที่เหลืออยู่ไม่ได้

## การตั้งค่านโยบาย (ผู้ดูแลระบบ)

ตั้งค่าที่ **การตั้งค่า > ความปลอดภัย** ในแผงผู้ดูแลระบบ เมื่อบันทึกแล้ว จะมีผลกับผู้ใช้ทุกคนตั้งแต่การโหลดหน้าครั้งถัดไป

| การตั้งค่า | คำอธิบาย |
|---|---|
| นโยบาย | **ไม่ใช้** / **แนะนำ (ไม่บังคับ)**: ผู้ใช้ที่ยังไม่ลงทะเบียนจะเห็นเพียงข้อความแจ้ง / **บังคับสำหรับบทบาทที่เลือก**: ผู้ใช้ที่มีบทบาทที่เลือกต้องลงทะเบียน / **บังคับสำหรับทุกคน** |
| บทบาทที่ต้องใช้การยืนยันตัวตนแบบสองขั้นตอน | เลือกเมื่อนโยบายเป็น "บังคับสำหรับบทบาทที่เลือก" |
| ระยะผ่อนผัน (วัน) | ระยะเวลาที่ผู้ใช้ยังทำงานต่อได้โดยไม่ต้องลงทะเบียน นับจากที่ข้อกำหนดเริ่มมีผลกับผู้ใช้นั้นครั้งแรก ระหว่างนี้จะมีข้อความแจ้งกำหนดเวลาที่ด้านบนของพอร์ทัลและแผงผู้ดูแลระบบ เมื่อพ้นกำหนดแล้ว จะใช้ได้เฉพาะหน้าความปลอดภัย 0 หมายถึงมีผลทันที |
| จดจำอุปกรณ์เป็นเวลา (วัน) | ระยะเวลาที่ไม่ต้องกรอกรหัสบนอุปกรณ์ที่เลือก **จดจำอุปกรณ์นี้** ไว้ 0 หมายถึงปิดใช้งาน |
| อนุญาตรหัสทางอีเมล | เมื่อปิด รหัสทางอีเมลจะไม่นับเป็นการยืนยันตัวตนแบบสองขั้นตอน ผู้ใช้ที่ลงทะเบียนเฉพาะรหัสทางอีเมลจะถูกขอให้ลงทะเบียนแอปยืนยันตัวตนตามนโยบาย |

แนวทางที่แนะนำ: ใช้ **บังคับสำหรับบทบาทที่เลือก** สำหรับบทบาทของเจ้าหน้าที่ (เจ้าหน้าที่ทะเบียน เจ้าหน้าที่ฝ่ายวิชาการ ผู้ดูแลระบบ ฯลฯ) และใช้แบบแนะนำสำหรับนักศึกษา

## การรีเซ็ต (โทรศัพท์สูญหาย ฯลฯ)

1. เปิดผู้ใช้ที่ **ผู้ใช้และสิทธิ์การเข้าถึง > ผู้ใช้**
2. กด **รีเซ็ตการยืนยันตัวตนแบบสองขั้นตอน** ที่ด้านบนของหน้า แล้วกรอกเหตุผล (ต้องมีสิทธิ์ `รีเซ็ตการยืนยันตัวตนแบบสองขั้นตอน`)
3. แอปยืนยันตัวตน รหัสกู้คืน รหัสทางอีเมล และอุปกรณ์ที่จดจำไว้ของผู้ใช้จะถูกล้างทั้งหมด และระยะผ่อนผันจะเริ่มนับใหม่

ท่านไม่สามารถรีเซ็ตบัญชีของตนเองได้ การรีเซ็ตจะถูกบันทึกพร้อมเหตุผลเป็นเหตุการณ์ด้านความปลอดภัยและในบันทึกการดำเนินงาน

หากผู้ดูแลระบบเพียงคนเดียวทำโทรศัพท์หายและเข้าแผงผู้ดูแลระบบไม่ได้ ผู้ดูแลด้าน IT จะรีเซ็ตให้ด้วย `uv run manage.py security_reset_mfa` (Docker: `docker compose exec app uv run manage.py security_reset_mfa`, [คู่มือคำสั่ง](../operations/commands.md))
