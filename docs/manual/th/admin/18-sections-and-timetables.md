# 18. กลุ่มเรียนและตารางเรียน

เมนู: **หลักสูตรและกลุ่มเรียน > กลุ่มเรียน**, **ตารางเรียน** (สิทธิ์ `ดูกลุ่มเรียน`, `วางแผนกลุ่มเรียน (อาจารย์ผู้สอน เวลา ห้อง)` หากกำหนดพร้อมขอบเขตหน่วยงาน จะครอบคลุมเฉพาะกลุ่มเรียนที่หน่วยงานนั้นเปิดสอน)

## การสร้างกลุ่มเรียน

1. ที่ **กลุ่มเรียน > สร้าง** ให้กรอกช่วงการเรียนของภาคการศึกษา รายวิชา หมายเลขกลุ่มเรียน (เช่น `01`) จำนวนรับ และหน่วยงานที่เปิดสอน ชื่อวิชาและหน่วยกิตมาจากฉบับรายวิชาที่มีผลในวันเริ่มต้นของช่วงการเรียน
2. ในแท็บของหน้าจอแก้ไข ให้กรอก **เวลาเรียน**, **อาจารย์ผู้สอน** และ **ที่นั่งสำรอง**
3. เมื่อพร้อมทุกอย่างแล้ว ให้ **เผยแพร่** เฉพาะกลุ่มเรียนที่เผยแพร่แล้วเท่านั้นที่ปรากฏใน **รายวิชาที่เปิดสอน** ของพอร์ทัลและลงทะเบียนได้ ([บทที่ 20](20-registration.md))

| สถานะ | ความหมาย |
|---|---|
| ฉบับร่าง | อยู่ระหว่างวางแผน มองเห็นได้เฉพาะเจ้าหน้าที่และอาจารย์ผู้สอนที่ได้รับมอบหมาย |
| เผยแพร่แล้ว | นักศึกษามองเห็นได้ สามารถ **กลับเป็นฉบับร่าง** ได้ |
| ยกเลิกแล้ว | ต้องระบุเหตุผล เวลาของห้องและอาจารย์ผู้สอนจะว่างลง **เปิดอีกครั้ง** จะเปลี่ยนกลับเป็นฉบับร่าง หากระหว่างนั้นมีกลุ่มเรียนอื่นใช้เวลานั้นไปแล้วจะเปิดอีกครั้งไม่ได้ |

ลบได้เฉพาะกลุ่มเรียนที่เป็นฉบับร่าง กลุ่มเรียนที่เคยเผยแพร่แล้วให้ยกเลิกแทน

| ช่อง | คำอธิบาย |
|---|---|
| ช่วงการเรียน | ช่วงการเรียนของภาคการศึกษา ([บทที่ 10](10-terms.md)) การย้ายไปช่วงการเรียนอื่นจะเปลี่ยนวันที่เรียนและฉบับรายวิชาให้ตรงกับช่วงการเรียนนั้น |
| ผู้มีสิทธิ์ลงทะเบียน, ผู้ไม่มีสิทธิ์ลงทะเบียน | ชั้นปี ปีที่เข้าศึกษา หลักสูตร หน่วยงาน ตัวอย่าง: ไม่ให้นักศึกษาวิชาเอกของรายวิชานั้นลงทะเบียนรายวิชาศึกษาทั่วไป นักศึกษาวิชาเอกที่สองและวิชาโทก็นับเป็นนักศึกษาของหลักสูตรนั้นด้วย |
| ภาษาที่ใช้สอน | เช่น `ko`, `en` |
| จำนวนรายชื่อสำรอง | จำนวนรายชื่อสำรองที่รับได้เมื่อกลุ่มเรียนเต็ม 0: ไม่มีรายชื่อสำรอง ([บทที่ 20](20-registration.md)) |
| วิธีวัดผล | การวัดผลแบบอิงเกณฑ์ (ค่าเริ่มต้น อาจารย์ผู้สอนกรอกคะแนนและระบบคำนวณเกรดจากคะแนน) หรือการวัดผลแบบอิงกลุ่ม (กรอกเฉพาะเกรด และใช้สัดส่วนสูงสุดของเกรด) อาจารย์ผู้สอนขอเปลี่ยนได้จากหน้าจอกรอกเกรด และเจ้าหน้าที่ที่ดูแลกลุ่มเรียนเป็นผู้อนุมัติ เปลี่ยนไม่ได้เมื่อกรอกเกรดแล้ว ([บทที่ 21](21-grades.md)) จะถูกคัดลอกไปด้วยเมื่อคัดลอกภาคการศึกษา |

## เวลาเรียนและห้อง

ในแท็บ **เวลาเรียน** ให้กรอกวัน เวลาเริ่มและสิ้นสุด และห้อง การเลือก **คาบ** จะกรอกเวลาให้ เว้นวันที่เรียนว่างไว้เพื่อใช้วันที่ของช่วงการเรียน

- กลุ่มเรียนสองกลุ่มใช้ห้องเดียวกันในเวลาเดียวกันไม่ได้ และอาจารย์ผู้สอนหนึ่งท่านสอนสองกลุ่มเรียนในเวลาเดียวกันไม่ได้ ฐานข้อมูลบังคับใช้ข้อนี้ หน้าจอจะแสดงกลุ่มเรียนที่ชนกัน เช่น "ห้องนี้ถูกจองในเวลานี้แล้วโดย OOO"
- เมื่อวันที่ไม่ทับซ้อนกัน เช่น ครึ่งแรกและครึ่งหลังของภาคการศึกษา สามารถใช้เวลาและห้องเดียวกันได้
- กลุ่มเรียนที่ยกเลิกแล้วไม่ใช้เวลาใด ๆ

## อาจารย์ผู้สอน

ในแท็บ **อาจารย์ผู้สอน** ให้กำหนดอาจารย์ผู้สอนพร้อมบทบาท (อาจารย์ผู้สอน อาจารย์ผู้สอนร่วม ผู้ช่วยสอน) กลุ่มเรียนหนึ่งมีได้หลายท่าน อาจารย์ที่สอนกลุ่มเรียนอื่นในเวลาเดียวกันอยู่แล้วจะกำหนดไม่ได้ อาจารย์ผู้สอนจัดการตารางเรียนและประมวลรายวิชาได้ในพอร์ทัลที่ **รายวิชาที่สอน**

## ที่นั่งสำรอง

ในแท็บ **ที่นั่งสำรอง** ให้กันที่นั่งไว้สำหรับกลุ่มนักศึกษา (เช่น 30 ที่นั่งสำหรับนักศึกษาวิชาเอกของหลักสูตร) หลังเวลา **เปิดให้ทุกคนเมื่อ** ที่นั่งที่ไม่ได้ใช้จะเปิดให้ทุกคน ที่นั่งสำรองรวมกันต้องไม่เกินจำนวนรับ ที่นั่งสำรองมีผลระหว่างการลงทะเบียนเรียน ([บทที่ 20](20-registration.md))

## ประมวลรายวิชา

อาจารย์ผู้สอนเขียนในพอร์ทัลที่ **รายวิชาที่สอน** (เปิดได้จากปุ่ม **ประมวลรายวิชา** ในหน้าจอกลุ่มเรียนด้วย) โดยกรอกภาพรวม วัตถุประสงค์การเรียนรู้ ตำราและเอกสารประกอบ ข้อกำหนดของรายวิชา การวัดและประเมินผล (รายการและสัดส่วน) และแผนการสอนรายสัปดาห์ เมื่อ **เผยแพร่แล้ว** นักศึกษาจะมองเห็น

## การคัดลอกจากภาคการศึกษาอื่น

**คัดลอกจากภาคการศึกษาอื่น** ในรายการกลุ่มเรียนจะเริ่มต้นจากแผนของภาคการศึกษาก่อนหน้า (โดยปกติคือภาคการศึกษาเดียวกันของปีที่แล้ว) ให้ตรวจสอบผลลัพธ์ด้วย **แสดงตัวอย่างเท่านั้น** ก่อน

- กลุ่มเรียนที่ไม่ได้ถูกยกเลิกและอยู่ในขอบเขตของท่านจะถูกคัดลอกเป็นฉบับร่าง
- สิ่งที่คัดลอกไปด้วย: อาจารย์ผู้สอนที่ยังปฏิบัติงานอยู่ เวลาเรียนและห้อง ที่นั่งสำรอง (เวลาเปิดให้ทุกคนจะเลื่อนตามผลต่างของวันเริ่มต้นของภาคการศึกษา) ประมวลรายวิชา (เป็นฉบับร่างที่ยังไม่เผยแพร่)
- ช่วงการเรียนจะจับคู่ตามรหัส (หากไม่มีจะใช้ทั้งภาคการศึกษา) ฉบับรายวิชาจะใช้ฉบับที่มีผล ณ วันเริ่มต้นของช่วงการเรียนใหม่
- กลุ่มเรียนที่หมายเลขกลุ่มเรียนมีอยู่แล้วในภาคการศึกษาปลายทางจะถูกข้าม เมื่อห้องไม่ว่าง กลุ่มเรียนจะถูกคัดลอกโดยไม่มีห้อง การแจ้งผลจะแสดงรายการกลุ่มเรียนที่ถูกข้ามและที่ต้องตรวจสอบ

ผู้ปฏิบัติงานฝ่ายไอทีทำสิ่งเดียวกันได้ด้วย `uv run manage.py section_copy`

## ตารางเรียนและการตรวจสอบ

- **ตารางเรียน**: เลือกภาคการศึกษา และห้องหรืออาจารย์ผู้สอน เพื่อดูตารางเรียนรายสัปดาห์
- การตรวจสอบก่อนเผยแพร่: ผู้ปฏิบัติงานฝ่ายไอทีรัน `uv run manage.py schedule_check_conflicts <term code>` เพื่อค้นหาห้องที่เล็กกว่าจำนวนรับ อาจารย์ผู้สอนที่เกษียณแล้ว ฉบับรายวิชาที่ไม่ตรงกัน และที่นั่งสำรองที่เกินจำนวนรับ ([คู่มือคำสั่ง](../operations/commands.md#schedule_check_conflicts))

## ขอบเขต

รายการและหน้าจอจะแสดงเฉพาะกลุ่มเรียนของหน่วยงานที่เปิดสอนซึ่งอยู่ในขอบเขตของสิทธิ์ `ดูกลุ่มเรียน` และ `วางแผนกลุ่มเรียน` แท็บเวลาเรียน อาจารย์ผู้สอน และที่นั่งสำรอง รวมทั้งปุ่มสถานะ (เผยแพร่, กลับเป็นฉบับร่าง, ยกเลิกกลุ่มเรียน, เปิดอีกครั้ง) ต้องมีสิทธิ์ `วางแผนกลุ่มเรียน` ในขอบเขตที่ครอบคลุมหน่วยงานที่เปิดสอนกลุ่มเรียนนั้น หน้าตารางเรียนจะเริ่มที่ภาคการศึกษาที่กำลังดำเนินอยู่ (หรือภาคถัดไป) บนโทรศัพท์จะแสดงเป็นรายการตามวันในสัปดาห์
