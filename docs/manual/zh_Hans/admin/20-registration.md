# 20. 选课

菜单：**选课 > 选课情况**、**选课限制**、**规则例外**、**选课规则**、**学分上限**、**选课尝试记录**，以及**课程与开课 > 开课**编辑界面的**课程名单**、**候补名单**标签页

| 权限 | 可以做的事 |
|---|---|
| `查看选课情况和课程名单` | 查看选课情况、课程名单、选课尝试记录 |
| `代学生选课、退课、撤课（需填写理由）` | 教职员代选课、退课和撤课、移出候补和立即递补。按组织单位范围分配时，只能处理该单位开设的班级 |
| `设置和解除选课限制，批准规则例外` | 选课限制、规则例外。按范围分配时，只能处理该范围内的学生 |
| `管理选课规则集和学分上限` | 按学期的规则集、学分上限 |

角色默认值：学籍管理员拥有全部四项权限，教务管理员拥有查看和规则、学分上限，院系助理拥有查看和选课调整（按院系范围分配）。

列表只显示可以查看学籍的学生，以及权限范围内班级的选课。数据库的行级安全也适用同样的范围。

## 与旧系统的不同之处

- 旧系统（YUSTIC）中按学号位数或院系代码硬编码的规则（学分上限、排除学分银行课程等）改为**按学期设置**。旧系统的 YUST 规则可通过安装配置文件 `yust-legacy` 重现（见下文）。
- 申请被拒绝时**一次显示所有原因**（旧系统在第一个原因处停止）。所有尝试和每条规则的结果都记入**选课尝试记录**。
- 不重现旧系统中 14 级以后护理学部学分上限的错误（应为 21 学分却应用了 18 学分）。按 21 学分处理。
- 选课过程中没有教材购买录入。

## 学期准备顺序

1. **业务期间**（[第 10 章](10-terms.md)）：选课购物车、选课（按年级分时开放）、加退选、退课。加退选和退课按时段设置。
2. **选课规则 > 准备学期规则**：选择学期，再选择要复制的上一学期。留空则从默认值开始。没有规则集的学期适用默认值。
3. **学分上限**：按学期类型和适用学生设置上限（见下文）。
4. **开课**：容量、预留名额（保留名额和转换时间）、**候补人数**（[第 18 章](18-sections-and-timetables.md)）。班级必须**发布**后才能接受选课。
5. **选课限制**：录入未缴费者等名单（可用 CSV，[第 9 章](09-csv-import.md)）。
6. 检查：`uv run manage.py registration_preflight 2027-SP`（[运维命令](../operations/commands.md)）。确认期间、规则集、容量，以及没有适用学分上限的学生数。

## 规则

规则按下列顺序全部检查。**期间、开课状态、名额**始终适用，不在列表中。

| 规则 | 内容 | 参数 |
|---|---|---|
| 选课时间 | 符合学生对象条件的业务期间必须开放。退课须在选课期间或该课程时段的加退选期间，撤课须在时段的退课期间 | 无 |
| 选课限制 | 存在阻止选课的限制时拒绝 | 无 |
| 学籍状态 | 只有所选学籍状态（默认：在读）可以选课 | 允许的状态 |
| 选课对象 | 班级的选课对象和排除条件 | 无 |
| 同一课程重复 | 同一学期同一课程只能选一次 | 无 |
| 时间冲突 | 与已选的其他班级时间重叠时拒绝。日期不重叠的上半学期和下半学期不算冲突 | 允许重叠（分钟） |
| 学分上限 | 已选学分合计 ≤ 适用的学分上限。课程的"计入学期学分上限"属性关闭的课程不计入 | 无（在学分上限界面设置） |
| 先修课程 | 先修课程已修完（认可替代课程、最低成绩），同修课程在同一学期选课也算 | 无（在课程界面设置） |
| 重修 | 已修完的课程能否再修 | 允许重修、最多次数、仅限低于此成绩 |

规则集界面列出各条规则，点击行中的**编辑**打开该规则的界面。每条规则分别设置。

- **启用**：关闭后不检查。
- **不满足时**：阻止或仅警告。仅警告时选课成功，只向学生显示消息。
- **允许例外**：开启后，规则例外和教职员选课时的"不适用的规则"才生效。选课限制和同一课程重复的默认值为关闭。
- 参数只在对应规则中显示（学籍状态：允许的状态；时间冲突：允许重叠（分钟）；重修：允许重修、最多次数、成绩标准）。留空的可选项表示"不限制"。

重修自动判定，并在选课记录中标记**重修**。重修的成绩处理在第 6 阶段。

新版本向规则目录添加规则时，安装（`setup_install`）会以默认值把该规则加入现有规则集。管理员修改过的设置保持不变。

## 学分上限

设置学期类型（留空则为所有学期类型）、适用学生（年级、入学年份、专业项目、组织单位）、最高学分、优先级。多个上限适用于同一学生时，只使用**优先级最高的**一条。没有适用的上限时不限制（`registration_preflight` 会提示）。

例：旧系统 YUST 规则（`yust-legacy` 配置文件）

| 学期类型 | 对象 | 最高 | 优先级 |
|---|---|---|---|
| 第 1、2 学期 | 2014 年以后入学，护理学部（组织代码 `NURS`） | 21 | 40 |
| 第 1、2 学期 | 2014 年以后入学 | 18 | 30 |
| 第 1、2 学期 | 2013 年以前入学，护理学部 | 20 | 20 |
| 第 1、2 学期 | 2013 年以前入学 | 17 | 10 |
| 夏季、冬季 | 2014 年以后入学，护理学部 / 其他 | 6 / 5 | 40 / 30 |
| 夏季、冬季 | 2013 年以前入学 | 6 | 10 |

课程代码以 `009`、`900` 开头的学分银行课程，关闭课程的"计入学期学分上限"。配置文件通过 `uv run manage.py setup_install --profile=yust-legacy` 导入（包含韩国大学配置文件）。再次运行会修正同名的上限。

## 名额与候补

- 名额在选课的瞬间锁定班级行后确保。即使多人同时选课也不会超过容量。
- **预留名额**（例：本专业学生 30 个）在转换时间之前只供对应学生使用。剩余的保留名额在转换时间转为普通名额。门户中显示为"空位 · 预留 · 容量"。
- **候补人数**大于 0 时，学生可以对已满的班级**加入候补**。加入候补同样必须通过除名额外的所有规则。
- 因退课、撤课或保留名额转换而出现空位时，按候补顺序**自动递补**（后台任务，同一班级的递补一次只运行一个）。递补时重新检查所有规则。如果其间选了其他课程导致超过学分上限或时间冲突，则移出候补并记录原因。学生会收到邮件。遗漏的情况由每小时运行的 `waitlist_promote` 处理。
- 选课和加退选期间全部关闭后，剩余的候补过期。
- 减少容量时不能少于已选人数。

没有调整候补顺序的功能。要优先让某个学生选入，就为该学生**为学生选课**（容量已满时先增加容量）。

## 学生界面

在门户的**选课**（`/portal/registration/`）中，学生选择学期，按课程代码或课程名称查找后选课、加入购物车、加入候补。界面显示选课时间状态（开放、仅购物车、开始时间）、已选学分/学分上限和课表。手机上课表按星期显示为列表。

- **购物车**：在购物车期间先放入，选课开放后**全部选课**。放入时会预先检查规则并提示问题，但除期间、开课状态、同一课程重复外不阻止放入。选课时再次检查。
- 退课和撤课按钮随业务期间变化。撤课的课程在记录中保留为**已撤**（成绩 W 在第 6 阶段）。
- 选课、加入候补、加入购物车、全部选课每人每分钟最多 30 次。

## 选课情况与教职员调整

**选课情况**：按学期、状态筛选，按学号或姓名查找。默认显示本学期（或下学期）已选状态的记录。

**为学生选课**（选课情况上方，或开课界面上方的按钮）：输入学号、班级（仅从选课情况打开时：本学期已发布的班级）、不适用的规则、满员时是否加入候补、理由。

- 检查与学生相同的规则。**选课时间不适用于教职员选课。**
- "不适用的规则"须该规则的**允许例外**已开启才生效。开课状态和名额不能选择（须增加容量）。
- 结果（已选、进入候补、拒绝及原因）以界面上方的消息显示。连同理由一起记入业务审计。

**退课、撤课**：在选课情况的行菜单，或开课界面**课程名单**标签页的**退课**、**撤课**中填写理由后操作。与业务期间无关，随时可以操作。出现空位时接着递补候补。

**候补名单**标签页（设有候补人数或有候补记录的班级）：按申请时间排列，显示状态和结果说明。用行中的**移出候补**填写理由后移出。增加容量后，用界面上方的**立即递补**马上递补。

## 选课限制与规则例外

**选课限制**（旧系统的选课拒绝 `SRDENY`）：在**设置限制**中输入学号、类型（未注册、财务、学业、行政、其他）、效果（限制选课 / 限制查看成绩 / 限制开具证明）、开始和结束、理由。限制查看成绩和限制开具证明默认关闭。除欠缴学费外，也用于作弊调查等需要暂时冻结成绩的行政处理。设置了限制查看成绩后，学生无法查看门户成绩界面和成绩单（[第 21 章](21-grades.md)，第 6 阶段起适用）。对教职员界面和教师的成绩录入没有影响。设置了限制开具证明后，教职员无法为其开具证明（[第 23 章](23-certificates.md)，第 8 阶段起适用）。不删除，而是在行中填写理由后**解除**。默认列表为生效中的限制。列表上方的 **CSV 导入**可以一次录入名单（[第 9 章](09-csv-import.md#选课限制)）。

**规则例外**（旧系统的选课允许 `SRALLOW`）：在**批准例外**中输入学号、学期、规则、适用范围（留空为整个学期，或以 `课程代码-班号` 指定班级、以课程代码指定课程）、到期、理由。有例外时，即使该规则不满足也能选课（前提是该规则已开启允许例外）。期间规则也可以用例外开放（例：错过期间的拟毕业生）。开课状态和名额没有例外。不再需要时在行中**撤销**。

## 选课尝试记录

所有选课、退课、撤课、候补、递补、加入购物车的尝试，连同时间、结果、未满足的规则和消息、操作人、请求 ID 一起保留。可按学期、结果、操作筛选，按学号查找。"为什么选不上课"的咨询可以按学号查找确认。现在选课会是什么结果，可以用 `uv run manage.py registration_simulate {学号} {课程代码-班号}` 预先查看（不保存，也不留记录）。
