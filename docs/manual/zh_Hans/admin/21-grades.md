# 21. 成绩

菜单：**成绩 > 成绩处理进度**、**成绩更正**、**学期记录**、**设置 > 成绩处理政策**。教师使用门户的**我的授课 > 成绩录入**。

| 权限 | 可以做的事 |
|---|---|
| `查看成绩、成绩处理进度和学期记录` | 查看成绩处理进度、学期记录、学生成绩单 |
| `确定和退回成绩、代教师录入成绩、学期结算` | 确定和退回班级成绩、代教师录入（不受期间限制）、超出等级比例的例外提交、学期结算、重新计算。按组织单位范围分配时，只能处理该单位开设的班级 |
| `教职员超出等级比例例外提交成绩时接收通知（系主任、教务负责人）` | 接收例外提交通知。按组织范围分配给系主任、教务管理员 |
| `申请更正已确定的成绩` | 对非本人任教班级的更正申请（例：因作弊取消成绩） |
| `批准或驳回成绩更正（本人申请除外）` | 处理更正申请 |
| `管理绩点、重修、学业警告和成绩优秀政策` | 设置成绩处理政策 |

任课教师无需权限即可录入自己班级的成绩并申请更正。角色默认值：学籍管理员拥有查看、确定、批准、例外提交审核，教务管理员拥有查看、申请更正、政策管理，证明书管理员和院系助理拥有查看。评价方式更改申请由`编排开课`权限处理。

## 与旧系统的不同之处

- 旧系统（YUSTIC）中教授保存成绩后即为最终成绩，教务处直接在界面上修改。没有理由和审批流程，部分账户的修改甚至不留在备份记录中。新系统设置**录入 → 提交 → 确定**三个阶段，已确定的成绩只有**更正申请经他人批准**后才能更改。应用程序和数据库（触发器）都会阻止。
- 旧系统中教授可以通过篡改请求保存非本人任教班级的成绩。新系统在服务器和数据库中检查任课教师和权限范围。
- 绩点、学业警告、成绩优秀不再在每个界面临时计算，而是保存为**学期记录**。学期结算时成为该学期的正式记录。
- 重修在新成绩**确定之后**才从累计绩点中扣除以前的成绩（旧系统在选课瞬间扣除，停开也不恢复）。
- 旧系统只禁用了成绩菜单，直接输入地址仍能看到成绩。新系统在服务器端应用限制查看成绩。

## 学期顺序

1. **业务期间**（[第 10 章](10-terms.md)）：按时段设置**成绩录入**期间。教师只能在此期间录入和提交。
2. 教师录入并提交成绩。用 `uv run manage.py grades_remind_missing {学期}` 向未提交的教师发送提醒邮件。
3. 在**成绩处理进度**中按班级确定或退回给教师。
4. 所有班级确定后，**学期记录 > 学期结算**。学期记录、学业状态、成绩优秀随之确定，学期变为**成绩已关闭**状态。
5. 此后要更改的成绩通过**成绩更正**处理。

## 成绩等级标准与评价方式

**成绩等级标准在安装时确定，不能更改**（2026-10-23 决定）。因为成绩和绩点都基于该标准。通过 `uv run manage.py setup_install --grade-scale=4.5|4.3` 指定，未指定时采用第一个配置文件的标准（韩国大学 4.5，旧系统 YUST 4.3）。基础数据 > 成绩等级中的**默认**标记不能更改，默认标准不能删除。各等级的**分数区间**（下限、上限 %）和绩点在同一界面修改（[第 11 章](11-course-categories-and-grade-scales.md)）。

每个班级都有**评价方式**。默认为**绝对评价**。

| 评价方式 | 教师录入 | 保存 | 提交条件 |
|---|---|---|---|
| 绝对评价（默认） | 每位学生的**分数（0~100）**。成绩由分数区间决定，不能选择（只有没有分数的成绩，如 I，才直接选择） | 分数（原始）、成绩、绩点 | 所有学生都有成绩 |
| 相对评价 | 每位学生的**成绩**。不录入分数（录入即拒绝） | 成绩、绩点 | 所有学生都有成绩 + 遵守**等级比例上限** |
| 通过/不通过课程 | 与评价方式无关，P/NP | 成绩 | 所有学生都有成绩 |

- 希望采用相对评价的教师在成绩录入界面**申请相对评价**（填写理由）。开课单位拥有`编排开课`权限的人员（院系助理、教务管理员）在**成绩 > 评价方式更改申请**中批准或驳回（必须填写意见），结果通过邮件通知教师。批准后，按原方式暂存的成绩将被清除。成绩**提交之后**不能申请也不能更改。教职员也只能在开课班级界面、录入成绩之前更改。
- 重修最高成绩：绝对评价中，分数对应的成绩高于上限时**降为上限成绩**（分数不变）。相对评价中不能选择高于上限的成绩。

## 等级比例上限（相对评价）

**设置 > 成绩处理政策 > 相对评价**：各等级组的上限（默认 A 组 30%、B 组 40%）、超出上限的允许幅度（默认 1 个百分点）、检查的最少学生数（默认 10 人）。

- 等级组按字母划分。A+、A0、A- 属于 A 组，B+、B0、B- 属于 B 组。没有上限的等级组（C、D、F）不限制。
- 比例的分母是该班级中获得计入绩点成绩的学生数。撤课学生和 P/NP/I 不计入。
- 少于最少学生数的班级不检查（7 人中 A 占 30% 无法满足）。
- 教师通过成绩录入界面的**检查等级比例**查看当前分布和上限，超出上限时**不能提交**。
- 拥有成绩管理权限的教职员即使超出上限也能提交，但属于**例外提交**。必须填写理由，业务审计中记录分布和理由，向拥有`成绩例外提交`审核权限的人员（按组织范围分配的系主任、教务管理员等）发送邮件，班级上留下**例外提交**标记。在**成绩处理进度**中可以只筛选例外提交的班级。

## 成绩录入（教师）

在门户的**我的授课**中打开班级的**成绩录入**。界面上方显示班级的评价方式、录入说明和评价方式更改申请。

- 绝对评价：输入分数后立即显示成绩。
- 相对评价：只选择成绩。没有分数栏。用**检查等级比例**确认上限后提交。
- 成绩列表遵循课程的成绩评定方式。普通课程显示等级，通过/不通过课程显示 P/NP（[第 11 章](11-course-categories-and-grade-scales.md)）。
- **暂存**随时可以进行。学生看不到暂存的成绩。
- **提交成绩**要求所有学生都有成绩。提交后教师不能再修改。错误的成绩在确定前请教务人员退回，确定后则申请更正。
- 撤课的学生显示为 W，不录入成绩。

## 确定与退回（教务人员）

**成绩处理进度**：按学期列出班级以及未提交、已提交、已确定的数量。**可确定**筛选只显示所有学生成绩都已提交的班级。

- **确定**：确定已提交的成绩。选课变为**已修完**状态，学生可以看到成绩。学生的学期记录重新计算。也可以选择多个班级**确定所选课程**。有未提交学生的班级会跳过。
- **退回教师**：填写理由后取消提交。成绩回到暂存状态，并向教师发送邮件。
- **成绩**：打开成绩录入界面。教务人员可以不受期间限制，在确定前录入或修改成绩。教职员修改教师**已提交**的成绩时，原值和新值记入审计 `grades.submitted_changed`。

## 成绩更正

更改已确定成绩的唯一方法。

1. 申请：教师在成绩录入界面对该学生**申请更正**（填写理由，绝对评价填更正后分数，相对评价填更正后成绩）。重修上限同样适用于更正。非本人任教的班级，由拥有`申请更正已确定的成绩`权限的教职员在同一界面申请。一个成绩只能有一个进行中的申请。
2. 处理：在**成绩 > 成绩更正**（默认为待处理列表，菜单上显示待处理数量）中**批准**或**驳回**（必须填写意见）。申请人不能处理自己的申请（数据库约束同样阻止）。
3. 批准后成绩（绝对评价为分数和成绩）立即更改，学生的学期记录和之后学期的累计绩点重新计算。学业状态和成绩优秀保持学期结算时确定的值。

申请人可以**撤回申请**待处理的申请。所有申请和处理连同理由一起记入业务审计。

## 绩点计算

| 项目 | 规则 |
|---|---|
| 修读学分 | 所有已确定的课程（包括 F、P、NP、I） |
| 获得学分 | 通过等级（不含 F、NP、I） |
| 计绩点学分 | 计入绩点计算的等级。F 按 0 分计入，P/NP/I 不计入 |
| 绩点 | 合计（绩点 × 学分）÷ 计绩点学分。只修了通过/不通过课程的学期没有绩点 |
| 位数 | 政策中的小数位数和位数处理（四舍五入、舍去）。采用整数运算，边界值（例：3.4375 → 3.438）没有误差 |
| 学期绩点 | 反映该学期的全部成绩（因重修被替代的以前成绩仍保留在该学期绩点中） |
| 累计绩点 | 重修的课程按政策只反映一次。**最近成绩**（默认，即使更差也取最近的）或**最高成绩**。被替代的成绩也从累计学分中扣除，成绩界面显示"因重修不计入累计绩点" |

重修关系在选课时确定（[第 20 章](20-registration.md)）：再次修读同一课程或替代课程时，与以前的选课关联。

## 学业状态与成绩优秀（学期结算）

| 政策 | 默认值 | 旧系统 YUST 配置文件 |
|---|---|---|
| 学业警告标准 | 学期绩点低于 1.75 | 低于 1.3 |
| 只判定正常学期 | 是 | 是 |
| 退学审查警告次数 | 0（关闭） | 4 |
| 只计算连续警告 | 否（总次数） | 否 |
| 成绩优秀最低绩点、最低计绩点学分 | 4.0、15 学分 | 0、0（旧系统为简单的前 N 名） |
| 有 F 则不评成绩优秀 | 是 | 否 |
| 绩点位数 | 2 位四舍五入 | 3 位四舍五入 |
| 成绩等级标准（安装时确定） | 4.5（KR45） | 4.3（YUST43） |
| 等级比例上限（相对评价） | A 30%、B 40%、允许 1 个百分点、10 人以上检查 | 相同 |

- **学业警告**：学期绩点**低于**标准。只修了通过/不通过课程的学期不警告。
- **退学审查**：警告次数达到标准时标记。退学本身通过学籍异动（[第 13 章](13-status-changes-and-advisors.md)）处理。
- 只判定正常学期时，夏季、冬季学期没有学业状态，也不中断连续警告。
- **成绩优秀**：对满足标准的学生按专业项目以学期绩点排名（同分同名次，下一名次跳过）。
- 学生学籍的**学业状态**更新为最近一次判定。业务期间或选课对象条件中的"学业状态"使用此值。

在**学期记录**界面按学期、学业状态、成绩优秀、专业项目筛选，查看学业警告名单和成绩优秀名单（旧系统的学业警告、成绩优秀报表）。**学期结算**先以**仅预览**（默认）运行，查看未确定的班级后，关闭该选项再次运行。**重新计算**用于更改政策后应用到以往学期记录（必须填写理由）。

## 学生界面与成绩单

教职员打开学生的成绩单时，记入审计 `transcript.viewed`（含学号）。

- 门户**成绩**：按学期的已确定成绩（撤课为 W）、学期绩点和获得学分、累计绩点、学业状态、成绩优秀。校友也可以查看。未确定的成绩不显示。
- **打印**：供核对用的成绩单（非正式）。正式成绩证明通过开具证明生成（[第 23 章](23-certificates.md)）。教职员通过学籍界面或学期记录的**成绩单**打开学生的成绩单（`查看成绩`权限）。
- 在**选课限制**中开启**限制查看成绩**的学生无法查看成绩界面和成绩单（[第 20 章](20-registration.md)）。
- 课程评价期间内未完成该学期课程评价的学生，该学期成绩被隐藏（设置，[第 22 章](22-course-evaluation.md)）。

## 成绩处理政策

**设置 > 成绩处理政策**（`管理绩点、重修、学业警告和成绩优秀政策`权限）。修改上表中的项目。更改后的政策从之后的计算开始适用。要应用到以往学期记录，请**重新计算**。学业状态和成绩优秀在学期结算时确定，因此不会重新应用于已结算的学期。

## 本系统的界面

界面和功能与原系统（Filament、Livewire）相同，操作方式略有不同。

- **成绩处理状况**的行菜单：**成绩**（门户的成绩录入界面）、**确定**（确认界面）、**退回给教师**（填写理由的界面）。要一次确定多个课程班，在列表中选择后在操作列表中选择**确定所选课程班**。筛选：学期（默认为进行中的学期，选**全部**显示所有学期）、开课单位、例外提交、可确定。
- **成绩更正**和**评价方式变更申请**行菜单中的**批准**、**驳回**会打开填写意见的界面。默认列表为待处理的申请，菜单上显示待处理件数。
- **学期记录**列表上方的**学期结算**：学期、**仅预览**（默认开启）、理由。预览以消息显示能否结算以及未确定的课程班（最多 30 个）。开始结算后以每 100 名学生为单位的队列任务（Celery）进行，进行中的结算在学期记录列表上方显示进度。完成后学期状态变为**成绩已关闭**，并向发起结算的职员发送邮件。某个任务失败时结算不会完成，学期保持不变；排除原因后再次结算（重新执行结果相同）。命令行：`uv run manage.py term_close {学期} --dry-run`、`uv run manage.py term_close {学期} --reason=...`（[运维命令](../operations/commands.md)）。
- **成绩处理政策**中的等级比例上限按 `A=30, B=40` 的形式用逗号连接等级字母和百分比填写。留空表示没有上限。
- 门户成绩录入：绝对评价时输入分数后稍等片刻，旁边会显示成绩。**暂存**、**检查等级比例**、**提交成绩**按钮在界面下方；保存失败时（例如分数超出范围）会连同错误再次显示所输入的值。点击学生行的**申请更正**，表格下方会打开填写栏。
- 职员用成绩单地址：`/student-records/{学籍 ID}/transcript/`（学籍界面的**成绩单**按钮、学期记录行的**成绩单**）。末尾加 `?format=pdf` 即为 PDF。
- 已关联 LMS 的课程班可在成绩录入界面把 LMS 分数作为草稿导入（[第 28 章](28-lms-integration.md)）。评价期间内未完成课程评价的学期成绩会被隐藏，并显示提示和**课程评价**链接（[第 22 章](22-course-evaluation.md)）。
