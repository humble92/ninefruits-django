# 18. 开课班级与课表

菜单：**培养方案与开课 > 开课**、**课表**（`查看开课`、`编排开课（任课教师、时间、教室）`权限。按组织单位范围分配时，只能处理该单位开设的班级）

## 创建开课班级

1. 在**开课 > 创建**中输入学期的时段、课程、班号（例：`01`）、容量、开课单位。课程名称和学分来自时段开始日期生效的课程版本。
2. 在编辑界面的标签页中输入**上课时间**、**任课教师**、**预留名额**。
3. 完成后**发布**。只有已发布的班级才会显示在门户的**开课查询**中并成为选课对象（[第 20 章](20-registration.md)）。

| 状态 | 含义 |
|---|---|
| 草稿 | 编排中。只有管理员和任课教师可见 |
| 已发布 | 学生可见。可以**改回草稿** |
| 已停开 | 必须填写原因。教室和教师的时间被释放。**重新开放**后变为草稿；如果其间其他班级占用了该时间，则无法重新开放 |

只有草稿状态的班级可以删除。已发布过的班级要用停开处理。

| 项目 | 说明 |
|---|---|
| 时段 | 学期的时段（[第 10 章](10-terms.md)）。移到其他时段时，上课日期和课程版本会按该时段调整 |
| 选课对象、排除对象 | 年级、入学年份、专业项目、组织单位。例：通识课程排除本专业学生。第二专业和辅修学生也视为该专业的学生 |
| 授课语言 | 例：`ko`、`en` |
| 候补人数 | 容量满后可接受的候补人数。0 表示不设候补（[第 20 章](20-registration.md)） |
| 评价方式 | 绝对评价（默认。教师录入分数，成绩由分数计算）或相对评价（只录入成绩，适用等级比例上限）。由教师在成绩录入界面申请更改，开课管理员批准。录入成绩后不能更改（[第 21 章](21-grades.md)）。从其他学期复制时一并复制 |

## 上课时间与教室

在**上课时间**标签页中输入星期、开始/结束时间和教室。选择**节次**后时间会自动填入。上课日期留空则为时段期间。

- 同一教室在同一时间不能被两个班级使用，一名教师在同一时间不能承担两个班级。由数据库阻止，界面会显示冲突的班级，如"该时间教室已被 OOO 使用"。
- 像上半学期和下半学期这样日期不重叠的情况，可以使用同一时间、同一教室。
- 已停开的班级不占用时间。

## 任课教师

在**任课教师**标签页中指定教师和角色（任课教师、合作教师、助教）。一个班级可以指定多人。已在同一时间承担其他班级的教师无法指定。任课教师在门户的**我的授课**中管理课表和教学大纲。

## 预留名额

在**预留名额**标签页中按对象学生设置名额（例：本专业学生 30 个）。过了**转为普通名额时间**后，未使用的名额任何人都可以申请。预留名额的合计不能超过容量。在选课中生效（[第 20 章](20-registration.md)）。

## 教学大纲

由任课教师在门户的**我的授课**中编写（也可以通过开课班级界面的**教学大纲**按钮打开）。输入课程概述、学习目标、教材与资料、课程规定、考核方式（项目和比例）、每周安排，**发布**后学生可见。

## 从其他学期复制

通过开课班级列表的**从其他学期复制**，以上一学期（通常是去年同一学期）的编排为起点。先用**仅预览**确认结果。

- 将未停开且在本人权限范围内的班级复制为草稿状态。
- 一并复制：在职的任课教师、上课时间和教室、预留名额（转换时间按学期开始日期的差值平移）、教学大纲（未发布的草稿）。
- 时段按代码匹配（没有则为整个学期）。课程版本以新时段开始日期为准。
- 目标学期已有相同班号时跳过；教室已被占用时不含教室复制。结果通知中会列出跳过的班级和需要确认的班级。

IT 运维人员可以用 `uv run manage.py section_copy` 完成同样的操作。

## 课表与检查

- **课表**：选择学期以及教室或教师后，显示周课表。
- 发布前检查：IT 运维人员用 `uv run manage.py schedule_check_conflicts <学期代码>` 查找教室容量小于班级容量、任课教师已离职、课程版本不一致、预留名额超过容量等问题（[命令参考](../operations/commands.md#schedule_check_conflicts)）。

## 权限范围

列表和界面只显示 `查看开课`、`编排开课` 权限范围内开课组织的课程班。上课时间、任课教师、预留名额标签页和状态按钮（发布、退回草稿、停开、重新开放）需要覆盖课程班开课组织的 `编排开课` 权限。课表页面默认选择正在上课的学期（没有则为下一学期）。在手机上按星期以列表显示。
