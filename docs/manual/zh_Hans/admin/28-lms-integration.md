# 28. LMS 对接

菜单：管理界面 **LMS 对接 > LMS 平台**、**课程关联**、**同步日志**（`管理 LMS 平台、关联和同步`权限，默认：系统管理员、教务管理员）。教师使用门户**我的授课**和班级详情中的 LMS 链接，以及成绩录入中的**从 LMS 导入分数**。导入的条件与成绩录入相同（任课教师在成绩录入期间内）。

开发者详细说明（实现连接器、API）见 [LMS 对接指南](../../../lms-integration-guide.md)。

## 什么数据流向哪里

| 教务 → LMS | 时点 |
|---|---|
| 开课班级（创建课程）+ 任课教师 | 班级**发布**时，以及 `lms_sync` |
| 选课确定 → 注册 | 选课、候补递补、教职员代选课后立即 |
| 退课、撤课 → 取消注册 | 立即 |
| 全量核对 | 每天 02:30（`lms_reconcile`，定时任务 `lms.reconcile`） |

| LMS → 教务 | 时点 |
|---|---|
| 最终分数（草稿） | 教师在成绩录入中点击**从 LMS 导入分数**时。保存和提交由教师完成 |

已确定的成绩不会发送到 LMS。教学资料、作业、测验都在 LMS 内。

## 平台

**LMS 平台**：代码、名称（各语言）、驱动、基础 URL、凭据、是否启用、同步选课名单、拉取最终分数。

- 驱动**无（仅记录）**：不调用任何接口，只记录将要发送的内容。用于对接前检查流程或演示。演示数据中的 `DEMO` 平台就是这种。
- `Moodle`、`Open edX`：连接器尚未实现（显示"尚未实现"）。选择后同步会记录为失败。
- 开启**启用**后，课程发布和选课变动即时传送，并成为每夜核对的对象。
- **凭据**每行写一个 `键=值`（例如 `token=...`）。加密存储，不会再显示。编辑时留空则保留已存储的值。数据变更记录中也不保留其值。

## 课程关联与同步日志

- **课程关联**：哪个开课班级关联到哪个平台课程（ID、URL）、状态（待处理/已关联/失败）、最近同步和错误。可按平台、状态、学期筛选，按课程代码搜索。行操作**重新同步**（经确认页面）重新推送班级、教师和学生。
- **同步日志**：按步骤（课程、添加和移除成员、拉取分数、成绩送达、核对）的结果和消息。失败原因在这里查看。打开一行可看到开始、结束时间和内容（payload）。
- 命令：`uv run manage.py lms_sync {平台} --term={学期}`（全量推送，`--dry-run`）、`uv run manage.py lms_reconcile`（核对）。见[运维命令](../operations/commands.md)。

## 门户

- 学生和教师的班级详情以及教师的**我的授课**列表（**LMS** 列）中显示平台课程链接（仅已关联的班级）。
- 成绩录入：平台开启了**拉取最终分数**且班级已关联时，显示**从 LMS 导入分数**按钮。只填充分数栏，不保存。

## 外部对接 API

为稍后回报结果或自行发送分数的平台提供了 API（`/api/v1/lms/platforms/...`）。另建一个对接专用账户，只授予`管理 LMS 平台、关联和同步`权限；由运维人员用 `uv run manage.py api_issue_token {邮箱} --days=365` 签发令牌并交给平台管理员。令牌只在签发时显示一次。用 `api_revoke_tokens` 撤销。签发和撤销都会记录在审计日志中。

- 通过成绩送达（`.../scores/`）收到的分数同样不会保存。教师点击**从 LMS 导入分数**时，最近收到的分数作为草稿填入。
- 同步结果（`.../sync-results/`）记录在**同步日志**中，课程结果会改变**课程关联**的状态。

## 常见问题

- **学生不在 LMS 中。** 学生必须有账户（用户）才能同步。没有账户时，邀请后（[第 14 章](14-merge-and-invitations.md)）在下一次核对时添加。
- **同步一直显示失败。** 查看日志中的消息。凭据过期很常见。在平台编辑中更改值后**重新同步**。
- **更换了平台。** 创建新平台并关闭旧平台的启用。关联按平台分别生成。

## 本安装中的界面

界面和功能与原系统（Filament、Livewire）相同，部分操作方式不同。

- 凭据在多行输入框中以 `键=值` 填写，代替原系统的键/值表格。格式错误的行会连同行号一起被拒绝。
- 平台的**选项**（各平台的角色 ID 等）在界面上没有输入项。连接器需要时由开发者设置（[对接指南](../../../lms-integration-guide.md)第 3 节）。
- **重新同步**需经过确认页面。连接器错误（没有连接器的驱动、平台故障）显示为"同步失败：..."消息，课程关联变为"失败"（原系统显示错误页面）。
- 同步日志为只读。打开一行会以 JSON 显示内容（payload）。
- 成绩录入中的**从 LMS 导入分数**位于表格下方的按钮行。点击后保留已输入的值，只更换分数栏并重新显示页面。点击**暂存**后才会保存。
- 外部对接 API 和令牌命令（`api_issue_token`、`api_revoke_tokens`）是本安装新增的（原系统没有 API）。
