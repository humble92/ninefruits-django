# 7. 组织单位与专业项目

菜单：**基础数据 > 组织单位类型**、**组织单位**、**专业项目**

## 组织单位

大学、学院、系、专业、行政部门在同一界面管理。替代旧系统（YUSTIC）的学院（`SFCOLLEGE`）和系（`SFDEPARTMENT`）。

| 项目 | 说明 |
|---|---|
| 代码 | 不会更改的标识代码。例：`CSE` |
| 类型 | 大学、学院、系等（可在组织单位类型界面添加） |
| 名称、简称 | 按语言填写 |
| 上级 | 所属单位。不能移到自身或其下级单位之下 |
| 生效日期、失效日期 | 单位存在的期间。失效日期为空表示目前仍在运行 |

- 列表默认只显示 **仅当前有效** 的单位。关闭筛选后也会显示过去的单位。
- 在角色分配中选择组织单位作为范围时，其下属所有单位都包含在内。例：工学院范围 = 工学院下属所有系。

## 组织重组

过去的学籍和成绩必须指向当时的单位，因此不直接改写单位，而是以 **重组** 记录。

1. 打开即将消失（变更）的单位的 **编辑** 界面。
2. 点击 **组织重组**。
3. 选择变更类型。
   - **更名**：先创建新名称的单位，再指定为承接单位
   - **合并**：多个单位合为一个时，在每个单位中指定同一承接单位
   - **拆分**：一个单位分为多个时，指定多个承接单位
   - **隶属变更**：移到其他上级单位下的新单位时
4. 填写 **重组生效日期** 和原因。单位在生效日期前一天结束，并在下方的 **承接单位** 列表中留下记录。

单纯的错别字修正不用重组，而是用名称 **编辑**（会记录在数据变更记录中）。

## 专业项目

学位项目或专业课程。学生学籍隶属于专业项目（Phase 2）。

| 项目 | 说明 |
|---|---|
| 代码、名称、学位名称 | 学位名称例：工学学士 |
| 学位层次 | 专科、学士、硕士、博士、结业证书、非学位 |
| 组织单位 | 运行的系 |
| 学制 | 标准修读年限（年） |
| 生效日期、失效日期 | 不是接收新生的期间，而是项目存在的期间 |
| 接受第二专业、接受辅修 | 其他专业项目的学生能否申请将本项目作为第二专业或辅修（[第 19 章](19-second-majors-and-minors.md)） |
