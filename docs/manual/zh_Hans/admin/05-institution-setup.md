# 5. 机构设置与初始设置顺序

## 机构设置

在 **设置 > 机构** 中设定（`管理机构设置` 权限）。

| 项目 | 说明 |
|---|---|
| 机构名称 | 按语言填写。显示在管理界面左上角 |
| 时区 | 判断学期日期和业务期间的基准。例：`Asia/Seoul`。所有保存的时间都按此时区显示 |
| 提供的语言 | 用户可选择的语言。只有已安装翻译文件的语言才会出现在列表中 |
| 默认语言 | 未选择语言的用户以及无法识别浏览器语言时使用的语言 |

## 新建大学的初始设置顺序

IT 运维人员完成 `setup_install` 后（运维手册 [安装](../operations/installation.md)），业务管理员按以下顺序录入。后面的步骤会引用前面步骤的代码，请遵守顺序。

1. **机构设置**：名称、时区、语言（本章）
2. **代码数据**：民族、入学类别、教室用途的值（[第 6 章](06-code-data.md)）。安装时如果应用了韩国大学配置档，教室用途已经存在。
3. 确认 **组织单位类型** 后录入 **组织单位**：按大学 → 学院 → 系的顺序（[第 7 章](07-org-units-and-programs.md)）。数量多时用 CSV（[第 9 章](09-csv-import.md)）。
4. **专业项目**：各系的学位项目（[第 7 章](07-org-units-and-programs.md)）
5. **楼宇**、**教室**（[第 8 章](08-facilities.md)，可用 CSV）
6. 确认 **学期类型**、**节次**（[第 10 章](10-terms.md)）
7. 确认 **课程类别**、**成绩等级制**。必须指定一个默认等级制（[第 11 章](11-course-categories-and-grade-scales.md)）
8. **学年** → **学期** → 各学期的 **业务期间**（[第 10 章](10-terms.md)）
9. **用户与权限**：像系助理这样需要组织单位范围的角色，现在可以选择系作为范围对象（[第 2 章](02-users-and-roles.md)）

录入完成后，请 IT 运维人员用 `uv run manage.py term_inspect` 检查业务期间。
