# 2. 用户与角色

## 概念

| 术语 | 含义 |
|---|---|
| 权限 | 使用某一项功能的资格。例：`查看用户`、`重置双重身份验证` |
| 角色 | 权限的集合。例：学籍管理员、系助理 |
| 角色分配 | 为用户指定角色，并限定范围和期间 |
| 范围 | 角色生效的地方。**全部**、**组织单位**（学院、系等）、**专业项目** |
| 身份角色 | 申请人、学生、校友、教师、指导教师。根据教务数据自动授予，不能手动分配 |

业务负责人变动时，无需修改程序，只需调整角色构成或分配即可。所有更改都会留在审计记录中。管理界面菜单和各界面中的按钮也会随权限立即变化。不使用 Django 默认的"组"和"超级用户"。

## 创建用户账户

1. 在 **用户与权限 > 用户** 中点击 **添加用户**。
2. 输入姓名、电子邮箱、语言，点击 **保存**。
3. 系统会向用户发送设置密码的邮件链接。管理员无法得知密码。

账户不删除。因离职等原因停止使用时，打开用户界面，关闭 **启用** 后保存。停用的账户无法登录，所有权限随之失效。已登录的界面也会在下一次请求时立即退出。

账户编辑的安全机制

- 不能停用自己的账户。
- 不能编辑拥有本人不具备权限的账户（权限更高的管理员）。
- 更改电子邮箱后，邮箱验证会被重置，该用户的所有登录会话结束，并记录安全事件 `邮箱已更改`。
- 用户更改密码后，其他设备的会话和已记住的设备结束，并记录安全事件 `密码已更改`。

## 创建与编辑角色

1. 在 **用户与权限 > 角色** 中点击 **添加角色**，或从列表中打开角色。
2. **内部名称** 使用小写英文字母和下划线（例：`exam_office`）。创建后最好不要再更改。
3. **显示名称** 按语言填写。英文名称为必填。将某语言的栏位清空会删除该语言的名称。
4. 在 **权限** 中按功能勾选。保存后，新增/移除的权限会记录在审计记录中。

| 角色种类 | 编辑 | 删除 |
|---|---|---|
| 系统角色（系统管理员） | 仅名称。权限始终为全部 | 不可 |
| 身份角色 | 显示名称和权限。内部名称不可 | 不可 |
| 一般角色 | 全部 | 仅在当前没有分配时 |

## 角色分配

1. 在 **用户与权限 > 用户** 中打开用户。界面下方的 **角色分配** 列表显示当前和过去的分配。
2. 点击界面上方的 **分配角色**，输入角色、范围、开始/结束（可选）和 **原因**。
   - 范围为组织单位或专业项目时，在 **范围对象** 中选择。选择组织单位时，其下属所有单位都包含在内。
   - 开始留空表示立即生效，结束留空表示无限期。
3. 分配不做修改。需要变更时，先点击现有分配的 **结束分配**（必须填写原因），再重新分配。历史记录会完整保留。

不能结束自己的分配（职责分离）。请委托其他管理员处理。

防止权限提升的规则

- 不能为自己分配角色。
- 不能分配包含本人不具备权限的角色。
- 范围只能在本人 `分配和结束角色` 权限的范围内选择。例如，仅获得工学院范围的管理员不能分配全部范围或其他学院范围。
- 创建首位管理员的 `security_create_administrator` 命令由服务器运维人员执行，不适用这些规则（[命令参考](../operations/commands.md)）。不能使用 Django 的 `createsuperuser`。
