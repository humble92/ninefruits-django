# 8. 楼宇与教室

菜单：**基础数据 > 楼宇**、**教室**（`管理楼宇与教室` 权限）

## 楼宇

填写代码（例：`SCI`）、名称（按语言）、地址。有教室的楼宇不能删除，不再使用时关闭 **启用**。

## 教室

| 项目 | 说明 |
|---|---|
| 楼宇、房间号 | 房间号在同一楼宇内不重复。例：`101` |
| 名称 | 可选。例：大礼堂 |
| 用途 | 代码数据 `room_type` 的值（教室、实验室等） |
| 组织单位 | 管理的系（可选） |
| 容量 | 排课时与开课人数比较（Phase 4） |
| 用于排课 | 关闭后，排课时不作为分配对象（办公室、仓库等） |

教室数量多时使用 [CSV 导入](09-csv-import.md)。必须先登记楼宇。
