# 17. 课程与毕业要求

菜单：**培养方案与开课 > 课程**、**毕业要求**（`管理课程、版本和先修课程`、`管理毕业要求`权限）

## 课程与版本

课程分为不变的**代码**和按期间划分的**版本**。课程名称、学分、学时、课程类别、成绩评定方式、先修课程都属于版本。旧系统（YUSTIC）用课程代码和开始日期区分课程，但成绩只指向课程代码，无法明确学生修读的是哪个版本。新系统中开课班级和成绩都指向版本。

- 同一课程的版本期间不能重叠（数据库约束）。任一日期只有一个生效版本。
- 开课班级按时段开始日期生效的版本开设。

| 项目 | 说明 |
|---|---|
| 课程代码 | 例：`CSE2010`。代码本身不承载业务含义（旧系统中 `009*` 判定为学分银行课程之类的规则，改用下面的项目代替） |
| 管理单位 | 管理该课程的组织单位。开课班级的默认开课单位 |
| 课程名称、课程简介 | 按语言填写 |
| 学分、理论/实验学时 | 以 0.5 为单位 |
| 课程类别 | 基础数据 > 课程类别 |
| 成绩评定 | 等级制或通过/不通过 |
| 计入学期学分上限 | 关闭后不计入选课学分上限的计算（学分银行课程等） |
| 参与课程评价 | 关闭后不进行课程评价（实习、实训等。[第 22 章](22-course-evaluation.md)） |
| 可重复修读计学分 | 再次修读时不视为重修，而是再次获得学分（主题变化的研讨课等） |

## 课程修订

学分或课程名称变更时，不要直接修改版本，而是进行**修订**。在课程**编辑**界面的**版本**标签页中，点击当前版本的**自某日修订**，输入新版本开始日期、变更后的值和原因。

- 当前版本在新版本开始日期的前一天结束，新版本复制当前版本及其先修课程后开始。
- 已开设的班级和以往成绩仍指向原版本。
- 只有错别字这类不改变含义的修改才直接修改版本（会记入数据变更记录）。

## 先修课程与同修课程

在版本编辑界面下方的**先修与同修课程**中输入。

| 项目 | 说明 |
|---|---|
| 类型 | 先修课程（须先修完）、同修课程（同一学期一起修读，已修完则视为满足） |
| 组 | 同一组内的课程任修其一即可（或）。所有组都须满足（且） |
| 最低成绩 | 默认成绩等级标准中的等级代码（例：`C0`）。留空表示及格成绩 |
| 允许同学期修读 | 允许先修课程在同一学期修读的情况 |

例：第 1 组为 `CSE1001`，第 2 组为 `MAT1001` 和 `MAT1002` → `CSE1001` 且（`MAT1001` 或 `MAT1002`）。选课时由先修课程规则检查（[第 20 章](20-registration.md)）。

## 替代课程

因培养方案改革而更换课程时，在课程**编辑**界面的**替代课程**标签页中连同期间一起输入。开启**相互认可**后两门课程互相替代；关闭时只认可替代课程代替本课程。用于重修判定（[第 20 章](20-registration.md)）和毕业审核（[第 26 章](26-graduation.md)）。

## 毕业要求

按专业项目、**修读类型**（主修、第二专业、辅修）、**适用培养方案年份**范围各创建一条。学生适用与其学籍培养方案年份对应的要求。

- 同一专业项目、同一修读类型的适用年份不能重叠。结束年份留空表示一直适用到下一条要求开始为止。
- 要求类型

| 类型 | 输入 | 例 |
|---|---|---|
| 类别学分 | 课程类别、最低学分 | 通识必修 9 学分 |
| 必修课程 | 课程列表 | 专业必修 4 门全部修完 |
| 指定课程中选修 | 课程列表、最低学分或最少门数 | 专业选修课程中修满 12 学分 |
| 考试合格 | 考试种类 | 英语综合考试合格（[第 24 章](24-assessments.md)） |

第二专业和辅修另行创建比主修少的要求（例：第二专业 36 学分、辅修 21 学分）。要求的判定在毕业审核（[第 26 章](26-graduation.md)）中进行。

## CSV 导入

在课程列表中使用 **导入 CSV**（`管理课程、版本和先修课程` 权限）批量导入课程版本。一行就是一个版本。课程按代码查找（没有则创建），版本按代码和开始日期查找，因此再次导入同一文件会更新，开始日期不同的行会成为修订版本。期间重叠的行只有该行失败。

| 列 | 说明 |
|---|---|
| `code` | 课程代码（必填） |
| `org_unit` | 管理组织代码。新课程必填 |
| `effective_start_date`、`effective_end_date` | 版本期间（`YYYY-MM-DD`） |
| `title_en`、`title_ko`、`title_zh-hans`、`title_lo` | 各语言的课程名称。新课程必须有英文 |
| `credits`、`lecture_hours`、`lab_hours` | 学分（新版本必填，0~30）、学时（0~40） |
| `category` | 课程类别代码 |
| `grading_basis` | `graded` 或 `pass_fail` |
| `counts_toward_credit_limit` | `1`/`0` |

也可以用 `uv run manage.py reference_import courses <文件> --actor=<邮箱>` 完成同样的操作（[第 9 章](09-csv-import.md)）。

先修课程与同修课程在**版本**标签页中打开版本（行的链接）后，在版本界面下方输入。新版本用课程界面的 **添加课程版本** 创建。
