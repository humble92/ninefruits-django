# 14. 人员合并与账户邀请

菜单：**学生与教职工 > 人员** 详情界面上方的 **合并重复人员**、**发送账户注册邀请**

## 合并重复人员

用于同一人被登记为两条人员记录的情况（例：重新入学时没有找到已有人员而新建了一条）。需要 `合并重复人员` 权限。

1. 查找候选：通过人员列表搜索确认是否有相同姓名和出生日期、相同身份证号的人员。IT 运维人员可以用 `uv run manage.py people_find_duplicates` 导出全部候选列表。
2. 在 **要去掉的（重复）人员** 的详情界面点击 **合并重复人员**，从列表中选择 **保留的人员**，然后填写原因。合并完成后会跳转到保留的人员的界面。
3. 要去掉的人员的学籍、申请、教师信息、监护人、账户会移到保留的人员名下。两人都有账户时，要去掉的人员的账户会被停用，关联的学校统一登录在可能的情况下会一并转移。
4. 要去掉的人员会以 **已合并** 状态保留（列表筛选 **已合并**），以便仍能找到以前的记录。不能再用于登记新学籍。

- 两人都有教师信息时无法合并。请先整理教师信息。
- 两人在同一招生批次都有进行中的申请时无法合并。请让申请人放弃其中一份。
- **不可撤销。** 合并前务必核对学籍和出生日期。合并会连同原因一起记录在业务审计记录中。

## 账户邀请

向通过 CSV 导入的学生、教师等没有账户的人员发送注册邀请邮件。需要 `邀请创建账户` 权限。

1. 在人员详情中点击 **发送账户注册邀请**，输入登录邮箱（通常为个人邮箱）。
2. 收件人通过邮件中的链接设置密码后，账户即创建并直接登录。

- 链接有效期为 **设置 > 学籍 > 邀请链接有效期**（默认 14 天）。
- 重新发送后，之前的链接不再有效。
- 不能向已有账户的人员或其他账户正在使用的邮箱发送。
- 毕业后仍使用同一账户。请提醒只使用学校邮箱的人员将登录邮箱改为个人邮箱（[第 15 章](15-sign-in-methods.md)）。
