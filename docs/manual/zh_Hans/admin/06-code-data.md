# 6. 代码数据、国家、语言

菜单：**基础数据 > 代码数据**、**国家**、**语言**（`管理代码数据、国家和语言` 权限）

## 代码数据

各大学不同的短列表。每个列表（类型）下有若干代码值。

| 列表代码 | 用途 | 旧系统（YUSTIC） |
|---|---|---|
| `ethnicity` | 民族 | `FNATION` |
| `admission_type` | 入学类别 | `FADMDIST` |
| `room_type` | 教室用途 | `ROOM.FORWHAT` |

- 系统列表（上述三个）由程序按代码查找，因此不能更改或删除列表代码。值可以自由添加。
- 打开列表，在下方的 **代码值** 中添加。代码使用小写英文字母、数字和下划线（例：`korean`）。名称按语言填写，英文名称为必填。
- 不再使用的值不要删除，而是关闭 **启用**。已有数据使用该值时无法删除。
- 大量的值通过 [CSV 导入](09-csv-import.md) 录入。

## 国家与语言

ISO 标准列表（国家 249 个，语言约 180 个）在安装时导入。名称按已安装的语言自动填写。

- 要更改界面上显示的名称，在 **编辑** 中修改。之后的系统更新也会保留修改后的名称。
- 不想让其出现在选择列表中时，关闭 **启用**。
