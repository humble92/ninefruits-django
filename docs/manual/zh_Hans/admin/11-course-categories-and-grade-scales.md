# 11. 课程类别与成绩等级制

## 课程类别

菜单：**基础数据 > 课程类别**（`管理课程类别` 权限）。替代旧系统（YUSTIC）的 `SFOBJDIST`。

像通识必修、专业选修这样划分课程的标准。可以指定 **上级** 进行分组（例：通识 → 通识必修、通识选修）。毕业要求（Phase 4、11）中会像"专业必修 30 学分"这样引用它。

## 成绩等级制

菜单：**基础数据 > 成绩等级制**（`管理成绩等级` 权限）。替代旧系统的 `SSCOREDEF`。

| 等级制项目 | 说明 |
|---|---|
| 满分绩点 | 例：4.5 |
| 默认 | 只能指定一个。仅在尚无默认等级制时才能开启（见下文） |

打开等级制，在下方的 **等级** 中添加等级。

| 等级项目 | 说明 |
|---|---|
| 等级 | 例：`A+`、`P` |
| 绩点 | 计入绩点的等级必填 |
| 下限/上限（%） | 原始分数换算基准（可选）。例：A+ 95~100 |
| 计入绩点 | 像 P/NP 这样不计入绩点的等级要关闭 |
| 及格 | 像 F、NP 这样不能获得学分的等级要关闭 |
| 适用课程 | 普通课程（等级）、合格制课程（P、NP）、两者（例：I 未完成）。成绩录入界面只显示与课程评分方式匹配的等级 |

**默认等级制在安装时确定，不能更改**（2026-10-23 决定）。因为成绩和绩点都基于该等级制。用 `setup_install --grade-scale=4.5|4.3` 指定；未指定时采用第一个配置档的等级制。默认标记不能在界面上更改，默认等级制也不能删除。各等级的分数区间和绩点在此界面修改（[第 21 章](21-grades.md)）。

配置档录入的等级制

- 韩国大学：4.5 等级制（`KR45`）：A+ 4.5（95~100）、A0 4.0（90~）、B+ 3.5（85~）、B0 3.0（80~）、C+ 2.5（75~）、C0 2.0（70~）、D+ 1.5（65~）、D0 1.0（60~）、F 0、P、NP
- `--grade-scale=4.3` 或旧系统 YUST 配置档：4.3 等级制（`KR43` 或 `YUST43`）：A+ 4.3（97~100）、A0 4.0（93~）、A- 3.7（90~）、B+ 3.3（87~）、B0 3.0（83~）、B- 2.7（80~）、C+ 2.3（77~）、C0 2.0（73~）、C- 1.7（70~）、D+ 1.3（67~）、D0 1.0（63~）、D- 0.7（60~）、F 0、P、NP（旧系统还包含 N、I）。分数区间初始按 3 分间隔设置，请按学校标准修改。

已用于成绩的等级制不能删除。
