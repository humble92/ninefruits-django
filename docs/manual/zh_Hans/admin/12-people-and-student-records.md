# 12. 人员与学籍

菜单：**学生与教职工 > 人员**、**学籍**、**教师**

## 人员与学籍的关系

| 概念 | 说明 |
|---|---|
| 人员 | 一个人。姓名、出生日期、联系方式、证件号码、照片、监护人。无论是学生还是教师，一个人就是一条人员记录 |
| 学籍 | 一次入学。学号、专业项目、入学日期、年级、状态。毕业后重新入学时，同一人员下会生成 **新学籍（新学号）** |
| 教师 | 人员的教师信息（工号、所属、聘用类型、职称）。一个人员只有一条 |
| 账户 | 登录账户。与人员一对一关联。即使有多个学籍，账户也只有一个 |

学生和毕业生在门户中选择学籍查看（有多个学籍时，上方会出现学籍选择）。

## 人员

- 姓名同时保存 **拉丁字母法定姓名**（以护照为准：姓、名）和 **各语言姓名**（例：韩语 `김민수`）。界面上有当前语言的姓名时显示该姓名，没有时显示拉丁字母姓名。两者都可以搜索。
- 身份证号、护照号加密保存并遮盖显示。拥有 `显示身份证号和护照号` 权限时，在人员详情上方点击 **查看身份证号**（或 **查看护照号**）并填写原因后，会在单独的界面中显示一次完整值。该值不会被保存（不出现在提示消息或日志中），查看操作连同原因记录在安全日志中。按号码搜索时只有完全匹配才能找到。
- 照片在人员编辑界面上传。照片只有在权限确认后才能下载（没有公开地址）。
- 监护人在人员详情的 **监护人** 标签页中管理。学生本人也可以在门户 **我的信息** 中修改监护人和联系方式（邮箱、电话、地址、邮政编码）。姓名、出生日期、证件号码本人不能修改。
- 人员详情下方的 **变更记录** 显示该人员及其监护人数据的最近 50 条变更（时间、表、变更的列、用户）。拥有 `查看审计记录` 权限时可打开每条记录的详情（变更前后的值）。学籍详情中也以同样方式显示学籍、学籍异动、导师、第二专业与辅修的变更记录。

| 权限 | 可以做的事 |
|---|---|
| `查看所有人员` | 查看所有人员 |
| `登记和编辑人员` | 创建、编辑人员 |
| `显示身份证号和护照号` | 查看身份证号、护照号的完整值 |
| `合并重复人员`、`邀请创建账户` | [第 14 章](14-merge-and-invitations.md) |

没有 `查看所有人员` 权限的负责人，也可以查看自己有权查看的学籍所对应的人员和教师。

## 登记学籍

1. 点击 **学籍** 列表上方的 **添加学籍**（界面标题为 **登记学籍**）。
2. 选择 **已有人员**（重新入学、教师考入研究生院等）或输入 **新人员**。创建新人员前，先通过搜索确认是否已有同一人。
3. 输入专业项目、入学日期、年级、入学类别。所属（管理单位）由专业项目的组织单位决定。
4. 学号留空时，按 **设置 > 学籍** 中的学号格式生成。默认格式 `{YYYY}{SEQ:5}` 为入学年份 + 5 位序号（例：`202600001`）。已使用的号码（包括导入的学籍）会跳过。

| 学号格式标记 | 含义 |
|---|---|
| `{YYYY}` | 入学年份 |
| `{YY}` | 入学年份后两位 |
| `{SEQ:n}` | n 位序号。格式中只能有一个。按前缀（例：`2026`）分别计数 |

学籍的学号和状态不在编辑界面更改。状态通过学籍异动更改（[第 13 章](13-status-changes-and-advisors.md)）。

## 学籍查看范围

| 权限范围 | 可查看的学籍 |
|---|---|
| `查看学籍` 或 `登记和编辑学籍`，全部范围 | 所有学籍 |
| 组织单位范围 | 该单位及下级单位所属的学籍（例：工学院范围 = 工学院所有系） |
| 专业项目范围 | 该专业项目的学籍 |
| 组织单位/专业项目范围（第二专业与辅修） | 正在以该单位或专业项目作为第二专业或辅修修读的学生的学籍（仅查看） |
| 第二专业与辅修审批负责人 | 提交了待处理申请的学生的学籍（仅查看） |
| 导师 | 当前指导的学生 |
| 学生本人 | 自己的学籍 |

同样的规则也存在于数据库（行级安全）中，因此在界面之外的查询（报表、直接连接）中也不能超出范围。

## 教师

在 **教师** 列表上方的 **添加教师**（界面标题为 **新建教师**）中选择已有人员或输入新人员（`管理教师` 权限）。结束日期过后，会从当前教师列表（默认筛选）和导师选择中移除。

## 用 CSV 批量录入

使用学籍、教师列表上方的 **导入 CSV**。列格式见[第 9 章](09-csv-import.md#学生与教师)。
