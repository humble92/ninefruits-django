# 13. 学籍异动与导师

菜单：**学生与教职工 > 学籍异动**、**学籍异动类型**，学籍详情的 **学籍异动**、**导师** 标签页

## 学籍状态

| 状态 | 含义 |
|---|---|
| 在读 | 可以选课 |
| 休学 | 保留学籍，不能选课 |
| 退学、开除学籍 | 学籍终止。重新入学时生成新学籍 |
| 毕业 | 毕业日期必填。账户以校友权限保留 |

在读和休学视为"当前学生"（学号登录、导师分配等）。

## 学籍异动类型

每种类型设定 **异动后状态**、**可异动的当前状态**、是否 **学生可申请**。安装时会创建休学、复学、退学、开除学籍、重新入学、毕业。名称可以更改，重新安装也会保留更改后的名称。

## 学生申请与审批

1. 学生在门户 **我的学籍** 中输入类型、生效日期、理由提交申请。一个学籍只能有一条待处理的申请，处理前学生可以取消。
2. 负责人在 **学籍异动** 列表（默认：待处理）中 **批准** 或 **驳回**。驳回必须填写意见。在列表每一行的操作菜单中处理，会弹出填写意见的窗口。
3. 批准后学籍状态立即改变，并记入异动历史。

- 需要 `审批和办理学籍异动` 权限，且只能处理权限范围（组织单位、专业项目）内的学籍。
- 不能批准自己提交的申请（职责分离）。
- 如果申请后学籍状态已改变（例：已通过其他途径办理休学），则不会被批准。请驳回并让学生重新申请。

## 负责人直接办理

开除学籍、以书面形式收到的申请等，通过学籍详情的 **办理学籍异动** 直接办理。必须填写原因，办理人记录为批准人。需要 `审批和办理学籍异动` 权限。

所有异动都会记录在业务审计记录和数据变更记录中（[第 4 章](04-audit.md)）。

## 导师

在学籍详情的 **分配导师** 中选择教师、类型（主导师、联合导师）、开始日期（`分配导师` 权限）。

- 主导师只有一位。分配新主导师时，之前的分配在开始日期前一天结束并保留历史。
- 只能选择当前在职的教师。
- 导师可以在门户 **指导学生** 中查看当前指导学生的列表，并查看这些学生的学籍。
