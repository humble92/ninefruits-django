# 22. 课程评价

菜单：**课程评价 > 学期课程评价**、**评价表**、**课程班回答**、**设置 > 课程评价**。学生使用门户的**课程评价**，教师使用门户的**我的授课 > 课程评价结果**。

| 权限 | 可以做的事 |
|---|---|
| `查看课程评价回答率和结果` | 各班级的回答数和回答率、已公布的结果。按组织单位范围分配时，只能查看该单位开设的班级 |
| `管理评价表、学期课程评价和结果公布` | 评价表和题目、学期课程评价设置、结果公布、课程评价设置 |

角色默认值：教务管理员拥有两项，院系助理拥有查看（院系范围）。

## 与旧系统的不同之处

- **匿名性。** 旧系统（YUSTIC）为每条回答保存学号，教授账户可以读取原始表。新系统将**谁评价了（完成记录）**和**回答了什么（回答）**分开保存。回答中没有学生、序号和时间。回答也不记入数据变更记录（审计）（因为审计记录中会留下操作人）。
- **结果公布标准。** 旧系统的教授界面没有最少回答标准，教授还能看到其他班级的结果。新系统在**公布**学期结果后，**只对达到最少回答数和回答率的班级**显示结果和意见。教师只能看自己的班级。
- **限制查看成绩。** 旧系统只拦住了菜单链接，评价期间过后锁定也不解除。新系统在服务器端阻止，评价期间结束后解除。
- **题目管理。** 旧系统每学期用 SQL 录入题目。新系统在界面上管理评价表和题目。
- 拒绝全部 1 分或全部 5 分回答的规则改为设置项（默认关闭）。

## 学期准备顺序

1. **评价表**：在**评价表**中选择评价表。韩国大学配置文件预置了 `STANDARD` 评价表（课程准备、授课方法、授课内容、考核方式、教学设施与设备各 3 题，5 分量表，意见 1 题）。
2. **设置学期课程评价**：学期、评价表、最少回答数、最低回答率（%）。默认值取自**设置 > 课程评价**（5 人、25%）。两项标准都达到后才显示结果。回答数是为了匿名性（回答只有几人时可能推测出学生），回答率是为了结果的代表性。
3. **评价期间**：在学期编辑界面的**业务期间**中按时段添加**课程评价**期间（[第 10 章](10-terms.md)）。也可以通过对象条件按年级设置期间。
4. 期间内用 `uv run manage.py evaluation_remind {学期}` 向未完成的学生发送提醒邮件（`--dry-run` 只统计学生数）。在**课程班回答**中查看回答率。
5. 成绩处理结束后**公布结果**（或 `uv run manage.py evaluation_publish_results {学期}`）。命令见[运维命令](../operations/commands.md)。

## 评价表与题目

| 项目 | 说明 |
|---|---|
| 代码、名称、说明 | 说明显示在学生评价界面上方 |
| 量表分数 | 2~10。通常为 5 |
| 1 分说明、最高分说明 | 例：完全不符合、非常符合 |

**题目**标签页：领域（同一领域的题目归在一起显示）、题目、类型（量表、主观题）、必答、**反向题**（否定表述的题目。计算平均分时反转回答。例："难以跟上课程进度"答 5 分按 1 分计）、顺序。

已有任何回答的评价表不能更改题目和量表（以免结果变成对未问过的问题的回答）。要更改时，用**复制评价表**创建新评价表，在下学期使用。

## 评价对象

- 已设置学期课程评价的学期中，正在修读或已修完的课程。撤课、退课的课程除外。
- 课程的**参与课程评价**已关闭的课程除外（实习、实训等。[第 17 章](17-courses-and-curriculum.md)）。
- 只有该课程时段的课程评价期间对学生开放时才能评价。

## 学生界面

门户**课程评价**：在待评价课程列表中点击**评价**，回答题目后提交。必答题必须全部回答，提交后不能更改。每门课程只能评价一次。

**限制查看成绩**（设置，默认开启）：评价期间内，如果该学期有未评价的课程，则该学期成绩在门户成绩界面和成绩单中被隐藏并显示提示。完成评价或评价期间结束后显示。其他学期的成绩照常显示。

## 结果

- 教师：门户**我的授课**中的**课程评价结果**。只有学期结果公布后才能打开。
- 教职员：在**课程评价 > 课程班回答**中查看各班级的回答数和回答率，通过**结果**打开结果界面。详细结果对教职员也只在公布后可见（因为对照期间内的结果变化和完成时间可能推测出学生）。
- 结果界面：回答数/对象数（回答率）、各题平均分和各分数的回答数（反向题反转后）、总平均、意见（随机顺序）。
- 回答数低于最少回答数或回答率低于最低回答率的班级不显示结果和意见，只显示回答数。

## 设置

**设置 > 课程评价**：完成课程评价前隐藏该学期成绩（默认开启）、所有题目答案相同时拒绝（默认关闭）、新学期课程评价的最少回答数（默认 5）和最低回答率（默认 25%，旧系统教务界面的标准）。

## 本安装的界面

界面和功能与原系统（Filament、Livewire）相同，操作方式略有不同。

- **学期课程评价**列表上方的**设置学期课程评价**打开输入界面（学期、评价表、最少回答数、最低回答率）。留空的标准：新学期取设置中的默认值，已有学期保持当前值。行菜单**更改**打开同一界面（学期不能更改）；已有回答的学期不能更换评价表。行菜单**公布结果**打开确认界面。已公布的学期也显示行菜单，执行时以消息提示已公布。
- 在**评价表**编辑界面的**题目**标签页中添加、修改、删除题目。已有回答的评价表题目为只读，量表分数栏被锁定。界面上方的**复制评价表**打开输入新代码的界面，复制完成后进入新评价表的编辑界面。
- **课程班回答**筛选：学期（默认为有课程评价的最近学期，**全部**为所有学期）、开课单位。搜索按课程代码开头匹配。行菜单**结果**在同一窗口打开门户结果界面（`/portal/sections/{班级 ID}/evaluation/`）。
- 门户**我的授课**表中的**课程评价结果**列：学期结果已公布时显示**结果**链接，否则显示**未公布**。
- 学生门户**课程评价**：点击**提交**时浏览器会再确认一次（关闭 JavaScript 时直接提交）。缺少必答题时，已输入的回答和错误会原样再次显示。成绩界面的提示中有**课程评价**链接。
- 回答的保存：回答 ID 为随机 UUID。回答、答案和完成记录在确认学生的选课、期间和重复后，在系统上下文中以一个事务保存，不记入数据变更记录（审计）。评价表是否锁定（是否有回答）与打开界面者的查看范围无关。
