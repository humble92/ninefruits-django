# 24. 语言/综合考试

菜单：**语言/综合考试 > 考试场次**、**考试成绩**、**成绩更正申请**、**考试种类**。学生在门户的**语言/综合考试**中报名并查看成绩。

| 权限 | 可以做的事 |
|---|---|
| `登记考生、录入和公布成绩、登记外部成绩` | 学生报名、取消、缺考，录入成绩，导入 CSV，公布成绩，申请更正，登记和删除外部成绩，查看成绩台账（在学籍查看范围内） |
| `管理考试种类、领域和场次` | 创建和修改种类、领域、场次，更改场次的合格分数，批准和驳回更正申请 |

角色默认值：学籍管理员和教务管理员拥有两项。查看考试种类和场次界面还需要`查看基础数据`权限（角色默认值中已有）。成绩只在学籍查看范围内可见，因此还需同时授予`查看学籍`（或管理）权限。

## 与旧系统的不同之处

- **不再按种类固定列。** 旧系统（YUSTIC）的 `CET` 固定为语法、写作、听力、阅读四列，综合考试（`SSCORE_ADD`）每科一个 P/N 字符，计算机考试（`COMEXAM`）又是另一张表。新系统在**考试种类**中定义领域和判定方式，所有考试采用相同的场次、报名、成绩结构。
- **合格判定。** 旧系统四个领域合计达到分数线即合格，没有各领域的最低分。新系统按种类（或场次）的合格分数和**各领域最低分**判定，并把判定结果保存在成绩中。合格/不合格类型由经办人判定。
- **报名期间和名额。** 旧系统没有。场次设有报名开始、截止和名额。
- **成绩公布。** 旧系统录入后学生立即可见，而且只能看到最新场次。新系统在场次**公布成绩**后学生才能看到，所有场次的成绩都保留。有成绩的场次不能删除。
- **外部成绩。** 旧系统没有记录 TOEFL、TOPIK 等外部考试的地方（毕业审核表的 HSK 栏只是空标签）。新系统可连同证明材料登记外部成绩。
- **与毕业要求联动。** 旧系统由人看毕业审核表判断。新系统通过毕业要求类型**考试合格**纳入培养方案（[第 17 章](17-courses-and-curriculum.md)）。

## 考试种类与领域

**考试种类**：代码、名称（按语言）、类别（语言、综合考试、毕业论文、外部认证考试）、判定方式、满分、合格分数、外部成绩、启用、排序。

| 判定方式 | 录入 | 判定 |
|---|---|---|
| 分数 | 各领域分数（没有领域则为总分） | 总分 ≥ 合格分数且所有领域 ≥ 领域最低分。没有合格分数时由经办人选择 |
| 合格/不合格 | 是否合格 | 由经办人选择 |

**领域**（种类编辑界面的**领域**标签页）：代码（CSV 列名，字母、数字、`-`、`_`）、名称、满分、领域最低分（可选）、排序。有领域时总分为各领域分数之和。分数等于领域最低分即通过，低 1 分则无论总分多高都不合格。

韩国大学配置文件（`setup_install --profile=korean-university`）预置的种类：

| 代码 | 种类 | 判定 | 备注 |
|---|---|---|---|
| `ENG_COMP` | 英语综合考试 | 分数，合格 60 | 听力、阅读、写作、语法各 25 分 |
| `COMP_EXAM` | 计算机综合考试 | 合格/不合格 | |
| `THESIS` | 毕业论文 | 合格/不合格 | |
| `TOPIK` | 韩国语能力考试（TOPIK） | 合格/不合格，外部 | 记录等级和证书编号 |

再次运行配置文件时，管理员修改过的值保持不变，删除的领域不会重新出现。

## 场次

**考试场次**：种类、考试日期（同一种类内唯一）、地点、名额、报名开始和截止、合格分数（留空则使用种类的值）。场次界面的**考生**标签页列出报名。

- **登记考生**（输入学号）：教职员不受报名期间限制，可在考试日期之前登记。名额仍然适用。考试日期已过的场次任何人都不能报名。成绩只能为已报名的学生录入，CSV 中未报名学生的行会报错并跳过。
- 学生在门户中于报名期间内报名、取消。只有在读、休学中的学生可以。取消后再次报名会恢复同一条报名记录。
- **录入成绩**：各领域分数（或总分），需要时填写是否合格和备注。公布前重新录入即可更改（审计 `assessment.result_recorded`）。**公布后锁定**（见下文更正申请）。
- **缺考**：已报名但未参加考试。录入成绩后恢复为已报名状态。
- **取消报名**：已录入成绩的报名不能取消。理由可选。
- **公布成绩**：从现在起学生可以查看该场次的成绩。公布后不能直接修改或删除成绩，只能通过**申请更正**更改（2026-10-23 决定）。与命令 `assessment_publish_results` 相同。
- 场次的**合格分数**（覆盖种类的值）：用于考试偏难时经会议下调分数线的情况。**公布前**可以更改，保存时会按保存的分数对该场次已录入的成绩**全部重新判定**（总分按新标准，领域最低分仍用种类的值）。填写**更改合格分数的理由**后，审计 `assessment.pass_score_changed` 中会记录更改前后的标准和判定发生变化的学生学号。保存后界面显示重新判定的件数。**公布后**为只读（只能通过更正申请）。各领域最低分不能在场次中更改（种类设置）。
- **导入成绩（CSV）**：格式见下。未报名学生的行报错并跳过。与命令 `assessment_import_results` 相同。

CSV 格式（带标题行，UTF-8，最大 5MB）：

| 列 | 内容 |
|---|---|
| `student_number` | 学号（必需） |
| 领域代码（`LISTENING`、…） | 领域分数。不区分大小写 |
| `total` | 没有领域的种类的总分 |
| `passed` | `Y`/`N`。合格/不合格种类或没有合格分数的种类中必需 |
| `absent` | 为 `Y` 时按缺考处理 |
| `note` | 备注 |

错误行跳过，并在结果消息（界面，前 10 条）或输出（命令）中连同行号一起报告。错误文本为英文（与命令输出相同）。

## 成绩更正申请

更改已公布场次成绩的流程。与成绩更正采用相同的方式。

1. 在场次的**考生**标签页中**申请更正**：新分数（或是否合格）和理由。每条成绩只能有一个待处理的申请。审计 `assessment.correction_requested`。
2. 在**语言/综合考试 > 成绩更正申请**中，由拥有`管理考试种类、领域和场次`权限的人员**批准**（处理意见可选）或**驳回**（处理意见必填）。**不能审批自己提出的申请。**
3. 批准的同时成绩更改为新值（按新分数重新判定是否合格）并对学生可见。审计 `assessment.correction_approved`、`assessment.result_corrected`。申请人在决定前可以撤回申请。

列表默认显示待处理的申请（状态筛选选择**全部**可显示所有申请），并排显示当前值和更正值。菜单中显示待处理件数。

## 成绩台账

**考试成绩**：所有成绩（校内场次、外部）。按种类、来源、是否合格筛选，按学号或姓名查找。查看范围与学籍查看范围相同。

- **登记外部成绩**（列表上方）：学号、种类（仅允许外部成绩的种类）、考试日期（不能是将来）、总分、等级、是否合格、证书编号、证明材料（PDF、JPG、PNG，5MB）、备注。审计 `assessment.external_recorded`。
- **证明材料**：打开文件。学生也可以打开自己的。
- **删除**（行）：必须填写理由，审计 `assessment.result_removed`。用于删除登记错误的外部成绩或公布前的成绩后重新登记。证明材料也一并删除。已公布场次的成绩不能删除（更正申请）。

## 毕业要求

在**培养方案 > 毕业要求**编辑中选择要求类型**考试合格**并指定**考试种类**。学生在该种类中有任何一条合格成绩（校内或外部）即满足。门户**语言/综合考试**上方显示学生培养方案所要求的种类和是否合格。毕业审核判定在第 11 阶段读取此要求。被要求使用的考试种类不能删除（改为不启用）。

## 学生门户

**语言/综合考试**：培养方案要求和是否合格、报名中的场次（报名、取消）、我的报名、我的成绩（已公布场次和外部成绩、各领域分数、证明材料）。

## 本系统的界面

界面和功能与原系统（Filament、Livewire）相同，操作方式略有不同。

- **考试场次**列表的行菜单：**公布成绩**（确认页面）、**导入成绩（CSV）**（选择文件页面）。场次界面上方的按钮：**登记考生**（考试日期之前）、**导入成绩（CSV）**、**公布成绩**。筛选：种类、是否已公布成绩。
- 场次界面的**考生**标签页可点击状态（全部、已报名、已取消、缺考）筛选。行中的**录入成绩**、**申请更正**、**缺考**、**取消报名**打开录入页面。录入成绩页面按种类的领域各有一个分数栏，按分数判定的种类会显示判定标准。
- **考试成绩**列表上方的**登记外部成绩**，行菜单的**删除**。证明材料列的链接在新窗口中打开文件。
- **成绩更正申请**的行菜单：**批准**、**驳回**、**撤回申请**（本人的申请）。
- 证明材料地址：`/assessment-results/{成绩 ID}/evidence/`（确认权限后下载）。门户地址：`/portal/assessments/`。
- 命令：`uv run manage.py assessment_import_results {种类代码} {考试日期} {CSV} --actor=... [--dry-run]`、`uv run manage.py assessment_publish_results {种类代码} {考试日期} --actor=...`（[运维命令](../operations/commands.md)）。

## 常见问题

- **不在报名期间但需要报名。** 由教职员在场次界面的**登记考生**中登记。
- **只想更改本场次的合格分数。** 公布前输入场次的合格分数并填写理由后保存。已录入的成绩会立即按新标准重新判定。
- **分数录入错误。** 公布前重新**录入成绩**即可更改。公布后提交**申请更正**，由其他经办人批准。
- **缺考统计。** 在**考生**标签页按状态**缺考**筛选。
