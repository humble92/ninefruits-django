# 13. 学籍異動と指導教員

メニュー: **学生・教職員 > 学籍異動**、**学籍異動種別**、および学籍の **学籍異動** タブと **指導教員** タブ

## 学籍状態

| 学籍状態 | 意味 |
|---|---|
| 在学 | 履修登録できます |
| 休学 | 学籍は維持され、履修登録はできません |
| 退学、除籍 | 学籍は終了します。再入学すると新しい学籍が作成されます |
| 卒業 | 卒業日が必須です。アカウントは卒業生としてのアクセス権で維持されます |

在学と休学は「在籍中の学生」として扱われます(学籍番号ログイン、指導教員の割り当てなど)。

## 学籍異動種別

各種別は **異動後の学籍状態**、**異動前に許可される学籍状態**、**学生による申請可** かどうかを定義します。インストール時に休学、復学、退学、除籍、再入学、卒業が作成されます。名称は変更でき、変更した名称は再インストール後も維持されます。

## 学生の申請と承認

1. 学生はポータルの **学籍情報** で、種別、発効日、理由を入力して申請します。1 つの学籍に同時に存在できる承認待ちの申請は 1 件だけで、学生は判定前であれば申請を取り消せます。
2. 職員は **学籍異動** 一覧(既定: 承認待ち)で **承認** または **却下** します。却下にはメモが必須です。各行の操作メニューを使用し、メモはウィンドウで入力します。
3. 承認すると、学籍の学籍状態がすぐに変わり、異動が履歴に追加されます。

- `学籍異動の承認・記録` 権限が必要です。判定できるのは権限の範囲(組織単位、プログラム)内の学籍だけです。
- 自分が提出した申請は承認できません(職務の分離)。
- 申請後に学籍の学籍状態が変わった場合(例: 別の方法で休学がすでに記録された)、その申請は承認できません。却下して、改めて申請するよう依頼してください。

## 職員による直接記録

除籍や書面で受け付けた申請などは、学籍の **学籍異動を記録** で直接記録します。理由は必須で、記録した人が承認者として保存されます。`学籍異動の承認・記録` 権限が必要です。

すべての異動は業務ログとデータ変更履歴に記録されます([第 4 章](04-audit.md))。

## 指導教員

学籍の **指導教員を割り当て** で、教員、区分(主指導教員、副指導教員)、開始日を選びます(`指導教員の割り当て` 権限)。

- 主指導教員は 1 人です。新しい主指導教員を割り当てると、以前の割り当ては開始日の前日に終了し、履歴は残ります。
- 選択できるのは現職の教員だけです。
- 指導教員はポータルの **指導学生** で現在の指導学生を確認し、その学生の学籍を閲覧できます。
