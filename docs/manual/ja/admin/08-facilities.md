# 8. 建物と教室

メニュー: **基準データ > 建物**、**教室**(`建物・教室の管理` 権限)

## 建物

コード(例: `SCI`)、名称(言語ごと)、住所を入力します。教室がある建物は削除できないため、使わなくなったら **有効** をオフにします。

## 教室

| 項目 | 説明 |
|---|---|
| 建物、教室番号 | 教室番号は建物内で一意です。例: `101` |
| 名称 | 任意。例: 大講堂 |
| 教室種別 | `room_type` コード種別の値(講義室、実験室など) |
| 組織単位 | 教室を管理する学科(任意) |
| 収容人数 | 時間割を作成するときに開講科目の定員と比較されます([第 18 章](18-sections-and-timetables.md)) |
| 時間割で使用 | オフにすると、時間割を作成するときにその教室は除外されます(事務室、倉庫など) |

教室が多い場合は [CSV 取り込み](09-csv-import.md) を使います。建物を先に登録しておく必要があります。
