# 5. 機関設定と初期設定の順序

## 機関設定

**設定 > 機関** で設定します(`機関設定の管理` 権限)。

| 設定 | 説明 |
|---|---|
| 機関名 | 言語ごとに入力します。管理画面の左上に表示されます |
| タイムゾーン | 学期の日付や業務期間を判断する基準です。例: `Asia/Seoul`。保存されたすべての時刻はこのタイムゾーンで表示されます |
| 提供する言語 | ユーザーが選択できる言語です。翻訳ファイルがインストールされている言語だけが一覧に表示されます |
| 既定の言語 | 言語を選択していないユーザーや、ブラウザーの言語が不明な場合に使われます |

## 新しい大学での初期設定の順序

IT 運用者が `setup_install` を完了した後(運用マニュアル [インストール](../operations/installation.md))、業務管理者が以下の順序でデータを入力します。後の手順は前の手順のコードを参照するため、順序を守ってください。

1. **機関設定**: 名称、タイムゾーン、言語(本章)
2. **コードデータ**: 民族、入学区分、教室種別の値([第 6 章](06-code-data.md))。インストール時に韓国の大学プロファイルを適用した場合、教室種別はすでに存在します。
3. **組織種別** を確認し、次に **組織単位**: 大学 → 学部 → 学科([第 7 章](07-org-units-and-programs.md))。組織単位が多い場合は CSV を使います([第 9 章](09-csv-import.md))。
4. **プログラム**: 学科ごとの学位プログラム([第 7 章](07-org-units-and-programs.md))
5. **建物**、**教室**([第 8 章](08-facilities.md)、CSV も可)
6. **学期種別** と **時限** を確認([第 10 章](10-terms.md))
7. **科目区分** と **成績評価基準** を確認。既定の評価基準を 1 つ指定する必要があります([第 11 章](11-course-categories-and-grade-scales.md))
8. **年度** → **学期** → 学期ごとの **業務期間**([第 10 章](10-terms.md))
9. **ユーザーとアクセス**: 学科助手など組織単位の範囲が必要なロールで、学科を範囲の対象として選べるようになります([第 2 章](02-users-and-roles.md))

データの入力が終わったら、IT 運用者に `uv run manage.py term_inspect` で業務期間の確認を依頼してください。
