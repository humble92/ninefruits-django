# 18. 開講科目と時間割

メニュー: **教育課程・開講科目 > 開講科目**、**時間割**(権限 `開講科目の閲覧`、`開講科目の編成(教員・時間・教室)`。組織単位の範囲付きで割り当てた場合は、その組織が開講する開講科目だけが対象になります)

## 開講科目の作成

1. **開講科目 > 作成** で、学期の授業期間、科目、クラス番号(例: `01`)、定員、開講組織を入力します。科目名と単位は、授業期間の開始日に有効な科目バージョンから取得されます。
2. 編集画面のタブで **授業時間**、**担当教員**、**確保枠** を入力します。
3. すべての準備ができたら **公開** します。公開された開講科目だけがポータルの **開講科目一覧** に表示され、履修登録できます([第 20 章](20-registration.md))。

| 状態 | 意味 |
|---|---|
| 下書き | 編成中。職員と割り当てられた教員だけが見られます |
| 公開 | 学生に表示されます。**下書きに戻す** ことができます |
| 開講取消 | 理由が必要です。教室と教員の時間が解放されます。**再開** で下書きに戻ります。その間に別の開講科目がその時間を使っている場合は再開できません |

削除できるのは下書きの開講科目だけです。一度公開した開講科目は、削除ではなく開講取消にします。

| 項目 | 説明 |
|---|---|
| 授業期間 | 学期内の授業期間([第 10 章](10-terms.md))。別の授業期間に移すと、授業日と科目バージョンがその授業期間に合わせて変わります |
| 履修可能な対象、履修できない対象 | 学年、入学年度、プログラム、組織単位。例: 教養科目から、その科目を開設する学科の専攻生を除外する。第二専攻・副専攻の学生もそのプログラムの学生として扱われます |
| 授業言語 | 例: `ko`、`en` |
| キャンセル待ちの人数 | 定員に達した後に受け付けるキャンセル待ちの件数。0: キャンセル待ちなし([第 20 章](20-registration.md)) |
| 評価方式 | 絶対評価(既定。教員が素点を入力し、成績はそこから算出されます)または相対評価(成績のみを入力し、成績分布上限が適用されます)。教員が成績入力画面から変更を申請し、開講科目の担当職員が承認します。成績が入力された後は変更できません([第 21 章](21-grades.md))。学期をコピーするときに一緒にコピーされます |

## 授業時間と教室

**授業時間** タブで曜日、開始・終了時刻、教室を入力します。**時限** を選ぶと時刻が入力されます。授業日を空欄にすると、授業期間の日付が使われます。

- 2 つの開講科目が同じ時間に同じ教室を使うことはできず、1 人の教員が同じ時間に 2 つの開講科目を担当することもできません。データベースがこれを保証し、画面には競合する開講科目が表示されます(例: 「この時間、教室はすでに OOO で使用されています。」)。
- 学期の前半と後半のように日付が重ならない場合は、同じ時間・教室を使えます。
- 開講取消の開講科目は時間を占有しません。

## 担当教員

**担当教員** タブで、役割(担当教員、共同担当教員、TA)を付けて教員を割り当てます。1 つの開講科目に複数人を割り当てられます。同じ時間にすでに別の開講科目を担当している教員は割り当てられません。教員はポータルの **担当授業** で時間割とシラバスを管理します。

## 確保枠

**確保枠** タブで、学生のグループ向けに席を確保します(例: そのプログラムの専攻生向けに 30 席)。**全員への開放日時** を過ぎると、使われていない席は誰でも履修できるようになります。確保枠の合計は定員を超えられません。確保枠は履修登録時に適用されます([第 20 章](20-registration.md))。

## シラバス

教員がポータルの **担当授業** で作成します(開講科目画面の **シラバス** ボタンからも開けます)。授業概要、到達目標、教科書・参考資料、授業の方針、成績評価(項目と割合)、授業計画を入力し、**公開** にすると学生に表示されます。

## 別の学期からのコピー

開講科目一覧の **別の学期からコピー** を使うと、以前の学期(通常は前年の同じ学期)の編成をもとに始められます。まず **プレビューのみ** で結果を確認してください。

- 開講取消になっておらず、自分の範囲内にある開講科目が下書きとしてコピーされます。
- 一緒にコピーされるもの: 在職中の教員、授業時間と教室、確保枠(開放日時は学期の開始日の差だけずらされます)、シラバス(未公開の下書きとして)。
- 授業期間はコードで対応付けられます(該当がなければ学期全体)。科目バージョンは新しい授業期間の開始日時点のものが使われます。
- コピー先の学期にすでに同じクラス番号がある開講科目はスキップされます。教室がすでに使われている場合は、教室なしでコピーされます。結果の通知には、スキップされた開講科目と確認が必要な開講科目が一覧表示されます。

IT 運用者は `uv run manage.py section_copy` で同じ操作ができます。

## 時間割と確認

- **時間割**: 学期と、教室または教員を選ぶと週間時間割が表示されます。
- 公開前の確認: IT 運用者が `uv run manage.py schedule_check_conflicts <term code>` を実行すると、定員より小さい教室、退職した教員、科目バージョンの不一致、定員を超える確保枠が見つかります([コマンドリファレンス](../operations/commands.md#schedule_check_conflicts))。

## 範囲

一覧と各画面には、`開講科目の閲覧` と `開講科目の編成(教員・時間・教室)` の範囲内にある開講組織の開講科目だけが表示されます。授業時間、担当教員、確保枠の各タブと状態ボタン(公開、下書きに戻す、開講を取消、再開)には、その開講科目の開講組織を含む範囲の `開講科目の編成(教員・時間・教室)` 権限が必要です。時間割ページは現在の学期(なければ次の学期)から表示されます。スマートフォンでは曜日ごとの一覧で表示されます。
