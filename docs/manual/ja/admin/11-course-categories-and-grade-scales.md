# 11. 科目区分と成績評価基準

## 科目区分

メニュー: **基準データ > 科目区分**(`科目区分の管理` 権限)。旧システム(YUSTIC)の `SFOBJDIST` を置き換えます。

教養必修、専攻選択などの科目の分類です。**上位** を設定するとグループ化できます(例: 教養 → 教養必修、教養選択)。卒業要件([第 17 章](17-courses-and-curriculum.md)、[第 26 章](26-graduation.md))は「専攻必修 30 単位」のようにこれを参照します。

## 成績評価基準

メニュー: **基準データ > 成績評価基準**(`成績評価基準の管理` 権限)。旧システムの `SSCOREDEF` を置き換えます。

| 評価基準の項目 | 説明 |
|---|---|
| 最高グレードポイント | 例: 4.5 |
| 既定 | 既定にできる評価基準は 1 つだけです。既定の評価基準がない間だけオンにできます(下記参照) |

評価基準を開き、下の **成績** で成績を追加します。

| 成績の項目 | 説明 |
|---|---|
| 成績 | 例: `A+`、`P` |
| グレードポイント | GPA に算入される成績では必須 |
| 下限(%)/上限(%) | 素点の換算範囲(任意)。例: A+ 95–100 |
| GPA に算入 | P/NP など GPA から除外する成績ではオフにします |
| 合格 | F や NP など単位を修得できない成績ではオフにします |
| 対象 | 段階評価科目(段階評価の成績)、合否科目(P、NP)、または両方(例: I、未完了)。成績入力画面には、科目の評価方法に合う成績だけが表示されます |

**既定の評価基準はインストール時に固定され、変更できません**(2026-10-23 の決定)。すべての成績と GPA がその評価基準で表されるためです。`setup_install --grade-scale=4.5|4.3` で設定します。オプションを指定しない場合は、最初のプロファイルの評価基準が既定になります。既定のフラグは画面で変更できず、既定の評価基準は削除できません。成績ごとの素点範囲とグレードポイントはこの画面で編集します([第 21 章](21-grades.md))。

プロファイルで読み込まれる評価基準

- 韓国の大学: 4.5 評価基準(`KR45`): A+ 4.5 (95–100)、A0 4.0 (90–)、B+ 3.5 (85–)、B0 3.0 (80–)、C+ 2.5 (75–)、C0 2.0 (70–)、D+ 1.5 (65–)、D0 1.0 (60–)、F 0、P、NP
- `--grade-scale=4.3` または旧 YUST プロファイル: 4.3 評価基準(`KR43` または `YUST43`): A+ 4.3 (97–100)、A0 4.0 (93–)、A- 3.7 (90–)、B+ 3.3 (87–)、B0 3.0 (83–)、B- 2.7 (80–)、C+ 2.3 (77–)、C0 2.0 (73–)、C- 1.7 (70–)、D+ 1.3 (67–)、D0 1.0 (63–)、D- 0.7 (60–)、F 0、P、NP(旧プロファイルには N と I も含まれます)。素点範囲は 3 点刻みで始まるため、学校の基準に合わせて調整してください。

すでに成績で使われている評価基準は削除できません。
