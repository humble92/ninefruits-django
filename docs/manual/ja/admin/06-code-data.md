# 6. コードデータ、国、言語

メニュー: **基準データ > コード種別**、**国**、**言語**(`コードデータ・国・言語の管理` 権限)

## コードデータ

大学ごとに異なる短い一覧です。各一覧(種別)がコードの値を持ちます。

| 種別コード | 用途 | 旧システム(YUSTIC) |
|---|---|---|
| `ethnicity` | 民族 | `FNATION` |
| `admission_type` | 入学区分 | `FADMDIST` |
| `room_type` | 教室種別 | `ROOM.FORWHAT` |

- システムの一覧(上の 3 つ)はアプリケーションがコードで参照するため、種別コードの変更や削除はできません。値は自由に追加できます。
- 一覧を開き、下の **コード** で値を追加します。コードには英小文字、数字、アンダースコアを使います(例: `korean`)。名前は言語ごとに入力し、英語名は必須です。
- 使わなくなった値は削除せず、**有効** をオフにします。データで使用中の値は削除できません。
- 多数の値は [CSV 取り込み](09-csv-import.md) で入力します。

## 国と言語

ISO 標準の一覧(249 の国、約 180 の言語)がインストール時に読み込まれます。インストールされている言語の名前は自動的に入力されます。

- 画面に表示される名前を変えるには、**編集** で変更します。変更した名前は以降のシステム更新でも維持されます。
- 選択リストに表示しないようにするには、**有効** をオフにします。
