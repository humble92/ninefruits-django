# 27. レポートと reporting ビュー

メニュー: **レポート > レポート**(`標準レポートの閲覧・ダウンロード` 権限)。ロールの既定: 学籍担当、教務担当、学科助手(範囲内)。

## 標準レポート

レポートと絞り込み条件を選びます。画面には最大 500 行が表示され、**CSV をダウンロード** ですべての行を取得できます(BOM 付きの UTF-8 で、そのまま Excel で開けます)。ダウンロードは監査イベント `reports.exported` とセキュリティログのイベント `data.exported`(レポート、絞り込み条件、行数)に記録されます。`=`、`+`、`-`、`@`(またはタブ、改行)で始まる値は、Excel が数式として実行しないよう、先頭にシングルクォート(`'`)を付けて出力されます。

| レポート | 絞り込み条件 | 内容 |
|---|---|---|
| 学生一覧 | 組織単位(下位の組織を含む)、学籍状態、学年 | 学籍番号、氏名、プログラム、組織単位、学年、学籍状態、入学日、卒業日、学位記番号 |
| 組織・プログラム・学年・学籍状態別の学生数 | 組織単位、学籍状態 | 学生数 |
| 学期成績集計 | 学期、学業状況 | 学期と累積の単位および GPA、学業警告の回数、成績優秀者の順位([第 21 章](21-grades.md)) |
| 卒業予定者 | 要件充足かどうか | 学生とプログラムごとの最新の卒業判定([第 26 章](26-graduation.md)) |
| 学籍異動 | 学期、期間 | 異動の種類、異動前後の学籍状態、発効日、申請の状態 |
| 開講科目別履修者数 | 学期、組織単位 | 開講科目、担当教員、定員、履修者、キャンセル待ち |
| 学期の未履修登録者 | 学期、組織単位 | その学期に履修がない在学生 |

表示される範囲は、閲覧者の権限の範囲(学籍閲覧の範囲など)に従います。旧システム(YUSTIC)の手数料・授業料関連のレポート(授業料未納など)は対象外で、存在しません。

## reporting ビュー

レポートは、データベースの `reporting` スキーマのビューを読み取ります。BI ツールや SQL の利用者は、読み取り専用ロール `app_reporting` で同じビューを照会します。

| ビュー | 内容 |
|---|---|
| `reporting.students` | 学籍 + 人物の氏名 + プログラムと組織単位の名称 |
| `reporting.headcount` | 組織単位、プログラム、学年、学籍状態ごとの学生数 |
| `reporting.term_records` | 学期ごとの成績集計 |
| `reporting.course_grades` | 科目ごとの成績(確定かどうか、成績、合格、再履修) |
| `reporting.section_enrollments` | 開講科目ごとの履修者数とキャンセル待ち、担当教員 |
| `reporting.section_meetings` | 授業時間と教室 |
| `reporting.status_changes` | 学籍異動 |
| `reporting.degree_audits` | 学生とプログラム区分ごとの最新の卒業判定 |

- 翻訳される列(`program_name` など)はセッションのロケールに従います: `SET app.locale = 'ko';`。元の jsonb 列(`program_name_i18n` など)も利用できます。
- ビューは `security_invoker` なので、閲覧者の行レベルセキュリティがそのまま適用されます。学生のアカウントで読み取ると、その学生の行だけが返ります。
- ビューの定義は `db/sql/views/reporting.sql`(元の `database/sql/views/reporting.sql` をそのまま使用)にあります。変更した後は `core` のマイグレーションから再適用します。アプリケーションは非管理モデル(`ninefruits.reporting.models`、例: `ReportStudent`)を通じて読み取ります。

旧システムの `AV_*` ビュー(約 90 個)は使われていなかったため、移行していません。

## このインストールの画面

- **レポート > レポート**(`/admin/reports/`): レポートを選んで **表示** を押すと、その絞り込み条件が表示されます(元のシステムはレポートを選んだ時点で切り替わっていました)。絞り込み条件を入力し、もう一度 **表示** を押します。学期の絞り込み条件があるレポートは、学期を選ぶまで行が表示されません。
- CSV のアドレスは `/reports/{report}.csv?filter=value` です(例: `/reports/students.csv?status=enrolled`)。一覧にあるレポート名と絞り込み条件名だけが受け付けられ、列と並び順はレポートの定義で固定されています。
- CSV の時刻(監査日時、判断日時)は、元のシステムと同じく UTC の PostgreSQL テキスト(`2026-10-24 07:26:59+00`)で出力されます。日付は `YYYY-MM-DD`、真偽値は `Y`/`N` です。
- 開講科目別履修者数の組織単位の絞り込みは、組織単位コードで絞り込みます(ビューに組織単位 ID がないため)。元のシステムではこの絞り込みを選ぶと失敗していました。
- 開講科目と授業時間には行レベルセキュリティがないため、開講科目の行はすべて表示されます。履修者数とキャンセル待ちの数は、閲覧者が閲覧できる履修とキャンセル待ちだけを数えます。
