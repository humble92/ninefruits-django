# 14. 人物の統合とアカウント招待

メニュー: **学生・教職員 > 人物** の後、人物の詳細ページ上部の **重複を統合** と **アカウント作成に招待**

## 重複した人物の統合

同じ人間が 2 つの人物として登録された場合に使います(例: 再入学で既存の人物が見つからず、新しい人物が作成された場合)。`重複した人物の統合` 権限が必要です。

1. 候補を探す: 人物一覧で同じ氏名と生年月日、または同じ国民識別番号を検索します。IT 運用者は `uv run manage.py people_find_duplicates` で候補の全一覧を作成できます。
2. **削除する人物(重複している側)** の詳細ページで **重複を統合** を押し、**残す人物** で一覧から人物を選び、理由を入力します。統合が終わると、残した人物のページに移動します。
3. 削除する人物の学籍、出願、教員情報、保護者、アカウントは、残す人物に移されます。両方にアカウントがある場合、削除する人物のアカウントは無効になり、紐づいた学内アカウントログインは可能な場合に移されます。
4. 削除した人物は **統合済み** として残る(一覧の絞り込み **統合済み**)ため、過去の記録も引き続き探せます。新しい学籍には使用できません。

- 両方の人物に教員情報がある場合、統合は拒否されます。先に教員情報を整理してください。
- 両方の人物に同じ入試回の進行中の出願がある場合、統合は拒否されます。志願者にどちらかを取り下げるよう依頼してください。
- **この操作は取り消せません。** 統合する前に、必ず学籍と生年月日を確認してください。統合は理由とともに業務ログに記録されます。

## アカウント招待

CSV で読み込んだ学生や教員など、アカウントのない人物に招待メールを送ります。`アカウント作成への招待` 権限が必要です。

1. 人物の詳細ページで **アカウント作成に招待** を押し、ログイン用のメールアドレス(通常は個人のメールアドレス)を入力します。
2. 受信者がメールのリンクからパスワードを設定すると、アカウントが作成され、すぐにログインした状態になります。

- リンクの有効期間は **設定 > 学籍 > 招待リンクの有効期間(日)** です(既定 14 日)。
- 再送すると、以前のリンクは無効になります。
- すでにアカウントを持つ人物を招待することや、他のアカウントが使っているメールアドレスを使うことはできません。
- 卒業後も同じアカウントが維持されます。学校のメールアドレスだけを使っていた人には、ログイン用のメールアドレスを個人のアドレスに変更するよう依頼してください([第 15 章](15-sign-in-methods.md))。
