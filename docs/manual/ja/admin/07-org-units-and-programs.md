# 7. 組織単位とプログラム

メニュー: **基準データ > 組織種別**、**組織単位**、**プログラム**

## 組織単位

大学、学部、学科、専攻、事務組織を 1 つの画面で管理します。旧システム(YUSTIC)の学部(`SFCOLLEGE`)と学科(`SFDEPARTMENT`)を置き換えます。

| 項目 | 説明 |
|---|---|
| コード | 恒久的な識別コード。例: `CSE` |
| 種別 | 大学、学部、学科など(組織種別の画面で追加できます) |
| 名称、略称 | 言語ごと |
| 上位組織 | この組織単位が所属する組織単位。自分自身や自分の下位組織の下には移動できません |
| 有効期間(開始)、有効期間(終了) | 組織単位が存在した期間。終了日が空の場合は現在運営中を意味します |

- 一覧は既定で **現在有効なもののみ** を表示します。過去の組織単位も見るには、絞り込みをオフにします。
- ロール割り当ての範囲として組織単位を選ぶと、その下位のすべての組織単位が含まれます。例: 工学部の範囲 = 工学部のすべての学科。

## 組織改編

過去の学籍や成績は当時の組織単位を指している必要があるため、組織単位をその場で書き換えず、変更を **組織改編** として記録します。

1. なくなる(または変わる)組織単位の **編集** ページを開きます。
2. **組織改編** を押します。
3. 変更の種類を選びます。
   - **名称変更**: 新しい名称の組織単位を先に作成し、承継組織として指定します
   - **統合**: 複数の組織単位が 1 つにまとまる場合、各組織単位から同じ承継組織を指定します
   - **分割**: 1 つの組織単位が複数に分かれる場合、複数の承継組織を指定します
   - **所属変更**: 組織単位が新しい組織単位として別の上位組織の下に移る場合
4. **発効日** と理由を入力します。組織単位は発効日の前日に終了し、記録が下の **承継組織** 一覧に表示されます。

単純な誤字は組織改編ではなく、名称の **編集** で修正します(データ変更履歴に記録されます)。

## プログラム

学位プログラムまたは専攻プログラムです。学籍はプログラムに所属します([第 12 章](12-people-and-student-records.md))。

| 項目 | 説明 |
|---|---|
| コード、名称、学位名称 | 学位名称の例: 学士(工学) |
| 学位の種類 | 短期大学士、学士、修士、博士、修了証、非学位 |
| 組織単位 | プログラムを運営する学科 |
| 標準修業年限 | 修了までの標準年数(年) |
| 有効期間(開始)、有効期間(終了) | プログラムが存在する期間であり、新入生を受け入れる期間ではありません |
| 第二専攻を受け入れる、副専攻を受け入れる | 他のプログラムの学生がこのプログラムを第二専攻または副専攻として申請できるかどうか([第 19 章](19-second-majors-and-minors.md)) |
