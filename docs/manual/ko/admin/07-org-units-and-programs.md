# 7. 조직 단위와 프로그램

메뉴: **기준정보 > 조직 단위 유형**, **조직 단위**, **프로그램**

## 조직 단위

대학교, 단과대학, 학과, 전공, 행정 부서를 같은 화면에서 관리한다. 레거시의 대학(`SFCOLLEGE`), 학과(`SFDEPARTMENT`)를 대신한다.

| 항목 | 설명 |
|---|---|
| 코드 | 바뀌지 않는 식별 코드. 예: `CSE` |
| 유형 | 대학교, 단과대학, 학과 등 (조직 단위 유형 화면에서 추가 가능) |
| 이름, 약칭 | 언어별 |
| 상위 | 소속 조직. 자기 자신이나 하위 조직 아래로는 옮길 수 없다 |
| 적용 시작일, 종료일 | 조직이 존재한 기간. 종료일이 비어 있으면 현재 운영 중 |

- 목록은 기본으로 **현재 유효한 조직만** 보여 준다. 필터를 끄면 과거 조직도 보인다.
- 역할 할당에서 조직 단위를 범위로 고르면 그 아래 모든 조직이 포함된다. 예: 공과대학 범위 = 공과대학 소속 모든 학과.

## 조직 개편

과거 학적과 성적은 당시 조직을 가리켜야 하므로, 조직을 고쳐 쓰지 않고 **개편**으로 기록한다.

1. 사라지는(바뀌는) 조직의 **수정** 화면을 연다.
2. **조직 개편**을 누른다.
3. 변경 유형을 고른다.
   - **명칭 변경**: 새 이름의 조직을 먼저 만들고 승계 조직으로 지정
   - **통합**: 여러 조직이 하나로 합쳐질 때, 각 조직에서 같은 승계 조직을 지정
   - **분리**: 한 조직이 여러 조직으로 나뉠 때, 승계 조직을 여러 개 지정
   - **소속 변경**: 다른 상위 조직 아래 새 조직으로 옮길 때
4. **개편 적용일**과 사유를 입력한다. 조직은 적용일 전날 종료되고, 아래 **승계 조직** 목록에 기록이 남는다.

단순한 오타 수정은 개편이 아니라 이름 **수정**으로 한다(데이터 변경 기록에 남는다).

## 프로그램

학위 과정이나 전공 과정이다. 학생 학적이 프로그램에 속한다(Phase 2).

| 항목 | 설명 |
|---|---|
| 코드, 이름, 학위명 | 학위명 예: 공학사 |
| 학위 과정 | 전문학사, 학사, 석사, 박사, 수료, 비학위 |
| 조직 단위 | 운영 학과 |
| 수업 연한 | 표준 이수 기간(년) |
| 적용 시작일, 종료일 | 신입생을 받는 기간이 아니라 과정이 존재하는 기간 |
| 복수전공 허용, 부전공 허용 | 다른 프로그램 학생이 이 프로그램을 복수전공·부전공으로 신청할 수 있는지([19장](19-second-majors-and-minors.md)) |
