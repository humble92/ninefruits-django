# 17. 교과목과 졸업 요건

메뉴: **교육과정과 개설 > 교과목**, **졸업 요건** (`교과목, 버전, 선수과목 관리`, `졸업 요건 관리` 권한)

## 교과목과 버전

교과목은 바뀌지 않는 **코드**와 기간별 **버전**으로 나뉜다. 교과목명, 학점, 시간, 교과 구분, 성적 평가 방식, 선수과목은 버전에 속한다. 레거시는 과목코드와 시작일로 교과목을 구분했지만 성적은 과목코드만 가리켜 어느 버전을 들었는지 모호했다. 신규는 개설강좌와 성적이 버전을 가리킨다.

- 같은 교과목의 버전 기간은 겹칠 수 없다(DB 제약). 날짜 하나에 유효한 버전은 하나다.
- 개설강좌는 세션 시작일에 유효한 버전으로 열린다.

| 항목 | 설명 |
|---|---|
| 교과목 코드 | 예: `CSE2010`. 코드에 업무 의미를 두지 않는다(레거시의 `009*` 학점은행 판정 같은 규칙은 아래 항목으로 대신한다) |
| 관리 조직 | 교과목을 관리하는 조직. 개설강좌의 기본 개설 조직 |
| 교과목명, 개요 | 언어별 |
| 학점, 이론·실습 시간 | 0.5 단위 |
| 교과 구분 | 기준정보 > 교과 구분 |
| 성적 평가 | 등급제 또는 P/F |
| 학기 학점 상한에 포함 | 끄면 수강신청 학점 상한 계산에서 빠진다(학점은행 과목 등) |
| 강의평가 대상 | 끄면 강의평가를 하지 않는다(실습, 인턴십 등. [22장](22-course-evaluation.md)) |
| 반복 이수 가능 | 다시 들으면 재수강이 아니라 학점을 또 받는다(주제가 바뀌는 세미나 등) |

## 교과목 개정

학점이나 교과목명이 바뀌면 버전을 고치지 말고 **개정**한다. 교과목 **수정** 화면의 **버전** 탭에서 현재 버전의 **날짜부터 개정**을 누르고 새 버전 시작일, 바뀐 값, 사유를 입력한다.

- 현재 버전은 시작일 전날 끝나고, 새 버전이 현재 버전과 선수과목을 복사해 시작한다.
- 이미 개설된 강좌와 지난 성적은 이전 버전을 그대로 가리킨다.
- 오타처럼 의미가 바뀌지 않는 수정만 버전을 직접 고친다(데이터 변경 기록에 남는다).

## 선수과목과 동시수강 과목

**버전** 탭에서 버전을 열면(행의 연결) 버전 화면 아래 **선수·동시수강 과목**에서 입력한다. 새 버전은 교과목 화면의 **교과목 버전 추가**로 만든다.

| 항목 | 설명 |
|---|---|
| 구분 | 선수과목(먼저 이수), 동시수강 과목(같은 학기에 함께 수강, 이미 이수했으면 충족) |
| 묶음 | 같은 묶음의 과목은 하나만 이수하면 된다(또는). 묶음은 모두 충족해야 한다(그리고) |
| 최저 성적 | 기본 성적 척도의 등급 코드(예: `C0`). 비우면 통과 성적 |
| 같은 학기 수강 허용 | 선수과목을 같은 학기에 들어도 되는 경우 |

예: 묶음 1에 `CSE1001`, 묶음 2에 `MAT1001`과 `MAT1002` → `CSE1001` 그리고 (`MAT1001` 또는 `MAT1002`). 수강신청 때 선수과목 규칙이 확인한다([20장](20-registration.md)).

## 대체과목

교육과정 개편으로 과목이 바뀌면 교과목 **수정** 화면의 **대체과목** 탭에 기간과 함께 입력한다. **상호 인정**을 켜면 두 과목이 서로를 대신하고, 끄면 대체과목이 이 과목을 대신하는 것만 인정한다. 재수강 판정([20장](20-registration.md))과 졸업 사정([26장](26-graduation.md))에서 쓴다.

## 졸업 요건

프로그램, **이수 구분**(주전공, 복수전공, 부전공), **적용 교육과정 연도** 범위마다 하나씩 만든다. 학생에게는 학적의 교육과정 연도에 해당하는 요건이 적용된다.

- 같은 프로그램, 같은 이수 구분의 적용 연도는 겹칠 수 없다. 끝 연도를 비우면 다음 요건이 시작될 때까지 계속 적용된다.
- 요건 종류

| 종류 | 입력 | 예 |
|---|---|---|
| 교과 구분별 학점 | 교과 구분, 최소 학점 | 교양필수 9학점 |
| 필수 과목 | 과목 목록 | 전공필수 4과목 모두 |
| 지정 과목 중 선택 | 과목 목록, 최소 학점 또는 최소 과목 수 | 전공선택 과목 중 12학점 |
| 시험 합격 | 시험 종류 | 영어종합시험 합격([24장](24-assessments.md)) |

복수전공과 부전공은 주전공보다 적은 요건을 따로 만든다(예: 복수전공 36학점, 부전공 21학점). 요건 판정은 졸업 사정([26장](26-graduation.md))에서 한다.

## CSV 가져오기

교과목 목록의 **CSV 가져오기**(`교과목, 버전, 선수과목 관리` 권한)로 교과목 버전을 한꺼번에 넣는다. 한 행이 한 버전이다. 교과목은 코드로 찾고(없으면 만든다), 버전은 코드와 시작일로 찾으므로 같은 파일을 다시 가져오면 갱신되고, 다른 시작일의 행은 개정 버전이 된다. 기간이 겹치는 행은 그 행만 실패한다.

| 열 | 설명 |
|---|---|
| `code` | 교과목 코드(필수) |
| `org_unit` | 관리 조직 코드. 새 교과목에 필수 |
| `effective_start_date`, `effective_end_date` | 버전 기간(`YYYY-MM-DD`) |
| `title_en`, `title_ko`, `title_zh-hans`, `title_lo` | 언어별 교과목명. 새 교과목은 영어 필수 |
| `credits`, `lecture_hours`, `lab_hours` | 학점(새 버전 필수, 0~30), 시간(0~40) |
| `category` | 교과 구분 코드 |
| `grading_basis` | `graded` 또는 `pass_fail` |
| `counts_toward_credit_limit` | `1`/`0` |

같은 작업을 `uv run manage.py reference_import courses <파일> --actor=<이메일>`로 할 수 있다([9장](09-csv-import.md)).
