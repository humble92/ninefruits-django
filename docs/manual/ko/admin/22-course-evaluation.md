# 22. 강의평가

메뉴: **강의평가 > 학기 강의평가**, **강의평가 양식**, **강좌별 응답**, **설정 > 강의평가**. 학생은 포털 **강의평가**, 교원은 포털 **담당 강좌 > 강의평가 결과**를 쓴다.

| 권한 | 할 수 있는 일 |
|---|---|
| `강의평가 응답률과 결과 조회` | 강좌별 응답 수와 응답률, 공개된 결과. 조직 단위 범위로 할당하면 그 조직이 개설한 강좌만 |
| `강의평가 양식, 학기 강의평가, 결과 공개 관리` | 양식과 문항, 학기 강의평가 설정, 결과 공개, 강의평가 설정 |

역할 기본값: 교무 담당은 둘 다, 학과 조교는 조회(학과 범위).

## 레거시와 다른 점

- **익명성.** 레거시는 응답마다 학번을 저장했고 교수 계정이 원본 테이블을 읽을 수 있었다. 신규 시스템은 **누가 평가했는지(완료 기록)**와 **무엇을 답했는지(응답)**를 따로 저장한다. 응답에는 학생, 순번, 시각이 없다. 응답은 데이터 변경 기록(감사)에도 남기지 않는다(감사 기록에 수행자가 남기 때문이다).
- **결과 공개 기준.** 레거시는 교수 화면에 최소 응답 기준이 없었고, 교수가 다른 강좌 결과도 볼 수 있었다. 신규 시스템은 학기 결과를 **공개**한 뒤, **최소 응답 수와 응답률을 채운 강좌만** 결과와 의견을 보여 준다. 교원은 자기 강좌만 본다.
- **성적 조회 제한.** 레거시는 메뉴 링크만 막았고, 평가 기간이 지나도 잠금이 풀리지 않았다. 신규 시스템은 서버에서 막고, 평가 기간이 끝나면 풀린다.
- **문항 관리.** 레거시는 학기마다 SQL로 문항을 넣었다. 신규 시스템은 화면에서 양식과 문항을 관리한다.
- 모두 1점이나 모두 5점인 응답을 거부하던 규칙은 설정으로 바꿨다(기본 끔).

## 학기 준비 순서

1. **양식**: **강의평가 양식**에서 양식을 고른다. 한국 대학 프로파일이 `STANDARD` 양식을 넣는다(강의 준비, 강의 방법, 강의 내용, 평가 방법, 교학 시설 및 장비 각 3문항, 5점 척도, 의견 1문항).
2. **학기 강의평가 설정**: 학기, 양식, 최소 응답 수, 최소 응답률(%). 기본값은 **설정 > 강의평가**의 값이다(5명, 25%). 두 기준을 모두 넘어야 결과가 보인다. 응답 수는 익명성(응답이 몇 명뿐이면 학생을 짐작할 수 있음), 응답률은 결과의 대표성을 위한 기준이다.
3. **평가 기간**: 학기 수정 화면의 **업무 기간**에 세션별 **강의평가** 기간을 넣는다([10장](10-terms.md)). 대상 조건으로 학년별 기간도 둘 수 있다.
4. 기간 중 `uv run manage.py evaluation_remind {학기}`로 미완료 학생에게 안내 메일을 보낸다(`--dry-run`이면 대상 학생 수만 센다). **강좌별 응답**에서 응답률을 본다.
5. 성적 처리가 끝나면 **결과 공개**(또는 `uv run manage.py evaluation_publish_results {학기}`). 명령은 [운영 명령](../operations/commands.md)에 있다.

## 양식과 문항

| 항목 | 설명 |
|---|---|
| 코드, 이름, 설명 | 설명은 학생 평가 화면 위에 나온다 |
| 척도 점수 | 2~10. 보통 5 |
| 1점 설명, 최고점 설명 | 예: 전혀 그렇지 않다, 매우 그렇다 |

**문항** 탭: 영역(같은 영역 문항은 묶어서 보인다), 문항, 유형(척도, 주관식), 필수, **역문항**(부정형 문항. 평균을 낼 때 응답을 뒤집는다. 예: "수업 진도를 따라가기 어려웠다"에 5점이면 1점으로 센다), 순서.

응답이 한 건이라도 있는 양식은 문항과 척도를 바꿀 수 없다(결과가 묻지 않은 질문의 답이 되지 않게). 바꾸려면 **양식 복사**로 새 양식을 만들어 다음 학기에 쓴다.

## 평가 대상

- 학기 강의평가가 설정된 학기의, 수강 중이거나 이수한 과목. 철회·취소한 과목은 빠진다.
- 교과목의 **강의평가 대상**을 끈 과목은 빠진다(실습, 인턴십 등. [17장](17-courses-and-curriculum.md)).
- 그 과목 세션의 강의평가 기간이 학생에게 열려 있을 때만 평가할 수 있다.

## 학생 화면

포털 **강의평가**: 평가할 과목 목록에서 **평가하기**를 눌러 문항에 답하고 제출한다. 필수 문항에 모두 답해야 하고, 제출하면 바꿀 수 없다. 한 과목에 한 번만 평가한다.

**성적 조회 제한**(설정, 기본 켬): 평가 기간 중 그 학기에 평가하지 않은 과목이 있으면 그 학기 성적이 포털 성적 화면과 성적표에서 가려지고 안내가 나온다. 평가를 마치거나 평가 기간이 끝나면 보인다. 다른 학기 성적은 그대로 보인다.

## 결과

- 교원: 포털 **담당 강좌**의 **강의평가 결과**. 학기 결과가 공개된 뒤에만 열린다.
- 직원: **강의평가 > 강좌별 응답**에서 강좌별 응답 수와 응답률, **결과**로 결과 화면을 연다. 세부 결과는 직원에게도 공개 뒤에만 보인다(기간 중 결과 변화와 완료 시각을 맞춰 보면 학생을 짐작할 수 있기 때문이다).
- 결과 화면: 응답 수/대상 수(응답률), 문항별 평균과 점수별 응답 수(역문항은 뒤집어서), 전체 평균, 의견(무작위 순서).
- 응답 수가 최소 응답 수 미만이거나 응답률이 최소 응답률 미만인 강좌는 결과와 의견을 보여 주지 않고 응답 수만 보여 준다.

## 설정

**설정 > 강의평가**: 강의평가를 마칠 때까지 그 학기 성적을 가림(기본 켬), 모든 문항에 같은 답이면 거부(기본 끔), 새 학기 강의평가의 최소 응답 수(기본 5)와 최소 응답률(기본 25%, 레거시 교무 화면 기준).

## 이 설치본의 화면

원본(Filament, Livewire) 화면과 기능은 같고 조작 방식이 조금 다르다.

- **학기 강의평가** 목록 위 **학기 강의평가 설정**은 입력 화면을 연다(학기, 양식, 최소 응답 수, 최소 응답률). 비운 기준은 새 학기면 설정의 기본값, 이미 있는 학기면 지금 값을 쓴다. 행 메뉴 **변경**은 같은 화면(학기는 바꿀 수 없다)이고, 응답이 생긴 학기는 양식을 바꿀 수 없다. 행 메뉴 **결과 공개**는 확인 화면을 연다. 행 메뉴는 공개된 학기에도 보이며, 이미 공개된 학기는 메시지로 알려 준다.
- **강의평가 양식** 수정 화면의 **문항** 탭에서 문항을 추가·수정·삭제한다. 응답이 있는 양식은 문항이 읽기 전용이고 척도 점수 칸이 잠긴다. 화면 위 **양식 복사**는 새 코드를 입력하는 화면을 열고, 복사가 끝나면 새 양식의 수정 화면으로 간다.
- **강좌별 응답** 필터: 학기(기본은 강의평가가 있는 가장 최근 학기, **전체**로 모든 학기), 개설 조직. 검색은 교과목 코드 앞부분. 행 메뉴 **결과**는 포털 결과 화면(`/portal/sections/{강좌 ID}/evaluation/`)을 같은 창에서 연다.
- 포털 **담당 강좌** 표의 **강의평가 결과** 열: 결과가 공개된 학기면 **결과** 링크, 아니면 **미공개**.
- 학생 포털 **강의평가**: **제출**을 누르면 브라우저가 한 번 더 묻는다(자바스크립트가 꺼져 있으면 바로 제출된다). 필수 문항이 빠지면 입력한 답과 오류가 그대로 다시 보인다. 성적 화면의 안내에 **강의평가** 링크가 있다.
- 응답 저장: 응답 ID는 무작위 UUID다. 응답, 답변, 완료 기록은 학생의 수강·기간·중복을 확인한 뒤 시스템 컨텍스트에서 한 트랜잭션으로 저장되며, 데이터 변경 기록(감사)에 남지 않는다. 양식이 잠겼는지(응답이 있는지)는 화면을 연 사람의 조회 범위와 관계없이 판단한다.
