# 11. 교과 구분과 성적 척도

## 교과 구분

메뉴: **기준정보 > 교과 구분** (`교과 구분 관리` 권한). 레거시 `SFOBJDIST`를 대신한다.

교양필수, 전공선택처럼 교과목을 나누는 기준이다. **상위**를 지정해 묶을 수 있다(예: 교양 → 교양필수, 교양선택). 졸업 요건(Phase 4, 11)에서 "전공필수 30학점"처럼 참조한다.

## 성적 척도

메뉴: **기준정보 > 성적 척도** (`성적 척도 관리` 권한). 레거시 `SSCOREDEF`를 대신한다.

| 척도 항목 | 설명 |
|---|---|
| 만점 평점 | 예: 4.5 |
| 기본 | 하나만 지정할 수 있다. 기본 척도가 아직 없을 때만 켤 수 있다(아래 참조) |

척도를 열고 아래 **등급**에서 등급을 추가한다.

| 등급 항목 | 설명 |
|---|---|
| 등급 | 예: `A+`, `P` |
| 평점 | 평점 계산에 포함하는 등급은 필수 |
| 하한/상한(%) | 원점수 환산 기준(선택). 예: A+ 95~100 |
| 평점 계산 포함 | P/NP처럼 평점에 넣지 않는 등급은 끈다 |
| 이수 | F, NP처럼 학점을 받지 못하는 등급은 끈다 |
| 적용 과목 | 일반 과목(등급), P/F 과목(P, NP), 둘 다(예: I 미완). 성적 입력 화면은 과목의 성적 방식에 맞는 등급만 보여 준다 |

**기본 척도는 설치할 때 정해지고 바꿀 수 없다**(2026-10-23 결정). 성적과 평점이 모두 그 척도에 있기 때문이다. `setup_install --grade-scale=4.5|4.3`으로 정하거나, 정하지 않으면 첫 프로파일의 척도가 된다. 기본 표시는 화면에서 바꿀 수 없고 기본 척도는 지울 수 없다. 등급별 점수 대역과 평점은 이 화면에서 고친다([21장](21-grades.md)).

프로파일이 넣는 척도

- 한국 대학: 4.5 척도(`KR45`): A+ 4.5(95~100), A0 4.0(90~), B+ 3.5(85~), B0 3.0(80~), C+ 2.5(75~), C0 2.0(70~), D+ 1.5(65~), D0 1.0(60~), F 0, P, NP
- `--grade-scale=4.3` 또는 레거시 YUST 프로파일: 4.3 척도(`KR43` 또는 `YUST43`): A+ 4.3(97~100), A0 4.0(93~), A- 3.7(90~), B+ 3.3(87~), B0 3.0(83~), B- 2.7(80~), C+ 2.3(77~), C0 2.0(73~), C- 1.7(70~), D+ 1.3(67~), D0 1.0(63~), D- 0.7(60~), F 0, P, NP(레거시는 N, I 포함). 점수 대역은 3점 간격으로 시작하므로 학교 기준에 맞게 고친다.

이미 성적에 쓰인 척도는 지울 수 없다.
