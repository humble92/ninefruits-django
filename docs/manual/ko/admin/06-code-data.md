# 6. 코드 데이터, 국가, 언어

메뉴: **기준정보 > 코드 데이터**, **국가**, **언어** (`코드 데이터, 국가, 언어 관리` 권한)

## 코드 데이터

대학마다 다른 짧은 목록이다. 목록(유형)마다 코드 값이 있다.

| 목록 코드 | 용도 | 레거시 |
|---|---|---|
| `ethnicity` | 민족 | `FNATION` |
| `admission_type` | 입학 구분 | `FADMDIST` |
| `room_type` | 강의실 용도 | `ROOM.FORWHAT` |

- 시스템 목록(위 세 개)은 프로그램이 코드로 찾으므로 목록 코드를 바꾸거나 지울 수 없다. 값은 자유롭게 추가한다.
- 목록을 열고 아래 **코드 값**에서 추가한다. 코드는 영문 소문자, 숫자, 밑줄로 짓는다(예: `korean`). 이름은 언어별로 입력하고 영어 이름은 필수다.
- 쓰지 않게 된 값은 지우지 말고 **사용**을 끈다. 이미 그 값을 쓰는 데이터가 있으면 삭제할 수 없다.
- 많은 값은 [CSV 가져오기](09-csv-import.md)로 넣는다.

## 국가와 언어

ISO 표준 목록(국가 249개, 언어 약 180개)이 설치 때 들어간다. 이름은 설치된 언어로 자동 입력된다.

- 화면에 표시되는 이름을 바꾸려면 **수정**에서 고친다. 이후 시스템 업데이트에서도 바꾼 이름은 유지된다.
- 선택 목록에 나오지 않게 하려면 **사용**을 끈다.
