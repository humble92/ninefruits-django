# 12. 인물과 학적

메뉴: **학생과 교직원 > 인물**, **학적**, **교원**

## 인물과 학적의 관계

| 개념 | 설명 |
|---|---|
| 인물 | 한 사람. 이름, 생년월일, 연락처, 신분 번호, 사진, 보호자. 학생이든 교원이든 한 사람은 인물 하나다 |
| 학적 | 입학 1건. 학번, 프로그램, 입학일, 학년, 상태. 졸업 후 재입학하면 같은 인물에 **새 학적(새 학번)**이 생긴다 |
| 교원 | 인물의 교원 정보(교직원 번호, 소속, 고용 구분, 직위). 한 인물에 하나 |
| 계정 | 로그인 계정. 인물과 1:1로 연결된다. 학적이 여러 개여도 계정은 하나다 |

학생과 졸업생은 포털에서 학적을 골라 본다(학적이 여러 개일 때 위쪽에 학적 선택이 나온다).

## 인물

- 이름은 **로마자 법적 이름**(여권 기준: 성, 이름)과 **언어별 이름**(예: 한국어 `김민수`)을 함께 둔다. 화면에는 현재 언어의 이름이 있으면 그 이름을, 없으면 로마자 이름을 보여 준다. 검색은 둘 다 된다.
- 주민등록번호, 여권번호는 암호화해 저장하고 가려서 표시한다. 전체 값은 `신분증·여권번호 표시` 권한으로 인물 상세 위쪽의 **주민등록번호 보기**(또는 **여권번호 보기**)를 누르고 사유를 입력하면 별도 화면에 한 번 보여 준다. 값은 저장되지 않고(메시지나 기록에 남지 않음), 보기는 사유와 함께 보안 로그에 남는다. 번호로 검색하면 정확히 일치할 때만 찾는다.
- 사진은 인물 수정 화면에서 올린다. 사진은 권한 확인 후에만 내려받을 수 있다(공개 주소 없음).
- 보호자는 인물 상세의 **보호자** 탭에서 관리한다. 학생 본인도 포털 **내 정보**에서 보호자와 연락처(이메일, 전화, 주소, 우편번호)를 고칠 수 있다. 이름, 생년월일, 신분 번호는 본인이 고칠 수 없다.
- 인물 상세 아래쪽 **변경 이력**에 이 인물과 보호자 행의 데이터 변경 기록(시각, 표, 바뀐 열, 사용자)이 최근 50건까지 나온다. `감사 기록 조회` 권한이 있으면 각 기록의 상세(변경 전후 값)로 이동한다. 학적 상세에도 학적, 학적 변동, 지도교수, 복수전공·부전공의 변경 이력이 같은 방식으로 나온다.

| 권한 | 할 수 있는 일 |
|---|---|
| `전체 인물 조회` | 모든 인물 조회 |
| `인물 등록과 수정` | 인물 만들기, 수정 |
| `신분증·여권번호 표시` | 주민등록번호, 여권번호 전체 보기 |
| `중복 인물 병합`, `계정 초대` | [14장](14-merge-and-invitations.md) |

`전체 인물 조회` 권한이 없는 담당자도 자기가 볼 수 있는 학적의 인물과 교원은 볼 수 있다.

## 학적 등록

1. **학적** 목록 위쪽의 **학적 추가**를 누른다(화면 제목 **학적 등록**).
2. **기존 인물**(재입학, 교원이 대학원 입학 등)을 고르거나 **새 인물**을 입력한다. 새 인물을 만들기 전에 검색으로 같은 사람이 이미 있는지 확인한다.
3. 프로그램, 입학일, 학년, 입학 구분을 입력한다. 소속(관리 조직)은 프로그램의 조직으로 정해진다.
4. 학번을 비워 두면 **설정 > 학적**의 학번 형식으로 만든다. 기본 형식 `{YYYY}{SEQ:5}`는 입학 연도 + 5자리 일련번호(예: `202600001`)다. 이미 쓰인 번호(가져온 학적 포함)는 건너뛴다.

| 학번 형식 토큰 | 뜻 |
|---|---|
| `{YYYY}` | 입학 연도 |
| `{YY}` | 입학 연도 끝 두 자리 |
| `{SEQ:n}` | n자리 일련번호. 형식에 하나만 있어야 한다. 앞부분(예: `2026`)마다 따로 센다 |

학적의 학번, 상태는 수정 화면에서 바꾸지 않는다. 상태는 학적 변동으로 바꾼다([13장](13-status-changes-and-advisors.md)).

## 학적 조회 범위

| 권한 범위 | 볼 수 있는 학적 |
|---|---|
| `학적 조회` 또는 `학적 등록과 수정`, 전체 범위 | 모든 학적 |
| 조직 단위 범위 | 그 조직과 하위 조직 소속 학적 (예: 공과대학 범위 = 공과대학 모든 학과) |
| 프로그램 범위 | 그 프로그램 학적 |
| 조직 단위·프로그램 범위(복수전공·부전공) | 그 조직이나 프로그램을 복수전공·부전공으로 이수 중인 학생의 학적(조회만) |
| 복수전공·부전공 승인 담당 | 처리할 신청을 낸 학생의 학적(조회만) |
| 지도교수 | 현재 지도 학생 |
| 학생 본인 | 자기 학적 |

같은 규칙이 DB(행 수준 보안)에도 있어서, 화면 밖 조회(보고서, 직접 접속)에서도 범위를 넘지 못한다.

## 교원

**교원** 목록 위쪽의 **교원 추가**(화면 제목 **교원 등록**)에서 기존 인물을 고르거나 새 인물을 입력한다(`교원 관리` 권한). 종료일이 지나면 현재 교원 목록(기본 필터)과 지도교수 선택에서 빠진다.

학적, 교원 목록 위쪽의 **CSV 가져오기**를 쓴다. 열 형식은 [9장](09-csv-import.md#학생과-교원).
