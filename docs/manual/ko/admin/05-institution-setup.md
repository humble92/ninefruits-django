# 5. 기관 설정과 초기 세팅 순서

## 기관 설정

**설정 > 기관**에서 정한다(`기관 설정 관리` 권한).

| 항목 | 설명 |
|---|---|
| 기관 이름 | 언어별로 입력. 관리 화면 왼쪽 위에 표시된다 |
| 시간대 | 학기 날짜와 업무 기간을 판단하는 기준. 예: `Asia/Seoul`. 저장된 시각은 모두 이 시간대로 표시된다 |
| 제공 언어 | 사용자가 고를 수 있는 언어. 번역 파일이 설치된 언어만 목록에 나온다 |
| 기본 언어 | 언어를 고르지 않은 사용자와 브라우저 언어를 알 수 없을 때 쓰는 언어 |

## 신규 대학 초기 세팅 순서

IT 운영자가 `setup_install`을 마친 뒤(운영 매뉴얼 [설치](../operations/installation.md)), 업무 관리자가 아래 순서로 입력한다. 앞 단계의 코드를 뒤 단계가 참조하므로 순서를 지킨다.

1. **기관 설정**: 이름, 시간대, 언어 (이 장)
2. **코드 데이터**: 민족, 입학 구분, 강의실 용도 값 ([6장](06-code-data.md)). 설치 때 한국 대학 프로파일을 적용했다면 강의실 용도는 이미 있다.
3. **조직 단위 유형** 확인 후 **조직 단위**: 대학교 → 단과대학 → 학과 순서 ([7장](07-org-units-and-programs.md)). 많으면 CSV로 ([9장](09-csv-import.md)).
4. **프로그램**: 학과별 학위 과정 ([7장](07-org-units-and-programs.md))
5. **건물**, **강의실** ([8장](08-facilities.md), CSV 가능)
6. **학기 종류**, **교시** 확인 ([10장](10-terms.md))
7. **교과 구분**, **성적 척도** 확인. 기본 척도가 하나 지정되어 있어야 한다 ([11장](11-course-categories-and-grade-scales.md))
8. **학년도** → **학기** → 학기별 **업무 기간** ([10장](10-terms.md))
9. **사용자와 권한**: 학과 조교처럼 조직 단위 범위가 필요한 역할은 이제 범위 대상으로 학과를 고를 수 있다 ([2장](02-users-and-roles.md))

입력이 끝나면 IT 운영자에게 `uv run manage.py term_inspect`로 업무 기간 점검을 요청한다.
