# 18. 개설강좌와 시간표

메뉴: **교육과정과 개설 > 개설강좌**, **시간표** (`개설강좌 조회`, `개설강좌 편성` 권한. 조직 단위 범위로 할당하면 그 조직이 개설한 강좌만)

## 개설강좌 만들기

1. **개설강좌 > 만들기**에서 학기의 세션, 교과목, 분반(예: `01`), 정원, 개설 조직을 입력한다. 교과목명과 학점은 세션 시작일에 유효한 교과목 버전에서 온다.
2. 수정 화면의 탭에서 **강의 시간**, **담당 교원**, **좌석 할당**을 입력한다.
3. 다 되면 **공개**한다. 공개된 강좌만 포털 **개설강좌 조회**에 보이고 수강신청 대상이 된다([20장](20-registration.md)).

| 상태 | 뜻 |
|---|---|
| 작성 중 | 편성 중. 담당자와 담당 교원만 본다 |
| 공개 | 학생에게 보인다. **작성 중으로** 되돌릴 수 있다 |
| 폐강 | 사유 필수. 강의실과 교원 시간이 비워진다. **다시 열기**하면 작성 중이 되고, 그 사이 다른 강좌가 시간을 썼으면 열리지 않는다 |

작성 중인 강좌만 삭제할 수 있다. 공개했던 강좌는 폐강한다.

| 항목 | 설명 |
|---|---|
| 세션 | 학기의 세션([10장](10-terms.md)). 다른 세션으로 옮기면 강의 날짜와 교과목 버전이 그 세션에 맞게 바뀐다 |
| 수강 대상, 수강 제외 대상 | 학년, 입학 연도, 프로그램, 조직 단위. 예: 교양 과목에서 해당 전공 학생 제외. 복수전공·부전공 학생은 그 프로그램 학생으로도 본다 |
| 강의 언어 | 예: `ko`, `en` |
| 대기 인원 | 정원이 찬 뒤 받을 대기자 수. 0이면 대기 없음([20장](20-registration.md)) |
| 평가 방식 | 절대평가(기본. 교원이 점수 입력, 성적은 점수로 계산) 또는 상대평가(성적만 입력, 등급 비율 상한 적용). 교원은 성적 입력 화면에서 변경을 요청하고 개설 담당자가 승인한다. 성적이 입력된 뒤에는 바꿀 수 없다([21장](21-grades.md)). 학기 복사 때 따라간다 |

## 강의 시간과 강의실

**강의 시간** 탭에서 요일, 시작·종료 시각, 강의실을 입력한다. **교시**를 고르면 시각이 채워진다. 강의 날짜는 비우면 세션 기간이다.

- 같은 강의실을 같은 시간에 두 강좌가 쓸 수 없고, 한 교원이 같은 시간에 두 강좌를 맡을 수 없다. DB가 막으며, 화면에는 "이 시간에 강의실을 OOO 강좌가 이미 사용합니다"처럼 겹치는 강좌가 표시된다.
- 전반기와 후반기처럼 날짜가 겹치지 않으면 같은 시간, 같은 강의실을 쓸 수 있다.
- 폐강된 강좌는 시간을 차지하지 않는다.

## 담당 교원

**담당 교원** 탭에서 교원과 역할(담당 교원, 공동 담당, 조교)을 지정한다. 한 강좌에 여러 명을 지정할 수 있다. 이미 같은 시간에 다른 강좌를 맡은 교원은 지정되지 않는다. 담당 교원은 포털 **담당 강좌**에서 시간표와 강의계획서를 관리한다.

## 좌석 할당

**좌석 할당** 탭에서 대상 학생별 좌석을 정한다(예: 전공 학생 30석). **일반 좌석 전환 시각**이 지나면 쓰지 않은 좌석은 누구나 신청할 수 있다. 할당 좌석의 합은 정원을 넘을 수 없다. 수강신청에서 적용된다([20장](20-registration.md)).

## 강의계획서

담당 교원이 포털 **담당 강좌**에서 작성한다(개설강좌 화면의 **강의계획서** 버튼으로도 열린다). 강의 개요, 학습 목표, 교재와 자료, 수업 운영 규정, 평가 방법(항목과 비율), 주차별 계획을 입력하고 **공개**하면 학생에게 보인다.

## 다른 학기에서 복사

개설강좌 목록의 **다른 학기에서 복사**로 이전 학기(보통 작년 같은 학기)의 편성으로 시작한다. 먼저 **미리 보기만**으로 결과를 확인한다.

- 폐강되지 않은, 내 권한 범위 안의 강좌를 작성 중 상태로 복사한다.
- 함께 복사: 재직 중인 담당 교원, 강의 시간과 강의실, 좌석 할당(전환 시각은 학기 시작일 차이만큼 이동), 강의계획서(비공개 초안).
- 세션은 코드로 맞춘다(없으면 전체 학기). 교과목 버전은 새 세션 시작일 기준.
- 대상 학기에 같은 분반이 있으면 건너뛰고, 강의실이 이미 사용 중이면 강의실 없이 복사한다. 결과 알림에 건너뛴 강좌와 확인할 강좌가 나온다.

IT 운영자는 `uv run manage.py section_copy`로 같은 작업을 할 수 있다.

## 시간표와 점검

- **시간표**: 학기와 강의실 또는 교원을 고르면 주간 시간표를 보여 준다.
- 공개 전 점검: IT 운영자가 `uv run manage.py schedule_check_conflicts <학기 코드>`로 정원보다 작은 강의실, 퇴직한 담당 교원, 교과목 버전 불일치, 정원을 넘는 좌석 할당을 찾는다([명령 레퍼런스](../operations/commands.md#schedule_check_conflicts)).

## 권한 범위

목록과 화면은 `개설강좌 조회`·`개설강좌 편성` 권한 범위의 개설 조직 강좌만 보여 준다. 강의 시간, 담당 교원, 좌석 할당 탭과 상태 버튼(공개, 작성 중으로, 폐강, 다시 열기)은 강좌의 개설 조직을 범위로 포함한 `개설강좌 편성` 권한이 있어야 쓸 수 있다. 시간표 화면은 학기 기본값으로 수업 중인 학기(없으면 다음 학기)를 고른다. 휴대폰에서는 요일별 목록으로 보인다.
