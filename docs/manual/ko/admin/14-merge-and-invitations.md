# 14. 인물 병합과 계정 초대

메뉴: **학생과 교직원 > 인물** 상세 화면 위쪽의 **중복 인물 병합**, **계정 가입 안내 보내기**

## 중복 인물 병합

같은 사람이 인물 두 개로 등록된 경우(예: 재입학 때 기존 인물을 찾지 못하고 새로 만듦)에 쓴다. `중복 인물 병합` 권한이 필요하다.

1. 후보 찾기: 같은 이름과 생년월일, 같은 주민등록번호를 인물 목록 검색으로 확인한다. IT 운영자는 `uv run manage.py people_find_duplicates`로 전체 후보 목록을 뽑을 수 있다.
2. **없앨(중복) 인물**의 상세 화면에서 **중복 인물 병합**을 누르고, **남길 인물**을 목록에서 고른 뒤 사유를 입력한다. 병합이 끝나면 남길 인물 화면으로 이동한다.
3. 없앨 인물의 학적, 지원서, 교원 정보, 보호자, 계정이 남길 인물로 옮겨진다. 두 사람 모두 계정이 있으면 없앨 인물의 계정은 비활성화되고, 연결된 학교 통합 로그인은 가능하면 옮겨진다.
4. 없앨 인물은 **병합됨**으로 남아(목록 필터 **병합됨**) 예전 기록이 계속 찾아진다. 새 학적 등록에는 쓸 수 없다.

- 두 사람 모두 교원 정보가 있으면 병합되지 않는다. 교원 정보를 먼저 정리한다.
- 두 사람 모두 같은 모집 회차에 진행 중인 지원서가 있으면 병합되지 않는다. 지원자에게 하나를 포기하게 한다.
- **되돌릴 수 없다.** 병합 전에 학적과 생년월일을 반드시 확인한다. 병합은 업무 감사 기록에 사유와 함께 남는다.

## 계정 초대

CSV로 가져온 학생, 교원처럼 계정이 없는 인물에게 가입 안내 메일을 보낸다. `계정 초대` 권한이 필요하다.

1. 인물 상세에서 **계정 가입 안내 보내기**를 누르고 로그인 이메일을 입력한다(보통 개인 이메일).
2. 받은 사람이 메일의 링크에서 비밀번호를 정하면 계정이 만들어지고 바로 로그인된다.

- 링크 유효 기간은 **설정 > 학적 > 가입 안내 링크 유효 기간**(기본 14일).
- 다시 보내면 이전 링크는 더 이상 쓰이지 않는다.
- 이미 계정이 있는 인물이나 다른 계정이 쓰는 이메일로는 보낼 수 없다.
- 졸업 후에도 같은 계정을 쓴다. 학교 이메일만 쓰던 사람은 개인 이메일로 로그인 이메일을 바꿔 두도록 안내한다([15장](15-sign-in-methods.md)).
