# 1. 시작하기

## 로그인

1. 브라우저에서 `/accounts/login/`으로 들어간다. 로그인하지 않은 상태로 `/portal/`이나 `/admin/`을 열어도 이 화면으로 이동하고, 로그인하면 원래 화면으로 돌아간다.
2. 이메일과 비밀번호를 입력하고 **로그인**을 누른다.
3. 2단계 인증을 등록했다면 인증 앱의 6자리 코드 또는 이메일로 받은 코드를 입력한다.
4. 개인 PC라면 **이 기기 기억하기**를 선택할 수 있다. 정해진 기간(기본 30일) 동안 코드 입력을 생략한다. 공용 PC에서는 선택하지 않는다.

비밀번호를 잊었다면 로그인 화면의 **비밀번호를 잊으셨나요?**에서 재설정 링크를 받는다. 로그인 실패가 반복되면 잠시 로그인이 제한된다.

관리 화면에는 별도의 로그인 화면이 없다. `/admin/login/`도 같은 로그인 화면(`/accounts/login/`)으로 보낸다.

## 포털과 관리 화면

| 화면 | 주소 | 사용자 |
|---|---|---|
| 포털 | `/portal/` | 모든 사용자. 홈(내 권한), 보안 설정. 학생/교수 기능은 이후 Phase에서 추가 |
| 관리 화면 | `/admin/` | `관리 화면 사용` 권한이 있는 교직원 |

두 화면은 같은 로그인을 쓴다.

- 포털 위쪽 메뉴에는 사용자의 신분(학생, 교원 등)과 권한에 맞는 항목만 보인다. `관리 화면 사용` 권한이 있으면 **관리** 항목으로 관리 화면에 간다.
- 관리 화면 오른쪽 위 사용자 메뉴에서 **2단계 인증**(포털 보안 설정)과 **포털**로 이동하고, **로그아웃**한다. 첫 화면(**대시보드**)에는 계정 이름과 이메일, 포털 링크, 로그아웃 버튼이 있다.
- 권한이 없는 계정으로 관리 화면 주소를 열면 "403 접근 거부"가 나온다.

관리 화면 왼쪽 메뉴는 권한에 따라 보인다. 메뉴는 원본과 같은 묶음 순서(학생과 교직원, 입학, 교육과정과 개설, 수강신청, 성적, 강의평가, 어학/종합시험, 증명서, 졸업, 보고서, LMS 연동, 기준정보, 사용자와 권한, 감사, 설정)로 나오고, 볼 수 있는 화면이 없는 묶음은 나오지 않는다. 메뉴가 보이지 않으면 시스템 관리자에게 역할 할당을 요청한다. 왼쪽 메뉴 위의 검색 칸으로 메뉴 이름을 찾을 수 있다.

## 2단계 인증 안내

2단계 인증 정책이 "권장"이거나 필수 정책의 유예 기간 중이면 포털과 관리 화면 위쪽에 안내가 나온다. **지금 설정**을 누르면 포털 보안 화면으로 간다. 자세한 내용은 [3. 2단계 인증](03-two-factor-authentication.md).

## 언어

포털 위쪽(로그인 화면도 같음)의 언어 선택, 또는 관리 화면 사용자 메뉴의 언어 목록에서 바꾼다. 로그인한 상태에서 바꾸면 계정에 저장되어 다음 로그인에도 유지된다. 제공 언어는 시스템 관리자가 **설정 > 기관**에서 정한다.
