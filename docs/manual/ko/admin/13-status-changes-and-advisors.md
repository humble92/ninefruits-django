# 13. 학적 변동과 지도교수

메뉴: **학생과 교직원 > 학적 변동**, **학적 변동 유형**, 학적 상세의 **학적 변동**, **지도교수** 탭

## 학적 상태

| 상태 | 뜻 |
|---|---|
| 재학 | 수강 가능 |
| 휴학 | 학적 유지, 수강 불가 |
| 자퇴, 제적 | 학적 종료. 재입학하면 새 학적 |
| 졸업 | 졸업일 필수. 계정은 졸업생 권한으로 유지된다 |

재학과 휴학을 "현재 학생"으로 본다(학번 로그인, 지도교수 배정 등).

## 학적 변동 유형

유형마다 **변동 후 상태**, **변동 가능한 현재 상태**, **학생 신청 가능** 여부를 정한다. 설치 시 휴학, 복학, 자퇴, 제적, 재입학, 졸업이 만들어진다. 이름은 바꿀 수 있고, 다시 설치해도 바꾼 이름은 유지된다.

## 학생 신청과 승인

1. 학생이 포털 **내 학적**에서 유형, 변동일, 사유를 입력해 신청한다. 한 학적에 처리 중인 신청은 하나만 둘 수 있고, 처리 전에는 학생이 취소할 수 있다.
2. 담당자가 **학적 변동** 목록(기본: 처리 대기)에서 **승인** 또는 **반려**한다. 반려는 의견이 필수다. 목록 각 행의 동작 메뉴에서 처리하고, 의견을 입력하는 창이 열린다.
3. 승인하면 학적 상태가 바로 바뀌고 변동 이력에 남는다.

- `학적 변동 승인과 처리` 권한이 필요하고, 권한 범위(조직 단위, 프로그램) 안의 학적만 처리할 수 있다.
- 자기가 신청한 건은 승인할 수 없다(직무 분리).
- 신청 후 학적 상태가 바뀌었으면(예: 다른 경로로 이미 휴학 처리) 승인되지 않는다. 반려하고 다시 신청하게 한다.

## 담당자가 직접 처리

제적, 서면으로 받은 신청 등은 학적 상세의 **학적 변동 처리**로 바로 처리한다. 사유가 필수이고 처리자가 승인자로 기록된다. `학적 변동 승인과 처리` 권한이 필요하다.

모든 변동은 업무 감사 기록과 데이터 변경 기록에 남는다([4장](04-audit.md)).

## 지도교수

학적 상세 **지도교수 배정**에서 교원, 구분(주 지도교수, 공동 지도교수), 시작일을 고른다(`지도교수 배정` 권한).

- 주 지도교수는 한 명이다. 새 주 지도교수를 배정하면 이전 배정이 시작일 전날 종료되어 이력이 남는다.
- 현재 재직 교원만 고를 수 있다.
- 지도교수는 포털 **지도 학생**에서 현재 지도 학생 목록을 보고, 그 학생의 학적을 조회할 수 있다.
