# 10. 학년도, 학기, 업무 기간

메뉴: **기준정보 > 학년도**, **학기 종류**, **학기**, **교시** (`학년도, 학기, 학기 종류, 교시 관리`, 업무 기간은 `업무 기간 관리` 권한)

## 레거시와 다른 점

레거시는 학기 상태 플래그(`AFS_CHECK`) 하나로 "현재 학기"를 정해서, 지난 학기 성적 처리와 다음 학기 수강신청을 동시에 하기 어려웠다. 신규 시스템에는 "현재 학기" 설정이 없다. 대신 업무마다 열린 **업무 기간**을 보고 학기를 판단한다. 지난 학기 성적 입력, 이번 학기 수업, 다음 학기 수강신청이 서로 막지 않는다.

## 학년도와 학기

1. **학년도**: 코드(예: `2026`), 이름, 시작일/종료일. 학년도끼리 기간이 겹칠 수 없다.
2. **학기 종류**: 1학기, 2학기, 여름/겨울 계절학기 등. **정규 학기** 표시는 이후 학점 상한 등 규칙에 쓰인다.
3. **학기**: 학년도, 학기 종류, 코드(예: `2026-FA`. 표시용), 이름, 수업 시작일/종료일. 같은 종류의 학기끼리 수업 기간이 겹칠 수 없다.

## 학기 상태

| 상태 | 뜻 | 업무 기간 |
|---|---|---|
| 계획 | 준비 중. 학생에게 보이지 않음 | 열리지 않음 |
| 공개 | 운영 중 | 열림 |
| 성적 마감 | 성적 확정 후 | 열림(성적 이의 등) |
| 보관 | 종료 | 열리지 않음 |

학기 **수정** 화면의 **상태 변경**으로만 바꾼다. 계획 → 공개 → 성적 마감 → 보관 순서이며, 공개와 성적 마감은 한 단계 되돌릴 수 있다. 변경은 사유와 함께 기록된다.

## 세션

학기 안에서 수업이 열리는 기간이다. 학기 **수정** 화면의 **세션** 탭에서 관리한다.

- 학기를 만들면 **전체 학기** 세션(코드 `FULL`)이 저절로 생기고, 학기 날짜를 바꾸면 따라 바뀐다.
- 전반기·후반기 8주 과목, 3주 집중 과목처럼 학기 일부에만 열리는 과목이 있으면 세션을 추가한다. 예: `A` 전반기 9/1~10/25, `B` 후반기 10/26~12/20, `I` 집중 11/1~11/21.
- 세션은 학기 기간 안이어야 한다. 학기 기간을 줄이면 밖으로 나가는 세션을 먼저 고쳐야 한다.
- 모든 개설강좌는 세션 하나에 속한다([18장](18-sections-and-timetables.md)). 세션을 쓰지 않는 대학은 전체 학기 세션 하나로 충분하다.

## 업무 기간

학기 **수정** 화면 아래 **업무 기간**에서 추가한다.

| 항목 | 설명 |
|---|---|
| 업무 | 장바구니, 수강신청, 수강 정정, 수강 철회, 성적 입력, 성적 이의, 강의평가, 졸업 신청, 복수전공·부전공 신청 |
| 세션 | 과목에 딸린 업무(수강 정정, 수강 철회, 성적 입력, 성적 이의, 강의평가)만. 기본은 전체 학기 세션 |
| 시작, 종료 | 기관 시간대 기준 시각. 종료 시각이 되면 닫힌다 |
| 대상 조건 | 비우면 전체. 학년, 입학 연도 범위, 프로그램, 조직 단위(하위 포함)를 조합한다. 모든 조건을 만족해야 대상이다 |

업무는 두 종류다.

| 종류 | 업무 | 기준 |
|---|---|---|
| 과목에 딸린 업무 | 수강 정정, 수강 철회, 성적 입력, 성적 이의, 강의평가 | 과목이 속한 세션. 후반기 과목은 후반기 세션의 정정·철회·성적 기간을 따른다 |
| 학생·학기 업무 | 장바구니, 수강신청, 졸업 신청, 복수전공·부전공 신청 | 학기 전체. 세션 없음 |

**세션별 업무 기간 만들기**: 세션 탭에서 세션의 **업무 기간 복사**를 누르면 다른 세션(보통 전체 학기)의 과목 업무 기간을 이 세션 날짜에 맞춰 복사한다. 앞쪽 기간(정정, 철회)은 세션 시작일 기준으로, 뒤쪽 기간(성적 입력, 강의평가)은 세션 종료일 기준으로 옮긴다. 복사한 뒤 확인하고 고친다.

**시차 오픈 예시**: 수강신청 기간을 세 개 만든다.

| 업무 | 시작 | 대상 조건 |
|---|---|---|
| 수강신청 | 2월 10일 10:00 | 학년 4 |
| 수강신청 | 2월 11일 10:00 | 학년 3 |
| 수강신청 | 2월 12일 10:00 | 학년 1, 2 |

학생별 학년과 입학 연도는 Phase 2 학적 데이터에서 판단한다.

## 교시

수업 시간 단위다. 코드(예: `1`), 이름(1교시), 시작/종료 시각, 요일을 정한다. 강의 시간을 입력할 때 교시를 고르면 시작·종료 시각이 채워진다. 한국 대학 프로파일은 09:00부터 50분 단위 10교시(월~금)를 넣는다.

교시 시각은 시간대와 관계없는 "벽시계 시각"이다. 입력한 그대로 저장된다.

업무 기간의 시작·종료 시각은 관리 화면에서 기관 시간대로 입력하고 표시하며, 저장은 UTC로 한다.
