# 24. 어학/종합시험

메뉴: **어학/종합시험 > 시험 회차**, **시험 결과**, **결과 정정 요청**, **시험 종류**. 학생은 포털 **어학/종합시험**에서 접수하고 결과를 본다.

| 권한 | 할 수 있는 일 |
|---|---|
| `응시 등록, 결과 입력·공개, 외부 성적 등록` | 학생 접수·취소·결시, 결과 입력, CSV 가져오기, 결과 공개, 정정 요청, 외부 성적 등록·삭제, 결과 대장 조회(학적 조회 범위 안에서) |
| `시험 종류, 영역, 회차 관리` | 종류와 영역, 회차 만들기·수정, 회차 합격 점수 변경, 정정 요청 승인·반려 |

역할 기본값: 학적 담당과 교무 담당이 둘 다. 시험 종류와 회차 화면을 보려면 `기준정보 조회` 권한도 필요하다(역할 기본값에 있다). 결과는 학적 조회 범위 안에서만 보이므로 `학적 조회`(또는 관리) 권한을 함께 준다.

## 레거시와 다른 점

- **종류마다 고정 칼럼이 아니다.** 레거시 `CET`는 문법·쓰기·듣기·읽기 네 칼럼이 박혀 있었고, 종합시험(`SSCORE_ADD`)은 과목당 P/N 한 글자, 전산시험(`COMEXAM`)은 또 다른 표였다. 신규 시스템은 **시험 종류**에 영역과 판정 방식을 정의하고, 모든 시험을 같은 회차·접수·결과 구조로 다룬다.
- **합격 판정.** 레거시는 네 영역 합계가 커트라인 이상이면 합격이었고 영역별 최저점이 없었다. 신규 시스템은 종류(또는 회차)의 합격 점수와 **영역별 최저점**으로 판정하고, 판정 결과를 결과에 저장한다. 합격/불합격 종류는 담당자가 판정한다.
- **접수 기간과 정원.** 레거시에는 없었다. 회차에 접수 시작·마감과 정원을 둔다.
- **결과 공개.** 레거시는 입력 즉시 학생이 봤고, 최신 회차만 보였다. 신규 시스템은 회차의 **결과 공개** 뒤에 학생이 보며, 모든 회차의 결과가 남는다. 결과가 있는 회차는 지울 수 없다.
- **외부 성적.** 레거시에는 TOEFL, TOPIK 같은 외부 시험을 기록할 곳이 없었다(졸업사정표의 HSK 칸은 빈 라벨). 외부 성적을 증빙 파일과 함께 등록한다.
- **졸업 요건 연계.** 레거시는 사람이 졸업사정표를 보고 판단했다. 졸업 요건 종류 **시험 합격**으로 교육과정에 넣는다([17장](17-courses-and-curriculum.md)).

## 시험 종류와 영역

**시험 종류**: 코드, 이름(언어별), 구분(어학, 종합시험, 졸업논문, 외부 공인시험), 판정 방식, 만점, 합격 점수, 외부 성적, 사용, 순서.

| 판정 방식 | 입력 | 판정 |
|---|---|---|
| 점수 | 영역별 점수(영역이 없으면 총점) | 총점 ≥ 합격 점수이고 모든 영역 ≥ 영역 최저점. 합격 점수가 없으면 담당자가 고른다 |
| 합격/불합격 | 합격 여부 | 담당자가 고른다 |

**영역**(종류 수정 화면의 **영역** 탭): 코드(CSV 열 이름, 영문·숫자·`-`·`_`), 이름, 만점, 영역 최저점(선택), 순서. 영역이 있으면 총점은 영역 점수의 합이다. 영역 최저점과 같은 점수는 통과, 1점이라도 낮으면 총점이 높아도 불합격이다.

한국 대학 프로파일(`setup_install --profile=korean-university`)이 넣는 종류:

| 코드 | 종류 | 판정 | 비고 |
|---|---|---|---|
| `ENG_COMP` | 영어종합시험 | 점수, 합격 60 | 듣기·읽기·쓰기·문법 각 25점 |
| `COMP_EXAM` | 전산종합시험 | 합격/불합격 | |
| `THESIS` | 졸업논문 | 합격/불합격 | |
| `TOPIK` | 한국어능력시험 | 합격/불합격, 외부 | 등급과 증서 번호 기록 |

프로파일을 다시 실행해도 관리자가 고친 값은 그대로이고, 지운 영역은 다시 생기지 않는다.

## 회차

**시험 회차**: 종류, 시험일(종류별로 유일), 장소, 정원, 접수 시작·마감, 합격 점수(비우면 종류의 값). 회차 화면의 **응시자** 탭에 접수 목록이 있다.

- **학생 접수**(학번 입력): 직원은 접수 기간과 관계없이 시험일까지 접수시킬 수 있다. 정원은 적용된다. 시험일이 지난 회차에는 아무도 접수할 수 없다. 결과는 접수한 학생에게만 입력되며, CSV의 미접수 학생 행은 오류로 보고하고 건너뛴다.
- 학생은 포털에서 접수 기간 중 접수·취소한다. 재학·휴학 중인 학생만 가능하다. 취소한 뒤 다시 접수하면 같은 접수 행이 되살아난다.
- **결과 입력**: 영역별 점수(또는 총점), 필요하면 합격 여부, 비고. 공개 전에는 다시 입력하면 바뀐다(감사 `assessment.result_recorded`). **공개 뒤에는 잠긴다**(아래 정정 요청).
- **결시**: 접수했으나 응시하지 않음. 결과를 입력하면 접수 상태로 돌아간다.
- **접수 취소**: 결과가 입력된 접수는 취소할 수 없다. 사유는 선택이다.
- **결과 공개**: 지금부터 학생이 이 회차의 결과를 본다. 공개 뒤에는 결과를 직접 고치거나 지울 수 없고 **정정 요청**으로 바꾼다(2026-10-23 결정). 명령 `assessment_publish_results`와 같다.
- 회차의 **합격 점수**(종류 값 덮어쓰기): 시험이 어려웠을 때 회의로 커트라인을 낮추는 경우에 쓴다. **공개 전**에는 바꿀 수 있고, 저장하는 순간 이미 입력된 그 회차의 결과를 저장된 점수로 **모두 다시 판정**한다(총점은 새 기준, 영역 최저점은 종류의 값 그대로). **합격 점수 변경 사유**를 적으면 감사 `assessment.pass_score_changed`에 이전·이후 기준과 판정이 바뀐 학생 학번이 함께 남는다. 저장 뒤 화면에 다시 판정한 건수가 나온다. **공개 뒤**에는 읽기 전용이다(정정 요청으로만). 영역별 최저점은 회차에서 바꿀 수 없다(종류 설정).
- **결과 가져오기(CSV)**: 아래 형식. 접수하지 않은 학생의 행은 오류로 건너뛴다. 명령 `assessment_import_results`와 같다.

CSV 형식(머리글 행, UTF-8, 5MB까지):

| 열 | 내용 |
|---|---|
| `student_number` | 학번(필수) |
| 영역 코드 (`LISTENING`, …) | 영역 점수. 대소문자 무관 |
| `total` | 영역이 없는 종류의 총점 |
| `passed` | `Y`/`N`. 합격/불합격 종류 또는 합격 점수가 없는 종류에서 필수 |
| `absent` | `Y`면 결시 처리 |
| `note` | 비고 |

오류 행은 건너뛰고 결과 메시지(화면, 처음 10건) 또는 출력(명령)에 줄 번호와 함께 보고한다. 오류 문구는 영어다(운영 명령 출력과 같음).

## 결과 정정 요청

공개된 회차의 결과를 바꾸는 절차. 성적 정정과 같은 방식이다.

1. 회차의 **응시자** 탭에서 **정정 요청**: 새 점수(또는 합격 여부)와 사유. 결과마다 대기 중인 요청은 하나다. 감사 `assessment.correction_requested`.
2. **어학/종합시험 > 결과 정정 요청**에서 `시험 종류, 영역, 회차 관리` 권한자가 **승인**(처리 의견 선택) 또는 **반려**(처리 의견 필수)한다. **자기 요청은 결정할 수 없다.**
3. 승인과 동시에 결과가 새 값으로 바뀌고(합격 여부도 새 점수로 다시 판정) 학생에게 보인다. 감사 `assessment.correction_approved`, `assessment.result_corrected`. 요청자는 결정 전까지 요청을 취소할 수 있다.

목록은 기본으로 대기 중인 요청을 보여 주고(상태 필터 **전체**로 모두), 현재 값과 정정 값을 나란히 보여 준다. 메뉴에 대기 건수가 보인다.

## 결과 대장

**시험 결과**: 모든 결과(교내 회차, 외부). 종류, 출처, 합격 여부로 거르고 학번이나 이름으로 찾는다. 조회 범위는 학적 조회 범위와 같다.

- **외부 성적 등록**(목록 위): 학번, 종류(외부 성적 허용 종류만), 응시일(미래 불가), 총점, 등급, 합격 여부, 증서 번호, 증빙 파일(PDF, JPG, PNG, 5MB), 비고. 감사 `assessment.external_recorded`.
- **증빙**: 파일을 연다. 학생도 자기 것을 열 수 있다.
- **삭제**(행): 사유 필수, 감사 `assessment.result_removed`. 잘못 등록한 외부 성적이나 공개 전 결과를 지우고 다시 등록한다. 증빙 파일도 함께 지워진다. 공개된 회차의 결과는 지울 수 없다(정정 요청).

## 졸업 요건

**교육과정 > 졸업 요건** 편집에서 요건 종류 **시험 합격**을 고르고 **시험 종류**를 지정한다. 학생이 그 종류에 합격 결과(교내 또는 외부)가 하나라도 있으면 충족한다. 포털 **어학/종합시험** 상단에 학생의 교육과정이 요구하는 종류와 합격 여부가 보인다. 졸업 사정 판정은 Phase 11에서 이 요건을 읽는다. 요건에 쓰인 시험 종류는 지울 수 없다(사용 안 함으로 바꾼다).

## 학생 포털

**어학/종합시험**: 교육과정 요건과 합격 여부, 접수 중인 회차(접수·취소), 내 접수, 내 결과(공개된 회차와 외부 성적, 영역 점수, 증빙).

## 이 설치본의 화면

원본(Filament, Livewire) 화면과 기능은 같고 조작 방식이 조금 다르다.

- **시험 회차** 목록의 행 메뉴: **결과 공개**(확인 화면), **결과 가져오기(CSV)**(파일 선택 화면). 회차 화면 위 버튼: **학생 접수**(시험일까지), **결과 가져오기(CSV)**, **결과 공개**. 필터: 종류, 결과 공개 여부.
- 회차 화면의 **응시자** 탭은 상태(전체, 접수, 취소, 결시)를 눌러 거른다. 행의 **결과 입력**, **정정 요청**, **결시**, **접수 취소**는 입력 화면을 연다. 결과 입력 화면은 종류의 영역마다 점수 칸이 있고, 점수로 판정하는 종류는 판정 기준이 안내된다.
- **시험 결과** 목록 위 **외부 성적 등록**, 행 메뉴 **삭제**. 증빙 열의 링크가 파일을 새 창에서 연다.
- **결과 정정 요청**의 행 메뉴 **승인**, **반려**, **요청 취소**(본인 요청).
- 증빙 파일 주소: `/assessment-results/{결과 ID}/evidence/`(권한 확인 뒤 내려받기). 포털 주소: `/portal/assessments/`.
- 명령: `uv run manage.py assessment_import_results {종류 코드} {시험일} {CSV} --actor=... [--dry-run]`, `uv run manage.py assessment_publish_results {종류 코드} {시험일} --actor=...`([운영 명령](../operations/commands.md)).

## 자주 묻는 질문

- **접수 기간이 아닌데 접수시켜야 한다.** 회차 화면의 **학생 접수**로 직원이 접수시킨다.
- **합격 점수를 이번 회차만 바꾸고 싶다.** 공개 전에 회차의 합격 점수를 입력하고 사유를 적어 저장한다. 이미 입력한 결과는 새 기준으로 바로 다시 판정된다.
- **점수를 잘못 입력했다.** 공개 전이면 다시 **결과 입력**하면 바뀐다. 공개 뒤에는 **정정 요청**을 올리고 다른 담당자가 승인한다.
- **결시자 통계.** 응시자 탭을 상태 **결시**로 거른다.
