# 8. 건물과 강의실

메뉴: **기준정보 > 건물**, **강의실** (`건물과 강의실 관리` 권한)

## 건물

코드(예: `SCI`), 이름(언어별), 주소를 입력한다. 강의실이 있는 건물은 삭제할 수 없으므로 쓰지 않으면 **사용**을 끈다.

## 강의실

| 항목 | 설명 |
|---|---|
| 건물, 호실 | 호실은 건물 안에서 겹치지 않는다. 예: `101` |
| 이름 | 선택. 예: 대강당 |
| 용도 | 코드 데이터 `room_type`의 값 (강의실, 실험실 등) |
| 조직 단위 | 관리 학과(선택) |
| 수용 인원 | 시간표 배정 때 정원과 비교한다([18장](18-sections-and-timetables.md)) |
| 시간표 배정 | 끄면 시간표를 만들 때 배정 대상에서 빠진다(사무실, 창고 등) |

강의실이 많으면 [CSV 가져오기](09-csv-import.md)를 쓴다. 건물을 먼저 등록해야 한다.
