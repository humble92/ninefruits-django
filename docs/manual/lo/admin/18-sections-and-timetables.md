# 18. ກຸ່ມຮຽນ ແລະ ຕາຕະລາງຮຽນ

ເມນູ: **ຫຼັກສູດ ແລະ ກຸ່ມຮຽນ > ກຸ່ມຮຽນ**, **ຕາຕະລາງຮຽນ** (ສິດ `ເບິ່ງກຸ່ມຮຽນ`, `ວາງແຜນກຸ່ມຮຽນ (ອາຈານ, ເວລາ, ຫ້ອງຮຽນ)`. ຖ້າມອບໝາຍຕາມຂອບເຂດໜ່ວຍງານ ຈະເຫັນສະເພາະກຸ່ມຮຽນທີ່ໜ່ວຍງານນັ້ນເປີດສອນ)

## ການສ້າງກຸ່ມຮຽນ

1. ທີ່ **ກຸ່ມຮຽນ > ສ້າງ** ປ້ອນຊ່ວງຮຽນ (ຊ່ວງຍ່ອຍຂອງພາກຮຽນ), ວິຊາ, ເລກກຸ່ມຮຽນ (ຕົວຢ່າງ: `01`), ຈຳນວນຮັບ ແລະ ໜ່ວຍງານເປີດສອນ. ຊື່ວິຊາ ແລະ ໜ່ວຍກິດມາຈາກສະບັບວິຊາທີ່ມີຜົນໃນວັນທີເລີ່ມຂອງຊ່ວງຮຽນ.
2. ໃນແຖບຂອງໜ້າແກ້ໄຂ ປ້ອນ **ເວລາຮຽນ**, **ອາຈານ** ແລະ **ບ່ອນນັ່ງສະຫງວນ**.
3. ເມື່ອສຳເລັດແລ້ວ ກົດ **ເຜີຍແຜ່**. ສະເພາະກຸ່ມຮຽນທີ່ເຜີຍແຜ່ແລ້ວຈຶ່ງສະແດງໃນພອດທໍ **ລາຍການວິຊາ** ແລະ ເປີດໃຫ້ລົງທະບຽນຮຽນໄດ້ ([ບົດທີ 20](20-registration.md)).

| ສະຖານະ | ຄວາມໝາຍ |
|---|---|
| ຮ່າງ | ກຳລັງວາງແຜນ. ມີແຕ່ພະນັກງານ ແລະ ອາຈານຜູ້ສອນເຫັນ |
| ເຜີຍແຜ່ແລ້ວ | ນັກສຶກສາເຫັນ. ສາມາດ **ກັບໄປເປັນຮ່າງ** ໄດ້ |
| ຍົກເລີກ | ຕ້ອງໃສ່ເຫດຜົນ. ຫ້ອງຮຽນ ແລະ ເວລາຂອງອາຈານຈະຖືກປ່ອຍວ່າງ. ຖ້າ **ເປີດຄືນ** ຈະກາຍເປັນຮ່າງ ແຕ່ຖ້າໃນລະຫວ່າງນັ້ນມີກຸ່ມຮຽນອື່ນໃຊ້ເວລານັ້ນໄປແລ້ວ ຈະເປີດຄືນບໍ່ໄດ້ |

ລຶບໄດ້ສະເພາະກຸ່ມຮຽນທີ່ເປັນຮ່າງ. ກຸ່ມຮຽນທີ່ເຄີຍເຜີຍແຜ່ແລ້ວ ໃຫ້ຍົກເລີກແທນ.

| ລາຍການ | ຄຳອະທິບາຍ |
|---|---|
| ຊ່ວງຮຽນ | ຊ່ວງຮຽນຂອງພາກຮຽນ ([ບົດທີ 10](10-terms.md)). ຖ້າຍ້າຍໄປຊ່ວງຮຽນອື່ນ ວັນທີຮຽນ ແລະ ສະບັບວິຊາຈະປ່ຽນຕາມຊ່ວງຮຽນນັ້ນ |
| ຜູ້ທີ່ລົງທະບຽນໄດ້, ຜູ້ທີ່ລົງທະບຽນບໍ່ໄດ້ | ປີຮຽນ, ປີເຂົ້າຮຽນ, ຫຼັກສູດ, ໜ່ວຍງານ. ຕົວຢ່າງ: ວິຊາທົ່ວໄປບໍ່ຮັບນັກສຶກສາຂອງວິຊາເອກນັ້ນເອງ. ນັກສຶກສາວິຊາເອກທີສອງ·ວິຊາໂທ ກໍຖືວ່າເປັນນັກສຶກສາຂອງຫຼັກສູດນັ້ນເຊັ່ນກັນ |
| ພາສາທີ່ໃຊ້ສອນ | ຕົວຢ່າງ: `ko`, `en` |
| ຂະໜາດລາຍຊື່ລໍຖ້າ | ຈຳນວນຜູ້ລໍຖ້າທີ່ຮັບຫຼັງຈາກເຕັມຈຳນວນຮັບ. ຖ້າເປັນ 0 ຈະບໍ່ມີລາຍຊື່ລໍຖ້າ ([ບົດທີ 20](20-registration.md)) |
| ວິທີປະເມີນ | ການປະເມີນແບບເກນຄະແນນ (ຄ່າເລີ່ມຕົ້ນ. ອາຈານປ້ອນຄະແນນ ເກຣດຄິດໄລ່ຈາກຄະແນນ) ຫຼື ການປະເມີນແບບອີງກຸ່ມ (ປ້ອນສະເພາະເກຣດ ນຳໃຊ້ເພດານສັດສ່ວນເກຣດ). ອາຈານຂໍປ່ຽນຈາກໜ້າປ້ອນເກຣດ ແລະ ພະນັກງານວາງແຜນກຸ່ມຮຽນອະນຸມັດ. ເມື່ອມີການປ້ອນເກຣດແລ້ວ ປ່ຽນບໍ່ໄດ້ ([ບົດທີ 21](21-grades.md)). ຖືກສຳເນົາໄປນຳເມື່ອສຳເນົາຈາກພາກຮຽນອື່ນ |

## ເວລາຮຽນ ແລະ ຫ້ອງຮຽນ

ໃນແຖບ **ເວລາຮຽນ** ປ້ອນວັນ, ເວລາເລີ່ມ·ສິ້ນສຸດ ແລະ ຫ້ອງຮຽນ. ຖ້າເລືອກ **ຄາບ** ເວລາຈະຖືກຕື່ມໃຫ້ອັດຕະໂນມັດ. ຖ້າປ່ອຍວ່າງວັນທີຮຽນ ຈະເປັນໄລຍະເວລາຂອງຊ່ວງຮຽນ.

- ສອງກຸ່ມຮຽນໃຊ້ຫ້ອງຮຽນດຽວກັນໃນເວລາດຽວກັນບໍ່ໄດ້ ແລະ ອາຈານຄົນດຽວສອນສອງກຸ່ມຮຽນໃນເວລາດຽວກັນບໍ່ໄດ້. DB ຈະຂັດຂວາງ ແລະ ໜ້າຈໍຈະສະແດງກຸ່ມຮຽນທີ່ຊ້ອນກັນ ເຊັ່ນ "ຫ້ອງຮຽນນີ້ຖືກຈອງແລ້ວໃນເວລານີ້ໂດຍກຸ່ມຮຽນ OOO".
- ຖ້າວັນທີບໍ່ຊ້ອນກັນ ເຊັ່ນ ເຄິ່ງທຳອິດ ແລະ ເຄິ່ງຫຼັງຂອງພາກຮຽນ ສາມາດໃຊ້ເວລາດຽວກັນ ແລະ ຫ້ອງຮຽນດຽວກັນໄດ້.
- ກຸ່ມຮຽນທີ່ຍົກເລີກແລ້ວບໍ່ຈອງເວລາ.

## ອາຈານຜູ້ສອນ

ໃນແຖບ **ອາຈານ** ກຳນົດອາຈານ ແລະ ບົດບາດ (ອາຈານ, ອາຈານຮ່ວມສອນ, ຜູ້ຊ່ວຍສອນ). ໜຶ່ງກຸ່ມຮຽນກຳນົດໄດ້ຫຼາຍຄົນ. ອາຈານທີ່ສອນກຸ່ມຮຽນອື່ນໃນເວລາດຽວກັນຢູ່ແລ້ວ ຈະກຳນົດບໍ່ໄດ້. ອາຈານຜູ້ສອນຄຸ້ມຄອງຕາຕະລາງຮຽນ ແລະ ແຜນການສອນໃນພອດທໍ **ການສອນຂອງຂ້ອຍ**.

## ບ່ອນນັ່ງສະຫງວນ

ໃນແຖບ **ບ່ອນນັ່ງສະຫງວນ** ກຳນົດບ່ອນນັ່ງຕາມກຸ່ມນັກສຶກສາເປົ້າໝາຍ (ຕົວຢ່າງ: ນັກສຶກສາວິຊາເອກ 30 ບ່ອນ). ເມື່ອຜ່ານ **ເວລາເປີດໃຫ້ທຸກຄົນ** ແລ້ວ ບ່ອນນັ່ງທີ່ຍັງບໍ່ໄດ້ໃຊ້ ໃຜກໍລົງທະບຽນໄດ້. ຜົນລວມຂອງບ່ອນນັ່ງສະຫງວນເກີນຈຳນວນຮັບບໍ່ໄດ້. ນຳໃຊ້ໃນການລົງທະບຽນຮຽນ ([ບົດທີ 20](20-registration.md)).

## ແຜນການສອນ

ອາຈານຜູ້ສອນຂຽນໃນພອດທໍ **ການສອນຂອງຂ້ອຍ** (ເປີດໄດ້ຈາກປຸ່ມ **ແຜນການສອນ** ໃນໜ້າກຸ່ມຮຽນເຊັ່ນກັນ). ປ້ອນພາບລວມ, ຈຸດປະສົງການຮຽນຮູ້, ປຶ້ມແບບຮຽນ ແລະ ເອກະສານ, ລະບຽບການຮຽນ, ການປະເມີນ (ລາຍການ ແລະ ນ້ຳໜັກ), ແຜນລາຍອາທິດ ແລ້ວ **ເຜີຍແຜ່** ຈຶ່ງຈະສະແດງໃຫ້ນັກສຶກສາເຫັນ.

## ສຳເນົາຈາກພາກຮຽນອື່ນ

ໃຊ້ **ສຳເນົາຈາກພາກຮຽນອື່ນ** ໃນລາຍຊື່ກຸ່ມຮຽນ ເພື່ອເລີ່ມຈາກແຜນຂອງພາກຮຽນກ່ອນ (ປົກກະຕິຄືພາກຮຽນດຽວກັນຂອງປີກ່ອນ). ກວດຜົນລັບດ້ວຍ **ເບິ່ງຕົວຢ່າງເທົ່ານັ້ນ** ກ່ອນ.

- ສຳເນົາກຸ່ມຮຽນທີ່ບໍ່ຖືກຍົກເລີກ ແລະ ຢູ່ໃນຂອບເຂດສິດຂອງຂ້ອຍ ເປັນສະຖານະຮ່າງ.
- ສຳເນົາໄປນຳ: ອາຈານຜູ້ສອນທີ່ຍັງເຮັດວຽກຢູ່, ເວລາຮຽນ ແລະ ຫ້ອງຮຽນ, ບ່ອນນັ່ງສະຫງວນ (ເວລາເປີດໃຫ້ທຸກຄົນເລື່ອນຕາມຄວາມຕ່າງຂອງວັນທີເລີ່ມພາກຮຽນ), ແຜນການສອນ (ຮ່າງທີ່ຍັງບໍ່ເຜີຍແຜ່).
- ຊ່ວງຮຽນຈັບຄູ່ຕາມລະຫັດ (ຖ້າບໍ່ມີ ໃຊ້ທັງພາກຮຽນ). ສະບັບວິຊາອີງຕາມວັນທີເລີ່ມຂອງຊ່ວງຮຽນໃໝ່.
- ຖ້າພາກຮຽນປາຍທາງມີເລກກຸ່ມຮຽນດຽວກັນຢູ່ແລ້ວ ຈະຂ້າມ ແລະ ຖ້າຫ້ອງຮຽນຖືກໃຊ້ຢູ່ແລ້ວ ຈະສຳເນົາໂດຍບໍ່ມີຫ້ອງຮຽນ. ການແຈ້ງເຕືອນຜົນລັບຈະສະແດງກຸ່ມຮຽນທີ່ຂ້າມ ແລະ ກຸ່ມຮຽນທີ່ຕ້ອງກວດ.

ຜູ້ດູແລລະບົບ IT ສາມາດເຮັດວຽກດຽວກັນດ້ວຍ `uv run manage.py section_copy`.

## ຕາຕະລາງຮຽນ ແລະ ການກວດສອບ

- **ຕາຕະລາງຮຽນ**: ເລືອກພາກຮຽນ ແລະ ຫ້ອງຮຽນ ຫຼື ອາຈານ ຈະສະແດງຕາຕະລາງຮຽນລາຍອາທິດ.
- ການກວດສອບກ່ອນເຜີຍແຜ່: ຜູ້ດູແລລະບົບ IT ແລ່ນ `uv run manage.py schedule_check_conflicts <ລະຫັດພາກຮຽນ>` ເພື່ອຊອກຫາຫ້ອງຮຽນທີ່ນ້ອຍກວ່າຈຳນວນຮັບ, ອາຈານຜູ້ສອນທີ່ອອກຈາກວຽກແລ້ວ, ສະບັບວິຊາທີ່ບໍ່ກົງກັນ ແລະ ບ່ອນນັ່ງສະຫງວນທີ່ເກີນຈຳນວນຮັບ ([ເອກະສານອ້າງອີງຄຳສັ່ງ](../operations/commands.md#schedule_check_conflicts)).

## ຂອບເຂດສິດ

ລາຍການ ແລະ ໜ້າຕ່າງໆ ສະແດງສະເພາະກຸ່ມຮຽນຂອງໜ່ວຍງານເປີດສອນທີ່ຢູ່ໃນຂອບເຂດສິດ `ເບິ່ງກຸ່ມຮຽນ` ແລະ `ຈັດກຸ່ມຮຽນ`. ແຖບເວລາສອນ, ອາຈານຜູ້ສອນ, ບ່ອນນັ່ງສະຫງວນ ແລະ ປຸ່ມສະຖານະ (ເຜີຍແຜ່, ກັບເປັນຮ່າງ, ຍົກເລີກກຸ່ມຮຽນ, ເປີດຄືນ) ຕ້ອງມີສິດ `ຈັດກຸ່ມຮຽນ` ທີ່ຂອບເຂດກວມໜ່ວຍງານເປີດສອນຂອງກຸ່ມຮຽນ. ໜ້າຕາຕະລາງຮຽນເລີ່ມດ້ວຍພາກຮຽນທີ່ກຳລັງສອນ (ຖ້າບໍ່ມີ ແມ່ນພາກຮຽນຕໍ່ໄປ). ໃນໂທລະສັບຈະສະແດງເປັນລາຍການຕາມມື້.
