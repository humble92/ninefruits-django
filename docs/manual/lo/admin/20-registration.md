# 20. ການລົງທະບຽນຮຽນ

ເມນູ: **ການລົງທະບຽນຮຽນ > ລາຍການລົງທະບຽນ**, **ການລະງັບການລົງທະບຽນ**, **ການຍົກເວັ້ນກົດ**, **ກົດການລົງທະບຽນຮຽນ**, **ຂີດຈຳກັດໜ່ວຍກິດ**, **ບັນທຶກຄວາມພະຍາຍາມລົງທະບຽນ** ແລະ ແຖບ **ລາຍຊື່ນັກສຶກສາ**, **ລາຍຊື່ລໍຖ້າ** ໃນໜ້າແກ້ໄຂ **ຫຼັກສູດ ແລະ ກຸ່ມຮຽນ > ກຸ່ມຮຽນ**

| ສິດ | ສິ່ງທີ່ເຮັດໄດ້ |
|---|---|
| `ເບິ່ງລາຍການລົງທະບຽນ ແລະ ລາຍຊື່ນັກສຶກສາ` | ເບິ່ງລາຍການລົງທະບຽນ, ລາຍຊື່ນັກສຶກສາ, ບັນທຶກຄວາມພະຍາຍາມລົງທະບຽນ |
| `ລົງທະບຽນ, ຖອນ ແລະ ຖອນຕົວແທນນັກສຶກສາ (ຕ້ອງມີເຫດຜົນ)` | ພະນັກງານລົງທະບຽນແທນ, ຖອນ·ຖອນຕົວ, ເອົາອອກຈາກລາຍຊື່ລໍຖ້າ ແລະ ເລື່ອນຂຶ້ນທັນທີ. ຖ້າມອບໝາຍຕາມຂອບເຂດໜ່ວຍງານ ຈະເຮັດໄດ້ສະເພາະກຸ່ມຮຽນທີ່ໜ່ວຍງານນັ້ນເປີດສອນ |
| `ວາງ ແລະ ປົດການລະງັບ, ໃຫ້ການຍົກເວັ້ນກົດ` | ການລະງັບການລົງທະບຽນ, ການຍົກເວັ້ນກົດ. ຖ້າມອບໝາຍຕາມຂອບເຂດ ຈະເຮັດໄດ້ສະເພາະນັກສຶກສາໃນຂອບເຂດນັ້ນ |
| `ຄຸ້ມຄອງຊຸດກົດການລົງທະບຽນຮຽນ ແລະ ຂີດຈຳກັດໜ່ວຍກິດ` | ຊຸດກົດຕາມພາກຮຽນ, ຂີດຈຳກັດໜ່ວຍກິດ |

ຄ່າເລີ່ມຕົ້ນຂອງບົດບາດ: ພະນັກງານທະບຽນມີທັງສີ່ສິດ, ພະນັກງານວິຊາການມີສິດເບິ່ງ ແລະ ກົດ·ຂີດຈຳກັດໜ່ວຍກິດ, ຜູ້ຊ່ວຍພາກວິຊາມີສິດເບິ່ງ ແລະ ປັບລາຍການລົງທະບຽນ (ມອບໝາຍຕາມຂອບເຂດພາກວິຊາ).

ລາຍການສະແດງສະເພາະນັກສຶກສາທີ່ທ່ານເບິ່ງບັນທຶກໄດ້ ແລະ ການລົງທະບຽນຂອງກຸ່ມຮຽນໃນຂອບເຂດສິດຂອງທ່ານ. ຄວາມປອດໄພລະດັບແຖວຂອງຖານຂໍ້ມູນກໍນຳໃຊ້ຂອບເຂດດຽວກັນ.

## ສິ່ງທີ່ຕ່າງຈາກລະບົບເກົ່າ

- ກົດທີ່ເຄີຍຖືກຂຽນຕາຍຕົວຕາມຕົວເລກລະຫັດນັກສຶກສາ ຫຼື ລະຫັດພາກວິຊາ (ຂີດຈຳກັດໜ່ວຍກິດ, ການຍົກເວັ້ນວິຊາທະນາຄານໜ່ວຍກິດ ແລະ ອື່ນໆ) ກາຍເປັນ **ການຕັ້ງຄ່າຕາມພາກຮຽນ**. ກົດ YUST ຂອງລະບົບເກົ່າ (YUSTIC) ຈຳລອງດ້ວຍໂປຣໄຟລ໌ຕິດຕັ້ງ `yust-legacy` (ເບິ່ງຂ້າງລຸ່ມ).
- ເມື່ອການລົງທະບຽນຖືກປະຕິເສດ ຈະສະແດງ **ທຸກເຫດຜົນພ້ອມກັນ** (ລະບົບເກົ່າຢຸດທີ່ເຫດຜົນທຳອິດ). ທຸກຄວາມພະຍາຍາມ ແລະ ຜົນລັບຂອງແຕ່ລະກົດ ຖືກບັນທຶກໃນ **ບັນທຶກຄວາມພະຍາຍາມລົງທະບຽນ**.
- ບັກຂີດຈຳກັດໜ່ວຍກິດຂອງຄະນະພະຍາບານສຳລັບນັກສຶກສາທີ່ເຂົ້າຮຽນຕັ້ງແຕ່ປີ 2014 ໃນລະບົບເກົ່າ (ຄວນເປັນ 21 ໜ່ວຍກິດ ແຕ່ນຳໃຊ້ 18 ໜ່ວຍກິດ) ບໍ່ຖືກຈຳລອງ. ນຳໃຊ້ 21 ໜ່ວຍກິດ.
- ບໍ່ມີການປ້ອນການຊື້ປຶ້ມແບບຮຽນໃນຂະນະລົງທະບຽນຮຽນ.

## ລຳດັບການກຽມພາກຮຽນ

1. **ໄລຍະເວລາດຳເນີນງານ** ([ບົດທີ 10](10-terms.md)): ກະຕ່າ, ການລົງທະບຽນຮຽນ (ເປີດຕ່າງເວລາຕາມປີຮຽນ), ການເພີ່ມ/ຖອນ, ການຖອນຕົວ. ການເພີ່ມ/ຖອນ ແລະ ການຖອນຕົວກຳນົດຕາມຊ່ວງຮຽນ (ຊ່ວງຍ່ອຍຂອງພາກຮຽນ).
2. **ກົດການລົງທະບຽນຮຽນ > ກຽມກົດສຳລັບພາກຮຽນ**: ເລືອກພາກຮຽນ ແລະ ເລືອກພາກຮຽນກ່ອນທີ່ຈະສຳເນົາ. ຖ້າປ່ອຍວ່າງ ຈະເລີ່ມຈາກຄ່າເລີ່ມຕົ້ນ. ພາກຮຽນທີ່ບໍ່ມີຊຸດກົດ ຈະນຳໃຊ້ຄ່າເລີ່ມຕົ້ນ.
3. **ຂີດຈຳກັດໜ່ວຍກິດ**: ຂີດຈຳກັດຕາມປະເພດພາກຮຽນ ແລະ ກຸ່ມນັກສຶກສາເປົ້າໝາຍ (ເບິ່ງຂ້າງລຸ່ມ).
4. **ກຸ່ມຮຽນ**: ຈຳນວນຮັບ, ບ່ອນນັ່ງສະຫງວນ (ບ່ອນນັ່ງສະຫງວນ ແລະ ເວລາເປີດໃຫ້ທຸກຄົນ), **ຂະໜາດລາຍຊື່ລໍຖ້າ** ([ບົດທີ 18](18-sections-and-timetables.md)). ຕ້ອງ **ເຜີຍແຜ່** ກຸ່ມຮຽນຈຶ່ງຈະຮັບການລົງທະບຽນໄດ້.
5. **ການລະງັບການລົງທະບຽນ**: ໃສ່ລາຍຊື່ຜູ້ຄ້າງຊຳລະ ແລະ ອື່ນໆ (ໃຊ້ CSV ໄດ້, [ບົດທີ 9](09-csv-import.md)).
6. ກວດສອບ: `uv run manage.py registration_preflight 2027-SP` ([ຄຳສັ່ງດຳເນີນງານ](../operations/commands.md)). ກວດເບິ່ງໄລຍະເວລາ, ຊຸດກົດ, ຈຳນວນຮັບ ແລະ ຈຳນວນນັກສຶກສາທີ່ບໍ່ມີຂີດຈຳກັດໜ່ວຍກິດ.

## ກົດ

ກົດທັງໝົດຖືກກວດຕາມລຳດັບຂ້າງລຸ່ມ. **ໄລຍະເວລາ, ສະຖານະກຸ່ມຮຽນ, ຈຳນວນຮັບ** ນຳໃຊ້ສະເໝີ ຈຶ່ງບໍ່ຢູ່ໃນລາຍການ.

| ກົດ | ເນື້ອໃນ | ພາຣາມິເຕີ |
|---|---|---|
| ໄລຍະເວລາລົງທະບຽນ | ຕ້ອງມີໄລຍະເວລາດຳເນີນງານທີ່ກົງກັບເງື່ອນໄຂເປົ້າໝາຍຂອງນັກສຶກສາເປີດຢູ່. ການຖອນໃຊ້ໄລຍະເວລາລົງທະບຽນຮຽນ ຫຼື ໄລຍະເວລາເພີ່ມ/ຖອນຂອງຊ່ວງຮຽນວິຊານັ້ນ, ການຖອນຕົວໃຊ້ໄລຍະເວລາຖອນຕົວຂອງຊ່ວງຮຽນ | ບໍ່ມີ |
| ການລະງັບ | ຖ້າມີການລະງັບທີ່ຂັດຂວາງການລົງທະບຽນ ຈະປະຕິເສດ | ບໍ່ມີ |
| ສະຖານະນັກສຶກສາ | ສະເພາະສະຖານະບັນທຶກນັກສຶກສາທີ່ເລືອກ (ຄ່າເລີ່ມຕົ້ນ: ກຳລັງຮຽນ) ຈຶ່ງລົງທະບຽນໄດ້ | ສະຖານະທີ່ອະນຸຍາດ |
| ເງື່ອນໄຂຜູ້ລົງທະບຽນຂອງກຸ່ມຮຽນ | ເງື່ອນໄຂຜູ້ທີ່ລົງທະບຽນໄດ້·ບໍ່ໄດ້ຂອງກຸ່ມຮຽນ | ບໍ່ມີ |
| ວິຊາດຽວກັນສອງຄັ້ງ | ໃນໜຶ່ງພາກຮຽນ ລົງທະບຽນວິຊາດຽວກັນໄດ້ຄັ້ງດຽວ | ບໍ່ມີ |
| ເວລາຊ້ອນກັນ | ຖ້າເວລາຊ້ອນກັບກຸ່ມຮຽນອື່ນທີ່ລົງທະບຽນແລ້ວ ຈະປະຕິເສດ. ເຄິ່ງທຳອິດ·ເຄິ່ງຫຼັງທີ່ວັນທີບໍ່ຊ້ອນກັນ ບໍ່ຖືວ່າຊ້ອນກັນ | ເວລາຊ້ອນກັນທີ່ອະນຸຍາດ (ນາທີ) |
| ຂີດຈຳກັດໜ່ວຍກິດ | ຜົນລວມໜ່ວຍກິດທີ່ລົງທະບຽນ ≤ ຂີດຈຳກັດໜ່ວຍກິດທີ່ນຳໃຊ້. ວິຊາທີ່ປິດຄຸນລັກສະນະ "ນັບເຂົ້າຂີດຈຳກັດໜ່ວຍກິດ" ຈະບໍ່ຖືກນັບ | ບໍ່ມີ (ຕັ້ງຄ່າໃນໜ້າຂີດຈຳກັດໜ່ວຍກິດ) |
| ວິຊາບັງຄັບກ່ອນ | ຮຽນຜ່ານວິຊາບັງຄັບກ່ອນ (ຮັບຮູ້ວິຊາທຽບເທົ່າ, ເກຣດຂັ້ນຕ່ຳ), ວິຊາຮຽນຄວບຄູ່ຮັບຮູ້ການລົງທະບຽນໃນພາກຮຽນດຽວກັນ | ບໍ່ມີ (ຕັ້ງຄ່າໃນໜ້າວິຊາ) |
| ການຮຽນຄືນ | ວິຊາທີ່ຮຽນຜ່ານແລ້ວ ຮຽນອີກໄດ້ຫຼືບໍ່ | ອະນຸຍາດການຮຽນຄືນ, ຈຳນວນຄັ້ງສູງສຸດ, ສະເພາະຕ່ຳກວ່າເກຣດທີ່ກຳນົດ |

ໜ້າຊຸດກົດສະແດງລາຍການກົດ, ກົດ **ແກ້ໄຂ** ໃນແຖວເພື່ອເປີດໜ້າຂອງກົດນັ້ນ. ຕັ້ງຄ່າໄດ້ຕໍ່ແຕ່ລະກົດ.

- **ເປີດ**: ຖ້າປິດ ຈະບໍ່ກວດ.
- **ເມື່ອບໍ່ຄົບເງື່ອນໄຂ**: ຂັດຂວາງ ຫຼື ເຕືອນເທົ່ານັ້ນ. ການເຕືອນຈະໃຫ້ລົງທະບຽນໄດ້ ແລະ ສະແດງຂໍ້ຄວາມໃຫ້ນັກສຶກສາເທົ່ານັ້ນ.
- **ອະນຸຍາດການຍົກເວັ້ນ**: ຕ້ອງເປີດ ການຍົກເວັ້ນກົດ ແລະ "ກົດທີ່ບໍ່ນຳໃຊ້" ຂອງການລົງທະບຽນໂດຍພະນັກງານຈຶ່ງມີຜົນ. ການລະງັບ ແລະ ວິຊາດຽວກັນສອງຄັ້ງ ມີຄ່າເລີ່ມຕົ້ນເປັນປິດ.
- ພາຣາມິເຕີສະແດງສະເພາະໃນກົດຂອງມັນ (ສະຖານະນັກສຶກສາ: ສະຖານະທີ່ອະນຸຍາດ, ເວລາຊ້ອນກັນ: ເວລາຊ້ອນກັນທີ່ອະນຸຍາດ (ນາທີ), ການຮຽນຄືນ: ອະນຸຍາດ·ຈຳນວນຄັ້ງສູງສຸດ·ເກຣດທີ່ກຳນົດ). ຄ່າທາງເລືອກທີ່ປ່ອຍວ່າງໝາຍເຖິງ "ບໍ່ຈຳກັດ".

ການຮຽນຄືນຖືກກຳນົດອັດຕະໂນມັດ ແລະ ໝາຍ **ການຮຽນຄືນ** ໃນລາຍການລົງທະບຽນ. ການຈັດການເກຣດຂອງການຮຽນຄືນແມ່ນ Phase 6.

ເມື່ອເວີຊັນໃໝ່ເພີ່ມກົດເຂົ້າໃນລາຍການກົດ ການຕິດຕັ້ງ (`setup_install`) ຈະເພີ່ມກົດນັ້ນດ້ວຍຄ່າເລີ່ມຕົ້ນໃສ່ຊຸດກົດທີ່ມີຢູ່. ການຕັ້ງຄ່າທີ່ຜູ້ບໍລິຫານປ່ຽນໄວ້ຈະຄົງເດີມ.

## ຂີດຈຳກັດໜ່ວຍກິດ

ກຳນົດປະເພດພາກຮຽນ (ຖ້າປ່ອຍວ່າງ ແມ່ນທຸກປະເພດພາກຮຽນ), ນັກສຶກສາເປົ້າໝາຍ (ປີຮຽນ, ປີເຂົ້າຮຽນ, ຫຼັກສູດ, ໜ່ວຍງານ), ໜ່ວຍກິດສູງສຸດ ແລະ ລຳດັບຄວາມສຳຄັນ. ຖ້ານັກສຶກສາກົງກັບຫຼາຍຂີດຈຳກັດ ຈະໃຊ້ພຽງ **ຂີດຈຳກັດທີ່ມີລຳດັບຄວາມສຳຄັນສູງສຸດ** ອັນດຽວ. ຖ້າບໍ່ມີຂີດຈຳກັດທີ່ກົງ ຈະບໍ່ມີການຈຳກັດ (`registration_preflight` ຈະແຈ້ງໃຫ້ຮູ້).

## ບ່ອນນັ່ງ ແລະ ລາຍຊື່ລໍຖ້າ

- ບ່ອນນັ່ງຖືກຈອງໂດຍລັອກແຖວກຸ່ມຮຽນໃນຂະນະລົງທະບຽນ. ເຖິງຫຼາຍຄົນລົງທະບຽນພ້ອມກັນ ກໍບໍ່ເກີນຈຳນວນຮັບ.
- **ບ່ອນນັ່ງສະຫງວນ** (ຕົວຢ່າງ: ນັກສຶກສາວິຊາເອກ 30 ບ່ອນ) ໃຊ້ໄດ້ສະເພາະນັກສຶກສາເປົ້າໝາຍຈົນກວ່າຈະເຖິງເວລາເປີດໃຫ້ທຸກຄົນ. ບ່ອນນັ່ງສະຫງວນທີ່ເຫຼືອຈະກາຍເປັນບ່ອນນັ່ງທົ່ວໄປເມື່ອເຖິງເວລາເປີດໃຫ້ທຸກຄົນ. ໃນພອດທໍສະແດງເປັນ "ບ່ອນວ່າງ · ສະຫງວນ · ຈຳນວນຮັບ".
- ຖ້າ **ຂະໜາດລາຍຊື່ລໍຖ້າ** ໃຫຍ່ກວ່າ 0 ນັກສຶກສາສາມາດ **ເຂົ້າລາຍຊື່ລໍຖ້າ** ຂອງກຸ່ມຮຽນທີ່ເຕັມແລ້ວໄດ້. ການເຂົ້າລາຍຊື່ລໍຖ້າກໍຕ້ອງຜ່ານທຸກກົດ ຍົກເວັ້ນຈຳນວນຮັບ.
- ເມື່ອມີບ່ອນວ່າງຍ້ອນການຖອນ·ຖອນຕົວ ຫຼື ການເປີດບ່ອນນັ່ງສະຫງວນ ຈະ **ເລື່ອນຂຶ້ນອັດຕະໂນມັດ** ຕາມລຳດັບລາຍຊື່ລໍຖ້າ (ວຽກພື້ນຫຼັງ, ການເລື່ອນຂຶ້ນຂອງກຸ່ມຮຽນໜຶ່ງເຮັດເທື່ອລະອັນ). ເມື່ອເລື່ອນຂຶ້ນ ຈະກວດທຸກກົດອີກຄັ້ງ. ຖ້າໃນລະຫວ່າງນັ້ນລົງທະບຽນວິຊາອື່ນຈົນເກີນຂີດຈຳກັດໜ່ວຍກິດ ຫຼື ເວລາຊ້ອນກັນ ຈະຖືກເອົາອອກຈາກລາຍຊື່ລໍຖ້າ ແລະ ບັນທຶກເຫດຜົນໄວ້. ມີອີເມວສົ່ງໄປຫານັກສຶກສາ. ສິ່ງທີ່ຕົກຫຼົ່ນ `waitlist_promote` ຈະຈັດການທຸກຊົ່ວໂມງ.
- ເມື່ອໄລຍະເວລາລົງທະບຽນຮຽນ ແລະ ເພີ່ມ/ຖອນປິດໝົດແລ້ວ ລາຍຊື່ລໍຖ້າທີ່ເຫຼືອຈະໝົດອາຍຸ.
- ເມື່ອຫຼຸດຈຳນວນຮັບ ຈະຫຼຸດໃຫ້ຕ່ຳກວ່າຈຳນວນທີ່ລົງທະບຽນແລ້ວບໍ່ໄດ້.

ບໍ່ມີຟັງຊັນປ່ຽນລຳດັບລາຍຊື່ລໍຖ້າ. ຖ້າຕ້ອງການໃຫ້ນັກສຶກສາຄົນໃດໜຶ່ງເຂົ້າກ່ອນ ໃຫ້ **ພະນັກງານລົງທະບຽນແທນ** ນັກສຶກສາຄົນນັ້ນ (ຖ້າເຕັມຈຳນວນຮັບ ໃຫ້ເພີ່ມຈຳນວນຮັບ).

## ໜ້າຈໍຂອງນັກສຶກສາ

ໃນພອດທໍ **ການລົງທະບຽນຮຽນ** (`/portal/registration/`) ນັກສຶກສາເລືອກພາກຮຽນ ຊອກຫາດ້ວຍລະຫັດວິຊາ ຫຼື ຊື່ວິຊາ ແລ້ວລົງທະບຽນ, ໃສ່ກະຕ່າ ຫຼື ເຂົ້າລາຍຊື່ລໍຖ້າ. ໜ້າຈໍສະແດງສະຖານະໄລຍະເວລາລົງທະບຽນ (ເປີດ, ກະຕ່າເທົ່ານັ້ນ, ເວລາເປີດ), ໜ່ວຍກິດທີ່ລົງທະບຽນ/ຂີດຈຳກັດໜ່ວຍກິດ ແລະ ຕາຕະລາງຮຽນ. ໃນໂທລະສັບ ຕາຕະລາງຮຽນສະແດງເປັນລາຍການຕາມມື້.

- **ກະຕ່າ**: ໃສ່ໄວ້ໃນໄລຍະເວລາກະຕ່າ ແລະ ເມື່ອການລົງທະບຽນຮຽນເປີດ ກົດ **ລົງທະບຽນທັງໝົດ**. ເມື່ອໃສ່ກະຕ່າ ຈະກວດກົດລ່ວງໜ້າ ແລະ ແຈ້ງບັນຫາ ແຕ່ຈະບໍ່ຂັດຂວາງການໃສ່ກະຕ່າ ຍົກເວັ້ນ ໄລຍະເວລາ·ສະຖານະກຸ່ມຮຽນ·ວິຊາດຽວກັນສອງຄັ້ງ. ເມື່ອລົງທະບຽນ ຈະກວດອີກຄັ້ງ.
- ປຸ່ມຖອນ ແລະ ຖອນຕົວປ່ຽນຕາມໄລຍະເວລາດຳເນີນງານ. ວິຊາທີ່ຖອນຕົວຈະຄົງຢູ່ໃນລາຍການເປັນ **ຖອນຕົວ** (ເກຣດ W ແມ່ນ Phase 6).
- ການລົງທະບຽນ, ເຂົ້າລາຍຊື່ລໍຖ້າ, ໃສ່ກະຕ່າ ແລະ ລົງທະບຽນທັງໝົດ ໜຶ່ງຄົນເຮັດໄດ້ສູງສຸດ 30 ຄັ້ງຕໍ່ນາທີ.

## ລາຍການລົງທະບຽນ ແລະ ການປັບໂດຍພະນັກງານ

**ລາຍການລົງທະບຽນ**: ກັ່ນຕອງຕາມພາກຮຽນ, ສະຖານະ ແລະ ຊອກຫາດ້ວຍລະຫັດນັກສຶກສາ ຫຼື ຊື່. ຄ່າເລີ່ມຕົ້ນຄືລາຍການສະຖານະລົງທະບຽນແລ້ວຂອງພາກຮຽນນີ້ (ຫຼື ພາກຮຽນໜ້າ).

**ລົງທະບຽນໃຫ້ນັກສຶກສາ** (ຢູ່ເທິງລາຍການລົງທະບຽນ ຫຼື ປຸ່ມເທິງໜ້າກຸ່ມຮຽນ): ປ້ອນລະຫັດນັກສຶກສາ, ກຸ່ມຮຽນ (ສະເພາະເມື່ອເປີດຈາກລາຍການລົງທະບຽນ: ກຸ່ມຮຽນທີ່ເຜີຍແຜ່ແລ້ວຂອງພາກຮຽນນີ້), ກົດທີ່ບໍ່ນຳໃຊ້, ເພີ່ມເຂົ້າລາຍຊື່ລໍຖ້າຖ້າເຕັມຫຼືບໍ່ ແລະ ເຫດຜົນ.

- ກວດກົດດຽວກັນກັບນັກສຶກສາ. **ໄລຍະເວລາລົງທະບຽນບໍ່ນຳໃຊ້ກັບການລົງທະບຽນໂດຍພະນັກງານ.**
- "ກົດທີ່ບໍ່ນຳໃຊ້" ມີຜົນສະເພາະເມື່ອ **ອະນຸຍາດການຍົກເວັ້ນ** ຂອງກົດນັ້ນເປີດຢູ່. ເລືອກສະຖານະກຸ່ມຮຽນ ແລະ ຈຳນວນຮັບບໍ່ໄດ້ (ຕ້ອງເພີ່ມຈຳນວນຮັບ).
- ຜົນລັບ (ລົງທະບຽນແລ້ວ, ເຂົ້າລາຍຊື່ລໍຖ້າ, ປະຕິເສດ ແລະ ເຫດຜົນ) ສະແດງເປັນຂໍ້ຄວາມເທິງໜ້າຈໍ. ຖືກບັນທຶກພ້ອມເຫດຜົນໃນບັນທຶກການກວດສອບກິດຈະກຳ.

**ຖອນ·ຖອນຕົວ**: ເຮັດຈາກເມນູແຖວໃນລາຍການລົງທະບຽນ ຫຼື **ຖອນວິຊາ**, **ຖອນຕົວ** ໃນແຖບ **ລາຍຊື່ຜູ້ຮຽນ** ຂອງໜ້າກຸ່ມຮຽນ ພ້ອມເຫດຜົນ. ເຮັດໄດ້ໂດຍບໍ່ຂຶ້ນກັບໄລຍະເວລາດຳເນີນງານ. ຖ້າມີບ່ອນວ່າງ ຈະເລື່ອນລາຍຊື່ລໍຖ້າຂຶ້ນຕໍ່ໄປ.

ແຖບ **ລາຍຊື່ລໍຖ້າ** (ກຸ່ມຮຽນທີ່ມີຂະໜາດລາຍຊື່ລໍຖ້າ ຫຼື ມີບັນທຶກລໍຖ້າ): ຕາມລຳດັບເວລາຮ້ອງຂໍ ພ້ອມສະຖານະ ແລະ ໝາຍເຫດຜົນລັບ. ກົດ **ລຶບອອກ** ໃນແຖວເພື່ອເອົາອອກພ້ອມເຫດຜົນ. ຫຼັງຈາກເພີ່ມຈຳນວນຮັບ ໃຫ້ກົດ **ເລື່ອນຂຶ້ນດຽວນີ້** ເທິງໜ້າ ເພື່ອເລື່ອນຂຶ້ນທັນທີ.

## ການລະງັບການລົງທະບຽນ ແລະ ການຍົກເວັ້ນກົດ

**ການລະງັບການລົງທະບຽນ** (ການປະຕິເສດການລົງທະບຽນ `SRDENY` ຂອງລະບົບເກົ່າ): ລະຫັດນັກສຶກສາ, ປະເພດ (ບໍ່ໄດ້ລົງທະບຽນພາກຮຽນ, ການເງິນ, ວິຊາການ, ບໍລິຫານ, ອື່ນໆ), ຜົນ (ຂັດຂວາງການລົງທະບຽນຮຽນ / ການເບິ່ງເກຣດ / ການອອກໃບຢັ້ງຢືນ), ເລີ່ມ·ສິ້ນສຸດ, ເຫດຜົນ. ການຂັດຂວາງການເບິ່ງເກຣດ·ໃບຢັ້ງຢືນມີຄ່າເລີ່ມຕົ້ນເປັນປິດ. ນອກຈາກການຄ້າງຊຳລະຄ່າຮຽນແລ້ວ ຍັງໃຊ້ກັບການດຳເນີນການທາງບໍລິຫານທີ່ຕ້ອງປິດເກຣດຊົ່ວຄາວ ເຊັ່ນ ການສືບສວນການທຸຈະລິດ. ເມື່ອຖືກຂັດຂວາງການເບິ່ງເກຣດ ນັກສຶກສາຈະເບິ່ງໜ້າເກຣດ ແລະ ໃບລາຍງານເກຣດໃນພອດທໍບໍ່ໄດ້ ([ບົດທີ 21](21-grades.md), ນຳໃຊ້ຕັ້ງແຕ່ Phase 6). ບໍ່ມີຜົນຕໍ່ໜ້າຈໍຂອງພະນັກງານ ແລະ ການປ້ອນເກຣດຂອງອາຈານ. ເມື່ອຖືກຂັດຂວາງໃບຢັ້ງຢືນ ພະນັກງານຈະອອກໃບຢັ້ງຢືນບໍ່ໄດ້ ([ບົດທີ 23](23-certificates.md), ນຳໃຊ້ຕັ້ງແຕ່ Phase 8). ບໍ່ລຶບ ແຕ່ **ປົດ** ພ້ອມເຫດຜົນ. ລາຍການເລີ່ມຕົ້ນຄືການລະງັບທີ່ມີຜົນຢູ່. **ນຳເຂົ້າ CSV** ເທິງລາຍການໃຊ້ໃສ່ລາຍຊື່ເທື່ອດຽວ ([ບົດທີ 9](09-csv-import.md)).

**ການຍົກເວັ້ນກົດ** (ການອະນຸຍາດການລົງທະບຽນ `SRALLOW` ຂອງລະບົບເກົ່າ): ນັກສຶກສາ, ພາກຮຽນ, ກົດ, ຂອບເຂດນຳໃຊ້ (ຖ້າປ່ອຍວ່າງ ແມ່ນທັງພາກຮຽນ ຫຼື ກຸ່ມຮຽນ `ລະຫັດວິຊາ-ເລກກຸ່ມ` ຫຼື ລະຫັດວິຊາ), ໝົດອາຍຸ, ເຫດຜົນ. ຖ້າມີການຍົກເວັ້ນ ເຖິງກົດນັ້ນບໍ່ຜ່ານ ກໍລົງທະບຽນໄດ້ (ເມື່ອອະນຸຍາດການຍົກເວັ້ນຂອງກົດເປີດຢູ່). ກົດໄລຍະເວລາກໍເປີດດ້ວຍການຍົກເວັ້ນໄດ້ (ຕົວຢ່າງ: ຜູ້ທີ່ຈະຈົບການສຶກສາທີ່ພາດໄລຍະເວລາ). ສະຖານະກຸ່ມຮຽນ ແລະ ຈຳນວນຮັບບໍ່ມີການຍົກເວັ້ນ. ເມື່ອບໍ່ຕ້ອງການແລ້ວ ໃຫ້ **ຍົກເລີກ**.

## ບັນທຶກຄວາມພະຍາຍາມລົງທະບຽນ

ທຸກຄວາມພະຍາຍາມລົງທະບຽນ, ຖອນ, ຖອນຕົວ, ເຂົ້າລາຍຊື່ລໍຖ້າ, ເລື່ອນຂຶ້ນ ແລະ ໃສ່ກະຕ່າ ຖືກບັນທຶກພ້ອມເວລາ, ຜົນລັບ, ກົດທີ່ບໍ່ຄົບເງື່ອນໄຂ ແລະ ຂໍ້ຄວາມ, ຜູ້ດຳເນີນການ ແລະ ID ຄຳຮ້ອງ. ສຳລັບຄຳຖາມ "ເປັນຫຍັງລົງທະບຽນບໍ່ໄດ້" ໃຫ້ຊອກຫາດ້ວຍລະຫັດນັກສຶກສາແລ້ວກວດເບິ່ງ. ສາມາດເບິ່ງລ່ວງໜ້າວ່າຖ້າລົງທະບຽນຕອນນີ້ຈະເປັນແນວໃດ ດ້ວຍ `uv run manage.py registration_simulate {ລະຫັດນັກສຶກສາ} {ລະຫັດວິຊາ-ເລກກຸ່ມຮຽນ}` (ບໍ່ບັນທຶກ ແລະ ບໍ່ເກັບບັນທຶກ).
