# 25. ຫ້ອງຮຽນຂອງອາຈານ ແລະ ການເຂົ້າຮຽນ

ເມນູ: ອາຈານໃຊ້ພອດທໍ **ການສອນຂອງຂ້ອຍ > ລາຍຊື່ ແລະ ການເຂົ້າຮຽນ** (`/portal/sections/{ID ກຸ່ມຮຽນ}/attendance/`), ນັກສຶກສາໃຊ້ພອດທໍ **ການເຂົ້າຮຽນ** (`/portal/attendance/`). ພະນັກງານໃຊ້ແຖບ **ຄາບຮຽນ** ຂອງໜ້າ **ຫຼັກສູດ ແລະ ກຸ່ມຮຽນ > ກຸ່ມຮຽນ > ແກ້ໄຂ** ໃນໜ້າບໍລິຫານ.

| ໃຜ | ສິ່ງທີ່ເຮັດໄດ້ |
|---|---|
| ອາຈານຜູ້ສອນ | ລາຍຊື່ນັກສຶກສາ (ລວມຮູບ) ແລະ CSV, PDF ບັນຊີເຂົ້າຮຽນ, ສ້າງ·ເພີ່ມ·ຍົກເລີກຄາບຮຽນ, ປ້ອນການເຂົ້າຮຽນ |
| ພະນັກງານທີ່ມີສິດ `ວາງແຜນກຸ່ມຮຽນ` (ພາຍໃນຂອບເຂດ) | ຄືກັບອາຈານ + ຄາບຮຽນໃນໜ້າບໍລິຫານ |
| ພະນັກງານທີ່ມີສິດ `ເບິ່ງກຸ່ມຮຽນ` (ພາຍໃນຂອບເຂດ) | ເບິ່ງລາຍຊື່ນັກສຶກສາ, ບັນຊີເຂົ້າຮຽນ, ການເຂົ້າຮຽນ |
| ນັກສຶກສາ | ການເຂົ້າຮຽນຂອງຕົນ |

ຟັງຊັນຫ້ອງຮຽນ ເຊັ່ນ ປະກາດ, ວຽກບ້ານ, ເອກະສານ ຍົກໃຫ້ LMS (ແຜນການຍ້າຍລະບົບ ຂໍ້ 12).

## ສິ່ງທີ່ຕ່າງຈາກລະບົບເກົ່າ

- **ລະບົບເກົ່າ (YUSTIC) ບໍ່ໄດ້ບັນທຶກການເຂົ້າຮຽນ.** "ບັນຊີເຂົ້າຮຽນ" ເປັນ PDF ທີ່ພິມລາຍຊື່ນັກສຶກສາພ້ອມຊ່ອງວ່າງ (27~34 ຊ່ອງ ຕ່າງກັນໄປຕາມສຳເນົາ) ບໍ່ມີວັນທີ ແລະ ບໍ່ມີການສະຫຼຸບ. ລະບົບໃໝ່ສ້າງ **ຄາບຮຽນ** ຈາກເວລາຮຽນ ບັນທຶກ ມາຮຽນ·ມາຊ້າ·ຂາດ·ລາ ໃນທຸກຄາບ ແລະ ພິມບັນທຶກ ແລະ ຜົນລວມໃນ PDF ບັນຊີເຂົ້າຮຽນ.
- **ລາຍຊື່ນັກສຶກສາ.** ໜ້າຈໍອາຈານຂອງລະບົບເກົ່າສະແດງພຽງລະຫັດນັກສຶກສາ·ຊື່ (ແຕ່ປັອບອັບເປີດເຜີຍເຖິງເລກປະຈຳຕົວ·ທີ່ຢູ່) ແລະ ບໍ່ມີການດາວໂຫຼດ Excel. ລະບົບໃໝ່ສະແດງສະເພາະລະຫັດນັກສຶກສາ, ຊື່, ຮູບ, ຫຼັກສູດ, ປີຮຽນ, ອີເມວຕິດຕໍ່ ແລະ ດາວໂຫຼດເປັນ CSV. ການດາວໂຫຼດຖືກບັນທຶກໃນບັນທຶກການກວດສອບ.
- **ສິດເບິ່ງນັກສຶກສາຂອງອາຈານ.** ນະໂຍບາຍຄວາມປອດໄພລະດັບແຖວ (`student_records_instructor_select`, ຟັງຊັນ `util.taught_student_record_ids()`) ໃຫ້ອາຈານເບິ່ງບັນທຶກນັກສຶກສາ·ບຸກຄົນຂອງນັກສຶກສາໃນກຸ່ມຮຽນທີ່ຕົນສອນໄດ້ ແລະ ຂອບເຂດການເບິ່ງຂອງແອັບພລິເຄຊັນກໍຄືກັນ (ກ່ອນໜ້ານີ້ລະບົບຕົ້ນສະບັບເຫັນສະເພາະນັກສຶກສາທີ່ປຶກສາ ຈຶ່ງມີຂໍ້ບົກພ່ອງທີ່ຊື່ວ່າງໃນໜ້າປ້ອນເກຣດ).

## ຄາບຮຽນ

- **ສ້າງ**: ສ້າງຄາບຮຽນໜຶ່ງຄາບຕໍ່ວັນຂອງເວລາຮຽນ (ວັນ·ເວລາ·ໄລຍະເວລາ). ອາຈານໃຊ້ປຸ່ມ **ສ້າງຈາກເວລາຮຽນ**, ພະນັກງານໃຊ້ປຸ່ມ **ສ້າງຄາບຮຽນ** ຢູ່ເທິງແຖບ **ຄາບຮຽນ** (ມີໜ້າຢືນຢັນ) ຫຼື ຄຳສັ່ງ `uv run manage.py attendance_generate_sessions {ພາກຮຽນ}` (ທັງພາກຮຽນ). ຄາບຮຽນ ແລະ ການເຂົ້າຮຽນທີ່ມີຢູ່ແລ້ວຈະຄົງໄວ້ ຈຶ່ງແລ່ນອີກຄັ້ງຫຼັງແກ້ໄຂເວລາຮຽນໄດ້. ກຸ່ມຮຽນທີ່ຖືກຍົກເລີກຈະຖືກຂ້າມ.
- **ເພີ່ມ**: ຄາບນອກເວລາຮຽນ ເຊັ່ນ ການສອນຊົດເຊີຍ (ວັນທີ, ເລີ່ມ, ສິ້ນສຸດ). ສະເພາະວັນທີພາຍໃນໄລຍະເວລາຂອງຊ່ວງຮຽນ ແລະ ວັນທີ·ເວລາເລີ່ມດຽວກັນມີໄດ້ພຽງຄາບດຽວ.
- **ຍົກເລີກ**: ໃສ່ເຫດຜົນແລ້ວຍົກເລີກຄາບ. ຄາບຍັງຄົງຢູ່ ແຕ່ບໍ່ນັບໃນການສະຫຼຸບ. ກູ້ຄືນດ້ວຍ **ກູ້ຄືນ**.
- ບໍ່ມີປະຕິທິນວັນພັກລັດຖະການ. ຄາບຮຽນທີ່ຕົກວັນພັກ ໃຫ້ຍົກເລີກ (ເມື່ອມີປະຕິທິນພາກຮຽນໃນອະນາຄົດ ຕົວສ້າງຈະຍົກເວັ້ນໃຫ້ໄດ້).

## ການປ້ອນການເຂົ້າຮຽນ

ທີ່ **ການເຂົ້າຮຽນ** ຂອງຄາບ ເລືອກ ມາຮຽນ/ມາຊ້າ/ຂາດ/ລາ ຕໍ່ນັກສຶກສາ, ໃສ່ໝາຍເຫດ (200 ຕົວອັກສອນ) ແລ້ວກົດ **ບັນທຶກການເຂົ້າຮຽນ**. ວິທີທີ່ໄວຄືກົດ **ມາຮຽນທັງໝົດ** (ໝາຍທຸກຄົນວ່າມາຮຽນໂດຍຍັງບໍ່ບັນທຶກ) ແລ້ວປ່ຽນສະເພາະຂໍ້ຍົກເວັ້ນ.

- ປ້ອນໄດ້ຕັ້ງແຕ່ມື້ຮຽນເປັນຕົ້ນໄປ (ຄາບໃນອະນາຄົດ ແລະ ຄາບທີ່ຍົກເລີກບໍ່ໄດ້).
- ຖ້າບັນທຶກອີກຄັ້ງ ຈະບັນທຶກສະເພາະນັກສຶກສາທີ່ປ່ຽນ ແລະ ບັນທຶກການກວດສອບ (`attendance.recorded`) ຈະມີຄ່າເກົ່າ ແລະ ຄ່າໃໝ່ຂອງແຕ່ລະຄົນ.
- ຖ້າປ່ອຍສະຖານະວ່າງ ຈະກັບໄປເປັນ "ຍັງບໍ່ໄດ້ບັນທຶກ".
- ປ້ອນໄດ້ສະເພາະນັກສຶກສາທີ່ກຳລັງຮຽນ ຫຼື ຮຽນສຳເລັດແລ້ວ (ນັກສຶກສາທີ່ຖອນ·ຍົກເລີກບໍ່ຢູ່ໃນລາຍຊື່).

## ການສະຫຼຸບ

| ລາຍການ | ນິຍາມ |
|---|---|
| ຄາບທີ່ດຳເນີນແລ້ວ | ຄາບທີ່ບໍ່ຖືກຍົກເລີກ ແລະ ຢູ່ກ່ອນມື້ນີ້ (ລວມມື້ນີ້) |
| ອັດຕາການເຂົ້າຮຽນ | (ມາຮຽນ + ມາຊ້າ + ລາ) ÷ ຄາບທີ່ດຳເນີນແລ້ວ × 100, ທົດສະນິຍົມໜຶ່ງຕຳແໜ່ງ (ປັດເຄິ່ງຂຶ້ນ) |
| ບໍ່ໄດ້ບັນທຶກ | ຈຳນວນຄາບທີ່ດຳເນີນແລ້ວທີ່ບໍ່ມີບັນທຶກ |

ບໍ່ມີກົດທີ່ແປງການມາຊ້າຈຳນວນໜຶ່ງເປັນການຂາດ ຫຼື ໃຫ້ F ເມື່ອຂາດເກີນ 1/3. ເພາະແຕ່ລະມະຫາວິທະຍາໄລຕ່າງກັນ ອາຈານຈຶ່ງນຳໄປສະທ້ອນໃນເກຣດເອງ. ກົດການນັບຢູ່ໃນບໍລິການດຽວ (`AttendanceSummary`) ສະນັ້ນລາຍຊື່, ບັນຊີເຂົ້າຮຽນ ແລະ ໜ້າຂອງນັກສຶກສາສະແດງຄ່າດຽວກັນ.

## PDF ບັນຊີເຂົ້າຮຽນ ແລະ CSV ລາຍຊື່ນັກສຶກສາ

ການດາວໂຫຼດທັງສອງຖືກບັນທຶກໃນບັນທຶກການກວດສອບ (`attendance.sheet_exported`, `attendance.roster_exported`). ຄ່າໃນ CSV ທີ່ຂຶ້ນຕົ້ນດ້ວຍ `=`, `+`, `-`, `@` (ແລະ ແທັບ, ການຂຶ້ນແຖວ) ຈະຖືກໃສ່ເຄື່ອງໝາຍວົງຢືມດ່ຽວນຳໜ້າເພື່ອບໍ່ໃຫ້ຖືກແລ່ນເປັນສູດ.

- **ບັນຊີເຂົ້າຮຽນ (PDF)** (`/sections/{ID ກຸ່ມຮຽນ}/attendance-sheet`): A4 ແນວນອນ. ນັກສຶກສາຕາມແນວຕັ້ງ ຄາບຮຽນຕາມແນວນອນ (ບໍ່ລວມຄາບທີ່ຍົກເລີກ) ເຄື່ອງໝາຍ O/△/X/E ແລະ ຜົນລວມຕໍ່ນັກສຶກສາ. ຄາບທີ່ຍັງບໍ່ມາເຖິງເປັນຊ່ອງວ່າງ ຈຶ່ງໃຊ້ສຳລັບບັນທຶກດ້ວຍມືໄດ້. ເມື່ອເຊີບເວີ PDF (Gotenberg) ບໍ່ຕອບ ຈະສະແດງ "ບໍ່ສາມາດສ້າງ PDF ໄດ້".
- **ລາຍຊື່ນັກສຶກສາ (CSV)** (`/sections/{ID ກຸ່ມຮຽນ}/roster.csv`): ລະຫັດນັກສຶກສາ, ຊື່, ຫຼັກສູດ, ປີຮຽນ, ອີເມວຕິດຕໍ່, ສະຖານະການລົງທະບຽນ. ເປັນ UTF-8 (BOM) ຈຶ່ງເປີດໃນ Excel ໄດ້ທັນທີ.

## ພອດທໍຂອງນັກສຶກສາ

**ການເຂົ້າຮຽນ**: ຈຳນວນ ມາຮຽນ·ມາຊ້າ·ຂາດ·ລາ ແລະ ອັດຕາການເຂົ້າຮຽນຂອງວິຊາທີ່ລົງທະບຽນຕາມພາກຮຽນ (ຄ່າເລີ່ມຕົ້ນແມ່ນພາກຮຽນຫຼ້າສຸດທີ່ເລີ່ມແລ້ວ), ເມື່ອເປີດອອກຈະເຫັນບັນທຶກຕໍ່ຄາບທີ່ດຳເນີນແລ້ວ (ສະເພາະທີ່ອາຈານປ້ອນແລ້ວ, ຖ້າບໍ່ມີແມ່ນ "ຍັງບໍ່ໄດ້ບັນທຶກ").

## ຂັ້ນຕອນການດຳເນີນງານ

1. ກ່ອນພາກຮຽນເລີ່ມ ຢືນຢັນເວລາຮຽນຂອງກຸ່ມຮຽນ ([ບົດທີ 18](18-sections-and-timetables.md)).
2. ສ້າງຄາບຮຽນດ້ວຍ `uv run manage.py attendance_generate_sessions {ພາກຮຽນ} --actor=...` (ອາຈານສ້າງເອງໃນໜ້າຈໍກໍໄດ້). ສະເພາະກຸ່ມຮຽນດຽວໃຊ້ `--section=CSE2010-01`, ເບິ່ງສະເພາະຈຳນວນກຸ່ມຮຽນໃຊ້ `--dry-run` ([ຄຳສັ່ງດຳເນີນງານ](../operations/commands.md)).
3. ຖ້າເວລາຮຽນປ່ຽນ ໃຫ້ແລ່ນອີກຄັ້ງ. ຄາບຂອງເວລາທີ່ຖືກລຶບບໍ່ຖືກລຶບອັດຕະໂນມັດ ຈຶ່ງຕ້ອງຍົກເລີກເອງ.

## ໜ້າຈໍຂອງການຕິດຕັ້ງນີ້

ໜ້າຈໍ ແລະ ຟັງຊັນຄືກັບຕົ້ນສະບັບ (Filament, Livewire) ແຕ່ວິທີໃຊ້ງານບາງຢ່າງຕ່າງກັນເລັກນ້ອຍ.

- ແຖບ **ຄາບຮຽນ** ຂອງໜ້າແກ້ໄຂກຸ່ມຮຽນໃນໜ້າບໍລິຫານ: ວັນທີ, ເວລາ, ຫ້ອງຮຽນ, ສະຖານະ, ຈຳນວນທີ່ປ້ອນ, ເຫດຜົນ. **ຍົກເລີກ** ໃນແຖວເປີດໜ້າໃສ່ເຫດຜົນ, **ກູ້ຄືນ** ເປີດໜ້າຢືນຢັນ. **ສ້າງຄາບຮຽນ** ເປັນປຸ່ມດຳເນີນການຢູ່ເທິງໜ້າຈໍ. ພະນັກງານທີ່ມີພຽງສິດ `ເບິ່ງກຸ່ມຮຽນ` ເຫັນແຖບໄດ້ ແຕ່ບໍ່ມີປຸ່ມ.
- ໃນພອດທໍອາຈານ **ຍົກເລີກ** ຈະເປີດຊ່ອງໃສ່ເຫດຜົນໃນແຖວຂອງຄາບ, ໃສ່ເຫດຜົນແລ້ວກົດ **ຍົກເລີກ** ອີກຄັ້ງ (ແທນກ່ອງປ້ອນຂໍ້ມູນຂອງບຣາວເຊີໃນຕົ້ນສະບັບ).
- ທີ່ຢູ່ຂອງໜ້າປ້ອນ **ການເຂົ້າຮຽນ** ລົງທ້າຍດ້ວຍ `?meeting={ID ຄາບຮຽນ}` ຈຶ່ງບັນທຶກເປັນບຸກມາກໄດ້. **ກັບຄືນ** ຈະກັບໄປລາຍຊື່ ແລະ ລາຍການຄາບຮຽນ.
- ພາຍໃຕ້ຄວາມປອດໄພລະດັບແຖວ ລາຍຊື່ຈະມີຂໍ້ມູນສະເພາະສຳລັບຜູ້ທີ່ເບິ່ງການລົງທະບຽນ ແລະ ບັນທຶກນັກສຶກສາໄດ້. ບົດບາດເລີ່ມຕົ້ນ (ຜູ້ຮັບຜິດຊອບວິຊາການ, ຜູ້ຊ່ວຍພາກວິຊາ) ມີສິດ `ເບິ່ງການລົງທະບຽນຮຽນ ແລະ ລາຍຊື່ຜູ້ຮຽນ` ແລະ `ເບິ່ງບັນທຶກນັກສຶກສາ` ນຳ. ບົດບາດທີ່ໃຫ້ພຽງ `ວາງແຜນກຸ່ມຮຽນ` ຈະເຫັນລາຍຊື່ ແລະ ບັນຊີເຂົ້າຮຽນວ່າງເປົ່າ (ຄືກັບຕົ້ນສະບັບ).
