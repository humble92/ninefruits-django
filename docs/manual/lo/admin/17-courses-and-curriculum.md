# 17. ວິຊາ ແລະ ເງື່ອນໄຂການຈົບການສຶກສາ

ເມນູ: **ຫຼັກສູດ ແລະ ກຸ່ມຮຽນ > ວິຊາ**, **ເງື່ອນໄຂການຈົບການສຶກສາ** (ສິດ `ຄຸ້ມຄອງວິຊາ, ສະບັບວິຊາ ແລະ ວິຊາບັງຄັບກ່ອນ`, `ຄຸ້ມຄອງເງື່ອນໄຂການຈົບການສຶກສາ`)

## ວິຊາ ແລະ ສະບັບວິຊາ

ວິຊາແບ່ງອອກເປັນ **ລະຫັດ** ທີ່ບໍ່ປ່ຽນແປງ ແລະ **ສະບັບວິຊາ** ຕາມໄລຍະເວລາ. ຊື່ວິຊາ, ໜ່ວຍກິດ, ຊົ່ວໂມງ, ປະເພດວິຊາ, ວິທີໃຫ້ເກຣດ ແລະ ວິຊາບັງຄັບກ່ອນ ຂຶ້ນກັບສະບັບວິຊາ. ລະບົບເກົ່າ (YUSTIC) ແຍກວິຊາດ້ວຍລະຫັດວິຊາ ແລະ ວັນທີເລີ່ມ ແຕ່ເກຣດອ້າງອີງພຽງລະຫັດວິຊາ ຈຶ່ງບໍ່ຊັດເຈນວ່ານັກສຶກສາຮຽນສະບັບໃດ. ລະບົບໃໝ່ໃຫ້ກຸ່ມຮຽນ ແລະ ເກຣດອ້າງອີງສະບັບວິຊາ.

- ໄລຍະເວລາຂອງສະບັບວິຊາດຽວກັນຊ້ອນກັນບໍ່ໄດ້ (ຂໍ້ຈຳກັດຂອງ DB). ໃນວັນທີໃດໜຶ່ງ ມີສະບັບວິຊາທີ່ມີຜົນພຽງສະບັບດຽວ.
- ກຸ່ມຮຽນເປີດດ້ວຍສະບັບວິຊາທີ່ມີຜົນໃນວັນທີເລີ່ມຂອງຊ່ວງຮຽນ (ຊ່ວງຍ່ອຍຂອງພາກຮຽນ).

| ລາຍການ | ຄຳອະທິບາຍ |
|---|---|
| ລະຫັດວິຊາ | ຕົວຢ່າງ: `CSE2010`. ບໍ່ໃສ່ຄວາມໝາຍທາງທຸລະກິດໃນລະຫັດ (ກົດເຊັ່ນ ການກຳນົດວ່າ `009*` ເປັນວິຊາທະນາຄານໜ່ວຍກິດໃນລະບົບເກົ່າ ແມ່ນແທນດ້ວຍລາຍການຂ້າງລຸ່ມ) |
| ໜ່ວຍງານຄຸ້ມຄອງ | ໜ່ວຍງານທີ່ຄຸ້ມຄອງວິຊາ. ເປັນໜ່ວຍງານເປີດສອນເລີ່ມຕົ້ນຂອງກຸ່ມຮຽນ |
| ຊື່ວິຊາ, ຄຳອະທິບາຍ | ແຍກຕາມພາສາ |
| ໜ່ວຍກິດ, ຊົ່ວໂມງບັນຍາຍ·ປະຕິບັດ | ຫົວໜ່ວຍ 0.5 |
| ປະເພດວິຊາ | ຂໍ້ມູນອ້າງອີງ > ປະເພດວິຊາ |

| ນັບເຂົ້າຂີດຈຳກັດໜ່ວຍກິດ | ຖ້າປິດ ຈະບໍ່ນັບເຂົ້າໃນການຄິດໄລ່ຂີດຈຳກັດໜ່ວຍກິດຂອງການລົງທະບຽນຮຽນ (ເຊັ່ນ ວິຊາທະນາຄານໜ່ວຍກິດ) |
| ການປະເມີນການສອນ | ຖ້າປິດ ຈະບໍ່ມີການປະເມີນການສອນ (ວິຊາປະຕິບັດ, ຝຶກງານ ແລະ ອື່ນໆ. [ບົດທີ 22](22-course-evaluation.md)) |
| ຮຽນຊ້ຳໄດ້ໜ່ວຍກິດອີກ | ການຮຽນອີກຄັ້ງຈະໄດ້ໜ່ວຍກິດອີກ ບໍ່ຖືເປັນການຮຽນຄືນ (ເຊັ່ນ ສຳມະນາທີ່ປ່ຽນຫົວຂໍ້) |

## ການປັບປຸງວິຊາ

ເມື່ອໜ່ວຍກິດ ຫຼື ຊື່ວິຊາປ່ຽນ ຢ່າແກ້ໄຂສະບັບວິຊາໂດຍກົງ ແຕ່ໃຫ້ **ປັບປຸງ** ແທນ. ໃນແຖບ **ສະບັບວິຊາ** ຂອງໜ້າ **ແກ້ໄຂ** ວິຊາ ກົດ **ປັບປຸງຈາກວັນທີ** ຂອງສະບັບປັດຈຸບັນ ແລ້ວປ້ອນວັນທີເລີ່ມຂອງສະບັບໃໝ່, ຄ່າທີ່ປ່ຽນ ແລະ ເຫດຜົນ.

- ສະບັບປັດຈຸບັນຈະສິ້ນສຸດໃນມື້ກ່ອນວັນທີເລີ່ມ ແລະ ສະບັບໃໝ່ຈະເລີ່ມໂດຍສຳເນົາສະບັບປັດຈຸບັນ ແລະ ວິຊາບັງຄັບກ່ອນຂອງມັນ.
- ກຸ່ມຮຽນທີ່ເປີດໄປແລ້ວ ແລະ ເກຣດທີ່ຜ່ານມາ ຍັງອ້າງອີງສະບັບເດີມ.
- ສະເພາະການແກ້ໄຂທີ່ບໍ່ປ່ຽນຄວາມໝາຍ ເຊັ່ນ ການພິມຜິດ ຈຶ່ງແກ້ໄຂສະບັບວິຊາໂດຍກົງ (ຖືກບັນທຶກໃນບັນທຶກການປ່ຽນແປງຂໍ້ມູນ).

## ວິຊາບັງຄັບກ່ອນ ແລະ ວິຊາຮຽນຄວບຄູ່

ປ້ອນທີ່ **ວິຊາບັງຄັບກ່ອນ ແລະ ຮຽນຄວບຄູ່** ຢູ່ລຸ່ມໜ້າແກ້ໄຂສະບັບວິຊາ.

| ລາຍການ | ຄຳອະທິບາຍ |
|---|---|
| ປະເພດ | ວິຊາບັງຄັບກ່ອນ (ຕ້ອງຮຽນຜ່ານກ່ອນ), ວິຊາຮຽນຄວບຄູ່ (ຮຽນພ້ອມກັນໃນພາກຮຽນດຽວກັນ ຫຼື ຖ້າຮຽນຜ່ານແລ້ວຖືວ່າຄົບເງື່ອນໄຂ) |
| ກຸ່ມ | ວິຊາໃນກຸ່ມດຽວກັນ ຮຽນຜ່ານພຽງໜຶ່ງວິຊາກໍພໍ (ຫຼື). ທຸກກຸ່ມຕ້ອງຄົບເງື່ອນໄຂ (ແລະ) |
| ເກຣດຂັ້ນຕ່ຳ | ລະຫັດເກຣດຂອງມາດຕາເກຣດເລີ່ມຕົ້ນ (ຕົວຢ່າງ: `C0`). ຖ້າປ່ອຍວ່າງ ແມ່ນເກຣດຜ່ານ |
| ຮຽນໃນພາກຮຽນດຽວກັນໄດ້ | ກໍລະນີທີ່ອະນຸຍາດໃຫ້ຮຽນວິຊາບັງຄັບກ່ອນໃນພາກຮຽນດຽວກັນໄດ້ |

ຕົວຢ່າງ: ກຸ່ມ 1 ມີ `CSE1001`, ກຸ່ມ 2 ມີ `MAT1001` ແລະ `MAT1002` → `CSE1001` ແລະ (`MAT1001` ຫຼື `MAT1002`). ກົດວິຊາບັງຄັບກ່ອນຈະຖືກກວດໃນຕອນລົງທະບຽນຮຽນ ([ບົດທີ 20](20-registration.md)).

## ວິຊາທຽບເທົ່າ

ເມື່ອວິຊາປ່ຽນຍ້ອນການປັບປຸງຫຼັກສູດ ໃຫ້ປ້ອນພ້ອມໄລຍະເວລາໃນແຖບ **ວິຊາທຽບເທົ່າ** ຂອງໜ້າ **ແກ້ໄຂ** ວິຊາ. ຖ້າເປີດ **ທຽບເທົ່າກັນທັງສອງທາງ** ສອງວິຊາຈະແທນກັນໄດ້ ຖ້າປິດ ຈະຮັບຮູ້ສະເພາະວິຊາທຽບເທົ່າແທນວິຊານີ້ເທົ່ານັ້ນ. ໃຊ້ໃນການກຳນົດການຮຽນຄືນ ([ບົດທີ 20](20-registration.md)) ແລະ ການກວດສອບເງື່ອນໄຂຈົບການສຶກສາ ([ບົດທີ 26](26-graduation.md)).

## ເງື່ອນໄຂການຈົບການສຶກສາ

ສ້າງໜຶ່ງຊຸດຕໍ່ ຫຼັກສູດ, **ບົດບາດຫຼັກສູດ** (ຫຼັກສູດຫຼັກ, ວິຊາເອກທີສອງ, ວິຊາໂທ) ແລະ ຊ່ວງ **ປີຫຼັກສູດ** ທີ່ນຳໃຊ້. ນັກສຶກສາຈະຖືກນຳໃຊ້ເງື່ອນໄຂທີ່ກົງກັບປີຫຼັກສູດໃນບັນທຶກນັກສຶກສາ.

- ປີທີ່ນຳໃຊ້ຂອງຫຼັກສູດດຽວກັນ ແລະ ບົດບາດຫຼັກສູດດຽວກັນ ຊ້ອນກັນບໍ່ໄດ້. ຖ້າປ່ອຍວ່າງປີສິ້ນສຸດ ຈະນຳໃຊ້ຕໍ່ໄປຈົນກວ່າຊຸດເງື່ອນໄຂຖັດໄປຈະເລີ່ມ.
- ປະເພດເງື່ອນໄຂ

| ປະເພດ | ການປ້ອນ | ຕົວຢ່າງ |
|---|---|---|
| ໜ່ວຍກິດຕາມປະເພດວິຊາ | ປະເພດວິຊາ, ໜ່ວຍກິດຂັ້ນຕ່ຳ | ວິຊາທົ່ວໄປບັງຄັບ 9 ໜ່ວຍກິດ |
| ວິຊາບັງຄັບ | ລາຍການວິຊາ | ວິຊາເອກບັງຄັບທັງ 4 ວິຊາ |
| ເລືອກຈາກວິຊາທີ່ກຳນົດ | ລາຍການວິຊາ, ໜ່ວຍກິດຂັ້ນຕ່ຳ ຫຼື ຈຳນວນວິຊາຂັ້ນຕ່ຳ | 12 ໜ່ວຍກິດຈາກວິຊາເອກເລືອກ |
| ສອບເສັງຜ່ານ | ປະເພດການສອບເສັງ | ຜ່ານການສອບເສັງພາສາອັງກິດລວມ ([ບົດທີ 24](24-assessments.md)) |

ວິຊາເອກທີສອງ ແລະ ວິຊາໂທ ສ້າງເງື່ອນໄຂແຍກຕ່າງຫາກທີ່ໜ້ອຍກວ່າຫຼັກສູດຫຼັກ (ຕົວຢ່າງ: ວິຊາເອກທີສອງ 36 ໜ່ວຍກິດ, ວິຊາໂທ 21 ໜ່ວຍກິດ). ການຕັດສິນເງື່ອນໄຂເຮັດໃນການກວດສອບເງື່ອນໄຂຈົບການສຶກສາ ([ບົດທີ 26](26-graduation.md)).

## ການນຳເຂົ້າ CSV

ໃຊ້ **ນຳເຂົ້າ CSV** ໃນລາຍການວິຊາ (ສິດ `ຈັດການວິຊາ, ສະບັບ ແລະ ວິຊາບັງຄັບກ່ອນ`) ເພື່ອນຳເຂົ້າສະບັບວິຊາເປັນຈຳນວນຫຼາຍ. ແຖວໜຶ່ງແມ່ນສະບັບໜຶ່ງ. ຊອກຫາວິຊາດ້ວຍລະຫັດ (ຖ້າບໍ່ມີຈະສ້າງ), ຊອກຫາສະບັບດ້ວຍລະຫັດ ແລະ ວັນທີເລີ່ມ ດັ່ງນັ້ນການນຳເຂົ້າໄຟລ໌ດຽວກັນອີກຈະເປັນການອັບເດດ ແລະ ແຖວທີ່ມີວັນທີເລີ່ມອື່ນຈະເປັນສະບັບປັບປຸງ. ແຖວທີ່ໄລຍະເວລາຊ້ອນກັນຈະລົ້ມເຫຼວສະເພາະແຖວນັ້ນ.

| `org_unit` | ລະຫັດໜ່ວຍງານຄຸ້ມຄອງ. ຈຳເປັນສຳລັບວິຊາໃໝ່ |
| `effective_start_date`, `effective_end_date` | ໄລຍະເວລາຂອງສະບັບ (`YYYY-MM-DD`) |
| `title_en`, `title_ko`, `title_zh-hans`, `title_lo` | ຊື່ວິຊາແຕ່ລະພາສາ. ວິຊາໃໝ່ຕ້ອງມີພາສາອັງກິດ |
| `credits`, `lecture_hours`, `lab_hours` | ໜ່ວຍກິດ (ຈຳເປັນສຳລັບສະບັບໃໝ່, 0–30), ຊົ່ວໂມງ (0–40) |
| `category` | ລະຫັດປະເພດວິຊາ |
| `grading_basis` | `graded` ຫຼື `pass_fail` |
| `counts_toward_credit_limit` | `1`/`0` |

ເຮັດແບບດຽວກັນໄດ້ດ້ວຍ `uv run manage.py reference_import courses <ໄຟລ໌> --actor=<ອີເມວ>` ([ບົດທີ 9](09-csv-import.md)).

ວິຊາບັງຄັບກ່ອນ ແລະ ວິຊາຮຽນຄວບຄູ່ ປ້ອນໃນໜ້າສະບັບວິຊາ ເຊິ່ງເປີດຈາກແຖບ **ສະບັບວິຊາ** (ລິ້ງຂອງແຖວ). ສະບັບໃໝ່ສ້າງດ້ວຍ **ເພີ່ມສະບັບວິຊາ** ໃນໜ້າວິຊາ.
