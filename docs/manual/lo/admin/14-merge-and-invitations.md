# 14. ການລວມບຸກຄົນ ແລະ ການເຊີນສ້າງບັນຊີ

ເມນູ: **ລວມບຸກຄົນຊ້ຳ**, **ເຊີນສ້າງບັນຊີ** ຢູ່ດ້ານເທິງຂອງໜ້າລາຍລະອຽດ **ນັກສຶກສາ ແລະ ພະນັກງານ > ບຸກຄົນ**

## ການລວມບຸກຄົນຊ້ຳ

ໃຊ້ເມື່ອຄົນດຽວກັນຖືກລົງທະບຽນເປັນສອງບຸກຄົນ (ຕົວຢ່າງ: ຕອນເຂົ້າຮຽນຄືນ ຫາບຸກຄົນເດີມບໍ່ພົບ ຈຶ່ງສ້າງໃໝ່). ຕ້ອງມີສິດ `ລວມບຸກຄົນຊ້ຳ`.

1. ຄົ້ນຫາຜູ້ທີ່ອາດຊ້ຳ: ກວດຊື່ ແລະ ວັນເດືອນປີເກີດດຽວກັນ, ເລກບັດປະຈຳຕົວດຽວກັນ ດ້ວຍການຄົ້ນຫາໃນລາຍການບຸກຄົນ. ຜູ້ດຳເນີນງານ IT ສາມາດດຶງລາຍຊື່ຜູ້ທີ່ອາດຊ້ຳທັງໝົດດ້ວຍ `uv run manage.py people_find_duplicates`.
2. ໃນໜ້າລາຍລະອຽດຂອງ **ບຸກຄົນທີ່ຈະຍຸບ (ຊ້ຳ)** ກົດ **ລວມບຸກຄົນຊ້ຳ**, ເລືອກ **ບຸກຄົນທີ່ຈະເກັບໄວ້** ຈາກລາຍການ ແລ້ວປ້ອນເຫດຜົນ. ເມື່ອລວມສຳເລັດ ຈະໄປທີ່ໜ້າຂອງບຸກຄົນທີ່ເກັບໄວ້.
3. ບັນທຶກນັກສຶກສາ, ໃບສະໝັກ, ຂໍ້ມູນອາຈານ, ຜູ້ປົກຄອງ ແລະ ບັນຊີຂອງບຸກຄົນທີ່ຍຸບ ຈະຍ້າຍໄປຫາບຸກຄົນທີ່ເກັບໄວ້. ຖ້າທັງສອງຄົນມີບັນຊີ ບັນຊີຂອງບຸກຄົນທີ່ຍຸບຈະຖືກປິດໃຊ້ງານ ແລະ ການເຂົ້າສູ່ລະບົບຂອງສະຖາບັນທີ່ເຊື່ອມຕໍ່ໄວ້ຈະຖືກຍ້າຍຖ້າເປັນໄປໄດ້.
4. ບຸກຄົນທີ່ຍຸບຈະຄົງຢູ່ເປັນ **ຖືກລວມແລ້ວ** (ຕົວກອງລາຍການ **ຖືກລວມແລ້ວ**) ເພື່ອໃຫ້ຍັງຄົ້ນຫາບັນທຶກເກົ່າໄດ້. ໃຊ້ໃນການລົງທະບຽນບັນທຶກນັກສຶກສາໃໝ່ບໍ່ໄດ້.

- ຖ້າທັງສອງຄົນມີຂໍ້ມູນອາຈານ ຈະລວມບໍ່ໄດ້. ໃຫ້ຈັດການຂໍ້ມູນອາຈານກ່ອນ.
- ຖ້າທັງສອງຄົນມີໃບສະໝັກທີ່ກຳລັງດຳເນີນການໃນຮອບການຮັບສະໝັກດຽວກັນ ຈະລວມບໍ່ໄດ້. ໃຫ້ຜູ້ສະໝັກຖອນອັນໜຶ່ງ.
- **ຍ້ອນກັບບໍ່ໄດ້.** ກ່ອນລວມ ຕ້ອງກວດບັນທຶກນັກສຶກສາ ແລະ ວັນເດືອນປີເກີດໃຫ້ແນ່ນອນ. ການລວມຈະຖືກບັນທຶກພ້ອມເຫດຜົນໃນບັນທຶກກິດຈະກຳ.

## ການເຊີນສ້າງບັນຊີ

ສົ່ງອີເມວເຊີນສ້າງບັນຊີໃຫ້ບຸກຄົນທີ່ຍັງບໍ່ມີບັນຊີ ເຊັ່ນ ນັກສຶກສາ ແລະ ອາຈານທີ່ນຳເຂົ້າດ້ວຍ CSV. ຕ້ອງມີສິດ `ເຊີນບຸກຄົນສ້າງບັນຊີ`.

1. ໃນລາຍລະອຽດບຸກຄົນ ກົດ **ເຊີນສ້າງບັນຊີ** ແລ້ວປ້ອນອີເມວເຂົ້າສູ່ລະບົບ (ປົກກະຕິແມ່ນອີເມວສ່ວນຕົວ).
2. ເມື່ອຜູ້ຮັບຕັ້ງລະຫັດຜ່ານຈາກລິ້ງໃນອີເມວ ບັນຊີຈະຖືກສ້າງ ແລະ ເຂົ້າສູ່ລະບົບທັນທີ.

- ອາຍຸການໃຊ້ງານຂອງລິ້ງແມ່ນ **ການຕັ້ງຄ່າ > ບັນທຶກນັກສຶກສາ > ລິ້ງເຊີນໃຊ້ໄດ້ເປັນເວລາ (ວັນ)** (ຄ່າເລີ່ມຕົ້ນ 14 ວັນ).
- ຖ້າສົ່ງຄືນໃໝ່ ລິ້ງເກົ່າຈະໃຊ້ບໍ່ໄດ້ອີກ.
- ສົ່ງໃຫ້ບຸກຄົນທີ່ມີບັນຊີແລ້ວ ຫຼື ອີເມວທີ່ບັນຊີອື່ນໃຊ້ຢູ່ບໍ່ໄດ້.
- ຫຼັງຈົບການສຶກສາກໍໃຊ້ບັນຊີດຽວກັນ. ຜູ້ທີ່ໃຊ້ແຕ່ອີເມວສະຖາບັນ ໃຫ້ແນະນຳໃຫ້ປ່ຽນອີເມວເຂົ້າສູ່ລະບົບເປັນອີເມວສ່ວນຕົວໄວ້ ([ບົດ 15](15-sign-in-methods.md)).
