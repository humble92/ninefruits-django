# 6. ຂໍ້ມູນລະຫັດ, ປະເທດ, ພາສາ

ເມນູ: **ຂໍ້ມູນອ້າງອີງ > ຂໍ້ມູນລະຫັດ**, **ປະເທດ**, **ພາສາ** (ສິດ `ຈັດການຂໍ້ມູນລະຫັດ, ປະເທດ ແລະ ພາສາ`)

## ຂໍ້ມູນລະຫັດ

ແມ່ນລາຍການສັ້ນໆທີ່ແຕກຕ່າງກັນໄປຕາມແຕ່ລະມະຫາວິທະຍາໄລ. ແຕ່ລະລາຍການ (ປະເພດ) ມີຄ່າລະຫັດຂອງມັນ.

| ລະຫັດລາຍການ | ການນຳໃຊ້ | ລະບົບເກົ່າ (YUSTIC) |
|---|---|---|
| `ethnicity` | ຊົນເຜົ່າ | `FNATION` |
| `admission_type` | ປະເພດການຮັບເຂົ້າຮຽນ | `FADMDIST` |
| `room_type` | ປະເພດຫ້ອງຮຽນ | `ROOM.FORWHAT` |

- ລາຍການລະບົບ (ສາມລາຍການຂ້າງເທິງ) ຖືກໂປຣແກຣມຄົ້ນຫາດ້ວຍລະຫັດ ຈຶ່ງບໍ່ສາມາດປ່ຽນ ຫຼື ລຶບລະຫັດລາຍການໄດ້. ຄ່າສາມາດເພີ່ມໄດ້ຢ່າງອິດສະລະ.
- ເປີດລາຍການ ແລ້ວເພີ່ມທີ່ **ລະຫັດ** ຢູ່ດ້ານລຸ່ມ. ລະຫັດຕັ້ງດ້ວຍຕົວອັກສອນລາຕິນຕົວນ້ອຍ, ຕົວເລກ ແລະ ຂີດກ້ອງ (ຕົວຢ່າງ: `korean`). ຊື່ປ້ອນຕາມແຕ່ລະພາສາ ແລະ ຊື່ພາສາອັງກິດແມ່ນບັງຄັບ.
- ຄ່າທີ່ບໍ່ໃຊ້ແລ້ວ ບໍ່ຄວນລຶບ ແຕ່ໃຫ້ປິດ **ເປີດໃຊ້**. ຖ້າມີຂໍ້ມູນທີ່ໃຊ້ຄ່ານັ້ນຢູ່ແລ້ວ ຈະລຶບບໍ່ໄດ້.
- ຄ່າຈຳນວນຫຼາຍ ໃຫ້ປ້ອນດ້ວຍ [ການນຳເຂົ້າ CSV](09-csv-import.md).

## ປະເທດ ແລະ ພາສາ

ລາຍການມາດຕະຖານ ISO (ປະເທດ 249, ພາສາປະມານ 180) ຖືກນຳເຂົ້າຕອນຕິດຕັ້ງ. ຊື່ຖືກປ້ອນອັດຕະໂນມັດຕາມພາສາທີ່ຕິດຕັ້ງ.

- ຖ້າຕ້ອງການປ່ຽນຊື່ທີ່ສະແດງໃນໜ້າຈໍ ໃຫ້ແກ້ທີ່ **ແກ້ໄຂ**. ຊື່ທີ່ປ່ຽນຈະຄົງຢູ່ແມ່ນແຕ່ໃນການອັບເດດລະບົບຄັ້ງຕໍ່ໄປ.
- ຖ້າບໍ່ຕ້ອງການໃຫ້ປາກົດໃນລາຍການເລືອກ ໃຫ້ປິດ **ເປີດໃຊ້**.
