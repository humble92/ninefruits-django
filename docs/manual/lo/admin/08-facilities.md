# 8. ອາຄານ ແລະ ຫ້ອງຮຽນ

ເມນູ: **ຂໍ້ມູນອ້າງອີງ > ອາຄານ**, **ຫ້ອງຮຽນ** (ສິດ `ຈັດການອາຄານ ແລະ ຫ້ອງຮຽນ`)

## ອາຄານ

ປ້ອນລະຫັດ (ຕົວຢ່າງ: `SCI`), ຊື່ (ຕາມແຕ່ລະພາສາ) ແລະ ທີ່ຢູ່. ອາຄານທີ່ມີຫ້ອງຮຽນຢູ່ຈະລຶບບໍ່ໄດ້ ດັ່ງນັ້ນຖ້າບໍ່ໃຊ້ແລ້ວ ໃຫ້ປິດ **ເປີດໃຊ້**.

## ຫ້ອງຮຽນ

| ລາຍການ | ຄຳອະທິບາຍ |
|---|---|
| ອາຄານ, ເລກຫ້ອງ | ເລກຫ້ອງຕ້ອງບໍ່ຊ້ຳກັນພາຍໃນອາຄານດຽວກັນ. ຕົວຢ່າງ: `101` |
| ຊື່ | ທາງເລືອກ. ຕົວຢ່າງ: ຫໍປະຊຸມໃຫຍ່ |
| ປະເພດຫ້ອງ | ຄ່າຈາກຂໍ້ມູນລະຫັດ `room_type` (ຫ້ອງຮຽນ, ຫ້ອງທົດລອງ ແລະ ອື່ນໆ) |
| ໜ່ວຍງານ | ພາກວິຊາທີ່ຄຸ້ມຄອງ (ທາງເລືອກ) |
| ຄວາມຈຸ | ນຳໄປທຽບກັບຈຳນວນຮັບເມື່ອຈັດຕາຕະລາງຮຽນ ([ບົດທີ 18](18-sections-and-timetables.md)) |
| ໃຊ້ສຳລັບຕາຕະລາງຮຽນ | ຖ້າປິດ ຈະບໍ່ຖືກນຳມາຈັດເມື່ອສ້າງຕາຕະລາງຮຽນ (ຫ້ອງການ, ສາງ ແລະ ອື່ນໆ) |

ຖ້າມີຫ້ອງຮຽນຫຼາຍ ໃຫ້ໃຊ້ [ການນຳເຂົ້າ CSV](09-csv-import.md). ຕ້ອງລົງທະບຽນອາຄານກ່ອນ.
