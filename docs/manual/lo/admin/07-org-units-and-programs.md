# 7. ໜ່ວຍງານ ແລະ ຫຼັກສູດ

ເມນູ: **ຂໍ້ມູນອ້າງອີງ > ປະເພດໜ່ວຍງານ**, **ໜ່ວຍງານ**, **ຫຼັກສູດ**

## ໜ່ວຍງານ

ຈັດການມະຫາວິທະຍາໄລ, ຄະນະ, ພາກວິຊາ, ສາຂາວິຊາ ແລະ ພະແນກບໍລິຫານ ໃນໜ້າຈໍດຽວກັນ. ທົດແທນຄະນະ (`SFCOLLEGE`) ແລະ ພາກວິຊາ (`SFDEPARTMENT`) ຂອງລະບົບເກົ່າ (YUSTIC).

| ລາຍການ | ຄຳອະທິບາຍ |
|---|---|
| ລະຫັດ | ລະຫັດປະຈຳຕົວທີ່ບໍ່ປ່ຽນແປງ. ຕົວຢ່າງ: `CSE` |
| ປະເພດ | ມະຫາວິທະຍາໄລ, ຄະນະ, ພາກວິຊາ ແລະ ອື່ນໆ (ເພີ່ມໄດ້ທີ່ໜ້າຈໍປະເພດໜ່ວຍງານ) |
| ຊື່, ຊື່ຫຍໍ້ | ຕາມແຕ່ລະພາສາ |
| ຂັ້ນເທິງ | ໜ່ວຍງານທີ່ສັງກັດ. ບໍ່ສາມາດຍ້າຍໄປຢູ່ລຸ່ມຕົນເອງ ຫຼື ໜ່ວຍງານລູກຂອງຕົນເອງໄດ້ |
| ມີຜົນຕັ້ງແຕ່, ຈົນເຖິງ | ໄລຍະເວລາທີ່ໜ່ວຍງານມີຢູ່. ຖ້າວັນສິ້ນສຸດວ່າງ ໝາຍຄວາມວ່າຍັງດຳເນີນງານຢູ່ |

- ລາຍການຈະສະແດງ **ສະເພາະທີ່ມີຜົນໃນປັດຈຸບັນ** ເປັນຄ່າເລີ່ມຕົ້ນ. ຖ້າປິດຕົວກອງ ຈະເຫັນໜ່ວຍງານໃນອະດີດນຳ.
- ຖ້າເລືອກໜ່ວຍງານເປັນຂອບເຂດໃນການມອບບົດບາດ ໜ່ວຍງານທັງໝົດທີ່ຢູ່ລຸ່ມມັນຈະຖືກລວມເຂົ້ານຳ. ຕົວຢ່າງ: ຂອບເຂດຄະນະວິສະວະກຳສາດ = ທຸກພາກວິຊາທີ່ສັງກັດຄະນະວິສະວະກຳສາດ.

## ການປັບໂຄງສ້າງໜ່ວຍງານ

ເນື່ອງຈາກບັນທຶກນັກສຶກສາ ແລະ ເກຣດໃນອະດີດຕ້ອງຊີ້ໄປຫາໜ່ວຍງານໃນເວລານັ້ນ ຈຶ່ງບໍ່ແກ້ໄຂທັບໜ່ວຍງານເດີມ ແຕ່ບັນທຶກເປັນ **ການປັບໂຄງສ້າງ**.

1. ເປີດໜ້າ **ແກ້ໄຂ** ຂອງໜ່ວຍງານທີ່ຈະຍຸບ (ປ່ຽນ).
2. ກົດ **ປັບໂຄງສ້າງ**.
3. ເລືອກປະເພດການປ່ຽນແປງ.
   - **ປ່ຽນຊື່**: ສ້າງໜ່ວຍງານທີ່ມີຊື່ໃໝ່ກ່ອນ ແລ້ວກຳນົດເປັນໜ່ວຍງານສືບທອດ
   - **ລວມ**: ເມື່ອຫຼາຍໜ່ວຍງານລວມເປັນໜຶ່ງ ໃຫ້ກຳນົດໜ່ວຍງານສືບທອດດຽວກັນໃນແຕ່ລະໜ່ວຍງານ
   - **ແຍກ**: ເມື່ອໜ່ວຍງານໜຶ່ງແຍກເປັນຫຼາຍໜ່ວຍງານ ໃຫ້ກຳນົດໜ່ວຍງານສືບທອດຫຼາຍລາຍການ
   - **ຍ້າຍ**: ເມື່ອຍ້າຍໄປເປັນໜ່ວຍງານໃໝ່ພາຍໃຕ້ໜ່ວຍງານຂັ້ນເທິງອື່ນ
4. ປ້ອນ **ວັນທີມີຜົນ** ແລະ ເຫດຜົນ. ໜ່ວຍງານຈະສິ້ນສຸດໃນມື້ກ່ອນວັນທີມີຜົນ ແລະ ບັນທຶກຈະຄົງຢູ່ໃນລາຍການ **ໜ່ວຍງານສືບທອດ** ຢູ່ດ້ານລຸ່ມ.

ການແກ້ຄຳຜິດທຳມະດາ ບໍ່ແມ່ນການປັບໂຄງສ້າງ ໃຫ້ໃຊ້ **ແກ້ໄຂ** ຊື່ແທນ (ຈະຖືກບັນທຶກໃນການປ່ຽນແປງຂໍ້ມູນ).

## ຫຼັກສູດ

ແມ່ນຫຼັກສູດປະລິນຍາ ຫຼື ຫຼັກສູດສາຂາວິຊາ. ບັນທຶກນັກສຶກສາສັງກັດຫຼັກສູດ (Phase 2).

| ລາຍການ | ຄຳອະທິບາຍ |
|---|---|
| ລະຫັດ, ຊື່, ຊື່ປະລິນຍາ | ຕົວຢ່າງຊື່ປະລິນຍາ: ວິສະວະກຳສາດບັນດິດ |
| ລະດັບປະລິນຍາ | ອະນຸປະລິນຍາ, ປະລິນຍາຕີ, ປະລິນຍາໂທ, ປະລິນຍາເອກ, ປະກາດສະນີຍະບັດ, ບໍ່ມີປະລິນຍາ |
| ໜ່ວຍງານ | ພາກວິຊາທີ່ຮັບຜິດຊອບ |
| ໄລຍະເວລາມາດຕະຖານ (ປີ) | ໄລຍະເວລາຮຽນມາດຕະຖານ (ປີ) |
| ມີຜົນຕັ້ງແຕ່, ຈົນເຖິງ | ບໍ່ແມ່ນໄລຍະເວລາຮັບນັກສຶກສາໃໝ່ ແຕ່ແມ່ນໄລຍະເວລາທີ່ຫຼັກສູດມີຢູ່ |
| ຮັບວິຊາເອກທີສອງ, ຮັບວິຊາໂທ | ນັກສຶກສາຂອງຫຼັກສູດອື່ນສາມາດສະໝັກຫຼັກສູດນີ້ເປັນວິຊາເອກທີສອງ·ວິຊາໂທໄດ້ຫຼືບໍ່ ([ບົດ 19](19-second-majors-and-minors.md)) |
