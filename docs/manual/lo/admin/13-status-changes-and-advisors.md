# 13. ການປ່ຽນສະຖານະ ແລະ ອາຈານທີ່ປຶກສາ

ເມນູ: **ນັກສຶກສາ ແລະ ພະນັກງານ > ການປ່ຽນສະຖານະ**, **ປະເພດການປ່ຽນສະຖານະ**, ແຖບ **ການປ່ຽນສະຖານະ** ແລະ **ອາຈານທີ່ປຶກສາ** ໃນລາຍລະອຽດບັນທຶກນັກສຶກສາ

## ສະຖານະນັກສຶກສາ

| ສະຖານະ | ຄວາມໝາຍ |
|---|---|
| ກຳລັງສຶກສາ | ລົງທະບຽນຮຽນໄດ້ |
| ພັກການຮຽນ | ຮັກສາບັນທຶກນັກສຶກສາ, ລົງທະບຽນຮຽນບໍ່ໄດ້ |
| ລາອອກ, ຖືກໃຫ້ອອກ | ບັນທຶກນັກສຶກສາສິ້ນສຸດ. ຖ້າເຂົ້າຮຽນຄືນ ຈະເປັນບັນທຶກນັກສຶກສາໃໝ່ |
| ຈົບການສຶກສາ | ຕ້ອງມີວັນທີຈົບການສຶກສາ. ບັນຊີຍັງຄົງຢູ່ດ້ວຍສິດຂອງຜູ້ຈົບການສຶກສາ |

ກຳລັງສຶກສາ ແລະ ພັກການຮຽນ ຖືວ່າເປັນ "ນັກສຶກສາປັດຈຸບັນ" (ການເຂົ້າສູ່ລະບົບດ້ວຍລະຫັດນັກສຶກສາ, ການມອບໝາຍອາຈານທີ່ປຶກສາ ແລະ ອື່ນໆ).

## ປະເພດການປ່ຽນສະຖານະ

ແຕ່ລະປະເພດກຳນົດ **ສະຖານະໃໝ່**, **ສະຖານະທີ່ອະນຸຍາດໃຫ້ປ່ຽນຈາກ** ແລະ **ນັກສຶກສາສາມາດຍື່ນຄຳຮ້ອງໄດ້** ຫຼືບໍ່. ຕອນຕິດຕັ້ງຈະສ້າງ ພັກການຮຽນ, ກັບຄືນມາຮຽນ, ລາອອກ, ຖືກໃຫ້ອອກ, ເຂົ້າຮຽນຄືນ ແລະ ຈົບການສຶກສາ. ຊື່ປ່ຽນໄດ້ ແລະ ເຖິງຈະຕິດຕັ້ງຄືນ ຊື່ທີ່ປ່ຽນກໍຍັງຄົງຢູ່.

## ຄຳຮ້ອງຂອງນັກສຶກສາ ແລະ ການອະນຸມັດ

1. ນັກສຶກສາຍື່ນຄຳຮ້ອງທີ່ **ບັນທຶກຂອງຂ້ອຍ** ໃນພອດທໍ ໂດຍປ້ອນປະເພດ, ວັນທີມີຜົນ ແລະ ເຫດຜົນ. ບັນທຶກນັກສຶກສາໜຶ່ງມີຄຳຮ້ອງທີ່ກຳລັງດຳເນີນການໄດ້ພຽງອັນດຽວ ແລະ ກ່ອນດຳເນີນການ ນັກສຶກສາສາມາດຍົກເລີກໄດ້.
2. ຜູ້ຮັບຜິດຊອບ **ອະນຸມັດ** ຫຼື **ປະຕິເສດ** ໃນລາຍການ **ການປ່ຽນສະຖານະ** (ຄ່າເລີ່ມຕົ້ນ: ລໍຖ້າດຳເນີນການ). ການປະຕິເສດຕ້ອງມີຄຳເຫັນ. ໃຊ້ເມນູການດຳເນີນການຂອງແຕ່ລະແຖວ; ຈະມີໜ້າຕ່າງໃຫ້ປ້ອນຄຳເຫັນ.
3. ເມື່ອອະນຸມັດ ສະຖານະຂອງບັນທຶກນັກສຶກສາຈະປ່ຽນທັນທີ ແລະ ຖືກບັນທຶກໃນປະຫວັດການປ່ຽນສະຖານະ.

- ຕ້ອງມີສິດ `ອະນຸມັດ ແລະ ບັນທຶກການປ່ຽນສະຖານະ` ແລະ ດຳເນີນການໄດ້ສະເພາະບັນທຶກນັກສຶກສາພາຍໃນຂອບເຂດສິດ (ໜ່ວຍງານ, ຫຼັກສູດ) ເທົ່ານັ້ນ.
- ບໍ່ສາມາດອະນຸມັດຄຳຮ້ອງທີ່ຕົນເອງຍື່ນໄດ້ (ການແບ່ງແຍກໜ້າທີ່).
- ຖ້າສະຖານະຂອງບັນທຶກນັກສຶກສາປ່ຽນຫຼັງຈາກຍື່ນຄຳຮ້ອງ (ຕົວຢ່າງ: ຖືກບັນທຶກພັກການຮຽນແລ້ວໂດຍທາງອື່ນ) ຈະອະນຸມັດບໍ່ໄດ້. ໃຫ້ປະຕິເສດ ແລ້ວໃຫ້ຍື່ນຄຳຮ້ອງໃໝ່.

## ການບັນທຶກໂດຍກົງໂດຍຜູ້ຮັບຜິດຊອບ

ການໃຫ້ອອກ, ຄຳຮ້ອງທີ່ໄດ້ຮັບເປັນເອກະສານ ແລະ ອື່ນໆ ດຳເນີນການໂດຍກົງດ້ວຍ **ບັນທຶກການປ່ຽນສະຖານະ** ໃນລາຍລະອຽດບັນທຶກນັກສຶກສາ. ຕ້ອງມີເຫດຜົນ ແລະ ຜູ້ດຳເນີນການຈະຖືກບັນທຶກເປັນຜູ້ອະນຸມັດ. ຕ້ອງມີສິດ `ອະນຸມັດ ແລະ ບັນທຶກການປ່ຽນສະຖານະ`.

ການປ່ຽນສະຖານະທັງໝົດຖືກບັນທຶກໄວ້ໃນບັນທຶກກິດຈະກຳ ແລະ ການປ່ຽນແປງຂໍ້ມູນ ([ບົດ 4](04-audit.md)).

## ອາຈານທີ່ປຶກສາ

ທີ່ **ມອບໝາຍອາຈານທີ່ປຶກສາ** ໃນລາຍລະອຽດບັນທຶກນັກສຶກສາ ເລືອກອາຈານ, ປະເພດ (ອາຈານທີ່ປຶກສາຫຼັກ, ອາຈານທີ່ປຶກສາຮ່ວມ) ແລະ ວັນເລີ່ມ (ສິດ `ມອບໝາຍອາຈານທີ່ປຶກສາ`).

- ອາຈານທີ່ປຶກສາຫຼັກມີພຽງຄົນດຽວ. ຖ້າມອບໝາຍອາຈານທີ່ປຶກສາຫຼັກຄົນໃໝ່ ການມອບໝາຍເດີມຈະສິ້ນສຸດໃນມື້ກ່ອນວັນເລີ່ມ ແລະ ປະຫວັດຈະຄົງຢູ່.
- ເລືອກໄດ້ສະເພາະອາຈານທີ່ກຳລັງປະຕິບັດງານຢູ່ເທົ່ານັ້ນ.
- ອາຈານທີ່ປຶກສາສາມາດເບິ່ງລາຍຊື່ນັກສຶກສາໃນຄວາມດູແລປັດຈຸບັນທີ່ **ນັກສຶກສາໃນຄວາມດູແລ** ໃນພອດທໍ ແລະ ເບິ່ງບັນທຶກນັກສຶກສາຂອງນັກສຶກສາເຫຼົ່ານັ້ນໄດ້.
