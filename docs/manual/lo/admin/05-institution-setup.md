# 5. ການຕັ້ງຄ່າສະຖາບັນ ແລະ ລຳດັບການຕັ້ງຄ່າເບື້ອງຕົ້ນ

## ການຕັ້ງຄ່າສະຖາບັນ

ກຳນົດທີ່ **ການຕັ້ງຄ່າ > ສະຖາບັນ** (ສິດ `ຈັດການການຕັ້ງຄ່າສະຖາບັນ`).

| ລາຍການ | ຄຳອະທິບາຍ |
|---|---|
| ຊື່ສະຖາບັນ | ປ້ອນຕາມແຕ່ລະພາສາ. ສະແດງຢູ່ມຸມຊ້າຍເທິງຂອງໜ້າບໍລິຫານ |
| ເຂດເວລາ | ເກນສຳລັບຕັດສິນວັນທີພາກຮຽນ ແລະ ໄລຍະເວລາດຳເນີນງານ. ຕົວຢ່າງ: `Asia/Vientiane`. ເວລາທີ່ບັນທຶກໄວ້ທັງໝົດຈະສະແດງຕາມເຂດເວລານີ້ |
| ພາສາທີ່ໃຫ້ບໍລິການ | ພາສາທີ່ຜູ້ໃຊ້ສາມາດເລືອກໄດ້. ສະເພາະພາສາທີ່ມີໄຟລ໌ແປຕິດຕັ້ງແລ້ວເທົ່ານັ້ນຈຶ່ງປາກົດໃນລາຍການ |
| ພາສາເລີ່ມຕົ້ນ | ພາສາທີ່ໃຊ້ສຳລັບຜູ້ໃຊ້ທີ່ບໍ່ໄດ້ເລືອກພາສາ ແລະ ເມື່ອບໍ່ຮູ້ພາສາຂອງບຣາວເຊີ |

## ລຳດັບການຕັ້ງຄ່າເບື້ອງຕົ້ນສຳລັບມະຫາວິທະຍາໄລໃໝ່

ຫຼັງຈາກຜູ້ດຳເນີນງານ IT ແລ່ນ `setup_install` ສຳເລັດ (ຄູ່ມືການດຳເນີນງານ [ການຕິດຕັ້ງ](../operations/installation.md)) ຜູ້ບໍລິຫານວຽກງານປ້ອນຂໍ້ມູນຕາມລຳດັບຂ້າງລຸ່ມນີ້. ຂັ້ນຕອນຫຼັງຈະອ້າງອີງລະຫັດຈາກຂັ້ນຕອນກ່ອນ ຈຶ່ງຕ້ອງຮັກສາລຳດັບ.

1. **ການຕັ້ງຄ່າສະຖາບັນ**: ຊື່, ເຂດເວລາ, ພາສາ (ບົດນີ້)
2. **ຂໍ້ມູນລະຫັດ**: ຄ່າຊົນເຜົ່າ, ປະເພດການຮັບເຂົ້າຮຽນ, ປະເພດຫ້ອງຮຽນ ([ບົດ 6](06-code-data.md)). ຖ້າຕອນຕິດຕັ້ງໄດ້ນຳໃຊ້ໂປຣໄຟລ໌ມະຫາວິທະຍາໄລເກົາຫຼີ ປະເພດຫ້ອງຮຽນຈະມີຢູ່ແລ້ວ.
3. ກວດ **ປະເພດໜ່ວຍງານ** ແລ້ວປ້ອນ **ໜ່ວຍງານ**: ຕາມລຳດັບ ມະຫາວິທະຍາໄລ → ຄະນະ → ພາກວິຊາ ([ບົດ 7](07-org-units-and-programs.md)). ຖ້າມີຫຼາຍ ໃຫ້ໃຊ້ CSV ([ບົດ 9](09-csv-import.md)).
4. **ຫຼັກສູດ**: ຫຼັກສູດປະລິນຍາຂອງແຕ່ລະພາກວິຊາ ([ບົດ 7](07-org-units-and-programs.md))
5. **ອາຄານ**, **ຫ້ອງຮຽນ** ([ບົດ 8](08-facilities.md), ໃຊ້ CSV ໄດ້)
6. ກວດ **ປະເພດພາກຮຽນ**, **ຊົ່ວໂມງຮຽນ** ([ບົດ 10](10-terms.md))
7. ກວດ **ປະເພດວິຊາ**, **ມາດຕາເກຣດ**. ຕ້ອງມີມາດຕາເລີ່ມຕົ້ນກຳນົດໄວ້ໜຶ່ງລາຍການ ([ບົດ 11](11-course-categories-and-grade-scales.md))
8. **ສົກຮຽນ** → **ພາກຮຽນ** → **ໄລຍະເວລາດຳເນີນງານ** ຂອງແຕ່ລະພາກຮຽນ ([ບົດ 10](10-terms.md))
9. **ຜູ້ໃຊ້ ແລະ ສິດເຂົ້າໃຊ້**: ບົດບາດທີ່ຕ້ອງການຂອບເຂດໜ່ວຍງານ ເຊັ່ນ ຜູ້ຊ່ວຍພາກວິຊາ ຕອນນີ້ສາມາດເລືອກພາກວິຊາເປັນເປົ້າໝາຍຂອບເຂດໄດ້ແລ້ວ ([ບົດ 2](02-users-and-roles.md))

ເມື່ອປ້ອນຂໍ້ມູນສຳເລັດ ໃຫ້ຂໍຜູ້ດຳເນີນງານ IT ກວດສອບໄລຍະເວລາດຳເນີນງານດ້ວຍ `uv run manage.py term_inspect`.
