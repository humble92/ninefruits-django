# 12. ບຸກຄົນ ແລະ ບັນທຶກນັກສຶກສາ

ເມນູ: **ນັກສຶກສາ ແລະ ພະນັກງານ > ບຸກຄົນ**, **ບັນທຶກນັກສຶກສາ**, **ອາຈານ**

## ຄວາມສຳພັນລະຫວ່າງບຸກຄົນ ແລະ ບັນທຶກນັກສຶກສາ

| ແນວຄວາມຄິດ | ຄຳອະທິບາຍ |
|---|---|
| ບຸກຄົນ | ຄົນໜຶ່ງຄົນ. ຊື່, ວັນເດືອນປີເກີດ, ຂໍ້ມູນຕິດຕໍ່, ເລກປະຈຳຕົວ, ຮູບ, ຜູ້ປົກຄອງ. ບໍ່ວ່າຈະເປັນນັກສຶກສາ ຫຼື ອາຈານ ຄົນໜຶ່ງແມ່ນບຸກຄົນດຽວ |
| ບັນທຶກນັກສຶກສາ | ການຮັບເຂົ້າຮຽນ 1 ຄັ້ງ. ລະຫັດນັກສຶກສາ, ຫຼັກສູດ, ວັນທີຮັບເຂົ້າ, ຊັ້ນປີ, ສະຖານະ. ຖ້າເຂົ້າຮຽນຄືນຫຼັງຈົບການສຶກສາ ບຸກຄົນດຽວກັນຈະມີ **ບັນທຶກນັກສຶກສາໃໝ່ (ລະຫັດນັກສຶກສາໃໝ່)** |
| ອາຈານ | ຂໍ້ມູນອາຈານຂອງບຸກຄົນ (ລະຫັດພະນັກງານ, ສັງກັດ, ປະເພດການຈ້າງງານ, ຕຳແໜ່ງວິຊາການ). ບຸກຄົນໜຶ່ງມີໜຶ່ງ |
| ບັນຊີ | ບັນຊີເຂົ້າສູ່ລະບົບ. ເຊື່ອມກັບບຸກຄົນແບບ 1:1. ເຖິງຈະມີຫຼາຍບັນທຶກນັກສຶກສາ ກໍມີບັນຊີດຽວ |

ນັກສຶກສາ ແລະ ຜູ້ຈົບການສຶກສາເລືອກເບິ່ງບັນທຶກນັກສຶກສາໃນພອດທໍ (ຖ້າມີຫຼາຍບັນທຶກນັກສຶກສາ ຕົວເລືອກບັນທຶກນັກສຶກສາຈະປາກົດຢູ່ດ້ານເທິງ).

## ບຸກຄົນ

- ຊື່ມີທັງ **ຊື່ຕາມກົດໝາຍດ້ວຍຕົວອັກສອນລາຕິນ** (ຕາມໜັງສືຜ່ານແດນ: ນາມສະກຸນ, ຊື່) ແລະ **ຊື່ໃນພາສາອື່ນ** (ຕົວຢ່າງ: ພາສາເກົາຫຼີ `김민수`). ໜ້າຈໍຈະສະແດງຊື່ໃນພາສາປັດຈຸບັນຖ້າມີ ຖ້າບໍ່ມີ ຈະສະແດງຊື່ຕົວອັກສອນລາຕິນ. ຄົ້ນຫາໄດ້ທັງສອງແບບ.
- ເລກບັດປະຈຳຕົວ ແລະ ເລກໜັງສືຜ່ານແດນ ຖືກເຂົ້າລະຫັດເກັບໄວ້ ແລະ ສະແດງແບບປິດບັງ. ຄ່າເຕັມຈະສະແດງຄັ້ງດຽວໃນໜ້າແຍກຕ່າງຫາກ ຫຼັງຈາກກົດ **ສະແດງເລກບັດປະຈຳຕົວ** (ຫຼື **ສະແດງເລກໜັງສືຜ່ານແດນ**) ຢູ່ດ້ານເທິງຂອງໜ້າບຸກຄົນ ແລະ ປ້ອນເຫດຜົນ (ສິດ `ເປີດເຜີຍເລກບັດປະຈຳຕົວ ແລະ ເລກໜັງສືຜ່ານແດນ`). ຄ່ານັ້ນບໍ່ຖືກເກັບໄວ້ (ບໍ່ມີໃນຂໍ້ຄວາມ ຫຼື ບັນທຶກ) ແລະ ການເບິ່ງຈະຖືກບັນທຶກໄວ້ໃນບັນທຶກຄວາມປອດໄພພ້ອມເຫດຜົນ. ການຄົ້ນຫາດ້ວຍເລກຈະພົບສະເພາະເມື່ອກົງກັນທັງໝົດ.
- ຮູບອັບໂຫຼດທີ່ໜ້າແກ້ໄຂບຸກຄົນ. ຮູບດາວໂຫຼດໄດ້ຫຼັງຈາກກວດສິດແລ້ວເທົ່ານັ້ນ (ບໍ່ມີທີ່ຢູ່ສາທາລະນະ).
- ຜູ້ປົກຄອງຈັດການທີ່ແຖບ **ຜູ້ປົກຄອງ** ໃນລາຍລະອຽດບຸກຄົນ. ນັກສຶກສາເອງກໍສາມາດແກ້ໄຂຜູ້ປົກຄອງ ແລະ ຂໍ້ມູນຕິດຕໍ່ (ອີເມວ, ໂທລະສັບ, ທີ່ຢູ່, ລະຫັດໄປສະນີ) ໄດ້ທີ່ **ຂໍ້ມູນຂອງຂ້ອຍ** ໃນພອດທໍ. ຊື່, ວັນເດືອນປີເກີດ ແລະ ເລກປະຈຳຕົວ ນັກສຶກສາແກ້ໄຂເອງບໍ່ໄດ້.
- **ປະຫວັດການປ່ຽນແປງ** ຢູ່ດ້ານລຸ່ມຂອງໜ້າບຸກຄົນ ສະແດງການປ່ຽນແປງຂໍ້ມູນຫຼ້າສຸດ 50 ລາຍການຂອງບຸກຄົນ ແລະ ຜູ້ປົກຄອງ (ເວລາ, ຕາຕະລາງ, ຖັນທີ່ປ່ຽນ, ຜູ້ໃຊ້). ຖ້າມີສິດ `ເບິ່ງບັນທຶກການກວດສອບ` ສາມາດເປີດແຕ່ລະລາຍການ (ຄ່າກ່ອນ ແລະ ຫຼັງ). ໜ້າບັນທຶກນັກສຶກສາກໍສະແດງປະຫວັດຂອງບັນທຶກ, ການປ່ຽນສະຖານະ, ອາຈານທີ່ປຶກສາ ແລະ ວິຊາເອກທີສອງ ແລະ ວິຊາໂທ ດ້ວຍວິທີດຽວກັນ.

| ສິດ | ສິ່ງທີ່ເຮັດໄດ້ |
|---|---|
| `ເບິ່ງບຸກຄົນທັງໝົດ` | ເບິ່ງບຸກຄົນທຸກຄົນ |
| `ສ້າງ ແລະ ແກ້ໄຂບຸກຄົນ` | ສ້າງ, ແກ້ໄຂບຸກຄົນ |
| `ເປີດເຜີຍເລກບັດປະຈຳຕົວ ແລະ ເລກໜັງສືຜ່ານແດນ` | ເບິ່ງເລກບັດປະຈຳຕົວ, ເລກໜັງສືຜ່ານແດນແບບເຕັມ |
| `ລວມບຸກຄົນຊ້ຳ`, `ເຊີນບຸກຄົນສ້າງບັນຊີ` | [ບົດ 14](14-merge-and-invitations.md) |

ຜູ້ຮັບຜິດຊອບທີ່ບໍ່ມີສິດ `ເບິ່ງບຸກຄົນທັງໝົດ` ກໍຍັງເບິ່ງບຸກຄົນ ແລະ ອາຈານຂອງບັນທຶກນັກສຶກສາທີ່ຕົນເບິ່ງໄດ້.

## ການລົງທະບຽນບັນທຶກນັກສຶກສາ

1. ກົດ **ເພີ່ມບັນທຶກນັກສຶກສາ** ຢູ່ດ້ານເທິງຂອງລາຍການ **ບັນທຶກນັກສຶກສາ** (ຫົວຂໍ້ໜ້າແມ່ນ **ລົງທະບຽນນັກສຶກສາ**).
2. ເລືອກ **ບຸກຄົນທີ່ມີຢູ່ແລ້ວ** (ການເຂົ້າຮຽນຄືນ, ອາຈານເຂົ້າຮຽນລະດັບບັນດິດສຶກສາ ແລະ ອື່ນໆ) ຫຼື ປ້ອນ **ບຸກຄົນໃໝ່**. ກ່ອນສ້າງບຸກຄົນໃໝ່ ໃຫ້ຄົ້ນຫາກວດວ່າມີຄົນດຽວກັນຢູ່ແລ້ວຫຼືບໍ່.
3. ປ້ອນຫຼັກສູດ, ວັນທີຮັບເຂົ້າ, ຊັ້ນປີ, ປະເພດການຮັບເຂົ້າຮຽນ. ສັງກັດ (ໜ່ວຍງານທີ່ຄຸ້ມຄອງ) ຈະຖືກກຳນົດຕາມໜ່ວຍງານຂອງຫຼັກສູດ.
4. ຖ້າປະລະຫັດນັກສຶກສາວ່າງ ຈະສ້າງຕາມຮູບແບບລະຫັດນັກສຶກສາໃນ **ການຕັ້ງຄ່າ > ບັນທຶກນັກສຶກສາ**. ຮູບແບບເລີ່ມຕົ້ນ `{YYYY}{SEQ:5}` ແມ່ນປີຮັບເຂົ້າ + ເລກລຳດັບ 5 ຫຼັກ (ຕົວຢ່າງ: `202600001`). ເລກທີ່ຖືກໃຊ້ແລ້ວ (ລວມທັງບັນທຶກນັກສຶກສາທີ່ນຳເຂົ້າ) ຈະຖືກຂ້າມ.

| ໂທເຄັນຂອງຮູບແບບລະຫັດນັກສຶກສາ | ຄວາມໝາຍ |
|---|---|
| `{YYYY}` | ປີຮັບເຂົ້າ |
| `{YY}` | ສອງຫຼັກສຸດທ້າຍຂອງປີຮັບເຂົ້າ |
| `{SEQ:n}` | ເລກລຳດັບ n ຫຼັກ. ຕ້ອງມີພຽງອັນດຽວໃນຮູບແບບ. ນັບແຍກຕາມສ່ວນນຳໜ້າ (ຕົວຢ່າງ: `2026`) |

ລະຫັດນັກສຶກສາ ແລະ ສະຖານະຂອງບັນທຶກນັກສຶກສາຈະບໍ່ປ່ຽນຈາກໜ້າແກ້ໄຂ. ສະຖານະປ່ຽນດ້ວຍການປ່ຽນສະຖານະ ([ບົດ 13](13-status-changes-and-advisors.md)).

| ຂອບເຂດສິດ | ບັນທຶກນັກສຶກສາທີ່ເບິ່ງໄດ້ |
|---|---|

| ຂອບເຂດໜ່ວຍງານ·ຫຼັກສູດ (ວິຊາເອກທີສອງ·ວິຊາໂທ) | ບັນທຶກນັກສຶກສາຂອງນັກສຶກສາທີ່ກຳລັງຮຽນໜ່ວຍງານ ຫຼື ຫຼັກສູດນັ້ນເປັນວິຊາເອກທີສອງ·ວິຊາໂທ (ເບິ່ງເທົ່ານັ້ນ) |
| ຜູ້ຮັບຜິດຊອບອະນຸມັດວິຊາເອກທີສອງ·ວິຊາໂທ | ບັນທຶກນັກສຶກສາຂອງນັກສຶກສາທີ່ຍື່ນໃບສະໝັກທີ່ຕ້ອງດຳເນີນການ (ເບິ່ງເທົ່ານັ້ນ) |
| ອາຈານທີ່ປຶກສາ | ນັກສຶກສາໃນຄວາມດູແລໃນປັດຈຸບັນ |
| ນັກສຶກສາເອງ | ບັນທຶກນັກສຶກສາຂອງຕົນ |

ກົດລະບຽບດຽວກັນນີ້ມີຢູ່ໃນຖານຂໍ້ມູນ (ຄວາມປອດໄພລະດັບແຖວ) ນຳ ດັ່ງນັ້ນການເບິ່ງນອກໜ້າຈໍ (ບົດລາຍງານ, ການເຊື່ອມຕໍ່ໂດຍກົງ) ກໍບໍ່ສາມາດເກີນຂອບເຂດໄດ້.

## ອາຈານ

ດ້ວຍ **ເພີ່ມອາຈານ** ຢູ່ດ້ານເທິງຂອງລາຍການ **ອາຈານ** (ຫົວຂໍ້ໜ້າແມ່ນ **ເພີ່ມອາຈານ**) ເລືອກບຸກຄົນທີ່ມີຢູ່ແລ້ວ ຫຼື ປ້ອນບຸກຄົນໃໝ່ (ສິດ `ຈັດການອາຈານ`). ເມື່ອວັນສິ້ນສຸດຜ່ານໄປແລ້ວ ຈະຫາຍຈາກລາຍການອາຈານປັດຈຸບັນ (ຕົວກອງເລີ່ມຕົ້ນ) ແລະ ຕົວເລືອກອາຈານທີ່ປຶກສາ.

## ການນຳເຂົ້າຈຳນວນຫຼາຍດ້ວຍ CSV

ໃຊ້ **ນຳເຂົ້າ CSV** ຢູ່ດ້ານເທິງຂອງລາຍການບັນທຶກນັກສຶກສາ ແລະ ອາຈານ. ຮູບແບບຖັນເບິ່ງທີ່ [ບົດ 9](09-csv-import.md#ນັກສຶກສາ-ແລະ-ອາຈານ).
