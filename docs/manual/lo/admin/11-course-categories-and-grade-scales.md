# 11. ປະເພດວິຊາ ແລະ ມາດຕາເກຣດ

## ປະເພດວິຊາ

ເມນູ: **ຂໍ້ມູນອ້າງອີງ > ປະເພດວິຊາ** (ສິດ `ຈັດການປະເພດວິຊາ`). ທົດແທນ `SFOBJDIST` ຂອງລະບົບເກົ່າ (YUSTIC).

ແມ່ນເກນແບ່ງປະເພດວິຊາ ເຊັ່ນ ວິຊາພື້ນຖານບັງຄັບ, ວິຊາເອກເລືອກ. ສາມາດຈັດກຸ່ມໄດ້ໂດຍກຳນົດ **ຂັ້ນເທິງ** (ຕົວຢ່າງ: ວິຊາພື້ນຖານ → ວິຊາພື້ນຖານບັງຄັບ, ວິຊາພື້ນຖານເລືອກ). ເງື່ອນໄຂຈົບການສຶກສາ (Phase 4, 11) ຈະອ້າງອີງເຖິງ ເຊັ່ນ "ວິຊາເອກບັງຄັບ 30 ໜ່ວຍກິດ".

## ມາດຕາເກຣດ

ເມນູ: **ຂໍ້ມູນອ້າງອີງ > ມາດຕາເກຣດ** (ສິດ `ຈັດການມາດຕາເກຣດ`). ທົດແທນ `SSCOREDEF` ຂອງລະບົບເກົ່າ.

| ລາຍການຂອງມາດຕາ | ຄຳອະທິບາຍ |
|---|---|
| ຄະແນນເກຣດສູງສຸດ | ຕົວຢ່າງ: 4.5 |
| ຄ່າເລີ່ມຕົ້ນ | ກຳນົດໄດ້ພຽງອັນດຽວ. ເປີດໄດ້ສະເພາະເມື່ອຍັງບໍ່ມີມາດຕາເລີ່ມຕົ້ນ (ເບິ່ງຂ້າງລຸ່ມ) |

ເປີດມາດຕາ ແລ້ວເພີ່ມເກຣດທີ່ **ເກຣດ** ຢູ່ດ້ານລຸ່ມ.

| ລາຍການຂອງເກຣດ | ຄຳອະທິບາຍ |
|---|---|
| ເກຣດ | ຕົວຢ່າງ: `A+`, `P` |
| ຄະແນນເກຣດ | ບັງຄັບສຳລັບເກຣດທີ່ນັບໃນການຄິດໄລ່ຄະແນນສະເລ່ຍ |
| ຈາກ/ເຖິງ (%) | ເກນການແປງຈາກຄະແນນດິບ (ທາງເລືອກ). ຕົວຢ່າງ: A+ 95~100 |
| ນັບໃນ GPA | ປິດສຳລັບເກຣດທີ່ບໍ່ນັບໃນຄະແນນສະເລ່ຍ ເຊັ່ນ P/NP |
| ຜ່ານ | ປິດສຳລັບເກຣດທີ່ບໍ່ໄດ້ຮັບໜ່ວຍກິດ ເຊັ່ນ F, NP |
| ໃຊ້ກັບວິຊາ | ວິຊາທົ່ວໄປ (ເກຣດ), ວິຊາ P/F (P, NP), ທັງສອງ (ຕົວຢ່າງ: I ບໍ່ຄົບຖ້ວນ). ໜ້າປ້ອນເກຣດຈະສະແດງສະເພາະເກຣດທີ່ກົງກັບວິທີໃຫ້ເກຣດຂອງວິຊາ |

**ມາດຕາເລີ່ມຕົ້ນຖືກກຳນົດຕອນຕິດຕັ້ງ ແລະ ປ່ຽນບໍ່ໄດ້** (ຕັດສິນໃຈວັນທີ 2026-10-23). ເພາະວ່າເກຣດ ແລະ ຄະແນນສະເລ່ຍທັງໝົດຢູ່ໃນມາດຕານັ້ນ. ກຳນົດດ້ວຍ `setup_install --grade-scale=4.5|4.3` ຫຼື ຖ້າບໍ່ກຳນົດ ຈະເປັນມາດຕາຂອງໂປຣໄຟລ໌ທຳອິດ. ເຄື່ອງໝາຍຄ່າເລີ່ມຕົ້ນປ່ຽນຈາກໜ້າຈໍບໍ່ໄດ້ ແລະ ມາດຕາເລີ່ມຕົ້ນລຶບບໍ່ໄດ້. ຊ່ວງຄະແນນ ແລະ ຄະແນນເກຣດຂອງແຕ່ລະເກຣດແກ້ໄຂໄດ້ໃນໜ້າຈໍນີ້ ([ບົດ 21](21-grades.md)).

ມາດຕາທີ່ໂປຣໄຟລ໌ໃສ່ໃຫ້

- ມະຫາວິທະຍາໄລເກົາຫຼີ: ມາດຕາ 4.5 (`KR45`): A+ 4.5(95~100), A0 4.0(90~), B+ 3.5(85~), B0 3.0(80~), C+ 2.5(75~), C0 2.0(70~), D+ 1.5(65~), D0 1.0(60~), F 0, P, NP
- `--grade-scale=4.3` ຫຼື ໂປຣໄຟລ໌ YUST ຂອງລະບົບເກົ່າ: ມາດຕາ 4.3 (`KR43` ຫຼື `YUST43`): A+ 4.3(97~100), A0 4.0(93~), A- 3.7(90~), B+ 3.3(87~), B0 3.0(83~), B- 2.7(80~), C+ 2.3(77~), C0 2.0(73~), C- 1.7(70~), D+ 1.3(67~), D0 1.0(63~), D- 0.7(60~), F 0, P, NP (ລະບົບເກົ່າລວມ N, I ນຳ). ຊ່ວງຄະແນນເລີ່ມຕົ້ນດ້ວຍໄລຍະຫ່າງ 3 ຄະແນນ ຈຶ່ງຄວນແກ້ໃຫ້ກົງກັບເກນຂອງສະຖາບັນ.

ມາດຕາທີ່ຖືກໃຊ້ໃນເກຣດແລ້ວລຶບບໍ່ໄດ້.
