# 8. Mga gusali at silid

Menu: **Sangguniang datos > Mga gusali**, **Mga silid** (pahintulot na `Pamahalaan ang mga gusali at silid`)

## Mga gusali

Ilagay ang code (halimbawa `SCI`), ang pangalan (bawat wika) at ang address. Hindi maaaring burahin ang gusaling may mga silid, kaya i-off ang **Aktibo** kapag hindi na ito ginagamit.

## Mga silid

| Field | Paglalarawan |
|---|---|
| Gusali, Numero ng silid | Natatangi ang numero ng silid sa loob ng isang gusali, halimbawa `101` |
| Pangalan | Opsiyonal, halimbawa Main Auditorium |
| Uri ng silid | Halaga mula sa listahan ng code na `room_type` (silid-aralan, laboratoryo, atbp.) |
| Yunit ng organisasyon | Ang departamentong namamahala sa silid (opsiyonal) |
| Kapasidad | Inihahambing sa kapasidad ng seksiyon kapag gumagawa ng talaorasan ([kabanata 18](18-sections-and-timetables.md)) |
| Ginagamit sa mga talaorasan | Kapag naka-off, hindi isinasama ang silid kapag gumagawa ng talaorasan (opisina, imbakan, atbp.) |

Para sa maraming silid, gumamit ng [pag-import ng CSV](09-csv-import.md). Kailangang nakarehistro muna ang mga gusali.
