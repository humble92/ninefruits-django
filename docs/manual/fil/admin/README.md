# Manwal ng administrator

- Para kanino: mga kawani ng administrasyong akademiko (rekord ng mag-aaral, Academic Affairs, sertipiko, admisyon) at mga administrator ng sistema
- Sinusunod ng mga pangalan ng screen ang mga label na makikita sa user interface na Filipino.

| Kabanata | Nilalaman |
|---|---|
| [1. Pagsisimula](01-getting-started.md) | Pag-sign in, ang portal at ang panel ng administrasyon, wika |
| [2. Mga user at tungkulin](02-users-and-roles.md) | Mga account ng user, mga tungkulin at pahintulot, pagtatalaga ng tungkulin (saklaw, panahon) |
| [3. Two-factor authentication](03-two-factor-authentication.md) | Paano nag-e-enroll ang mga user, mga setting ng patakaran, pag-reset |
| [4. Audit](04-audit.md) | Log ng aktibidad, mga pagbabago ng datos, mga pangyayaring pangseguridad |
| [5. Mga setting ng institusyon at pagkakasunod-sunod ng unang pag-set up](05-institution-setup.md) | Pangalan ng institusyon, mga wika, time zone, ang pagkakasunod-sunod ng paglalagay ng sangguniang datos sa isang bagong unibersidad |
| [6. Mga code, bansa, wika](06-code-data.md) | Mga listahan ng code gaya ng etnisidad, uri ng admisyon, uri ng silid |
| [7. Mga yunit ng organisasyon at programa](07-org-units-and-programs.md) | Estruktura ng kolehiyo/departamento, mga panahon ng bisa, muling pagsasaayos, mga degree program |
| [8. Mga gusali at silid](08-facilities.md) | Mga gusali, silid, kapasidad |
| [9. Pag-import ng CSV](09-csv-import.md) | Format ng file, resulta ng pag-import at pag-aayos ng mga row na nabigo |
| [10. Mga taong akademiko, termino, takdang panahon ng termino](10-terms.md) | Katayuan ng termino, mga sesyon, mga takdang panahon ng termino gaya ng pagpapatala at ang kwalipikasyon nito, mga period ng klase |
| [11. Mga kategorya ng asignatura at iskala ng marka](11-course-categories-and-grade-scales.md) | Mga kategorya ng asignatura, mga marka at grade point |
| [12. Mga tao at rekord ng mag-aaral](12-people-and-student-records.md) | Mga tao, pagrehistro ng mag-aaral at student number, saklaw ng pagtingin, mga instruktor |
| [13. Mga pagbabago ng katayuan at tagapayo](13-status-changes-and-advisors.md) | Katayuan ng mag-aaral, mga kahilingan sa pagbabago at pag-apruba, direktang pagtatala, mga tagapayo |
| [14. Pagsasanib ng mga tao at imbitasyon sa account](14-merge-and-invitations.md) | Pagsasanib ng mga duplicate na tao, pag-imbita sa mga taong walang account |
| [15. Mga paraan ng pag-sign in](15-sign-in-methods.md) | Pag-sign in gamit ang student number, pag-lock ng account, school sign-in (SSO) |
| [16. Admisyon](16-admissions.md) | Mga account ng aplikante, mga siklo ng admisyon, pagsusuri at pagpapasya sa aplikasyon, paggawa ng rekord ng mag-aaral |
| [17. Mga asignatura at kinakailangan sa pagtatapos](17-courses-and-curriculum.md) | Mga bersiyon at rebisyon ng asignatura, mga requisite at katumbas na asignatura, mga kinakailangan sa pagtatapos ayon sa kategorya ng asignatura |
| [18. Mga seksiyon at talaorasan](18-sections-and-timetables.md) | Mga sesyon, oras ng klase at silid, mga instruktor, paglalaan ng upuan, syllabus, pagkopya ng termino |

| [20. Pagpapatala](20-registration.md) | Mga set ng panuntunan, limitasyon ng units, upuan at waitlist, hold at override sa panuntunan, pagsasaayos ng pagpapatala ng kawani, kasaysayan ng pagpapatala |
| [21. Mga marka](21-grades.md) | Pagpasok, pagsusumite at paggawang pinal ng marka, pag-apruba ng pagbabago ng marka, GPA at retake, pagsasara ng termino (academic probation, karangalan), Transcript of Records, patakaran sa pagmamarka |
| [22. Ebalwasyon ng asignatura](22-course-evaluation.md) | Anonimong tugon, mga form at tanong, mga setting at takdang panahon ng termino, paglalathala ng resulta at pinakamababang bilang ng tugon, paghihigpit sa pagtingin ng marka |
| [23. Mga sertipiko](23-certificates.md) | Mga uri at template bawat wika, numero ng sertipiko, pag-isyu at mga paghihigpit, talaan ng pag-isyu (muling pag-render, pagbawi), pahina ng beripikasyon, portal ng mag-aaral |
| [24. Mga pagsusulit](24-assessments.md) | Mga uri at larangan ng pagsusulit, pasya sa pagpasa, mga sesyon at pagpapatala, pagpasok ng resulta at CSV, paglalathala ng resulta, panlabas na resulta at ebidensiya, ugnayan sa mga kinakailangan sa pagtatapos |
| [25. Silid-aralan ng instruktor at pagdalo](25-classroom-and-attendance.md) | Mga roster at CSV, paggawa at pagkansela ng pagkikita ng klase, pagpasok at kabuuan ng pagdalo, PDF ng attendance sheet, pagtingin ng mag-aaral sa pagdalo |
| [26. Degree audit at pagtatapos](26-graduation.md) | Mga panuntunan ng kinakailangan, pag-save ng audit at batch audit, waiver ng kinakailangan, pagproseso ng pagtatapos at numero ng degree |
| [27. Mga ulat at reporting view](27-reports.md) | Mga karaniwang ulat at CSV, mga view ng reporting schema, access ng BI |
| [28. Integrasyon ng LMS](28-lms-integration.md) | Mga platform at driver, mga link ng asignatura at kasaysayan ng sync, agarang update at gabi-gabing reconciliation, mga draft na iskor mula sa LMS |

Makikita ang mga screen ng sangguniang datos (menu **Sangguniang datos**) kapag may pahintulot na `Tingnan ang sangguniang datos`; kailangan din ng bawat screen ang pahintulot sa pamamahala nito (halimbawa `Pamahalaan ang mga yunit ng organisasyon at muling pagsasaayos`) para makagawa o makapag-edit ng mga rekord.
