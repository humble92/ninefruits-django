# 6. Mga code, bansa, wika

Menu: **Sangguniang datos > Mga listahan ng code**, **Mga bansa**, **Mga wika** (pahintulot na `Pamahalaan ang mga code, bansa at wika`)

## Mga code

Maiikling listahang nagkakaiba-iba sa bawat unibersidad. May mga halaga ng code ang bawat listahan (uri).

| Code ng listahan | Layunin | Lumang sistema (YUSTIC) |
|---|---|---|
| `ethnicity` | Etnisidad | `FNATION` |
| `admission_type` | Uri ng admisyon | `FADMDIST` |
| `room_type` | Uri ng silid | `ROOM.FORWHAT` |

- Hinahanap ng application ayon sa code ang mga listahan ng sistema (ang tatlo sa itaas), kaya hindi maaaring palitan o burahin ang mga code ng listahan nila. Malayang makapagdadagdag ng mga halaga.
- Buksan ang isang listahan at magdagdag ng mga halaga sa **Mga code** sa ibaba. Gumagamit ang mga code ng maliliit na titik, digit at underscore (halimbawa `korean`). Ilagay ang pangalan sa bawat wika; kinakailangan ang pangalan sa Ingles.
- Huwag burahin ang mga halagang hindi na ginagamit; i-off na lang ang **Aktibo**. Hindi maaaring burahin ang halaga habang ginagamit pa ito ng datos.
- Maglagay ng maraming halaga gamit ang [pag-import ng CSV](09-csv-import.md).

## Mga bansa at wika

Inilo-load sa pag-install ang mga listahan ng pamantayang ISO (249 na bansa, mga 180 wika). Awtomatikong pinupunan ang mga pangalan para sa mga naka-install na wika.

- Para palitan ang pangalang ipinapakita sa screen, palitan ito sa **I-edit**. Nananatili ang binagong pangalan sa mga susunod na update ng sistema.
- Para itago ang isang entry sa mga listahang pinagpipilian, i-off ang **Aktibo**.
