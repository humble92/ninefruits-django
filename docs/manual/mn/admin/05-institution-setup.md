# 5. Байгууллагын тохиргоо ба анхны тохируулгын дараалал

## Байгууллагын тохиргоо

**Тохиргоо > Байгууллага** хэсэгт тохируулна (`Байгууллагын тохиргоог удирдах` эрх).

| Тохиргоо | Тайлбар |
|---|---|
| Байгууллагын нэр | Хэл тус бүрээр оруулна. Удирдлагын самбарын зүүн дээд буланд харагдана |
| Цагийн бүс | Улирлын огноо болон үйл ажиллагааны хугацааг тодорхойлох суурь, жишээ нь `Asia/Seoul`. Хадгалсан бүх цагийг энэ цагийн бүсээр харуулна |
| Санал болгох хэлүүд | Хэрэглэгчийн сонгож болох хэлүүд. Зөвхөн орчуулгын файл суулгасан хэлүүд жагсаалтад гарна |
| Үндсэн хэл | Хэл сонгоогүй хэрэглэгч болон хөтчийн хэл тодорхойгүй үед ашиглана |

## Шинэ их сургуулийн анхны тохируулгын дараалал

IT оператор `setup_install`-ийг дуусгасны дараа (үйл ажиллагааны гарын авлага, [Суулгах](../operations/installation.md)) бизнесийн админ доорх дарааллаар өгөгдөл оруулна. Дараагийн алхмууд өмнөх алхмын кодыг ашигладаг тул дарааллыг баримтална уу.

1. **Байгууллагын тохиргоо**: нэр, цагийн бүс, хэл (энэ бүлэг)
2. **Кодын мэдээлэл**: үндэс угсаа, элсэлтийн төрөл, танхимын төрлийн утгууд ([6-р бүлэг](06-code-data.md)). Суулгах үед Солонгосын их сургуулийн профайлыг хэрэглэсэн бол танхимын төрлүүд аль хэдийн бий.
3. **Бүтцийн нэгжийн төрлүүд**-ийг шалгаад **Бүтцийн нэгжүүд**: их сургууль → бүрэлдэхүүн сургууль → тэнхим ([7-р бүлэг](07-org-units-and-programs.md)). Нэгж олон бол CSV ашиглана ([9-р бүлэг](09-csv-import.md)).
4. **Хөтөлбөрүүд**: тэнхим тус бүрийн зэрэг олгох хөтөлбөр ([7-р бүлэг](07-org-units-and-programs.md))
5. **Байрууд**, **Танхимууд** ([8-р бүлэг](08-facilities.md), CSV боломжтой)
6. **Улирлын төрлүүд** болон **Парууд**-ыг шалгана ([10-р бүлэг](10-terms.md))
7. **Хичээлийн ангиллууд** болон **Дүнгийн шкалууд**-ыг шалгана. Нэг анхдагч шкалыг заавал тогтооно ([11-р бүлэг](11-course-categories-and-grade-scales.md))
8. **Хичээлийн жилүүд** → **Улирлууд** → улирал тус бүрийн **Үйл ажиллагааны хугацаанууд** ([10-р бүлэг](10-terms.md))
9. **Хэрэглэгч ба эрх**: тэнхимийн туслах ажилтан зэрэг бүтцийн нэгжийн хамрах хүрээ шаардах үүрэгт одоо тэнхимийг хамрах хүрээний объект болгон сонгож болно ([2-р бүлэг](02-users-and-roles.md))

Өгөгдөл оруулж дууссаны дараа IT оператороос `uv run manage.py term_inspect`-ээр үйл ажиллагааны хугацааг шалгуулахыг хүснэ үү.
