# 19. Хоёрдугаар мэргэжил ба дэд мэргэжил

Цэс: **Оюутан ба ажилтан > Хоёрдугаар мэргэжил, дэд мэргэжлийн өргөдөл**, мөн оюутны бүртгэлийн дэлгэрэнгүй дэх **Хоёрдугаар мэргэжил ба дэд мэргэжил** таб

Оюутнууд порталаас өргөдөл гаргаж, өргөдөл гаргасан хөтөлбөрийн ажилтнууд шийдвэрлэнэ. Батлагдсан тохиолдолд хоёрдугаар мэргэжил эсвэл дэд мэргэжил оюутны бүртгэлд нэмэгдэнэ. Оюутны бүртгэл (оюутны код) хэвээр үлдэнэ.

## Бэлтгэл

1. **Лавлах мэдээлэл > Хөтөлбөрүүд**-д хүлээн авдаг хөтөлбөрүүдэд **Хоёрдугаар мэргэжил хүлээн авна** болон **Дэд мэргэжил хүлээн авна**-г идэвхжүүлнэ.
2. **Тохиргоо > Оюутны бүртгэл**-д оюутан нэгэн зэрэг хэдэн хоёрдугаар мэргэжил, дэд мэргэжилтэй байж болохыг тохируулна (анхдагч нь тус бүр 1).
3. Өргөдөл хүлээн авах улирлын **үйл ажиллагааны хугацаа**-нуудын дунд **Хоёрдугаар мэргэжил, дэд мэргэжлийн өргөдөл** хугацааг үүсгэнэ. Хамрах шалгуураар тодорхой курсүүдээр хязгаарлаж болно (жишээ нь 2, 3-р курс). Батлагдсан хөтөлбөрийг тухайн улирлын эхний өдрөөс эхлэн судална.
4. Хөтөлбөрийн хоёрдугаар мэргэжил болон дэд мэргэжлийн шаардлагыг **Сургалтын төлөвлөгөө ба бүлэг > Төгсөлтийн шаардлага**-д үүсгэнэ ([17-р бүлэг](17-courses-and-curriculum.md)).

## Оюутны өргөдөл

Өргөдлийн хугацаанд оюутан порталын **Миний бүртгэл** хэсэгт төрөл (хоёрдугаар мэргэжил, дэд мэргэжил), хөтөлбөр болон шалтгааныг оруулж өргөдөл гаргана. Өргөдлийг шийдвэрлэгдэх хүртэл цуцалж болно.

- Зөвхөн суралцаж буй эсвэл чөлөөтэй оюутны бүртгэл өргөдөл гаргаж болно.
- Оюутан өөрийн үндсэн хөтөлбөр эсвэл аль хэдийн судалж буй хөтөлбөртөө өргөдөл гаргах боломжгүй.
- Судалж буй хөтөлбөрийн тоо дээр хүлээгдэж буй өргөдлийн тоог нэмсэн нь хязгаараас хэтэрч болохгүй.
- Нэг хөтөлбөрт зөвхөн нэг хүлээгдэж буй өргөдөл байна.

## Батлах

**Хоёрдугаар мэргэжил, дэд мэргэжлийн өргөдөл** жагсаалтад (анхдагч: хүлээгдэж буй) **Батлах** эсвэл **Татгалзах**-ыг дарна (тайлбар заавал).

- `Хоёрдугаар мэргэжил, дэд мэргэжлийн өргөдлийг шийдвэрлэх` эрхийн хамрах хүрээнд өргөдөл гаргасан хөтөлбөр (эсвэл түүний бүтцийн нэгж) багтсан байх ёстой. Жишээ: Солонгос хэл, уран зохиолын тэнхимийн хамрах хүрээтэйгээр томилогдсон тэнхимийн туслах ажилтан зөвхөн тухайн тэнхимийн өргөдлийг шийдвэрлэнэ.
- Шийдвэрлэж буй ажилтан өргөдөл гаргагчийн оюутны бүртгэлийг харж болно. Оюутны үндсэн тэнхимийн ажилтнууд өөрийн оюутнуудын өргөдлийг харах боловч шийдвэрлэх боломжгүй.
- Хэн ч өөрийн гаргасан өргөдлийг шийдвэрлэх боломжгүй.
- Батлагдсаны дараа тухайн хөтөлбөрийн бүтцийн нэгжийн ажилтнууд (оюутны бүртгэл харах хамрах хүрээ) энэ оюутны бүртгэлийг харж болно. Бүлгийн хамрагдах нөхцөл ч оюутныг тухайн хөтөлбөрийн оюутанд тооцно.

## Дуусгах

Оюутны бүртгэлийн дэлгэрэнгүй дэх **Хоёрдугаар мэргэжил ба дэд мэргэжил** табд **Дуусгах**-ыг дарж дуусах огноо болон шалтгааныг оруулна. Үүнийг сургалтын алба (оюутны бүртгэлийн хамрах хүрээ) эсвэл тухайн хөтөлбөрийн шийдвэрлэх ажилтан хийж болно. Дуусгасан хөтөлбөрт хожим дахин өргөдөл гаргаж болно.
