# 4. Аудит

**Аудит** цэсийн гурван дэлгэц зөвхөн унших зориулалттай; хэн ч засах, устгах боломжгүй (`Аудитын бүртгэл харах` болон `Аюулгүй байдлын үйл явдал харах` эрх шаардлагатай). Жагсаалтуудад нэмэх, засах, устгах товч байхгүй; мөрийг нээвэл дэлгэрэнгүйг зөвхөн унших горимоор харуулна.

| Дэлгэц | Юуг харуулах | Жишээ |
|---|---|---|
| Үйлдлийн бүртгэл | Хэн юу хийсэн, **яагаад**. Шалтгаан ба дэлгэрэнгүй | Үүргийн оноолт (шалтгаан: улирлын турш орлон гүйцэтгэх), эрхийн өөрчлөлт (нэмсэн/хассан жагсаалт), тохиргооны өөрчлөлт (өмнө/дараа), команд ажиллуулсан |
| Өгөгдлийн өөрчлөлт | Хүснэгтийн мөрийн өмнөх ба дараах утга. Программыг тойрч хийсэн шууд өөрчлөлтийг ч бүртгэнэ | `users` UPDATE, өөрчлөгдсөн багана `locale` |
| Аюулгүй байдлын үйл явдал | Нэвтрэлт, амжилтгүй нэвтрэлт, хоёр шатлалт баталгаажуулалт, эрхтэй холбоотой үйл явдал, нууц үг ба и-мэйлийн өөрчлөлт, аудитыг цэвэрлэх (`audit_prune`) | Нэвтрэлт амжилтгүй (нэвтрэх нэр, IP) |

## Хэрхэн унших

- **Хэрэглэгч** багана: дэлгэц дээр хийсэн үйлдэлд хэрэглэгчийн нэр эсвэл `user:дугаар`, автомат ажилд (Celery) `system:task:...`, командад `system:command:...` харагдана.
- Нууц үг, хоёр шатлалт баталгаажуулалтын нууц түлхүүр зэрэг утгыг `[redacted]` гэж далдална.
- Ижил **Хүсэлтийн ID**-тай бичлэгүүд нэг дэлгэцийн хүсэлтээр үүссэн. Ижил хүсэлтийн ID-г дэлгэц бүрээс хайвал нэг үйлдлийн бүрэн мөрийг харна. Командын ажиллагаа `cmd-`-ээр эхэлсэн ажиллагааны ID ашиглана.

Жагсаалтын баруун дээд хэсэгт байх **Шүүлтүүрүүд**-ээс нөхцөл сонгож, хайлтын талбарт утга бичнэ.

## Түгээмэл хайлт

| Мэдэхийг хүссэн зүйл | Арга |
|---|---|
| Хэрэглэгчийн эрх хэзээ өөрчлөгдсөн | Үйлдлийн бүртгэлд бүртгэл `security`, үйл явдал `role.assigned`, `role.assignment_revoked` |
| Олон удаа амжилтгүй нэвтэрсэн бүртгэл | Аюулгүй байдлын үйл явдалд `Нэвтрэлт амжилтгүй` үйл явдлаар шүүж, нэвтрэх нэрийн баганыг харна |
| Аюулгүй байдлын бодлогыг хэн өөрчилсөн | Үйлдлийн бүртгэлийн `settings.updated` үйл явдал |
| Тодорхой мөр хэрхэн өөрчлөгдсөн | Өгөгдлийн өөрчлөлтөд хүснэгтээр шүүж, бичлэгийн ID-аар хайна |
