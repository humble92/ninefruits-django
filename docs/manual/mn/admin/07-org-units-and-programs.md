# 7. Бүтцийн нэгж ба хөтөлбөр

Цэс: **Лавлах мэдээлэл > Бүтцийн нэгжийн төрлүүд**, **Бүтцийн нэгжүүд**, **Хөтөлбөрүүд**

## Бүтцийн нэгж

Их сургууль, бүрэлдэхүүн сургууль, тэнхим, мэргэжил, захиргааны албыг нэг дэлгэцээр удирдана. Эдгээр нь хуучин системийн (YUSTIC) бүрэлдэхүүн сургууль (`SFCOLLEGE`) болон тэнхимийг (`SFDEPARTMENT`) орлоно.

| Талбар | Тайлбар |
|---|---|
| Код | Байнгын таних код, жишээ нь `CSE` |
| Төрөл | Их сургууль, бүрэлдэхүүн сургууль, тэнхим гэх мэт (Бүтцийн нэгжийн төрлүүд дэлгэцэд нэмж болно) |
| Нэр, Товч нэр | Хэл тус бүрээр |
| Дээд нэгж | Энэ нэгжийн харьяалагдах нэгж. Нэгжийг өөрийнхөө доор эсвэл өөрийн доод нэгжийн доор шилжүүлэх боломжгүй |
| Хүчинтэй эхлэх, Хүчинтэй дуусах | Нэгж оршин байсан хугацаа. Дуусах огноо хоосон бол одоо үйл ажиллагаа явуулж байна |

- Жагсаалт анхдагчаар **Зөвхөн одоо хүчинтэй**-г харуулна. Өмнөх нэгжүүдийг ч харах бол шүүлтүүрийг унтраана.
- Бүтцийн нэгжийг үүргийн оноолтын хамрах хүрээ болгон сонговол түүний доорх бүх нэгж хамаарна. Жишээ: Инженерийн сургуулийн хүрээ = Инженерийн сургуулийн бүх тэнхим.

## Бүтцийн өөрчлөлт

Өмнөх оюутны бүртгэл болон дүн тухайн үеийн нэгжийг заах ёстой тул нэгжийг шууд засахгүй, харин өөрчлөлтийг **бүтцийн өөрчлөлт** болгон бүртгэнэ.

1. Алга болох (эсвэл өөрчлөгдөх) нэгжийн **Засах** хуудсыг нээнэ.
2. **Бүтэц өөрчлөх**-ийг дарна.
3. Өөрчлөлтийн төрлийг сонгоно.
   - **Нэр өөрчилсөн**: эхлээд шинэ нэртэй нэгжийг үүсгээд залгамжлагчаар тогтооно
   - **Нэгтгэсэн**: хэд хэдэн нэгж нэг болж нийлэх үед нэгж бүрээс ижил залгамжлагчийг тогтооно
   - **Салгасан**: нэг нэгжийг хэд хэдэн болгон хуваах үед хэд хэдэн залгамжлагч тогтооно
   - **Харьяалал өөрчилсөн**: нэгж шинэ нэгж болж өөр дээд нэгжийн доор шилжих үед
4. **Хүчинтэй огноо** болон шалтгааныг оруулна. Нэгж хүчинтэй огнооны өмнөх өдөр дуусч, бичлэг доорх **Залгамжлагчид** жагсаалтад харагдана.

Энгийн үсгийн алдааг бүтцийн өөрчлөлтөөр биш, нэрийг **засах**-аар засна (өгөгдлийн өөрчлөлт бүртгэгдэнэ).

## Хөтөлбөр

Зэрэг олгох хөтөлбөр эсвэл мэргэжлийн хөтөлбөр. Оюутны бүртгэл хөтөлбөрт харьяалагдана ([12-р бүлэг](12-people-and-student-records.md)).

| Талбар | Тайлбар |
|---|---|
| Код, Нэр, Зэргийн нэр | Зэргийн нэрийн жишээ: Инженерийн бакалавр |
| Боловсролын зэрэг | Дипломын, Бакалавр, Магистр, Доктор, Сертификат, Зэрэггүй |
| Бүтцийн нэгж | Хөтөлбөрийг хэрэгжүүлэх тэнхим |
| Суралцах хугацаа | Стандарт суралцах хугацаа (жил) |
| Хүчинтэй эхлэх, Хүчинтэй дуусах | Хөтөлбөр оршин байх хугацаа, шинэ оюутан элсүүлэх хугацаа биш |
| Хоёрдугаар мэргэжил хүлээн авна, Дэд мэргэжил хүлээн авна | Бусад хөтөлбөрийн оюутан энэ хөтөлбөрийг хоёрдугаар мэргэжил эсвэл дэд мэргэжлээр сонгох өргөдөл гаргаж болох эсэх ([19-р бүлэг](19-second-majors-and-minors.md)) |
