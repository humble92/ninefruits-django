# 8. Байр ба танхим

Цэс: **Лавлах мэдээлэл > Байрууд**, **Танхимууд** (`Байр, танхим удирдах` эрх)

## Байр

Код (жишээ нь `SCI`), нэр (хэл тус бүрээр) болон хаягийг оруулна. Танхимтай байрыг устгах боломжгүй тул ашиглахаа больсон үед **Идэвхтэй**-г унтраана.

## Танхим

| Талбар | Тайлбар |
|---|---|
| Байр, Танхимын дугаар | Танхимын дугаар нэг байр дотор давхцахгүй, жишээ нь `101` |
| Нэр | Сонголтоор, жишээ нь Их танхим |
| Танхимын төрөл | `room_type` кодын жагсаалтын утга (лекцийн танхим, лаборатори гэх мэт) |
| Бүтцийн нэгж | Танхимыг хариуцах тэнхим (сонголтоор) |
| Суудлын тоо | Хичээлийн хуваарь гаргахад бүлгийн суудлын тоотой харьцуулна ([18-р бүлэг](18-sections-and-timetables.md)) |
| Хуваарьт ашиглах | Унтраасан үед хичээлийн хуваарь гаргахад танхимыг оруулахгүй (оффис, агуулах гэх мэт) |

Танхим олон бол [CSV оруулах](09-csv-import.md)-ыг ашиглана. Байрыг эхэлж бүртгэсэн байх ёстой.
