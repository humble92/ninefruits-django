# 6. Кодын мэдээлэл, улс, хэл

Цэс: **Лавлах мэдээлэл > Кодын жагсаалтууд**, **Улсууд**, **Хэлүүд** (`Кодын мэдээлэл, улс, хэлийг удирдах` эрх)

## Кодын мэдээлэл

Их сургууль бүрт ялгаатай богино жагсаалтууд. Жагсаалт (төрөл) бүр кодын утгуудтай.

| Жагсаалтын код | Зориулалт | Хуучин систем (YUSTIC) |
|---|---|---|
| `ethnicity` | Үндэс угсаа | `FNATION` |
| `admission_type` | Элсэлтийн төрөл | `FADMDIST` |
| `room_type` | Танхимын төрөл | `ROOM.FORWHAT` |

- Системийн жагсаалтуудыг (дээрх гурав) программ кодоор нь хайдаг тул жагсаалтын кодыг өөрчлөх, устгах боломжгүй. Утгыг чөлөөтэй нэмж болно.
- Жагсаалтыг нээгээд доорх **Кодууд** хэсэгт утга нэмнэ. Код нь жижиг латин үсэг, тоо, доогуур зураас ашиглана (жишээ нь `korean`). Нэрийг хэл тус бүрээр оруулна; англи нэр заавал шаардлагатай.
- Ашиглахаа больсон утгыг устгалгүй **Идэвхтэй**-г унтраана. Өгөгдөл ашиглаж байгаа утгыг устгах боломжгүй.
- Олон утгыг [CSV оруулах](09-csv-import.md)-аар оруулна.

## Улс ба хэл

ISO стандартын жагсаалтууд (249 улс, 180 орчим хэл) суулгах үед ачаалагдана. Суулгасан хэлүүд дээрх нэрс автоматаар бөглөгдөнө.

- Дэлгэцэд харагдах нэрийг өөрчлөх бол **Засах** хэсэгт өөрчилнө. Өөрчилсөн нэр дараагийн системийн шинэчлэлтүүдэд хадгалагдана.
- Сонголтын жагсаалтаас нуух бол **Идэвхтэй**-г унтраана.
