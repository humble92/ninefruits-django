# 15. Нэвтрэх аргууд

Цэс: **Тохиргоо > Нэвтрэх аргууд** (`Нэвтрэх арга, SSO-г удирдах` эрх)

## Нэвтрэх нэр

Бүртгэлийн и-мэйл нь үндсэн нэвтрэх нэр болно. Оюутны кодоор нэвтрэхийг идэвхжүүлбэл нэвтрэх дэлгэц дээрх талбар "И-мэйл эсвэл оюутны код" болж өөрчлөгдөнө.

| Оюутны кодоор нэвтрэх | Ажиллах байдал |
|---|---|
| Зөвшөөрөхгүй | Зөвхөн и-мэйлээр |
| Зөвхөн одоо суралцаж буй оюутан | Суралцаж буй болон чөлөөтэй бүртгэлийн оюутны кодоор нэвтэрч болно |
| Одоо суралцаж буй оюутан ба төгсөгч | Дууссан бүртгэлийн (төгссөн, сургуулиас гарсан гэх мэт) оюутны кодоор ч нэвтэрч болно |

Хэд хэдэн оюутны бүртгэлтэй хүн аль ч оюутны кодоо ашигласан ижил бүртгэлд нэвтэрнэ.

## Бүртгэл түгжих

| Тохиргоо | Тайлбар |
|---|---|
| Амжилтгүй оролдлогын дараа түгжих | Буруу нууц үгийг энэ тоогоор дараалан оруулбал бүртгэл түгжигдэнэ. 0 бол түгжихгүй |
| Түгжих хугацаа (минут) | Энэ хугацаа өнгөрмөгц түгжээ автоматаар тайлагдана |

И-мэйлээр болон оюутны кодоор хийсэн оролдлогууд нэг бүртгэлийн амжилтгүй оролдлогод тооцогдоно. Түгжигдсэн бүртгэлд буруу нууц үгийн үеийнхтэй ижил мэдэгдэл харагдах тул бүртгэл байгаа эсэх нь илчлэгдэхгүй. Түгжилт аюулгүй байдлын үйл явдал (**Нэвтрэлт түгжигдсэн**) болж бүртгэгдэнэ.

Түгжээг хугацаанаас нь өмнө тайлахын тулд **Хэрэглэгчид**-ийн дэлгэрэнгүй хуудас дээрх **Нэвтрэлтийн түгжээг тайлах**-ыг ашиглана (шалтгаан заавал, `Хэрэглэгч засах` эрх). Удирдлагын самбарыг ашиглах боломжгүй үед IT ажилтан `uv run manage.py security_unlock_user`-ийг ашиглана.

## Сургуулийн нэвтрэлт (SSO)

Сургуулийн OpenID Connect нэвтрэлтийг (жишээ нь Microsoft Entra ID, Google Workspace, Keycloak) бүртгэвэл нэвтрэх дэлгэц дээр "... -ээр нэвтрэх" товч нэмэгдэнэ.

| Талбар | Тайлбар |
|---|---|
| Түлхүүр | Жижиг үсгээр бичсэн танигч, жишээ нь `school`. Өөрчилбөл одоо байгаа холболтууд тасарна |
| Товчны бичвэр | Нэвтрэх дэлгэц дээр харагдах нэр |
| Issuer URL | Үйлчилгээ үзүүлэгчийн issuer. Энэ хаягийн доор `/.well-known/openid-configuration` хандах боломжтой байх ёстой |
| Client ID, Client secret | Үйлчилгээ үзүүлэгч дээр аппликейшн бүртгэхэд олгогдсон утгууд. Secret-ийг шифрлэн хадгална |
| Scope-ууд | Анхдагч утга `openid email profile` |
| Хоёр шатлалт баталгаажуулалтад тооцох | Сургуулийн нэвтрэлт өөрөө хоёр шатлалт баталгаажуулалт шаарддаг үед л идэвхжүүлнэ. Идэвхтэй бол энэ нэвтрэлтэд энд дахин хоёр шатлалт баталгаажуулалт асуухгүй |
| Үйлчилгээ үзүүлэгчид бүртгүүлэх Redirect URI | Дэлгэц дээр харагдах хаягийг (`https://<server>/auth/sso/<key>/callback/`) үйлчилгээ үзүүлэгчийн аппликейшний тохиргоонд яг хэвээр нь бүртгэнэ |

### Бүртгэл холбох

| Горим | Ажиллах байдал |
|---|---|
| Хэрэглэгч бүртгэлээ өөрөө холбоно | Хэрэглэгч нууц үгээрээ нэвтэрч, порталын **Аюулгүй байдал > Сургуулийн нэвтрэлт** хэсэгт **Холбох**-ыг дарна (нууц үг дахин баталгаажуулна) |
| Баталгаажсан сургуулийн и-мэйлээр автоматаар холбох | Үйлчилгээ үзүүлэгчийн баталгаажуулсан и-мэйл оюутны бүртгэл дээрх сургуулийн и-мэйлтэй таарвал анхны нэвтрэлтийн үед бүртгэл автоматаар холбогдоно |

- Холбогдоогүй сургуулийн бүртгэлээр нэвтрэхэд нууц үгээр нэвтэрч холбохыг зөвлөсөн мэдэгдэл харагдана. Зөвхөн сургуулийн бүртгэлээр шинэ бүртгэл хэзээ ч үүсэхгүй.
- Холбох, салгах үйлдэл аюулгүй байдлын бүртгэлд тэмдэглэгдэнэ.

### Нууц үгээр нэвтрэхийг зөвшөөрөх

**Сургуулийн нэвтрэлттэй хэрэглэгчид нууц үг ашиглахыг зөвшөөрөх**-ийг унтраавал холбогдсон хэрэглэгчид зөвхөн сургуулийн нэвтрэлтийг ашиглана. Сургуулийн бүртгэл төгссөний дараа устах нь элбэг тул үүнийг идэвхтэй хэвээр үлдээж, төгсөх гэж буй оюутнуудад хувийн и-мэйл, нууц үгээ бэлдэхийг зөвлөхийг санал болгож байна. Төгсөгчид бүртгэлийн нэвтрэх и-мэйл (хувийн и-мэйл) болон нууц үгээрээ үргэлжлүүлэн нэвтэрнэ.
