# 28. LMS холболт

Цэс: удирдлагын самбарын **LMS холболт > LMS платформууд**, **Хичээлийн холбоосууд**, **Синхрончлолын бүртгэлүүд** (`LMS платформ, холбоос, синхрончлолыг удирдах` эрх; анхдагч: Системийн админ, Сургалтын албаны ажилтан). Багш нар порталын **Миний заах хичээл** болон бүлгийн дэлгэрэнгүй дэх LMS холбоос, дүн оруулах дэлгэц дээрх **LMS-ээс оноо татах**-ыг ашиглана. Татах нь дүн оруулахтай ижил нөхцөлийг дагана (томилогдсон багш, дүн оруулах хугацаанд).

Хөгжүүлэгчийн дэлгэрэнгүй мэдээлэл (холбогч бичих, API) [LMS холболтын гарын авлага](../../../lms-integration-guide.md)-д байна.

## Юу хаашаа явах вэ

| SIS → LMS | Хэзээ |
|---|---|
| Бүлэг (хичээл үүсгэх) + багш нар | Бүлэг **нийтлэгдэх** үед болон `lms_sync`-ээр |
| Баталгаажсан хичээлийн бүртгэл → элсүүлэх | Хичээл бүртгэх, хүлээлгийн жагсаалтаас дэвших эсвэл ажилтны бүртгэлийн үед шууд |
| Хасалт эсвэл цуцлалт → элсэлтийг цуцлах | Шууд |
| Бүрэн тулгалт | Өдөр бүр 02:30-д (`lms_reconcile`, төлөвлөгдсөн ажил `lms.reconcile`) |

| LMS → SIS | Хэзээ |
|---|---|
| Эцсийн оноо (ноорог) | Багш дүн оруулах дэлгэц дээр **LMS-ээс оноо татах**-ыг дарах үед. Хадгалах болон илгээхийг багш хийнэ |

Баталгаажсан дүнг LMS рүү илгээхгүй. Хичээлийн материал, даалгавар, сорил LMS-д байна.

## Платформууд

**LMS платформууд**: код, нэр (хэл тус бүрээр), драйвер, үндсэн URL, нэвтрэх түлхүүр, идэвхтэй, нэрсийн жагсаалтыг синхрончлох, эцсийн оноог татах.

- **Байхгүй (зөвхөн бүртгэнэ)** драйвер: юу ч дуудахгүй бөгөөд илгээх байсан зүйлийг бүртгэнэ. Холбохоос өмнө урсгалыг шалгах эсвэл үзүүлэнд ашиглана. Демо өгөгдлийн `DEMO` платформ үүнийг ашигладаг.
- `Moodle`, `Open edX`: холбогч хараахан байхгүй ("хараахан хэрэгжээгүй" гэж тэмдэглэсэн). Сонговол синхрончлолууд амжилтгүй гэж бүртгэгдэнэ.
- **Идэвхтэй**-г асаавал түүнээс хойш бүлгийн нийтлэл болон хичээлийн бүртгэлийн өөрчлөлтүүд шууд дамжиж, платформ шөнийн тулгалтад орно.
- **Нэвтрэх түлхүүр**-ийг мөр бүрт нэг `key=value` хэлбэрээр бичнэ (жишээ нь `token=...`). Шифрлэн хадгалах бөгөөд хэзээ ч буцааж харуулахгүй. Засахдаа талбарыг хоосон үлдээвэл хадгалсан утгууд хэвээр үлдэнэ. Өгөгдлийн өөрчлөлтийн түүх ч утгуудыг хадгалахгүй.

## Хичээлийн холбоос ба синхрончлолын бүртгэл

- **Хичээлийн холбоосууд**: аль бүлэг аль платформын хичээлтэй (id, URL) холбогдсон, төлөв (Хүлээгдэж буй/Холбогдсон/Амжилтгүй), сүүлийн синхрончлол болон алдаа. Платформ, төлөв, улирлаар шүүж, хичээлийн индексээр хайна. Мөрийн үйлдэл **Дахин синхрончлох** (баталгаажуулах хуудастай) нь бүлэг, багш нар болон нэрсийн жагсаалтыг дахин илгээнэ.
- **Синхрончлолын бүртгэлүүд**: алхам тус бүрийн үр дүн ба мэдэгдэл (хичээл, гишүүн нэмэх ба хасах, оноо татах, илгээсэн оноо, тулгалт). Алдааны шалтгааныг эндээс хайна. Мөрийг нээвэл эхэлсэн ба дууссан цаг болон агуулгыг харуулна.
- Командууд: `uv run manage.py lms_sync {platform} --term={term}` (бүрэн илгээлт, `--dry-run`), `uv run manage.py lms_reconcile` (тулгалт). [Үйл ажиллагааны командууд](../operations/commands.md#lms-холболт-12-р-үе-шат)-ыг үзнэ үү.

## Портал

- Платформын хичээлийн холбоос оюутан болон багшийн хичээлийн дэлгэрэнгүйд, мөн багшийн **Миний заах хичээл** жагсаалтад (**LMS** багана; зөвхөн холбогдсон бүлгүүд) харагдана.
- Дүн оруулах: платформд **Эцсийн оноог татах** идэвхтэй бөгөөд бүлэг холбогдсон бол **LMS-ээс оноо татах** товч гарч ирнэ. Энэ нь зөвхөн онооны баганыг бөглөх бөгөөд хадгалахгүй.

## Холболтын API

Үр дүнгээ хожим мэдээлдэг эсвэл оноогоо өөрсдөө илгээдэг платформуудад API (`/api/v1/lms/platforms/...`) үйлчилнэ. Зөвхөн `LMS платформ, холбоос, синхрончлолыг удирдах` эрхтэй тусдаа холболтын бүртгэл үүсгэнэ; оператор түүний токенийг `uv run manage.py api_issue_token {email} --days=365`-аар олгож, платформын админд хүлээлгэн өгнө. Токеныг зөвхөн олгох үед нэг удаа харуулна. `api_revoke_tokens` түүнийг хүчингүй болгоно. Олгох болон хүчингүй болгохыг аудитын бүртгэлд тэмдэглэнэ.

- Оноо илгээх (`.../scores/`)-ээр хүлээн авсан оноог ч хадгалахгүй. Багш **LMS-ээс оноо татах**-ыг дарахад хамгийн сүүлд хүлээн авсан оноо маягтыг ноорог болгон бөглөнө.
- Синхрончлолын үр дүнг (`.../sync-results/`) **Синхрончлолын бүртгэлүүд**-д хадгалах бөгөөд хичээлийн үр дүн **Хичээлийн холбоосууд** дахь төлөвийг өөрчилнө.

## Түгээмэл асуултууд

- **LMS-д оюутан дутуу байна.** Синхрончлогдохын тулд оюутан бүртгэлтэй (хэрэглэгч) байх шаардлагатай. Бүртгэлгүй бол урилга илгээнэ ([14-р бүлэг](14-merge-and-invitations.md)); дараагийн тулгалт түүнийг нэмнэ.
- **Синхрончлол амжилтгүй хэвээр байна.** Синхрончлолын бүртгэл дэх мэдэгдлийг уншина. Нэвтрэх мэдээллийн хугацаа дууссан байх нь элбэг. Платформын засах дэлгэцэд утгуудыг өөрчлөөд **Дахин синхрончлох**.
- **Платформ сольсон.** Шинэ платформ үүсгэж, хуучных нь Идэвхтэй-г унтраана. Холбоосууд платформ тус бүрээр тусад нь үүснэ.

## Энэ суулгалтын дэлгэцүүд

Дэлгэц болон функцүүд нь анхны системийнх (Filament, Livewire) бөгөөд зарим харилцан үйлдэл ялгаатай.

- Нэвтрэх түлхүүрийг анхны системийн түлхүүр/утгын хүснэгтийн оронд текст талбарт `key=value` мөрүүдээр оруулна. Буруу хэлбэртэй мөрийг мөрийн дугаарын хамт татгалзана.
- Платформын **тохиргоо** (платформ тус бүрийн үүргийн id гэх мэт) дэлгэц дээр талбаргүй. Холбогчид шаардлагатай үед хөгжүүлэгчид тохируулна ([холболтын гарын авлага](../../../lms-integration-guide.md)-ын 3-р хэсэг).
- **Дахин синхрончлох** нь баталгаажуулах хуудсаар дамжина. Холбогчийн алдаа (холбогчгүй драйвер, платформын тасалдал) "Синхрончлол амжилтгүй: ..." мессежээр харагдаж, хичээлийн холбоос Амжилтгүй болно (анхны систем алдааны хуудас харуулдаг байсан).
- Синхрончлолын бүртгэлүүд зөвхөн унших горимтой. Мөрийг нээвэл агуулгыг JSON хэлбэрээр харуулна.
- Дүн оруулах дэлгэц дээрх **LMS-ээс оноо татах** нь хүснэгтийн доорх товчны мөрөнд байна. Аль хэдийн бичсэн зүйлийг хадгалж, зөвхөн онооны талбаруудыг өөрчилсөн хуудсыг дахин харуулна. **Ноорог хадгалах** хүртэл юу ч хадгалахгүй.
- Холболтын API болон токены командууд (`api_issue_token`, `api_revoke_tokens`) нь энэ суулгалтад шинээр нэмэгдсэн (анхны системд API байгаагүй).
