# 17. Хичээл ба төгсөлтийн шаардлага

Цэс: **Сургалтын төлөвлөгөө ба бүлэг > Хичээлүүд**, **Төгсөлтийн шаардлага** (эрх `Хичээл, хувилбар, холбоо хичээлийг удирдах`, `Төгсөлтийн шаардлагыг удирдах`)

## Хичээл ба хувилбар

Хичээл нь өөрчлөгддөггүй **код** болон хүчинтэй хугацаатай **хувилбарууд**-аас бүрдэнэ. Нэр, кредит, цаг, хичээлийн ангилал, үнэлгээний хэлбэр, холбоо хичээлүүд нь хувилбарт хамаарна. Хуучин систем (YUSTIC) хичээлийг хичээлийн индекс болон эхлэх огноогоор ялгадаг байсан боловч дүн нь зөвхөн хичээлийн индекс рүү заадаг байсан тул оюутан аль хувилбарыг судалсан нь тодорхойгүй байв. Шинэ системд бүлэг болон дүн нь хувилбар руу заана.

- Нэг хичээлийн хувилбаруудын хугацаа давхцах боломжгүй (өгөгдлийн сангийн хязгаарлалт). Аль ч огноонд яг нэг хувилбар хүчинтэй байна.
- Бүлгийг хичээллэх хугацааны эхлэх огноонд хүчинтэй байгаа хувилбараар нээнэ.

| Талбар | Тайлбар |
|---|---|
| Хичээлийн индекс | жишээ нь `CSE2010`. Код нь ямар нэг ажлын утга агуулахгүй (хуучин `009*` кредит банкны шалгалт гэх мэт дүрмүүдийг доорх талбарууд орлоно) |
| Хариуцах нэгж | Хичээлийг хариуцдаг бүтцийн нэгж. Хичээлийн бүлгүүдийг нээх анхдагч нэгж |
| Гарчиг, Тайлбар | Хэл тус бүрээр |
| Кредит, лекц ба лабораторийн цаг | 0.5-ын алхмаар |
| Хичээлийн ангилал | Лавлах мэдээлэл > Хичээлийн ангилал |
| Үнэлгээ | Үсгэн дүн эсвэл Тэнцсэн/тэнцээгүй |
| Кредитийн хязгаарт тооцох | Унтраалттай бол хичээл сонголтын кредитийн хязгаарт тооцогдохгүй (кредит банкны хичээл гэх мэт) |
| Хичээлийн үнэлгээ | Унтраалттай бол хичээлийг үнэлэхгүй (практик хичээл, үйлдвэрлэлийн дадлага гэх мэт; [22-р бүлэг](22-course-evaluation.md)) |
| Дахин судлаж кредит авч болно | Дахин судлахад давтан судлах биш, дахин кредит авна (сэдэв нь өөрчлөгддөг семинар гэх мэт) |

## Хичээлийг шинэчлэх

Кредит эсвэл нэр өөрчлөгдөхөд хувилбарыг засахгүй, харин **шинэчилнэ**. Хичээлийн **Засах** дэлгэцийн **Хувилбарууд** табаас одоогийн хувилбар дээр **Тодорхой огнооноос шинэчлэх**-ийг дарж, шинэ хувилбарын эхлэх огноо, өөрчлөгдсөн утгууд болон шалтгааныг оруулна.

- Одоогийн хувилбар эхлэх огнооны өмнөх өдөр дуусна; шинэ хувилбар одоогийн хувилбар болон түүний холбоо хичээлүүдийн хуулбараар эхэлнэ.
- Аль хэдийн нээгдсэн бүлгүүд болон өнгөрсөн дүнгүүд өмнөх хувилбар руу заасан хэвээр байна.
- Хувилбарыг шууд засах нь зөвхөн бичгийн алдаа гэх мэт утгыг нь өөрчлөхгүй засварт зориулагдсан (өгөгдлийн өөрчлөлтийн бүртгэлд харагдана).

## Өмнөх холбоо хичээл ба зэрэг судлах хичээл

Хувилбарыг **Хувилбарууд** табаас (мөрийн холбоос) нээнэ; хувилбарын дэлгэцийн доод хэсгийн **Холбоо хичээлүүд**-д оруулна. Шинэ хувилбарыг хичээлийн дэлгэц дээрх **Хичээлийн хувилбар нэмэх**-ээр нэмнэ.

| Талбар | Тайлбар |
|---|---|
| Төрөл | Өмнөх холбоо хичээл (урьдчилан дүүргэсэн байх ёстой) эсвэл Зэрэг судлах хичээл (нэг улиралд хамт судална; аль хэдийн дүүргэсэн бол хангагдсанд тооцно) |
| Бүлэг | Нэг бүлэг доторх хичээлүүдээс зөвхөн нэгийг дүүргэхэд хангалттай (эсвэл). Бүх бүлэг хангагдсан байх ёстой (ба) |
| Доод дүн | Анхдагч дүнгийн шкалын дүнгийн код (жишээ нь `C0`). Хоосон: тэнцэх дүн |
| Нэг улиралд зэрэг судалж болно | Өмнөх холбоо хичээлийг нэг улиралд зэрэг судалж болох үед |

Жишээ: 1-р бүлэгт `CSE1001`, 2-р бүлэгт `MAT1001` болон `MAT1002` байвал → `CSE1001` ба (`MAT1001` эсвэл `MAT1002`). Өмнөх холбоо хичээлийн дүрэм үүнийг хичээл сонголтын үед шалгана ([20-р бүлэг](20-registration.md)).

## Дүйцэх хичээл

Сургалтын төлөвлөгөөний шинэчлэлээр хичээл солигдоход орлох хичээлийг хугацааных нь хамт хичээлийн **Засах** дэлгэцийн **Дүйцэх хичээлүүд** табд оруулна. **Харилцан** идэвхтэй бол хичээл бүр нөгөөгийнхөө оронд тооцогдоно; унтраалттай бол зөвхөн дүйцэх хичээл энэ хичээлийн оронд тооцогдоно. Давтан судлах шалгалт ([20-р бүлэг](20-registration.md)) болон төгсөлтийн шалгалтад ([26-р бүлэг](26-graduation.md)) ашиглагдана.

## Төгсөлтийн шаардлага

Шаардлагын багцыг хөтөлбөр, **Хөтөлбөрийн төрөл** (үндсэн хөтөлбөр, хоёрдугаар мэргэжил, дэд мэргэжил) болон **сургалтын төлөвлөгөөний жил**-ийн хүрээ тус бүрээр нэгийг үүсгэнэ. Оюутанд оюутны бүртгэлийнх нь сургалтын төлөвлөгөөний жилд тохирох багц хамаарна.

- Нэг хөтөлбөр, нэг хөтөлбөрийн төрлийн сургалтын төлөвлөгөөний жилүүд давхцах боломжгүй. Дараагийн багц эхлэх хүртэл хүчинтэй байлгахын тулд дуусах жилийг хоосон үлдээнэ.
- Шаардлагын төрлүүд

| Төрөл | Оруулах утга | Жишээ |
|---|---|---|
| Ангиллын кредит | Хичээлийн ангилал, доод кредит | Ерөнхий суурь (заавал)-аас 9 кредит |
| Заавал судлах хичээлүүд | Хичээлийн жагсаалт | Мэргэжлийн заавал судлах 4 хичээл бүгд |
| Хичээлүүдээс сонгох | Хичээлийн жагсаалт, доод кредит эсвэл хичээлийн доод тоо | Мэргэжлийн сонгон хичээлүүдээс 12 кредит |
| Тэнцсэн шалгалт | Шалгалтын төрөл | Англи хэлний иж бүрэн шалгалтад тэнцсэн ([24-р бүлэг](24-assessments.md)) |

Хоёрдугаар мэргэжил болон дэд мэргэжил нь үндсэн хөтөлбөрөөс жижиг, өөрийн гэсэн багцтай байна (жишээ нь хоёрдугаар мэргэжилд 36 кредит, дэд мэргэжилд 21 кредит). Шаардлагуудыг төгсөлтийн шалгалт ([26-р бүлэг](26-graduation.md)) шалгана.

## CSV оруулах

Хичээлийн жагсаалт дахь **CSV оруулах** (`Хичээл, хувилбар, холбоо хичээлийг удирдах` эрх) нь хичээлийн хувилбаруудыг бөөнөөр ачаална. Нэг мөр нь нэг хувилбар. Хичээлийг кодоор нь олно (байхгүй бол үүсгэнэ); хувилбарыг код ба эхлэх огноогоор олох тул ижил файлыг дахин оруулахад шинэчлэх бөгөөд өөр эхлэх огноотой мөр шинэ засвар болно. Хугацаа нь давхцсан мөр зөвхөн өөрөө алдаатай болно.

| Багана | Тайлбар |
|---|---|
| `code` | Хичээлийн код (заавал) |
| `org_unit` | Хариуцах нэгжийн код. Шинэ хичээлд заавал |
| `effective_start_date`, `effective_end_date` | Хувилбарын хугацаа (`YYYY-MM-DD`) |
| `title_en`, `title_ko`, `title_zh-hans`, `title_lo` | Хэл тус бүрийн нэр. Шинэ хичээлд англи нэр заавал |
| `credits`, `lecture_hours`, `lab_hours` | Кредит (шинэ хувилбарт заавал, 0–30), цаг (0–40) |
| `category` | Хичээлийн ангиллын код |
| `grading_basis` | `graded` эсвэл `pass_fail` |
| `counts_toward_credit_limit` | `1`/`0` |

Мөн адил үйлдлийг `uv run manage.py reference_import courses <file> --actor=<email>`-ээр хийж болно ([9-р бүлэг](09-csv-import.md)).
