# 11. Хичээлийн ангилал ба дүнгийн шкал

## Хичээлийн ангилал

Цэс: **Лавлах мэдээлэл > Хичээлийн ангиллууд** (`Хичээлийн ангиллыг удирдах` эрх). Хуучин системийн (YUSTIC) `SFOBJDIST`-ийг орлоно.

Ерөнхий суурь (заавал), мэргэжлийн (сонгон) зэрэг хичээлийн ангилал. **Дээд**-ийг тохируулж ангиллыг бүлэглэж болно (жишээ нь Ерөнхий суурь → Ерөнхий суурь (заавал), Ерөнхий суурь (сонгон)). Төгсөлтийн шаардлага ([17-р бүлэг](17-courses-and-curriculum.md), [26-р бүлэг](26-graduation.md)) "мэргэжлийн заавал хичээлээс 30 кредит" гэх мэтээр тэдгээрийг ашиглана.

## Дүнгийн шкал

Цэс: **Лавлах мэдээлэл > Дүнгийн шкалууд** (`Дүнгийн шкалыг удирдах` эрх). Хуучин системийн `SSCOREDEF`-ийг орлоно.

| Шкалын талбар | Тайлбар |
|---|---|
| Дээд дүнгийн оноо | Жишээ нь 4.5 |
| Анхдагч | Зөвхөн нэг шкал анхдагч байж болно. Ямар ч шкал анхдагч биш үед л асааж болно (доороос үзнэ үү) |

Шкалыг нээгээд доорх **Дүнгүүд** хэсэгт дүн нэмнэ.

| Дүнгийн талбар | Тайлбар |
|---|---|
| Дүн | Жишээ нь `A+`, `P` |
| Дүнгийн оноо | Голч дүнд тооцогдох дүнд заавал |
| Доод/Дээд (%) | Анхны онооны хөрвүүлэх муж (сонголтоор), жишээ нь A+ 95–100 |
| Голч дүнд тооцох | P/NP зэрэг голч дүнгээс хасагдах дүнд унтраана |
| Тэнцсэн | F эсвэл NP зэрэг кредит олгохгүй дүнд унтраана |
| Хамаарах | Дүнгээр үнэлэх хичээл (үсгэн дүн), Тэнцсэн/тэнцээгүй хичээл (P, NP) эсвэл Аль аль нь (жишээ нь I, дутуу). Дүн оруулах дэлгэц зөвхөн хичээлийн үнэлгээний хэлбэрт тохирох дүнг харуулна |

**Анхдагч шкалыг суулгах үед тогтоох бөгөөд өөрчлөх боломжгүй** (2026-10-23-ны шийдвэр), учир нь бүх дүн болон голч дүнг тэр шкалаар илэрхийлдэг. `setup_install --grade-scale=4.5|4.3`-аар тохируулна; сонголтгүй бол эхний профайлын шкал анхдагч болно. Анхдагч тэмдэглэгээг дэлгэц дээр өөрчлөх боломжгүй бөгөөд анхдагч шкалыг устгах боломжгүй. Дүн тус бүрийн онооны муж болон дүнгийн оноог энэ дэлгэцэд засна ([21-р бүлэг](21-grades.md)).

Профайлаар ачаалдаг шкалууд

- Солонгосын их сургууль: 4.5 шкал (`KR45`): A+ 4.5 (95–100), A0 4.0 (90–), B+ 3.5 (85–), B0 3.0 (80–), C+ 2.5 (75–), C0 2.0 (70–), D+ 1.5 (65–), D0 1.0 (60–), F 0, P, NP
- `--grade-scale=4.3` эсвэл хуучин YUST профайл: 4.3 шкал (`KR43` эсвэл `YUST43`): A+ 4.3 (97–100), A0 4.0 (93–), A- 3.7 (90–), B+ 3.3 (87–), B0 3.0 (83–), B- 2.7 (80–), C+ 2.3 (77–), C0 2.0 (73–), C- 1.7 (70–), D+ 1.3 (67–), D0 1.0 (63–), D- 0.7 (60–), F 0, P, NP (хуучин профайлд N болон I мөн орно). Онооны муж 3 онооны зайтай эхэлдэг тул сургуулийн стандартад тааруулна уу.

Дүнд аль хэдийн ашигласан шкалыг устгах боломжгүй.
