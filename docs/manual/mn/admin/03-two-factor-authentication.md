# 3. Хоёр шатлалт баталгаажуулалт

## Хэрэглэгч хэрхэн бүртгүүлэх

Хэрэглэгч порталын **Аюулгүй байдал** хуудсанд бүртгүүлнэ (`/portal/security/`, удирдлагын самбарт хэрэглэгчийн цэсийн **Хоёр шатлалт баталгаажуулалт**). Бүртгүүлэх эсвэл идэвхгүй болгохын өмнө нууц үгийг дахин нэг удаа баталгаажуулна.

### Баталгаажуулах апп (зөвлөмж болгох)

1. **Хоёр шатлалт баталгаажуулалтыг идэвхжүүлэх**-ийг дарна.
2. QR кодыг Google Authenticator эсвэл Microsoft Authenticator зэрэг баталгаажуулах аппаар уншуулна.
3. Аппад харагдах 6 оронтой кодыг оруулаад **Баталгаажуулах**-ыг дарна.
4. Дэлгэцэд харагдах **сэргээх код**-уудыг аюулгүй газар хадгална. Утсаа алдсан тохиолдолд код бүрийг нэг удаа ашиглаж болно.

### И-мэйлийн код

Зөвхөн системийн админ зөвшөөрсөн үед харагдана. Баталгаажуулах апп ашиглаж чадахгүй хэрэглэгчдэд зориулсан бөгөөд аппаас аюулгүй байдал сул.

1. **И-мэйлийн код** хэсэгт **Тохируулах код илгээх**-ийг дарна.
2. Бүртгэлийн и-мэйлд ирсэн 6 оронтой кодыг оруулаад **Баталгаажуулах**-ыг дарна.
3. Үүнээс хойш нэвтрэх бүрт кодыг и-мэйлээр илгээнэ. Кодыг 10 минутын дотор нэг удаа ашиглана; 5 удаа буруу оруулбал шинэ код шаардлагатай. Кодыг минутад нэг удаа, цагт 5 хүртэл удаа илгээж болно.

Хоёр аргад хоёуланд нь бүртгүүлж болно. Бодлого "заавал" үед үлдсэн сүүлийн аргыг идэвхгүй болгох боломжгүй.

## Бодлогын тохиргоо (системийн админ)

Удирдлагын самбарын **Тохиргоо > Аюулгүй байдал** хэсэгт тохируулна. Хадгалсны дараа бүх хэрэглэгчид дараагийн хуудас ачаалах үеэс үйлчилнэ.

| Тохиргоо | Тайлбар |
|---|---|
| Бодлого | **Ашиглахгүй** / **Зөвлөмж (сонголтоор)**: бүртгүүлээгүй хэрэглэгч зөвхөн мэдэгдэл харна / **Сонгосон үүрэгт заавал**: сонгосон үүрэгтэй хэрэглэгч заавал бүртгүүлнэ / **Бүх хүнд заавал** |
| Хоёр шатлалт баталгаажуулалт заавал ашиглах үүргүүд | Бодлого "Сонгосон үүрэгт заавал" үед сонгоно |
| Хөнгөлөлтийн хугацаа (хоног) | Шаардлага хэрэглэгчид анх хамаарснаас хойш бүртгүүлэлгүйгээр үргэлжлүүлэн ажиллах хугацаа. Энэ хугацаанд порталын болон удирдлагын самбарын дээд хэсэгт эцсийн хугацааны мэдэгдэл харагдана. Хугацаа дуусвал зөвхөн аюулгүй байдлын хуудсыг ашиглах боломжтой. 0 бол нэн даруй |
| Төхөөрөмжийг санах хугацаа (хоног) | **Энэ төхөөрөмжийг санах**-ыг сонгосон төхөөрөмж дээр код оруулахгүй байх хугацаа. 0 бол унтраана |
| И-мэйлээр код илгээхийг зөвшөөрөх | Унтраасан үед и-мэйлийн код хоёр шатлалт баталгаажуулалтад тооцогдохгүй. Зөвхөн и-мэйлийн кодод бүртгүүлсэн хэрэглэгчээс бодлогын дагуу баталгаажуулах аппад бүртгүүлэхийг шаардана |

Санал болгох ажиллагаа: ажилтны үүрэгт (оюутны бүртгэл хариуцсан ажилтан, сургалтын албаны ажилтан, системийн админ гэх мэт) **Сонгосон үүрэгт заавал**, оюутанд зөвлөмж.

## Шинэчлэх (утсаа алдсан гэх мэт)

1. **Хэрэглэгч ба эрх > Хэрэглэгчид** хэсэгт хэрэглэгчийг нээнэ.
2. Хуудасны дээд хэсэгт байх **Хоёр шатлалт баталгаажуулалтыг шинэчлэх**-ийг дараад шалтгаанаа оруулна (`Хоёр шатлалт баталгаажуулалтыг шинэчлэх` эрх шаардлагатай).
3. Хэрэглэгчийн баталгаажуулах апп, сэргээх код, и-мэйлийн код болон санасан төхөөрөмжүүд бүгд устна. Хөнгөлөлтийн хугацаа дахин эхэлнэ.

Өөрийн бүртгэлийг шинэчлэх боломжгүй. Шинэчлэлтийг шалтгаантай нь аюулгүй байдлын үйл явдал болон үйлдлийн бүртгэлд бичнэ.

Цорын ганц админ утсаа алдаж удирдлагын самбарт нэвтэрч чадахгүй бол IT оператор `uv run manage.py security_reset_mfa`-аар шинэчилнэ (Docker: `docker compose exec app uv run manage.py security_reset_mfa`, [командын лавлах](../operations/commands.md)).
