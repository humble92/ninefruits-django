# Алдааг олж засварлах

- Зориулалт: МТ-ийн ашиглалтын ажилтнууд
- Холбогдох: [байршуулалтын хяналтын хуудас](deployment-checklist.md), [төлөвлөгдсөн ажлууд](scheduled-jobs.md), [командын лавлах](commands.md)

| Шинж тэмдэг | Шалгах зүйл |
|---|---|
| Нэвтэрсний дараа шууд аюулгүй байдлын хуудас руу шилжүүлнэ | Хоёр шатлалт баталгаажуулалтын бодлого "заавал" бөгөөд хөнгөлөлтийн хугацаа өнгөрсөн. Хэрэглэгч бүртгүүлмэгц шийдэгдэнэ. Бодлого нь **Тохиргоо > Аюулгүй байдал** хэсэгт байна |
| Удирдлагын самбарт 403 | Хэрэглэгчид `admin_panel.access` эрхтэй (`Удирдлагын самбарыг нээх`) хүчинтэй үүргийн оноолт байхгүй. **Хэрэглэгч ба эрх > Хэрэглэгчид**-ээс хэрэглэгчийг нээж **Үүргийн оноолт** жагсаалтыг (хугацаа, хамрах хүрээ) шалгана |
| Цэсийн зүйл харагдахгүй | Үүрэгт тухайн дэлгэцийн эрх (жишээ нь `roles.view`) байхгүй |
| И-мэйлийн код ирэхгүй | Мэйлийн тохиргоо (`MAIL_*`, `DEFAULT_FROM_EMAIL`), **Аудит > Аюулгүй байдлын үйл явдлууд** дахь `И-мэйлийн код илгээсэн` бичлэгүүд, илгээх хязгаар (хэрэглэгч тус бүрт минутад нэг удаа, цагт тав) |
| Нэвтрэх хуудас `429 Too Many Requests` гэж хариулна | Нэг хаяг минутад `LOGIN_RATE_LIMIT_PER_IP` (анхдагч 30) оролдлогоос хэтэрсэн. Олон хэрэглэгч нэг дор хаагдвал `TRUSTED_PROXY_COUNT` бодит проксины тоотой таарч буйг шалгана (бүгд Nginx-ийн хаягаар харагдах); кампусын NAT-ийн ард бол утгыг нэмэгдүүлнэ ([байршуулалтын хяналтын хуудас](deployment-checklist.md#прокси-ба-клиентийн-хаяг)) |
| Зөв нууц үгээр нэвтэрч чадахгүй | Нэвтрэлт түгжигдсэн (**аюулгүй байдлын үйл явдлууд** дахь `Нэвтрэлт түгжигдсэн`) эсвэл бүртгэл идэвхгүй. Түгжээг `uv run manage.py security_unlock_user <email> --reason="..."`-ээр тайлна |
| Дэлгэц бусдын өгөгдлийг 0 мөр харуулна | Хэвийн байж болно (мөрийн түвшний хамгаалалт). **Аудит > Өгөгдлийн өөрчлөлтүүд** дэх хэрэглэгчийн баганаас DB сессийн гүйцэтгэгч тохируулагдсан эсэхийг шалгана |
| `400 Bad Request` | Хүссэн хостын нэр `DJANGO_ALLOWED_HOSTS`-д байхгүй |
| `403 CSRF verification failed` | `DJANGO_CSRF_TRUSTED_ORIGINS`-д `https://` хаяг байхгүй, эсвэл Nginx `X-Forwarded-Proto` дамжуулахгүй байна |
| HTTPS чиглүүлэлт төгсгөлгүй давтагдана | Nginx `X-Forwarded-Proto $scheme` дамжуулахгүй тул Django хүсэлтийг HTTP гэж харна (`SECURE_PROXY_SSL_HEADER`) |
| Загвар, скриптгүй дэлгэц, `manifest.json` алдаа | `npm ci && npm run build` (`static/dist/`), `collectstatic`, Nginx-ийн `/static/` location. Production `VITE_DEV_MODE=false` ашиглана |
| Дэлгэцийн зарим хэсэг англиар харагдана | `compilemessages --ignore=.venv` ажиллуулаагүй (`.mo` файл байхгүй). Шинэ мөрүүдийн хувьд `uv run manage.py i18n_missing <locale>` |
| `permission denied for schema public` | Аппликейшн `app_runtime`-аар DDL хийхийг оролдсон. Миграцыг зөвхөн `uv run manage.py migrate` эсвэл `setup_install`-ээр ажиллуулна (хоёулаа автоматаар `app_migrator` ашиглана) |
| `Audit records are append-only` | Аудитын хүснэгтийг шинэчлэх эсвэл устгах оролдлого. Энэ хориг нь зориуд хийгдсэн |
| PDF үүсгэж чадахгүй | `uv run manage.py pdf_sample`, Gotenberg-ийн төлөв, `GOTENBERG_URL`, `GOTENBERG_TIMEOUT` |
| Дарааллын ажлууд гацсан | Flower дээр worker-ийн холболт болон амжилтгүй ажлууд, `uv run celery -A config inspect active`, Redis-ийн холболт (`REDIS_URL`)-ыг шалгана |
| Төлөвлөгдсөн ажлууд ажиллахгүй, `/api/v1/health/` `degraded` гэж хариулна | Beat зогссон (5 минутаас дээш төлөвлөгчийн heartbeat алга). Beat процесс болон түүний логийг шалгана. Зөвхөн нэг beat |
| Worker-ийн логт `Received unregistered task` | Worker өмнөх кодыг ажиллуулсаар байна. Байршуулсны дараа worker-ийг дахин эхлүүлнэ |
| Улирал хаах ажил дуусахгүй | Flower дээрх амжилтгүй `grading.close_term_records` ажлууд. Шалтгааныг засаад улирал хаахыг дахин эхлүүлнэ (оюутан тус бүрийн тооцоолол дахин ажиллуулахад ижил үр дүн өгнө) |

Хүсэлт тус бүрийг мөрдөх: `X-Request-Id` хариултын толгойн утгаар лог (JSON дахь `request_id`), үйлдлийн бүртгэл, өгөгдлийн өөрчлөлт, аюулгүй байдлын үйл явдлыг хамтад нь хайж болно. Nginx `X-Request-Id $request_id` дамжуулбал Nginx-ийн хандалтын лог ч нэгдэнэ. Командын ажиллагаа `cmd-`-ээр эхэлсэн ажиллагааны ID ашиглана.
