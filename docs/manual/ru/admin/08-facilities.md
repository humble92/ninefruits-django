# 8. Здания и аудитории

Меню: **Справочные данные > Здания**, **Аудитории** (разрешение `Управлять зданиями и аудиториями`)

## Здания

Укажите код (например, `SCI`), название (на каждом языке) и адрес. Здание, в котором есть аудитории, удалить нельзя, поэтому, если оно больше не используется, отключите **Активен**.

## Аудитории

| Поле | Описание |
|---|---|
| Здание, Номер аудитории | Номера аудиторий уникальны в пределах здания, например `101` |
| Название | Необязательно, например «Большой актовый зал» |
| Тип аудитории | Значение из справочника `room_type` (учебная аудитория, лаборатория и т. п.) |
| Подразделение | Кафедра, которая отвечает за аудиторию (необязательно) |
| Вместимость | Сравнивается с вместимостью группы при составлении расписания ([глава 18](18-sections-and-timetables.md)) |
| Используется в расписании | Если выключено, аудитория не учитывается при составлении расписания (кабинеты, склады и т. п.) |

Если аудиторий много, используйте [импорт CSV](09-csv-import.md). Здания должны быть зарегистрированы заранее.
