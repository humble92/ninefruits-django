# 14. Объединение лиц и приглашения создать учётную запись

Меню: **Студенты и сотрудники > Лица**, затем **Объединить дубликат** и **Пригласить создать учётную запись** в верхней части страницы сведений о лице

## Объединение дубликатов лиц

Используется, когда один и тот же человек зарегистрирован как два лица (например, при восстановлении существующее лицо не было найдено и было создано новое). Требуется разрешение `Объединять дубликаты лиц`.

1. Найдите кандидатов: выполните поиск в списке лиц по одинаковым имени и дате рождения или по одинаковому номеру удостоверения личности. ИТ-оператор может получить полный список кандидатов командой `uv run manage.py people_find_duplicates`.
2. На странице сведений о **лице, которое нужно удалить (дубликате)**, нажмите **Объединить дубликат**, выберите из списка лицо в поле **Оставить это лицо** и укажите причину. По завершении объединения откроется страница сохранённого лица.
3. Личные дела студентов, заявления, данные преподавателя, законные представители и учётная запись удаляемого лица переходят к сохранённому лицу. Если учётная запись есть у обоих, учётная запись удаляемого лица деактивируется, а связанный с ней вход через вуз по возможности переносится.
4. Удалённое лицо остаётся со статусом **Объединённые** (фильтр списка **Объединённые**), чтобы старые записи можно было найти. Использовать его для новых личных дел студентов нельзя.

- Если у обоих лиц есть данные преподавателя, объединение отклоняется. Сначала упорядочьте данные преподавателя.
- Если у обоих лиц есть открытое заявление в одной и той же приёмной кампании, объединение отклоняется. Попросите абитуриента отозвать одно из них.
- **Отменить это действие невозможно.** Перед объединением всегда проверяйте личные дела студентов и дату рождения. Объединение записывается в журнал действий вместе с причиной.

## Приглашения создать учётную запись

Отправляет письмо с приглашением лицам без учётной записи, например студентам и преподавателям, загруженным через CSV. Требуется разрешение `Приглашать лиц создать учётную запись`.

1. На странице сведений о лице нажмите **Пригласить создать учётную запись** и укажите адрес электронной почты для входа (обычно личный адрес).
2. Когда получатель задаст пароль по ссылке из письма, учётная запись будет создана, и он сразу войдёт в систему.

- Ссылка действительна в течение срока, заданного в **Настройки > Личные дела студентов > Срок действия ссылок-приглашений (дней)** (по умолчанию 14 дней).
- Повторная отправка делает предыдущую ссылку недействительной.
- Нельзя пригласить лицо, у которого уже есть учётная запись, или использовать адрес электронной почты, занятый другой учётной записью.
- После выпуска сохраняется та же учётная запись. Попросите тех, кто использовал только адрес электронной почты вуза, сменить адрес для входа на личный ([глава 15](15-sign-in-methods.md)).
