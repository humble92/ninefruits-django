# 5. Настройки учебного заведения и порядок первоначальной настройки

## Настройки учебного заведения

Задаются в разделе **Настройки > Учебное заведение** (разрешение `Управлять настройками учебного заведения`).

| Параметр | Описание |
|---|---|
| Название учебного заведения | Вводится на каждом языке. Отображается в левом верхнем углу панели администрирования |
| Часовой пояс | Основа для определения дат семестра и периодов семестра, например `Asia/Seoul`. Всё сохранённое время отображается в этом часовом поясе |
| Доступные языки | Языки, которые могут выбирать пользователи. В списке отображаются только языки с установленными файлами перевода |
| Язык по умолчанию | Используется для пользователей, не выбравших язык, и когда язык браузера неизвестен |

## Порядок первоначальной настройки нового вуза

После того как ИТ-оператор выполнил `setup_install` (руководство по эксплуатации, [Установка](../operations/installation.md)), администратор учебного процесса вводит данные в указанном ниже порядке. Последующие шаги ссылаются на коды предыдущих, поэтому соблюдайте порядок.

1. **Настройки учебного заведения**: название, часовой пояс, языки (эта глава)
2. **Справочники**: значения национальности, вида поступления и типа аудитории ([глава 6](06-code-data.md)). Если при установке был применён профиль корейского университета, типы аудиторий уже существуют.
3. Проверьте **Виды подразделений**, затем **Подразделения**: университет → институт → кафедра ([глава 7](07-org-units-and-programs.md)). Если подразделений много, используйте CSV ([глава 9](09-csv-import.md)).
4. **Программы**: образовательные программы каждой кафедры ([глава 7](07-org-units-and-programs.md))
5. **Здания**, **Аудитории** ([глава 8](08-facilities.md), можно через CSV)
6. Проверьте **Виды семестров** и **Пары** ([глава 10](10-terms.md))
7. Проверьте **Категории дисциплин** и **Шкалы оценок**. Одна шкала должна быть назначена шкалой по умолчанию ([глава 11](11-course-categories-and-grade-scales.md))
8. **Учебные годы** → **Семестры** → **Периоды семестра** для каждого семестра ([глава 10](10-terms.md))
9. **Пользователи и доступ**: для ролей, которым нужна область действия «подразделение» (например, методистов кафедр), теперь можно выбрать кафедру в качестве объекта области действия ([глава 2](02-users-and-roles.md))

Когда данные введены, попросите ИТ-оператора проверить периоды семестра командой `uv run manage.py term_inspect`.
