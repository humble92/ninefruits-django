# 11. Категории дисциплин и шкалы оценок

## Категории дисциплин

Меню: **Справочные данные > Категории дисциплин** (разрешение `Управлять категориями дисциплин`). Заменяет `SFOBJDIST` прежней системы (YUSTIC).

Классификация дисциплин, например «обязательные общеобразовательные» или «элективные по специальности». Категории можно группировать, задав **Вышестоящее** (например, Общеобразовательные → Обязательные общеобразовательные, Элективные общеобразовательные). На них ссылаются требования к выпуску ([глава 17](17-courses-and-curriculum.md), [глава 26](26-graduation.md)), например «30 кредитов обязательных дисциплин специальности».

## Шкалы оценок

Меню: **Справочные данные > Шкалы оценок** (разрешение `Управлять шкалами оценок`). Заменяет `SSCOREDEF` прежней системы.

| Поле шкалы | Описание |
|---|---|
| Максимальный балл | Например, 4.5 |
| По умолчанию | Шкалой по умолчанию может быть только одна шкала. Включить признак можно, только пока ни одна шкала не является шкалой по умолчанию (см. ниже) |

Откройте шкалу и добавьте оценки в разделе **Оценки** ниже.

| Поле оценки | Описание |
|---|---|
| Оценка | Например, `A+`, `P` |
| Баллы оценки | Обязательны для оценок, которые учитываются в среднем балле |
| От (%), До (%) | Диапазоны пересчёта исходного балла (необязательно), например A+ 95–100 |
| Учитывается в среднем балле | Отключите для оценок, исключаемых из среднего балла, например P/NP |
| Положительная | Отключите для оценок, по которым кредиты не начисляются, например F или NP |
| Для | Дисциплины с дифференцированной оценкой (буквенные оценки), Дисциплины с зачётом/незачётом (P, NP) или Оба (например, I — не завершено). Экран ввода оценок показывает только оценки, соответствующие способу оценивания дисциплины |

**Шкала по умолчанию задаётся при установке и не может быть изменена** (решение от 23.10.2026), поскольку все оценки и средние баллы выражаются в этой шкале. Она задаётся параметром `setup_install --grade-scale=4.5|4.3`; без этого параметра шкалой по умолчанию становится шкала первого профиля. Признак «По умолчанию» нельзя изменить на экране, а шкалу по умолчанию нельзя удалить. Диапазоны баллов и баллы оценок редактируются на этом экране ([глава 21](21-grades.md)).

Шкалы, загружаемые профилями

- Корейский университет: шкала 4.5 (`KR45`): A+ 4.5 (95–100), A0 4.0 (90–), B+ 3.5 (85–), B0 3.0 (80–), C+ 2.5 (75–), C0 2.0 (70–), D+ 1.5 (65–), D0 1.0 (60–), F 0, P, NP
- `--grade-scale=4.3` или прежний профиль YUST: шкала 4.3 (`KR43` или `YUST43`): A+ 4.3 (97–100), A0 4.0 (93–), A- 3.7 (90–), B+ 3.3 (87–), B0 3.0 (83–), B- 2.7 (80–), C+ 2.3 (77–), C0 2.0 (73–), C- 1.7 (70–), D+ 1.3 (67–), D0 1.0 (63–), D- 0.7 (60–), F 0, P, NP (прежний профиль также включает N и I). Диапазоны баллов изначально заданы с шагом 3 балла, поэтому скорректируйте их в соответствии с нормами вуза.

Шкалу, которая уже использовалась в оценках, удалить нельзя.
