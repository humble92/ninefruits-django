# 9. Импорт CSV

Используйте кнопку **Импорт CSV** в верхней части экранов подразделений, программ, зданий, аудиторий и справочников (разрешение `Импортировать справочные данные из CSV`). Личные дела студентов, преподаватели, дисциплины и ограничения на запись импортируются тем же способом (см. ниже). Очень большие файлы ИТ-оператор может импортировать тем же способом командой `reference_import`.

## Общие правила

- Первая строка содержит названия столбцов (см. таблицы ниже). Кодировка — UTF-8; в Excel сохраняйте файл как «CSV UTF-8».
- Строка, код которой уже существует, **обновляет** соответствующую запись. Повторный импорт того же файла не создаёт дубликатов.
- Столбцы для разных языков имеют вид `столбец_язык`: `name_en`, `name_ko`, `name_zh-hans`. Для новых строк обязательно английское название (`name_en`). Пустые ячейки не удаляют существующие переводы.
- Даты записываются как `2026-03-01`; значения «да/нет» — как `1`/`0` или `true`/`false`.
- Сначала проверяется строка заголовков (если не хватает обязательного столбца, ничего не импортируется). Файлы до 500 строк импортируются сразу; более крупные файлы обрабатываются в фоновом режиме (Celery). Результат отображается на странице импорта в разделе **Справочные данные > Импорты CSV** (импортированные строки, строки с ошибками и их причины). Если какие-то строки не удалось импортировать, по ссылке **Скачать строки с ошибками** можно получить CSV с причиной для каждой строки. Исправьте его и импортируйте только этот файл ещё раз.
- Названия столбцов должны совпадать с таблицами ниже; неизвестные столбцы игнорируются. Название столбца `name_zh_CN` исходной системы принимается как `name_zh-hans`.

## Форматы столбцов

| Вид | Обязательные столбцы | Необязательные столбцы |
|---|---|---|
| Подразделения | `code`, `type` (код вида подразделения), `name_en`, `effective_start_date` | `parent` (код вышестоящего), `name_ko` и т. п., `short_name_*`, `effective_end_date`, `sort_order` |
| Программы | `code`, `org_unit` (код подразделения), `degree_level`, `name_en`, `effective_start_date` | `degree_title_*`, `standard_duration_years`, `effective_end_date`, `allows_second_major`, `allows_minor` |
| Здания | `code`, `name_en` | `name_*`, `address`, `is_active` |
| Аудитории | `building` (код здания), `code` (номер аудитории) | `name_*`, `room_type` (код типа аудитории), `org_unit`, `capacity`, `is_schedulable`, `is_active` |
| Значения справочников | `type` (код справочника), `code`, `name_en` | `name_*`, `sort_order`, `is_active` |

Значения `degree_level`: `associate`, `bachelor`, `master`, `doctorate`, `certificate`, `non_degree`

Для подразделений вышестоящие подразделения должны идти первыми (упорядочьте как университет → институт → кафедра).

## Пример: подразделения

```csv
code,type,parent,name_en,name_ko,effective_start_date
UNI,university,,Sample University,샘플대학교,1990-03-01
ENG,college,UNI,College of Engineering,공과대학,1990-03-01
CSE,department,ENG,Computer Science,컴퓨터공학과,1995-03-01
```

## Студенты и преподаватели

Личные дела студентов сопоставляются и обновляются по `student_number`, преподаватели — по `employee_number`. Оба вида используют общие столбцы лица.

| Вид | Обязательные столбцы для новых строк | Необязательные столбцы |
|---|---|---|
| Личные дела студентов | `student_number`, `program` (код программы), `admission_date`, `family_name` | `catalog_year` (если пусто — год поступления), `year_level`, `status`, `graduation_date`, `institutional_email` |
| Преподаватели | `employee_number`, `org_unit` (код подразделения), `employment_type`, `family_name` | `academic_title_*`, `hire_date`, `end_date` |
| Столбцы лица (общие) | — | `given_name`, имена на разных языках, например `name_ko`, `birth_date`, `gender`, `email`, `phone`, `national_id` |

- Значения `status`: `enrolled`, `on_leave`, `withdrawn`, `dismissed`, `graduated` (для `graduated` обязателен `graduation_date`). Статус, изменённый импортом, считается **исправлением данных** и не создаёт истории изменения статуса. Фактические изменения записываются на экране ([глава 13](13-status-changes-and-advisors.md)).
- Значения `employment_type`: `full_time`, `part_time`, `adjunct`, `visiting`, `emeritus`. Значения `gender`: `female`, `male`, `other`, `undisclosed`.
- Если `national_id` нового личного дела студента совпадает с существующим лицом, личное дело привязывается к этому лицу (восстановление). В противном случае создаётся новое лицо. При обновлении пустые ячейки не удаляют существующие значения.
- У импортированных студентов и преподавателей нет учётной записи. Отправьте им приглашение через [приглашения создать учётную запись](14-merge-and-invitations.md#приглашения-создать-учётную-запись).

```csv
student_number,program,admission_date,year_level,status,family_name,given_name,name_ko,birth_date
202600001,B-CSE,2026-03-02,1,enrolled,Kim,Minsu,김민수,2007-05-01
```

Импорт версий дисциплин описан в [главе 17](17-courses-and-curriculum.md), импорт ограничений на запись — в [главе 20](20-registration.md).

## Ограничения на запись

**Импорт CSV** в верхней части списка **Запись на дисциплины > Ограничения** (разрешение `Устанавливать и снимать ограничения, предоставлять исключения из правил`) или `uv run manage.py reference_import registration_holds`. Используется для загрузки данных `SRDENY` прежней системы или списка студентов с неоплаченным обучением из финансового отдела.

| Обязательные столбцы | Необязательные столбцы |
|---|---|
| `student_number`, `hold_type` (`unregistered`, `financial`, `academic`, `administrative`, `other`), `reason` | `starts_at` (по умолчанию — время импорта), `ends_at`, `blocks_registration` (по умолчанию 1), `blocks_grades`, `blocks_certificates` |

- Каждая строка создаёт новое ограничение (источник `import`). Если импортировать один и тот же файл дважды, ограничения будут созданы дважды, поэтому перед повторным импортом проверьте список.
- Время записывается как `2027-03-15` или `2027-03-15 09:00` (без часового пояса — в часовом поясе сервера, UTC). `ends_at` должно быть позже `starts_at`.
- Строки с неизвестным студенческим номером не импортируются. Ограничения снимаются на экране с указанием причины ([глава 20](20-registration.md)).

```csv
student_number,hold_type,reason,ends_at
202312345,financial,Tuition unpaid 2027-1,
202254321,academic,Probation meeting needed,2027-03-15
```
