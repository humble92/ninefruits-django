# 22. Анкетирование по дисциплинам

Меню: **Анкетирование по дисциплинам > Анкетирование по семестрам**, **Анкеты**, **Ответы по группам**, **Настройки > Анкетирование по дисциплинам**. Студенты используют на портале **Анкетирование по дисциплинам**; преподаватели — на портале **Мои дисциплины > Результаты анкетирования по дисциплинам**.

| Разрешение | Что позволяет |
|---|---|
| `Просматривать долю ответивших и результаты анкетирования по дисциплинам` | Число ответов и доля ответивших по группам, опубликованные результаты. При назначении с областью действия «подразделение» — только группы, открываемые этим подразделением |
| `Управлять анкетами, анкетированием по семестрам и публикацией` | Анкеты и вопросы, настройки анкетирования семестра, публикация результатов, настройки анкетирования по дисциплинам |

Роли по умолчанию: у сотрудника учебного управления (Academic Affairs) есть оба разрешения, у методиста кафедры — просмотр (область действия кафедры).

## Отличия от прежней системы

- **Анонимность.** Прежняя система (YUSTIC) хранила студенческий номер вместе с каждым ответом, а учётные записи преподавателей могли читать исходную таблицу. Новая система хранит **кто прошёл анкетирование (отметки о прохождении)** и **что было отвечено (ответы)** раздельно. В ответе нет ни студента, ни порядкового номера, ни времени. Ответы не записываются и в историю изменений данных (аудит), потому что запись аудита сохранила бы автора действия.
- **Порог для показа результатов.** В прежней системе на экране преподавателя не было минимального порога ответов, и преподаватели могли видеть результаты чужих групп. Новая система показывает результаты и комментарии после **публикации** результатов семестра и **только для групп, достигших минимального числа ответов и минимальной доли ответивших**. Преподаватели видят только свои группы.
- **Запрет просмотра оценок.** Прежняя система блокировала только ссылку в меню, и блокировка не снималась по окончании периода анкетирования. Новая система блокирует на сервере и снимает запрет при закрытии периода.
- **Управление вопросами.** Прежняя система каждый семестр вставляла вопросы через SQL. Новая система управляет анкетами и вопросами на экране.
- Правило, отклонявшее ответы «все 1» или «все 5», стало настройкой (по умолчанию выключено).

## Подготовка семестра

1. **Анкета**: выберите анкету в разделе **Анкеты**. Профиль корейского университета создаёт анкету `STANDARD` (по 3 вопроса о подготовке, методике преподавания, содержании, оценивании, а также помещениях и оборудовании по 5-балльной шкале плюс 1 вопрос-комментарий).
2. **Подготовить семестр**: семестр, анкета, минимум ответов, минимальная доля ответивших (%). Значения по умолчанию берутся из **Настройки > Анкетирование по дисциплинам** (5 ответов, 25 %). Чтобы результаты показывались, должны быть выполнены оба порога. Число ответов защищает анонимность (при малом числе ответов студентов можно угадать); доля ответивших обеспечивает представительность результатов.
3. **Период анкетирования**: добавьте период **Анкетирование по дисциплинам** для каждого учебного периода в разделе **Периоды семестра** на экране редактирования семестра ([глава 10](10-terms.md)). Критерии охвата позволяют задавать периоды по курсам.
4. В течение периода `uv run manage.py evaluation_remind {term}` отправляет письма-напоминания студентам, которые ещё не завершили анкетирование (`--dry-run` только подсчитывает их). Долю ответивших смотрите в разделе **Ответы по группам**.
5. Когда обработка оценок завершена, нажмите **Опубликовать результаты** (или выполните `uv run manage.py evaluation_publish_results {term}`). Команды описаны в разделе [команды](../operations/commands.md).

## Анкеты и вопросы

| Поле | Описание |
|---|---|
| Код, Название, Описание | Описание показывается над экраном анкетирования студента |
| Число баллов шкалы | От 2 до 10, обычно 5 |
| Подпись для 1, Подпись для высшего балла | Например, «Совершенно не согласен», «Полностью согласен» |

Вкладка **Вопросы**: раздел (вопросы одного раздела группируются), вопрос, тип (Шкала, Комментарий), обязательный, **Обратный** (вопрос с отрицательной формулировкой; при расчёте средних ответ инвертируется, например 5 на вопрос «Было трудно успевать за темпом занятий» считается как 1), порядок.

В анкете, на которую есть хотя бы один ответ, больше нельзя изменить вопросы или шкалу (чтобы результаты никогда не превратились в ответы на вопрос, который не задавался). Чтобы изменить её, создайте новую анкету кнопкой **Копировать анкету** и используйте её в следующем семестре.

## Что подлежит анкетированию

- Дисциплины, на которые студент записан или которые он завершил в семестре с подготовленным анкетированием. Дисциплины с выходом и с отменённой записью не учитываются.
- Дисциплины с выключенным параметром **Анкетирование по дисциплине** не учитываются (практики, стажировки и т. п.; [глава 17](17-courses-and-curriculum.md)).
- Дисциплину можно оценить только пока для студента открыт период анкетирования по дисциплинам её учебного периода.

## Экран студента

**Анкетирование по дисциплинам** на портале: в списке дисциплин для оценки нажмите **Оценить**, ответьте на вопросы и отправьте. Нужно ответить на все обязательные вопросы, а отправленную анкету изменить нельзя. Каждая дисциплина оценивается один раз.

**Запрет просмотра оценок** (настройка, по умолчанию включена): в течение периода у студента с неоценённой дисциплиной в семестре оценки этого семестра скрыты на экране оценок портала и в ведомости оценок, и выводится уведомление. Оценки появляются после завершения анкетирования или окончания периода. Оценки других семестров остаются видимыми.

## Результаты

- Преподаватели: **Результаты анкетирования по дисциплинам** в разделе **Мои дисциплины** на портале. Открываются только после публикации результатов семестра.
- Сотрудники: **Анкетирование по дисциплинам > Ответы по группам** показывает число ответов и долю ответивших по группам; **Результаты** открывает экран результатов. Подробные результаты сотрудникам тоже показываются только после публикации (во время периода сопоставление изменений в результатах со временем прохождения позволило бы установить студентов).
- Экран результатов: ответы/ожидаемые (доля ответивших), среднее по каждому вопросу и число ответов по каждому баллу (для обратных вопросов — инвертированное), общее среднее, комментарии (в случайном порядке).
- Для группы, где ответов меньше минимума или доля ответивших ниже минимальной, показывается только число ответов, без результатов и комментариев.

## Настройки

**Настройки > Анкетирование по дисциплинам**: скрывать оценки за семестр до завершения анкетирования (по умолчанию включено), не принимать одинаковый ответ на все вопросы (по умолчанию выключено), минимум ответов (по умолчанию 5) и минимальная доля ответивших (по умолчанию 25 %, порог экрана прежнего учебного управления) для анкетирования нового семестра.

## Экраны в этой установке

Экраны и функции те же, что и в исходной системе (Filament, Livewire); порядок работы с ними немного отличается.

- **Подготовить семестр** над списком **Анкетирование по семестрам** открывает экран ввода (семестр, анкета, минимум ответов, минимальная доля ответивших). Пустой порог для нового семестра принимает значение по умолчанию из настроек, а для существующего сохраняет текущее значение. **Изменить** в меню строки открывает тот же экран (семестр изменить нельзя); у семестра с ответами нельзя сменить анкету. **Опубликовать результаты** в меню строки открывает экран подтверждения. Меню строки показывается и для опубликованных семестров; для них сообщение указывает, что результаты уже опубликованы.
- На экране редактирования в разделе **Анкеты** вопросы добавляются, изменяются и удаляются на вкладке **Вопросы**. Анкета с ответами показывает вопросы только для чтения и блокирует поле числа делений шкалы. **Копировать анкету** вверху открывает экран для нового кода; после копирования открывается экран редактирования новой анкеты.
- Фильтры раздела **Ответы по группам**: семестр (по умолчанию — последний семестр с анкетированием, **Все** — все семестры), подразделение-организатор. Поиск сопоставляет начало кода дисциплины. **Результаты** в меню строки открывает экран результатов на портале (`/portal/sections/{section id}/evaluation/`) в том же окне.
- Столбец **Результаты анкетирования по дисциплинам** в таблице **Мои дисциплины** на портале: ссылка **Результаты**, когда результаты семестра опубликованы, иначе **Не опубликованы**.
- **Анкетирование по дисциплине** на студенческом портале: **Отправить** ещё раз запрашивает подтверждение в браузере (без JavaScript форма отправляется сразу). Если не заполнен обязательный вопрос, введённые ответы показываются снова вместе с ошибкой. Уведомление на экране оценок ссылается на **Анкетирование по дисциплине**.
- Хранение ответов: ID ответа — случайный UUID. Ответы, ответы на вопросы и отметки о завершении записываются одной транзакцией в системном контексте после проверки записи студента на дисциплину, периода и дубликатов и не записываются в журнал изменений данных (аудит). Заблокирована ли анкета (есть ли у неё ответы), определяется независимо от области просмотра того, кто открывает экран.
