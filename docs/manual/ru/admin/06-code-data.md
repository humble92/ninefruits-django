# 6. Справочники, страны, языки

Меню: **Справочные данные > Справочники**, **Страны**, **Языки** (разрешение `Управлять справочниками, странами и языками`)

## Справочники

Короткие списки значений, которые различаются от вуза к вузу. Каждый справочник (тип) содержит значения с кодами.

| Код справочника | Назначение | Прежняя система (YUSTIC) |
|---|---|---|
| `ethnicity` | Национальность | `FNATION` |
| `admission_type` | Вид поступления | `FADMDIST` |
| `room_type` | Тип аудитории | `ROOM.FORWHAT` |

- Системные справочники (три указанных выше) приложение ищет по коду, поэтому их коды нельзя изменить или удалить. Значения можно добавлять свободно.
- Откройте справочник и добавьте значения в разделе **Значения справочника** ниже. Коды состоят из строчных латинских букв, цифр и символов подчёркивания (например, `korean`). Название вводится на каждом языке; английское название обязательно.
- Не удаляйте значения, которые больше не используются; вместо этого отключите **Активен**. Значение нельзя удалить, пока его используют данные.
- Много значений удобно вводить через [импорт CSV](09-csv-import.md).

## Страны и языки

Списки по стандартам ISO (249 стран, около 180 языков) загружаются при установке. Названия на установленных языках заполняются автоматически.

- Чтобы изменить название, отображаемое на экране, измените его через **Изменить**. Изменённое название сохраняется при последующих обновлениях системы.
- Чтобы скрыть запись из списков выбора, отключите **Активен**.
