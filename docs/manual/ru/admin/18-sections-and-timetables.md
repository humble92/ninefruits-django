# 18. Группы и расписания

Меню: **Учебные планы и группы > Группы**, **Расписания** (разрешения `Просматривать группы`, `Планировать группы (преподаватели, время, аудитории)`. При назначении с областью действия «подразделение» охватывают только группы, открываемые этим подразделением)

## Создание группы

1. В разделе **Группы > Создать** укажите учебный период семестра, дисциплину, номер группы (например, `01`), число мест и подразделение, открывающее группу. Название и кредиты берутся из версии дисциплины, действующей на дату начала учебного периода.
2. На вкладках экрана редактирования введите **Расписание занятий**, **Преподаватели** и **Зарезервированные места**.
3. Когда всё готово, нажмите **Опубликовать**. Только опубликованные группы появляются на портале в разделе **Каталог дисциплин** и доступны для записи ([глава 20](20-registration.md)).

| Статус | Значение |
|---|---|
| Черновик | Идёт планирование. Видят только сотрудники и назначенные преподаватели |
| Опубликована | Видна студентам. Можно **Вернуть в черновик** |
| Отменена | Требуется причина. Аудитория и время преподавателей освобождаются. **Открыть снова** возвращает группу в черновик; если за это время другая группа заняла это время, открыть её снова нельзя |

Удалять можно только группы в статусе черновика. Группа, которая уже публиковалась, вместо этого отменяется.

| Поле | Описание |
|---|---|
| Учебный период | Учебный период семестра ([глава 10](10-terms.md)). При переносе в другой учебный период даты занятий и версия дисциплины меняются в соответствии с ним |
| Кто может записаться, Кто не может записаться | Курс, год поступления, программа, подразделение. Пример: исключение студентов собственной специальности из общеобразовательной дисциплины. Студенты второй специальности и minor также считаются студентами этой программы |
| Язык обучения | Например, `ko`, `en` |
| Размер листа ожидания | Сколько записей в лист ожидания принимается после заполнения группы. 0: без листа ожидания ([глава 20](20-registration.md)) |
| Способ оценивания | Абсолютное оценивание (по умолчанию; преподаватель вводит баллы, оценки вычисляются из них) или относительное оценивание (вводятся только оценки, действуют квоты оценок). Преподаватель запрашивает смену на экране ввода оценок, а сотрудники, ответственные за группу, утверждают её. После ввода оценок изменить нельзя ([глава 21](21-grades.md)). Копируется при копировании семестра |

## Время занятий и аудитории

На вкладке **Расписание занятий** укажите день, время начала и окончания и аудиторию. Выбор значения в поле **Пара** заполняет время. Оставьте даты занятий пустыми, чтобы использовать даты учебного периода.

- Две группы не могут занимать одну аудиторию в одно и то же время, и один преподаватель не может вести две группы одновременно. Это обеспечивает база данных; на экране показывается конфликтующая группа, например «Аудитория в это время уже занята группой OOO».
- Если даты не пересекаются, как у первой и второй половины семестра, можно использовать одно и то же время и аудиторию.
- Отменённые группы время не занимают.

## Преподаватели

На вкладке **Преподаватели** назначьте преподавателей с ролью (Преподаватель, Второй преподаватель, Ассистент). У группы их может быть несколько. Нельзя назначить преподавателя, который в то же время уже ведёт другую группу. Преподаватели ведут расписание и рабочую программу на портале в разделе **Мои дисциплины**.

## Зарезервированные места

На вкладке **Зарезервированные места** выделите места для групп студентов (например, 30 мест для студентов специальности программы). После момента **Открывается для всех** неиспользованные места может занять любой. Сумма зарезервированных мест не может превышать число мест. Они применяются при записи на дисциплины ([глава 20](20-registration.md)).

## Рабочая программа

Преподаватель составляет её на портале в разделе **Мои дисциплины** (она открывается и кнопкой **Рабочая программа** на экране группы). В неё вводятся общее описание, цели обучения, учебники и материалы, правила курса, оценивание (элементы и веса) и понедельный план; после перевода в статус **Опубликована** она видна студентам.

## Копирование из другого семестра

**Копировать из другого семестра** в списке групп позволяет начать с плана прошлого семестра (обычно того же семестра прошлого года). Сначала проверьте результат с параметром **Только предпросмотр**.

- Неотменённые группы в пределах вашей области действия копируются как черновики.
- Копируются: преподаватели, которые продолжают работать, время занятий и аудитории, зарезервированные места (время открытия сдвигается на разницу между датами начала семестров), рабочая программа (как неопубликованный черновик).
- Учебные периоды сопоставляются по коду (если его нет — весь семестр). Версия дисциплины берётся на дату начала нового учебного периода.
- Группы, номер которых уже существует в целевом семестре, пропускаются; если аудитория уже занята, группа копируется без аудитории. В уведомлении о результате перечислены пропущенные группы и группы, требующие проверки.

ИТ-операторы могут сделать то же самое командой `uv run manage.py section_copy`.

## Расписания и проверки

- **Расписания**: выберите семестр и аудиторию или преподавателя, чтобы увидеть недельное расписание.
- Проверка перед публикацией: ИТ-оператор выполняет `uv run manage.py schedule_check_conflicts <код семестра>`, чтобы найти аудитории меньше числа мест, уволившихся преподавателей, несоответствие версий дисциплин и зарезервированные места сверх числа мест ([справочник команд](../operations/commands.md#schedule_check_conflicts)).

## Область действия

Список и экраны показывают только группы тех подразделений-организаторов, которые входят в область действия разрешений `Просматривать группы` и `Планировать группы`. Для вкладок времени занятий, преподавателей и зарезервированных мест, а также кнопок статуса (Опубликовать, Вернуть в черновик, Отменить группу, Открыть снова) нужно разрешение `Планировать группы` с областью действия, охватывающей подразделение-организатор группы. Страница расписаний открывается на текущем семестре (если его нет — на следующем). На телефонах она показывает список по дням недели.
