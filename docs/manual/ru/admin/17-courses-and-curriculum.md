# 17. Дисциплины и требования к выпуску

Меню: **Учебные планы и группы > Дисциплины**, **Требования к выпуску** (разрешения `Управлять дисциплинами, версиями и реквизитами`, `Управлять требованиями к выпуску`)

## Дисциплины и версии

Дисциплина состоит из неизменного **кода** и **версий** со сроками действия. Название, кредиты, часы, категория дисциплины, способ оценивания и реквизиты относятся к версии. Прежняя система (YUSTIC) различала дисциплины по коду и дате начала, но оценки ссылались только на код дисциплины, поэтому было неясно, какую версию изучал студент. В новой системе группы и оценки ссылаются на версию.

- Сроки действия версий одной дисциплины не могут пересекаться (ограничение базы данных). На любую дату действует ровно одна версия.
- Группа открывается с версией, действующей на дату начала учебного периода.

| Поле | Описание |
|---|---|
| Код дисциплины | Например, `CSE2010`. Код не несёт бизнес-смысла (правила вроде прежней проверки банка кредитов по `009*` заменены полями ниже) |
| Ответственное подразделение | Подразделение, которое ведёт дисциплину. Подразделение, открывающее её группы, по умолчанию |
| Название, Описание | Для каждого языка |
| Кредиты, лекционные и лабораторные часы | С шагом 0,5 |
| Категория дисциплины | Справочные данные > Категории дисциплин |
| Оценивание | Дифференцированная оценка или Зачёт/незачёт |
| Учитывается в лимите кредитов | Если выключено, дисциплина не учитывается в лимите кредитов при записи (дисциплины банка кредитов и т. п.) |
| Анкетирование по дисциплине | Если выключено, по дисциплине не проводится анкетирование (практики, стажировки и т. п.; [глава 22](22-course-evaluation.md)) |
| Можно изучать повторно с получением кредитов | Повторное изучение снова приносит кредиты и не считается повторным изучением для исправления оценки (семинары с меняющейся тематикой и т. п.) |

## Новая версия дисциплины

Если меняются кредиты или название, не редактируйте версию, а создайте **новую версию**. На экране **Редактировать** дисциплины, на вкладке **Версии**, нажмите **Новая версия с даты** у текущей версии и введите дату начала новой версии, изменённые значения и причину.

- Текущая версия завершается накануне даты начала; новая версия начинается с копии текущей версии вместе с её реквизитами.
- Уже открытые группы и прошлые оценки продолжают ссылаться на прежнюю версию.
- Редактируйте версию напрямую только для исправлений, не меняющих её смысла, например опечаток (они отражаются в истории изменений данных).

## Пререквизиты и кореквизиты

Откройте версию на вкладке **Версии** (по ссылке в строке); реквизиты вводятся в разделе **Реквизиты** внизу экрана версии. Новая версия добавляется кнопкой **Добавить версию дисциплины** на экране дисциплины.

| Поле | Описание |
|---|---|
| Вид | Пререквизит (должен быть изучен заранее) или Кореквизит (изучается вместе в том же семестре; условие выполнено, если уже изучен) |
| Группа | Достаточно изучить одну дисциплину из группы (или). Должна быть выполнена каждая группа (и) |
| Минимальная оценка | Код оценки шкалы оценок по умолчанию (например, `C0`). Пусто: любая положительная оценка |
| Можно изучать в том же семестре | Если пререквизит можно изучать в том же семестре |

Пример: группа 1 содержит `CSE1001`, группа 2 — `MAT1001` и `MAT1002` → `CSE1001` и (`MAT1001` или `MAT1002`). Правило пререквизитов проверяет это при записи на дисциплины ([глава 20](20-registration.md)).

## Эквивалентные дисциплины

Если при реформе учебного плана дисциплина заменяется, введите заменяющую дисциплину и срок на вкладке **Эквивалентные дисциплины** экрана **Редактировать** дисциплины. При включённом параметре **Взаимная** каждая дисциплина засчитывается вместо другой; при выключенном только эквивалентная дисциплина засчитывается вместо этой. Используется при проверке повторного изучения ([глава 20](20-registration.md)) и проверке требований к выпуску ([глава 26](26-graduation.md)).

## Требования к выпуску

Набор требований создаётся для каждой программы, **роли программы** (основная программа, вторая специальность, minor) и диапазона **годов учебного плана**. К студенту применяется набор, соответствующий году учебного плана в его личном деле.

- Годы учебного плана одной программы и роли программы не могут пересекаться. Оставьте конечный год пустым, чтобы набор действовал до начала следующего набора.
- Виды требований

| Вид | Ввод | Пример |
|---|---|---|
| Кредиты в категории | Категория дисциплин, минимум кредитов | 9 кредитов общеобразовательных дисциплин (обязательных) |
| Обязательные дисциплины | Список дисциплин | Все 4 обязательные дисциплины специальности |
| Выбор из дисциплин | Список дисциплин, минимум кредитов или минимум дисциплин | 12 кредитов из элективных дисциплин специальности |
| Сданный экзамен | Вид экзамена | Сдан комплексный экзамен по английскому языку ([глава 24](24-assessments.md)) |

Для второй специальности и minor создаются собственные наборы, меньше, чем у основной программы (например, 36 кредитов для второй специальности, 21 — для minor). Требования проверяются при проверке требований к выпуску ([глава 26](26-graduation.md)).

## Импорт CSV

**Импорт CSV** в списке дисциплин (разрешение `Управлять дисциплинами, версиями и реквизитами`) массово загружает версии дисциплин. Одна строка — одна версия. Дисциплины находятся по коду (и создаются, если их нет); версии — по коду и дате начала, поэтому повторный импорт того же файла обновляет данные, а строка с другой датой начала становится новой редакцией. Строка, период которой пересекается с другим, не импортируется, не затрагивая остальные.

| Столбец | Описание |
|---|---|
| `code` | Код дисциплины (обязателен) |
| `org_unit` | Код ответственного подразделения. Обязателен для новых дисциплин |
| `effective_start_date`, `effective_end_date` | Период действия версии (`YYYY-MM-DD`) |
| `title_en`, `title_ko`, `title_zh-hans`, `title_lo` | Название на каждом языке. Для новых дисциплин обязательно английское |
| `credits`, `lecture_hours`, `lab_hours` | Кредиты (обязательны для новых версий, 0–30), часы (0–40) |
| `category` | Код категории дисциплин |
| `grading_basis` | `graded` или `pass_fail` |
| `counts_toward_credit_limit` | `1`/`0` |

То же самое доступно командой `uv run manage.py reference_import courses <file> --actor=<email>` ([глава 9](09-csv-import.md)).
