# 8. Binolar va auditoriyalar

Menyu: **Asosiy maʼlumotlar > Binolar**, **Auditoriyalar** (`Binolar va auditoriyalarni boshqarish` ruxsati)

## Binolar

Kodni (masalan, `SCI`), nomni (har bir til uchun) va manzilni kiriting. Auditoriyalari bor binoni oʻchirib boʻlmaydi, shuning uchun bino endi ishlatilmasa, **Faol** belgisini oʻchiring.

## Auditoriyalar

| Maydon | Tavsifi |
|---|---|
| Bino, Auditoriya raqami | Auditoriya raqamlari bino ichida takrorlanmaydi, masalan `101` |
| Nomi | Ixtiyoriy, masalan Katta majlislar zali |
| Auditoriya turi | `room_type` kodlar roʻyxatidagi qiymat (oʻquv xonasi, laboratoriya va h.k.) |
| Tashkiliy birlik | Auditoriyani boshqaruvchi kafedra (ixtiyoriy) |
| Sigʻim | Dars jadvali tuzilayotganda fan guruhi sigʻimi bilan solishtiriladi ([18-bob](18-sections-and-timetables.md)) |
| Dars jadvalida ishlatiladi | Oʻchirilganda auditoriya dars jadvali tuzishda hisobga olinmaydi (idoralar, omborlar va h.k.) |

Auditoriyalar koʻp boʻlsa, [CSV import](09-csv-import.md) dan foydalaning. Avval binolar roʻyxatga olingan boʻlishi kerak.
