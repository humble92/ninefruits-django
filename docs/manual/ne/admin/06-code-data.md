# 6. कोड डेटा, देश, भाषा

मेनु: **सन्दर्भ डेटा > कोड सूचीहरू**, **देशहरू**, **भाषाहरू** (`कोड डेटा, देश र भाषा व्यवस्थापन गर्ने` अनुमति)

## कोड डेटा

विश्वविद्यालयअनुसार फरक हुने छोटा सूचीहरू। प्रत्येक सूची (प्रकार) मा कोड मानहरू हुन्छन्।

| सूची कोड | प्रयोजन | पुरानो प्रणाली (YUSTIC) |
|---|---|---|
| `ethnicity` | जातीयता | `FNATION` |
| `admission_type` | भर्नाको प्रकार | `FADMDIST` |
| `room_type` | कोठाको प्रकार | `ROOM.FORWHAT` |

- प्रणाली सूचीहरू (माथिका तीन) एप्लिकेसनले कोडद्वारा खोज्ने भएकाले तिनका सूची कोड परिवर्तन गर्न वा मेटाउन सकिँदैन। मानहरू भने स्वतन्त्र रूपमा थप्न सकिन्छ।
- सूची खोली तलको **कोडहरू** मा मान थप्नुहोस्। कोडमा साना अक्षर, अङ्क र अन्डरस्कोर प्रयोग हुन्छ (उदाहरण: `korean`)। भाषाअनुसार नाम प्रविष्ट गर्नुहोस्; अङ्ग्रेजी नाम अनिवार्य छ।
- अब प्रयोग नहुने मानहरू नमेटाउनुहोस्; बरु **सक्रिय** बन्द गर्नुहोस्। डेटाले अझै प्रयोग गरिरहेको मान मेटाउन सकिँदैन।
- धेरै मानहरू [CSV आयात](09-csv-import.md) ले प्रविष्ट गर्नुहोस्।

## देश र भाषा

ISO मानक सूचीहरू (249 देश, करिब 180 भाषा) स्थापनाका बेला लोड हुन्छन्। स्थापित भाषाहरूका नाम स्वतः भरिन्छन्।

- स्क्रिनमा देखिने नाम परिवर्तन गर्न **सम्पादन गर्नुहोस्** मा परिवर्तन गर्नुहोस्। परिवर्तित नाम पछिका प्रणाली अद्यावधिकमा पनि कायम रहन्छ।
- छनोट सूचीबाट कुनै प्रविष्टि लुकाउन **सक्रिय** बन्द गर्नुहोस्।
