# 8. भवन र कोठा

मेनु: **सन्दर्भ डेटा > भवनहरू**, **कोठाहरू** (`भवन र कोठा व्यवस्थापन गर्ने` अनुमति)

## भवनहरू

कोड (उदाहरण: `SCI`), नाम (भाषाअनुसार) र ठेगाना प्रविष्ट गर्नुहोस्। कोठा भएको भवन मेटाउन सकिँदैन, त्यसैले अब प्रयोग नहुने भवनमा **सक्रिय** बन्द गर्नुहोस्।

## कोठाहरू

| फिल्ड | विवरण |
|---|---|
| भवन, कोठा नम्बर | कोठा नम्बर एउटै भवनभित्र अद्वितीय हुन्छ, उदाहरण: `101` |
| नाम | वैकल्पिक, उदाहरण: मुख्य सभाहल |
| कोठाको प्रकार | `room_type` कोड सूचीको मान (कक्षाकोठा, प्रयोगशाला आदि) |
| संगठन एकाइ | कोठा व्यवस्थापन गर्ने विभाग (वैकल्पिक) |
| क्षमता | समयतालिका बनाउँदा सेक्सनको क्षमतासँग तुलना गरिन्छ ([अध्याय 18](18-sections-and-timetables.md)) |
| समयतालिकामा प्रयोग हुने | बन्द हुँदा समयतालिका बनाउँदा कोठा समावेश गरिँदैन (कार्यालय, भण्डार आदि) |

धेरै कोठाका लागि [CSV आयात](09-csv-import.md) प्रयोग गर्नुहोस्। भवनहरू पहिले दर्ता गरिनुपर्छ।
