# Ninefruits (Django)

대학 학사 행정 시스템(Student Information System) [Ninefruits](https://github.com/humble92/ninefruits-laravel)의 Django 구현. 원본(Laravel 13)의 기능 전체를 Python 3.14 / Django 6.1 / PostgreSQL 18로 옮기는 중이다.

- 이식 계획: [porting/porting-plan.md](porting/porting-plan.md)
- 이식 기록과 설계 결정: [porting/](porting/README.md)
- 이전 Django 프로토타입은 `legacy-playground` 브랜치에 있다. 참고용이며 이 구현의 기반이 아니다.
